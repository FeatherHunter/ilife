① 备菜：各技能攒自己的 5 键 JSON

不管作息还是卡路里，最后都要拼成同一张单子：技能名 / 标题 / 副标题 / 联系人 / 分组，分组下是 子功能 → 场景，每个场景 5 件套：标题 / 唤醒词 / 提示词 / 可填栏 / 待开发标记。

  • 作息：老例子文件 → 生成器 → HELP_GROUPS（85 条，提示词短、可填栏英文）
  • 卡路里：436 条触发器 → 投影成同一形状（提示词自带 ____，可填栏只放命令三行）

备菜只管内容，不管长什么样。长相全归壳管。

② 验货：冻住的契约（门卫）

就在这个文件，一字不差：

C:\Users\辰辰洋洋\.dsh\profiles\web\node_modules\base-paint\dist\spec\help.js

第 50-100 行：场景必须有 id/title/wake_word/status/prompt_template，可填栏每条必须有 name/label/value，多一个键即拒收，不返空页。源码头写的是 packages/base-render/src/spec/help.ts，你机器上冻住的就是上面这个编译后的。

为什么卡路里加不了“命令”一栏？门卫不让加，只能借用现成的“可填栏”来贴命令。这就是上一页说的借槽。

③ 套壳：共用壳＋功能一次性注入

文件：base-paint/dist/helpShell.js（renderHelpShellHtml）

干三件事：① 把 5 键 JSON 转成文字塞进 <script id="help-data">；② 前面套标题＋样式，后面接功能 JS（搜索 / 切页 / 弹层表单 / 复制）；③ 小于号转义防破壳。6 家壳一模一样，换的只是那坨 JSON。

弹层公式（你填完复制到的就是它）：

复制物 = 提示词 ＋ 空行 ＋ 你填的每行「中文名：值」

卡片上的“复制”是只复提示词；弹层里填完复制的才是全量。这就是死日期打架的根子：提示词里写死一个，填的又追加一个。

④ 落盘：存文件、回地址

文件：base-paint/dist/output/saveHtml.js（各技能的 help/output.js 只是传目录＋文件名主体）

  • 独占创建，同秒撞名自动 _2/_3，不覆盖
  • 24 小时内同主体只留一份（复用窗口）
  • 回执 delivery.path 恒为绝对路径，字节对上才算成功
