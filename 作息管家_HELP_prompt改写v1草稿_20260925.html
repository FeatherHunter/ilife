作息管家 prompt 改写 v1 草稿 · 新旧对照（85 条）

第一性原理：复制出来 → 贴进全新 Agent 会话 → 能高质量走完。五段式：装载 / 目标 / 槽位 / 铁则 / 交付。对标卡路里三段＋饼干“请办两件”，我们多两条铁则：先查后写、不编造＋无记录阻断、破坏性确认。旧 prompt 原样 trích help-assets.js，新 prompt 是本版草稿，可直接复制讨论。
来源 HELP：作息管家_HELP_20260925_002745.html · 待开发 11 条照样改了，方便你决定下架还是留着。

v1 规范（冻住讨论）

  1. 装载：第一句必须是“请你加载技能 作息管家，执行唤醒词「xxx」”。新会话靠它路由，不许省略。
  2. 目标：一句话用户话，不许出现 唤醒词:/HTML/vs/id/title/completion/upsert/diff/start-end/T4/T5/三档/建三表/软删/反向对账。
  3. 槽位：已知写出来，待填用 ____，带格式和缺省（今天/昨天/周一起始/YYYY-MM-DD/HH:MM）。
  4. 铁则：缺参追问不编；改删先列候选让我认准；分类走白名单二级；0 条直说无记录；24h 计划必须 00:00-24:00 接满，预览确认再落库。
  5. 交付：落盘 HTML 并回绝对路径，文字只概括结论 ≤三句话。
