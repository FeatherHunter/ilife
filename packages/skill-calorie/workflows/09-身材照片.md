## 常驻规则 D2–D7（照做，不重新讨论）

- D2 发图与路径双模式＋文字与图片分离到达：可直接发照片（手机／飞书），也可给照片文件路径（电脑）；文字先到等图片，图片先到追问上下文；同轮所有图片＝本次要存的照片。
- D3 标签必填、缺则逐张追问（批量时每张可单独指定标签，没指定的用默认标签）。
- D4 多标签模型：逗号分隔、单个 ≤20 字、单张 ≤10 个；改＝覆盖整套（`op=set`）／加＝追加判重（`op=add`，已存在即提示）／删＝移除且至少保留 1 个（`op=remove`，删空报错，想清空用改）。
- D6 删的候选与快照：删身材照走「先列候选→快照确认→回执」三步；候选与快照页只做选中与复制，不含删除动作（删除走写命令；硬删除、不可恢复）。
- D7 跑完必须主动把 HTML 交给用户，不只给路径（思想保留，机制按本环境＝把文件交给用户）。
- D5（GIF 规划坐标，供场景 6 用）：裁剪 JSON `{id:[x1,y1,x2,y2]}`，像素左上原点；缺项时 prompt 为指到步骤的占位句。

## 逐词工作流（每条从哪一步往下走）

### 1 存一张照片

- 用户说「记身材照」，要存一张。先问标签（D3：缺则追问）与来源（发图或路径，D2）。
- 跑 `calorie-cmd-read calorie.photo.add --params '{"srcPaths":["<照片路径>"],"tag":"正面"}'`。
- 回执页核对 id 卡＋明细＋间隔行；跑完把 HTML 交给用户（D7）。

### 2 存照片（含备注）

- 同场景 1，另问备注（如当时状态／饮食阶段），随 `--note` 入库。
- 跑同一条 `calorie.photo.add`；回执多一行备注；跑完把 HTML 交给用户（D7）。

### 3 批量存照片

- 用户连发多张或给多个路径即批量（D2：同轮所有图片＝本次要存的照片）。
- 每张可单独指定标签，没指定的用默认标签（D3 逐张追问）。
- 跑 `calorie.photo.add`（多 `srcPaths`）；回执看 `items[]` 逐张状态；跑完把 HTML 交给用户（D7）。
- 预检确认页可用 `calorie-cmd-read calorie.view.photo-log-wizard`（看身材照向导：四段表单＋prompt 生成，缺项为指步骤占位句）。

### 4 看身材照

- 用户说「查身材照」，想浏览。时间可用天数／日期／范围，没填默认最近 90 天；标签选填。
- 跑 `calorie-cmd-read calorie.photo.list --params '{"tag":"正面"}'` 看画廊（筛选＋体积横幅＋网格三态）。
- 单张大图跑 `calorie-cmd-read calorie.photo.detail --params '{"id":1}'`（查身材照详情：黑底 75vh contain，上一张／下一张首尾禁用，删改链走回执流程）。
- 看身材照HELP跑 `calorie-cmd-read calorie.help.center --params '{"q":"记身材照"}'`（结果型；`q` 与 `mode` 互斥）。

### 5 对比两张照片

- 用户说「对比两张照片」。可说日期（如月初 vs 月底）、编号，或从最近照片里选（选不出来先跑选身材照候选）。
- 跑 `calorie-cmd-read calorie.photo.compare --params '{"id1":1,"id2":2}'`；读间隔 N 天横幅＋跨标签警告行；跑完把 HTML 交给用户（D7）。

### 6 生成身材照GIF

- 用户说「生成身材照GIF」。先确认照片范围（标签／时间），前置跑 `calorie-cmd-read calorie.view.gif-planner --params '{"tag":"正面"}'`（看GIF规划器：候选表＋裁剪 JSON＋prompt 生成）。
- 再跑 `calorie-cmd-read calorie.photo.gif --params '{"tag":"正面"}'` 出 GIF 结果页（过大降级给本地路径，缺值 `—`）；跑完把 HTML 交给用户（D7）。

### 7 删身材照

- 用户说「删身材照」（删除后无法恢复）。若没说清哪张，先跑 `calorie-cmd-read calorie.view.photo-picker`（选身材照：列候选缩略图＋日期＋标签→选中看快照→复制 prompt）。
- 快照只读，不含删除动作；核对无误后跑 `calorie-cmd-read calorie.photo.remove --params '{"id":1}'`。
- 回执为删除态徽章＋删前快照；跑完把 HTML 交给用户（D7）。

### 8 改照片标签

- 用户说「改照片标签」：整套覆盖（可多个）。先跑 `calorie-cmd-read calorie.view.photo-picker --params '{"id":1}'` 确认该照片原来的完整标签列表与快照。
- 再跑 `calorie-cmd-read calorie.photo.tag --params '{"id":1,"op":"set","tag":"晨起"}'`；对照行读改前改后；跑完把 HTML 交给用户（D7）。

### 9 加照片标签

- 用户说「加照片标签」：追加不覆盖（可多个）。先跑选身材照看快照。
- 再跑 `calorie-cmd-read calorie.photo.tag --params '{"id":1,"op":"add","tag":"晨起"}'`；已存在即提示判重；对照行读加前加后；跑完把 HTML 交给用户（D7）。

### 10 删照片标签

- 用户说「删照片标签」：移除（可多个），其余保留。先跑选身材照告诉用户当前有哪些标签。
- 再跑 `calorie-cmd-read calorie.photo.tag --params '{"id":1,"op":"remove","tag":"晨起"}'`；每张至少保留 1 个，删空报错，想清空用改照片标签；对照行读删除前删除后；跑完把 HTML 交给用户（D7）。

## 过程型页入口一览（写前先出页）

- 看身材照向导：`calorie-cmd-read calorie.view.photo-log-wizard`（记身材照纯配置；缺项指步骤占位）。
- 看GIF规划器：`calorie-cmd-read calorie.view.gif-planner --params '{"tag":"正面"}'`（查身材照／生成身材照GIF；框选＋4 数字裁剪）。
- 选身材照：`calorie-cmd-read calorie.view.photo-picker`（删身材照与标签三条的候选快照；代表唤醒词「选身材照」，#283 冻结键名；无 id 时为指步骤占位，复制的即写命令照抄即跑形状）。
