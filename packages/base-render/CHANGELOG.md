## 0.3.3

### Patch Changes

- 修复 HELP 页面复制提示落不到视口底部（#693）：提示栈的定位样式按类名 `.hm-toast-stack` 下发，
  而运行时创建栈元素时只写了 `id`——选择器与元素对不上，定位从未生效；提示因此排在文档末尾，
  短页看不见、长页滚到底被固定底栏压住只露一点黑边。修法是给栈元素补上该定位类名（`id` 保留做兼容）。
  同源的减动效归零条 `.hm-toast-stack .hm-toast{transition:none}` 也随之按设计生效。
