# stacked-bar · 构成条

**一句话**：一整块按占比切成几段（**形态 A**＝100% 堆叠 ＋ 图例）——段宽 ＝ 占比，够宽的段里直接写读数，窄段让位图例，**图例必带数值**。

## 何时用它（选型四条）

| 你要的 | 用 |
|---|---|
| 「这一整块怎么分的」——各段共享一根轴、看谁占大头 | **本件** |
| 「各项各多少」——逐项一根独立条 | `renderDistributionRows`（区块层） |
| 「到了目标的几成」——一个数对一个目标 | `scale-bar`（刻度条，同族） |
| 二维的深浅（行 × 列） | `heat-grid`（热力格，同族） |

用在哪：记账（消费结构）／卡路里（营养结构）／作息管家（24h 构成）。

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `title` | `string` | 必填 | 卡头标题（`3 月消费结构`） |
| `stamp` | `string` | — | 卡头右端那句（`合计 ¥7 000`）；不给＝不出 |
| `segments` | `{name,value}[]` | 必填 | 各分段：**1–6 段**，逐段 `value` 必须是**正**有限数 |
| `unit` | `string` | — | 数量单位（`元`／`克`／`条`）：只上屏，不参与占比口径 |
| `note` | `string` | — | 脚注一句人话（这张图读出来的结论）；不给＝不出 |
| `form` | `'stack'` | `'stack'` | 形态闭集（本件只落地形态 A）；闭集外报 `BlocksError` |
| `extraClass` | `string` | — | 附加类名（空格分隔，逐个过类名正则） |

**占比不由调用方给**：本件按各段之和算，段宽、段内读数、图例百分数、无障碍名都从同一个比例出。

**分段（`segments` 的每一个元素）**

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `name` | `string` | 必填 | 分段的名字（图例里那一列，可换行） |
| `value` | `number` | 必填 | 分段的量（与同批其它段同单位），**必须 > 0** |

## 契约与不变量

- **段宽之和恰好 100%**：段宽走千分比整数（`flex: 380 1 0`），**末段吃下舍入余数** ⇒ 条永远填满整宽，
  也永远不会把根撑出横向滚动。
- **色不是唯一信息**（三条通路同时在）：段内文字（顺序 ＋ 名字 ＋ 读数）／图例（名字 ＋ 百分数 ＋ 数量）／
  段与段的排列顺序；`aria-label` 另给读屏一句逐段读数。
- **段内读数的两档阈值**（渲染期定，判据钉住）：占比 ≥ `STACKED_BAR_NAME_MIN_PCT`（20%）连名字一起写；
  ≥ `STACKED_BAR_VALUE_MIN_PCT`（12%）只写百分数；更窄的段一个字都不写，**数字退回图例**。
  窄容器（`@container ≤ 420px`）再退一档：「只写百分数」那批段的段内字让位图例——**不压字、不用 `…`**。
- **数据色全部算出来**：`is-k1`…`is-k6` 由 `color-mix()` 从 `accent` 往主文字（深端）／往卡面（浅端）混，
  源码里**没有色值**；强调色变黑时自动退化成灰阶（浅端仍与卡面分得开）。深端两档的段内字用
  `accent-ink`，浅端四档用主文字色。
- **名字可换行、数字永不截断**：图例四列是 `色块 ｜ minmax(0,1fr) ｜ 3.4em ｜ minmax(4.6em,auto)`，
  两列数字右对齐且 `white-space:nowrap` ⇒ 挤的时候是名字换行。
- 宽度只由 `@container` 判（阈 420px），**不写任何 `@media` 宽度查询**（视口宽 ≠ 组件宽）。

## 常见错法

- **色块没图例**（颜色就是全部信息）⇒ 色盲读者拿不到任何数；
- **超过 6 段**：数据色档只有 6 档，再多必然重色 —— 尾巴请调用方并成「其他」（本件不替你聚合）；
- **拿本件当"逐项对比"**：构成条看的是"一整块怎么分"，各项各多少走 `renderDistributionRows`；
- **把百分比写死在段里**：段宽与百分数必须同出一份真值，写死必然对不上（本件不认 `pct` 入参）。

## 关系

- 与 `summary-head` 配对：头给总量，本件给"总量怎么分的"；
- 与 `progress-ring`／`heat-grid` 同族（形状与比例）：**一块怎么分**用本件，**离目标多远**用 `progress-ring`，
  **哪一格更忙**用 `heat-grid`。
