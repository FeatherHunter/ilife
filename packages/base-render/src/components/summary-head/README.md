# summary-head · 主数字头

**一句话**：一页只该有一个"主要读数"——eyebrow（「当日摄入」）＋ 主数字（`860` ＋ 单位）＋ 分母（`/ 1850 卡`）＋ 脚行（左：一句人话；右：一枚**印章**）。

## 何时用它（选型三条）

| 你要的 | 用 |
|---|---|
| 一页的**唯一主要读数**（跟目标比的那一个数） | **本件** |
| 并列的几组读数（今日／本周／本月各一行） | `renderKpiGrid`（区块层） |
| 只陈述事实、不带主次（窗口／条数／来源） | `renderFactStrip`（页面级形状件） |

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `value` | `string` | 必填 | 主读数（**已是给人看的样子**：取整与单位口径由调用方定） |
| `eyebrow` | `string` | — | 这一行数字说的是什么（人话短标签） |
| `unit` | `string` | — | 主读数的单位（`卡`／`ml`／`kg`），小一号跟在同一行 |
| `denominator` | `string` | — | 分母／标尺（`/ 1850 卡`） |
| `note` | `string` | — | 脚行左侧那句人话（「已吃目标的 46%」） |
| `stamp` | `{ text: string; tone?: 'ok' \| 'warn' \| 'danger' }` | — | 脚行右侧那枚印章（一页至多一枚） |
| `size` | `'m' \| 'l' \| 'xl'` | `'l'` | 40／56／92px（三档读数见 `SUMMARY_HEAD_VALUE_PX`） |
| `face` | `'sans' \| 'serif'` | `'sans'` | `serif` 档把数字当"标题"排（衬线回退链含宋体） |
| `extraClass` | `string` | — | 附加类名 |

## 契约与不变量

- **三档字号只改字号与字距**，盒模型与槽位不动 ⇒ 同一页换档不重排；数字一律 `tabular-nums`（换值不跳位）。
- **印章与态徽标分形**：印章是描边 ＋ 微斜（`rotate(-1.2deg)`）＋ 一页至多一枚；`renderStatusBadge` 是实心胶囊。两者不许撞形。
- `xl` 档把单位与分母同档放大（原型：`/ 1850 卡` 是 26px）；窄屏（≤640px）降到 64px 以免溢出。
- 样式 scope 在 `.ilife-page-ui` 下；本件零 DOM、零内联脚本。

## 常见错法

- 同一个数在首屏说两到三遍（结论句一遍、KPI 卡一遍、事实条再一遍）；
- 主数字与目标并排却**同级同字号** ⇒ 分不出哪个是读数、哪个是标尺；
- 把「还剩 990 卡」这类一句话塞进 KPI 卡的值位（与「目标」那一卡同形）；
- 一页里放两枚印章（印章一多就不再是"要注意的那一处"）。

## 关系

- 常与 `scale-bar`（刻度条）配对：**头给数、条给形**，同一份 `value／goal`。
- 样式随 `sheetCss()` 一起挂；单独用时可只挂 `summaryHeadCss()`。
