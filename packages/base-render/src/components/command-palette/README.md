# command-palette · 命令面板

**一句话**：一页顶部一枚**看得见的**入口键（`找页面 / 动作`），点开是一块面板——搜一行 ＋「动作（在当前技能里直接做）」一组 ＋「页面（跳到别的技能）」一组，**每一行整行可点**，行右那一格写着这一行要干什么（执行／打开）。

它替掉的错法：功能藏在三级菜单里只能一层层点进去找；入口做成**隐式**（按某个键才出现，手机上等于不存在）；把「能去哪儿、能做什么」摊成一长条不分组的清单（读到第三行还不知道这一条是就地做还是跳走）。

**形态**：本件只落地**形态 A「单栏分组结果（动作在前／页面在后）」**——出处＝原型墙 `.scratch/ui-组件墙/新件/parts-交互与流程.mjs` 第 81 件（2026-09 用户三个形态逐格打分，A 档 4/4/4），按层规重写（原型是一次性代码：无判据、无错误处理、读的是墙稿变量）。形态键住 `COMMAND_PALETTE_FORMS` 闭集（今天只有 `A` 一格）——**加第二形态是在闭集里加一格，不是新开一件**；闭集外的值一律报 `BlocksError`。

## 何时用它（选型四条）

| 你要的 | 用 |
|---|---|
| 跨技能找「哪一页、哪个动作」，一次输入里**既给当前技能的动作、也给别的技能的页面** | **本件** |
| **本页内**的搜索框：作用域是当前那一列，结果就摆在页面里 | `search-field`（形态 B） |
| 贴着某一颗按钮弹出「这一颗键能做的事」 | `popover-menu` |
| 装一件事的细节或确认（一条正文 ＋ 两条动作） | `dialog` |

用在哪：六个技能通用。记账的「记一笔」、卡路里的「记一餐」、作息的「补一条」这类高频动作最吃它——它们平时都埋在页面的第三个层级里。

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `id` | `string` | 必填 | 面板 `id`（同页唯一）。**只许标识符字符**（字母、数字、下划线、连字符）：它还要当入口键的 `popovertarget` 用 |
| `items` | `CommandPaletteItem[]` | 必填 | 面板条目的**全部行**（至少一项）。分组由每一行的 `kind` 决定，**不按数组顺序**：动作组在前、页面组在后（下表） |
| `entry` | `string` | `找页面 / 动作` | 入口键上的字 |
| `hint` | `string` | 一句现成的提示 | 入口键旁那行提示（解释「入口就是这一枚」）。空串＝未给＝用缺省那一句 |
| `label` | `string` | ＝`entry` | 面板的无障碍名（屏读器念的那一句） |
| `query` | `string` | — | 打开时的初值：渲染期就按它筛一遍（不给＝空，**列的是常用去处**） |
| `error` | `string` | — | 面板的错态：写在输入框下边那一行，并由输入框的 `aria-describedby` 指到它 |
| `loading` | `boolean` | `false` | 载入档：脚注原地换成「正在找…」，行与宽度都不动 |
| `form` | `'A'` | `'A'` | 形态键（闭集；闭集外一律 `BlocksError`） |
| `extraClass` | `string` | — | 附加类名（空格分隔，逐个过类名正则） |

**行（`items` 的每一个元素）**

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `id` | `string` | 必填 | 这一行的机器值（点它时原样送出）。**只许标识符字符**，面板内唯一 |
| `kind` | `'action' \| 'page'` | 必填 | `action`＝在当前技能里就地做；`page`＝跳到别的技能。**这一位决定它在哪一组** |
| `label` | `string` | 必填 | 主文字（`记体重`）。**非空**；命中词在这里被标出来；长了**换行**，绝不 `…` 截断 |
| `note` | `string` | — | 副文字，一行一句人话（`上次 68.4 kg（09-24）`） |
| `skill` | `string` | — | 来源技能（行左那枚片，`卡路里`）；不给＝不出这枚片 |
| `go` | `string` | 动作＝`执行`／页面＝`打开` | 行右那一格的字 |
| `primary` | `boolean` | `false` | 把行右那一格抬到强调档——**意思是「这一行最像你要的」，不是「你选中了它」** |
| `keywords` | `string` | — | 搜得着但不上屏的别名（拼音、旧叫法） |
| `disabled` | `boolean` | `false` | 停用档：这一行现在点不动（**必须同时给 `why`**） |
| `why` | `string` | — | 停用的原因，写在行的副文字那一位（`不可用：这周已经记过了`） |

## 契约与不变量（判据逐条断）

1. **开与关不靠脚本**：入口键带 `popovertarget`、面板是原生 `popover`（`popover="auto"`）、关掉键带 `popovertargetaction="hide"` ⇒ 运行时段一行都没跑到，面板照样开、照样关；**点面板外那一下**也是浏览器给的 light dismiss。`Esc` 是浏览器白送的**额外**一路，界面上从不提它。
2. **整行就是那颗按钮**：一行 ＝ 一枚 `<button>`（面板里唯一的一颗），行右那格「执行／打开」是它的写法（`<button>` 里再套 `<button>` 是无效标记）。命中盒＝整行（≥48 高、通栏），相邻两行之间留 8px 缝；入口键与关掉键都 ≥44×44。
3. **零键帽**：标记与文案里没有 ⌘K／方向键／`Esc`／`Tab` 这一路，也**没有把它们当通路**——每一行都点得到，`:focus-visible` 只是给真实键盘用户的无障碍地板。
4. **输入即筛只改 `hidden`**：`data-ilife-command-palette-search` 是这一行的可搜底串（主文字 ＋ 副文字 ＋ 来源技能 ＋ 别名，小写），运行时段只翻每一行自己的 `hidden`，**不重排 DOM**（重排会把输入法打断）；一组的行全不露时，那一组的标题也收起来。
5. **脚注与空态是真读数**：脚注按「空输入／命中几条／一条没中／正在找」四档现算，空态那句把用户打的词夹在中间（`data-ilife-command-palette-query` 的 `hits` 也按同一个数派发）。**空输入时列的是常用去处**，不是「等您按某个键」。
6. **命中词不只靠颜色**：`<mark data-ilife-command-palette-hit>` 的形是下划线、字是加粗；重画走 `createElement('text')`／`mark` ＋ `textContent`，**不碰 `innerHTML`**（用户打的词永远进不了标签）。
7. **样式只经 `skinVar()` 读皮肤**：源码里不写 `var(--ilife-…)`；不写 `:root`／`!important`；不新增 token 名；全部规则 scope 在 `.<prefix>page-ui` 之下。浮面走「硬边 ＋ 零模糊外圈」（不拿 `shadow` 表达浮起来——`paper`／`broadsheet` 两套皮肤里投影本就是 `none`）。
8. **宽度只许容器判**：面板自己声明 `container: ilife-command-palette-panel / inline-size`，行内折行按**面板自己的宽度**走 `@container`；媒体查询只判设备能力（`(hover: hover) and (pointer: fine)` 的悬停增强、`prefers-reduced-motion` 的减动效），**一条视口宽度查询都没有**。窄档（面板 <560px）：来源技能片独占一行，主文字与行右那格并到下一行。
9. **焦点只在真有指针的机器上抢**：桌面打开时把焦点放进输入框（打字就筛）；手机上不抢——一抢就弹软键盘，把列表压掉一半。样式段与运行时段读**同一个**能力查询串（`COMMAND_PALETTE_HOVER_QUERY`）。
10. **停用说得清为什么**：`disabled` 那一行点不动（`cursor: not-allowed`），原因写在行的副文字那一位，行右那格写「不可用」。
11. **加法式**：不挂本件事的页面零命中、逐字节不变；本件只读自己的类名（`ilife-block-command-palette-*`），不碰公共选择器。
12. **用词纪律**：上屏的字里不出现 `·`／`；`／三段并列顿号（仓库分隔符门对可见文本零豁免）；缺什么就写清楚，不写键帽。

## 常见错法

- **把入口做成隐式**（「按某个键出面板」「点页面空白处双击」）——手机上等于没有这个功能；入口必须是页头一枚看得见的按钮；
- **面板里每一行只有主文字**——读者分不出「就地做」还是「跳走」；两组必须分开，且组标题带一句说明；
- **行右那颗按钮真的写成第二颗 `<button>`**——嵌在整行按钮里是无效标记，屏幕阅读器会念两遍；
- **拿 `hidden` 之外的招数筛行**（`display:none` 内联、重建列表）——前者与样式打架、后者打断输入法；
- **把命中词画成一块色**（只靠底色）——色不是唯一信息，形（下划线）与字重（加粗）至少再给一样；
- **`query` 给了却不筛**——渲染期那一次筛与运行时段那一次筛必须同口径（都按可搜底串子串匹配，大小写不敏感）；
- **拿它当本页搜索框**（作用域只有当前这一列）——那是 `search-field`；**拿它当菜单**（贴着某一颗键、只列那一颗键的事）——那是 `popover-menu`；
- **一页放两块命令面板**：`id` 与入口的对应关系是逐实例的，两块会让读者不知道点哪枚键开哪一块。

## 接线（页面侧）

```html
<!-- 样式段与标记：commandPaletteCss() ＋ renderCommandPalette(input)；外层挂 .ilife-page-ui 与皮肤类 -->
<script>/* buildCommandPaletteJs() 产出的那段文本 */</script>
<script>
  document.addEventListener('ilife:command-palette-run', (e) => {
    const { id, value, kind, label } = e.detail;   // 面板已收起、焦点已回到入口键
    if (id !== 'cmdk-main') return;
    if (value === 'log-weight') openWeightSheet();  // 动作＝就地做
    else if (value === 'page-sleep') gotoSleep();   // 页面＝跳走
  });
  document.addEventListener('ilife:command-palette-query', (e) => {
    const { query, hits } = e.detail;               // 要接服务端搜就在这里取
  });
</script>
```

**有意偏离原型的地方**（都在回执里写过，理由留在这儿）：

| 原型里是 | 落地是 | 为什么 |
|---|---|---|
| 行间一条 1px 发丝线 | 行间 8px 缝 | 相邻触控目标间距 ≥8px（工艺书地板）；结构（单栏分组、动作在前）一个字没动 |
| 第一行带 `.on`（选中态） | 没有常驻选中；按压那一档用同一套语汇（次要面底 ＋ 左侧主色标） | 触屏上没有「光标」这回事；常驻高亮会被读成「已经选好了」。`:focus-visible` 另给真实键盘用户 |
| 面板画在页面里（假底页 ＋ 遮罩） | 面板住**顶层**（原生 `popover`） | 开合／点外面关掉／关掉键都不用脚本，焦点锁与遮罩由浏览器给；代价写在下面那条 |
| 行右那颗「执行／打开」是真 `<button>` | 是整行那颗按钮的写法（`<span>`） | `<button>` 里套 `<button>` 是无效标记；整行本来就是命中区 |
| 脚注固定一句「点 ✕ 或面板外关掉」 | 脚注四档真读数（常用去处／命中几条／换个词／正在找） | 用户原话：空输入时该给「常用去处」；状态句比说明书更有用，关掉那两枚入口在界面上看得见 |

**一处口径要说清**：面板住顶层 ⇒ 它的**可用宽度来自视口**（`min(640px, calc(100% - 28px))`），不是宿主容器的宽度；所以「两档几何」的读数按**视口宽 390／1280** 量（先例 `popover-menu`／`dialog`），而面板**内部**的折行仍一律按面板自己的容器判（`@container`，不是视口媒体查询）。
