# section-head · 小节头

**一句话**：一段内容的开头一行 —— 序号 ＋ 小节标题（`<h4>`）＋ 计数（`6 步`／`11 味`）＋ 展开指示，正文原生开合。

**形态**：本件只落地**形态 C「可折叠小节（原生 `details`，零脚本）」**——出处＝原型墙 `.scratch/ui-组件墙/parts-01-纸面与页头.mjs` 的 `.c-section-head.fd`（2026-09 用户裁定落地的那一形态），按层规重写（原型是一次性代码：无判据、无错误处理、读的是墙稿变量）。
形态键住 `SECTION_HEAD_FORMS` 闭集（今天只有 `fd` 一格）——**加第二形态是在闭集里加一格，不是新开一件**（形态是骨架，不是地址）。

## 何时用它（选型三条）

| 你要的 | 用 |
|---|---|
| 一段内容的**开头一行**（小节标题 ＋ 计数 ＋ 开合） | **本件** |
| 一页最上面那段（眉标 ＋ `<h1>` ＋ 主读数） | `page-head`（页头） |
| 一页里**唯一的**主要读数单独成块 | `summary-head`（主数字头） |

**没有正文的不走本件**：`body` 必填（空小节给 `''`）。只想要一条标题行、不留正文位的，是标题排版、不是小节。

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `title` | `string` | 必填 | 小节标题（`<h4>`）。**非空**；长了换行，不许 `…` |
| `body` | `string` | 必填 | 正文（**已渲染好的标记**，受信透传、不转义；空小节给 `''`） |
| `seq` | `number` | — | 序号（`1`–`999` 的整数）：多小节文档里的一、二、三。不给＝不出这一槽 |
| `count` | `string` | — | 计数（`6 步`／`11 味`／`3 件`）。恒不换行，窄档只换行、不掉字 |
| `open` | `boolean` | `false` | 起始展开（一页里展开多节＝读者先要滚动） |
| `form` | `'fd'` | `'fd'` | 形态键（闭集；闭集外一律 `badInput`）。形态类走槽位表里的 `form-fd`（`ilife-block-section-head-form-fd`），**不是**自造的 `is-*` 短类名——件自己挂上元素的类名一律从 `attrs.ts` 的槽位表拼 |
| `id` | `string` | — | 锚点 id（页内导航指到这一节用）。**不以数字打头**，无空白与引号 |
| `extraClass` | `string` | — | 附加类名（空格分隔，逐个过类名正则） |

## 契约与不变量（判据逐条断）

1. **零脚本**：开合走 `<details>` 原生行为；标记里没有 `<script>`、没有 `on*=` 内联事件处理器；「展开／收起」两枚字与箭头由样式的 `::before`／`::after` 出（按 `[open]` 换字、按 `[open]` 旋转箭头）⇒ **换字不跳版**。
2. **计数与关键语义不截断**：计数恒 `flex:none` ＋ `white-space:nowrap`（只换行、不掉字）；标题恒 `overflow-wrap:anywhere`（**永不 `…` 截断**）。
3. **命中盒地板**：标题行（`<summary>`）`min-height` ＝ `SECTION_HEAD_SUM_MIN_PX`（44px）——视觉上是"一行标题"，可点的是整行。
4. **窄宽两档**：容器宽 390 与 1280 下**零横向溢出**（`scrollWidth ≤ clientWidth`）；窄档（<420px）计数与展开指示整行掉到第二行，标题占满整行（不被挤成一列孤字）。
5. **三套皮肤下标记逐字节相同**：皮肤只换样式段（取值表），标记一个字节不动。
6. **零 DOM**：模块代码剥掉字面量后不出现 `document.`／`window.`／`navigator.`。
7. **样式只经 `skinVar()` 读皮肤**：组件里不出现手写的 `var(--ilife-…)`；不写 `:root`／`!important`；不定义新 token 名；全部规则 scope 在 `.<prefix>page-ui` 之下。
8. **响应式一律容器驱动**：本件设 `container-type: inline-size`（它自己就是容器）；折行靠内在尺寸 ＋ `flex-wrap`，窄档调整走 `@container`；`@media` 只判设备能力（`hover:hover and pointer:fine`、`prefers-reduced-motion:reduce`），**不判宽度**。
9. **无障碍地板**：`<summary>` 是原生可聚焦元素（键盘开合可用），`:focus-visible` 给 2px 可见焦点（**不 `outline:none`**）；序号是呈现位（`aria-hidden`，读屏从标题就知道这一节是什么）；展开指示的文本是**呈现事实**（住样式，不住标记），开合态由 `<details>` 原生报给读屏。
10. **折叠时正文真的不可见**：正文槽那条 `display:grid` 会顶掉 UA 给闭合内容的 `content-visibility:hidden`（实测折叠后正文仍占 26px 高）⇒ 样式段里另有一条 `:not([open]) > 正文槽 { display:none }` 按闭合态显式收口（`>` 限直系，不碰调用方塞进来的东西）。

## 常见错法

- 标题长了就用 `…` 截断（关键信息不许截；要短就调用方自己短）；
- 计数跟着标题一起被压没（计数是"这一节有多少条"的唯一落点，掉了就没人知道是 11 味还是 1 味）；
- 为了折叠引入一行脚本（原生 `<details>` 就够；多一行脚本 = 多一处要与页面运行时对齐的状态）；
- 把 `.c-section-head` 的其余三形态（计数徽标挂右上／标题＋副语＋动作／色块＋口径）当成本件的一个参数（形态是骨架：那三档是另一次裁定，不是本件的一个开关）；
- 在 `body` 里塞未转义的用户串（`body` 是**受信透传**位：用户串走各自的文本字段）；
- 把序号写进标题文案（`title: '1. 步骤'`）——序号住 `seq`，这样窄档换行与读屏都还能各管各的。

## 关系

- 与 `page-head` 的分工：`page-head` 是**页的开头那段**（带眉标与 `<h1>`），本件是**页中每一段的开头一行**（`<h4>`）。同一页里 `page-head` 至多一个，本件可以有很多个（这正是 `seq` 存在的原因）。
- `body` 里通常放别的组件产出的区块标记（`entry-rows`／`ledger-rows`／`key-value-list`…）——本件只给它们一层可折叠的壳，不替它们排版。
- 样式由页面按需挂 `sectionHeadCss()`（加法式：不调它、不挂 `.ilife-page-ui` 的页零命中）。
- 本件暂不提供族汇总入口（同族第二件落地后，由先成立的那件立汇总，照 `sheetCss()` 先例）。
