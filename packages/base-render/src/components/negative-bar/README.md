# negative-bar · 负值条

**一句话**：负值那一行的落点 —— **虚线空框 ＋ 数值原文 ＋ 一句注**（1017-M5 落定，不画实条）。

**为什么没条**：条的长度语义是“越多越长”，负值套它会读成“欠得越多条越长”。
故框是空的（`dashed` 描边、底透明），数照常印，注说清口径。

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `value` | `string` | 必填 | 负值原文（调用侧算好再传，如“−1123”；本件不做数值运算） |
| `label` | `string` | 必填 | 行名（如账户名） |
| `pctText` | `string` | 可选 | 占比文案（只作字印，不定条长） |
| `mode` | `hollow` | `hollow` | 形态键（闭集；只落地虚线空框） |
| `tone` | `neutral \| danger` | `danger` | 语气（只改描边与数字色） |
| `note` | `string` | `负值不画实条，只留数` | 注（为什么没条） |
| `extraClass` | `string` | 可选 | 附加类名（空格分隔） |

<!-- 示例入参：皮肤矩阵判据拿它渲染本件，必须能直接渲染成功 -->

```json 示例入参
{ "value": "−1123", "label": "某账户", "pctText": "−12.3%", "tone": "danger" }
```

## 样式

`negativeBarCss()`：空框虚线描边 ＋ 透明底 ＋ 数字等宽 ＋ 注弱文字。
颜色只经皮肤 token 读，不手写色值。

## 无运行时

本件不接事件（`runtime.ts` 不存在）；负值行点不动，读数都在标记里。
