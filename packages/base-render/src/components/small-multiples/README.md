# small-multiples · 小倍数面板

**一句话**：同一个读数的若干**期间并排**成一根一根迷你柱（共用一套归一化刻度，横着比相对高低），
一条虚线给出这几期的均值，每根柱下面写着那一期的**绝对读数**。

**形态**：本件只落地**原型墙 no.68 的 C 档「期间并排迷你柱阵 ＋ 均值线」**
（出处＝`.scratch/ui-组件墙/新件/parts-数据与仪表.mjs`；2026-09 用户在墙上给这一格打 4 分，
A 档「每格一张面积 sparkline」与 B 档「对齐基线的多条 sparkline」没全过，故不落）。
形态键住 `SMALL_MULTIPLES_FORMS` 闭集（今天只有 `columns` 一格；`C` 是原型墙那一格的格号，不是接口名）
——日后 A／B 两档复看过了线，是在闭集里加一格，不是新开一件（形态是骨架，不是地址）。

它替掉的两种错法：**把 N 段拼成一张多线图**（线全缠在一起，谁是谁看不出来）与
**只给最后一期**（看不出这一段在涨还是在跌）。

## 何时用它（选型四条）

| 你要的 | 用 |
|---|---|
| 「同一个读数，这几期一期一根柱，横着比高低」 | **本件** |
| 「同一类东西各占多少」（一整块怎么分，没有期间轴） | `stacked-bar`（构成条） |
| 「一期之内的名次」（谁第一谁第二） | `rank-list`（榜单） |
| 「两个纬度切成格子的浓淡」（格内没有形状、读不出数） | `heat-grid`（热力格） |

用在哪：六个技能都用（同一个读数在多个期间并排）——卡路里（日均摄入逐周）／作息管家（睡眠时长逐周）／
记账（每周支出）／居家管家（每月消耗）。**任意期间轴**：哪几周、哪几段由调用方给，
本件不认「周」也不认「月」（只认 `label` 与 `value`）。

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `title` | `string` | 必填 | 卡头标题（`日均摄入 · 六周并排`）。**非空** |
| `periods` | `SmallMultiplesPeriod[]` | 必填 | 期间与读数（**2–8 期**，顺序就是横轴上的顺序） |
| `unit` | `string` | — | 读数单位（`卡`／`小时`）：写在均值那枚标注与无障碍名里。**建议写中文** |
| `stamp` | `string` | — | 卡头那枚期间范围（`W35 – W40`）；不给＝不出 |
| `form` | `'columns'` | `'columns'` | 形态闭集；闭集外报 `BlocksError` |
| `note` | `string` | 本件算出来的口径句 | 脚注一句人话；**给了就整句替换**那句口径 |
| `extraClass` | `string` | — | 附加类名（空格分隔，逐个过类名正则） |

**期间（`periods` 的每一个元素）**

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `label` | `string` | 必填 | 期间名（`第 35 周`／`W35`）：上屏在横轴，**永不 `…` 截断**（长了换行） |
| `value` | `number` | 必填 | 这一期的读数（**有限数**：`NaN`／`Infinity`／数字串一律拒） |
| `now` | `boolean` | — | 是不是「本期」那一列；**最多标一期**（标两期当场报错） |

可选的文本字段（`unit`／`stamp`／`note`）**空串＝未给**（与全层 `optText` 同口径）。

## 契约与不变量（判据逐条断）

1. **一套坐标，只有一处算**：`scale.ts` 的 `barPct()` 把读数映射成柱高百分比（**下限 20%、上限 84%**，
   不做 0 起点）；**柱高与均值线都从它出**，每根柱下面那枚读数也出自同一个轴域
   ⇒ 读者按柱高比的相对高低，与底下那个数永远对得上。
2. **归一化写在明面上**：口径句里点名这一组数据的最低与最高（`柱高只在最低 1,690 与最高 1,940 之间归一化`），
   并写清「拿它比相对高低，不比绝对量」、绝对读数写在每根柱子下面。
3. **均值不是目标**：虚线给的是这几期的**算术平均**；口径句明写「「均值」不是「目标」」。
   要跟目标比，请调用方另给一个数（本件不替你判目标）。
4. **一段读数完全相同时不除零**：全部相等时柱高一律画在中线（`flat` 分支），口径句改成「读数完全一样」，
   不画 NaN、也不静默画成一条压线的细条。
5. **色不是唯一信息**：均值线是**虚线**（线型）＋ 线上那枚标注写着「均值 …」（标注）＋
   卡头那句「虚线＝N 期均值」（字）；本期那一列是**贯穿柱阵的竖标**（形）＋ 轴上写着「本期」（字）
   ＋ 强调色（色）——三样同时在。
6. **色都从强调色系出**：柱＝无文字的条走 `accent` 实底；本期竖标是 `accent` 往纸面掺的**淡洗**；
   「本期」那枚字走 `accent-text`（文本档）。**没有一处拿正文墨色当"面"**，也不写死任何色值。
7. **期间名与读数永不 `…` 截断**：全件没有 `text-overflow`／`line-clamp`／`nowrap`；
   长串走 `overflow-wrap: anywhere` 换行。
8. **两档几何**：容器宽 390 与 1280 下**零横向溢出**（`scrollWidth ≤ clientWidth`）、
   柱与均值线都在柱阵内、标签零截断；柱阵与横轴标签行是**同一份列划分**（同一个 `gap` ＋ `flex: 1 1 0`），
   任何列数下标签都对着它那一根柱。
9. **一根柱都不减**：这一档的「列」就是数据里的期间本身（减列＝删期间，那是改结构）。
   窄容器（`@container ≤ 460px`）只把间距收紧、图区矮一档，把宽度还给柱子。
10. **零 DOM、零可点元素、没有运行时段**：本件只产标记、不带脚本、不带 `tabindex`／`on*` 内联事件；
    所以**没有 `runtime.ts`**——纯静态图没有需要运行时才能发生的交互（这一件不折叠、不浮出、不切换）。
    调用方若把某一列包成入口，件里那条 `:focus-visible` 地板保证焦点看得见（见常见错法最后一条）。
11. **样式只有一份出口**：`smallMultiplesCss()` 是唯一的样式入口，全部规则 scope 在 `.<prefix>page-ui` 之下；
    不写 `:root`／`!important`／任何 `@media`（媒体查询只许判设备能力），颜色／圆角／字号一律经 `skinVar()` 读。
12. **各套皮肤下标记逐字节相同**：皮肤只换取值表，标记一个字节不动（换皮不换结构）。

## 常见错法

- **`periods` 只给一期** ⇒ 当场报错：一期谈不上「跨期怎么变」（那用 `summary-head` 给一个读数就行）；
- **给到 9 期以上** ⇒ 当场报错：窄容器里每列不到 42px，期间名与读数只能压字——
  请调用方先合并期间（要一次看几十期，用 `calendar-month` 或 `heat-grid`）；
- **某一期没数就传 `0` 顶替** ⇒ 均值被拉低、柱阵多出一根假的「0」，整张图读错。
  本件**不认缺值**：那一期没数就别给这一期（宁可少一期，也别给一个假数）；要保留占位请在 `label` 上写明缺；
- **把 `value` 当"相对高度"传进来**（传 `0–100`）⇒ 本件按真实读数归一化，传相对值等于把口径在地图上抹掉。
  要给的是**绝对读数**，柱高由本件算；
- **自己先算好平均值再传一个"均值期"进来** ⇒ 均值线会把那一期也算进均值，读出来的是个假数；
- **柱高当绝对量比**：它比的是**相对高低**（同一组数据内），绝对量在每根柱下面的那枚读数里；
- **把每一列包成可点入口** ⇒ 8 期并排时每列不到 44px 宽，触控命中盒不够（触屏地板 ≥44×44）。
  要点开某一期，请用横轴标签行做行内入口（够高够宽），或改用 `calendar-month`；
- **拿它当"构成"**：一根柱只表示一个读数，构成（一整块怎么分）走 `stacked-bar`。

## 关系

- 与 `heat-grid` 的分工：热力格是**色阶**（只看浓淡、格内没有形状、读不出数）；
  小倍数每格是一根**有高度的柱**，且每格下面写着它自己的读数；
- 与 `calendar-month` 的分工：月历格按**日子**排；小倍数是**任意期间轴**；
- 与 `rank-list` 的分工：榜单是一期之内的名次；小倍数问的是**同一个读数跨期**怎么变；
- 与 `scatter-fit` 的分工：那是两个读数之间的**关系**（点云＋拟合）；本件只有一个读数、沿期间摊开；
- **本件暂不提供族汇总入口**（同批第二件落地后，由先成立的那件立汇总，照 `sheetCss()` 先例）。

## 判据（`test/small-multiples.test.mjs`）

① 渲染契约：槽位与枚数／**柱高与均值线是同一份真值**（逐柱按 `barPct` 的公式验算）／本期那一列的三样信息／
转义面／**全部**非法入参分支（每个都断 `BlocksError`）；② 样式与零 DOM 纪律（scope 恰一次、零 `@media`、
零颜色字面量、零手写 `var(--ilife-…)`、零 `…` 截断写法）；③ 加法式（不开＝逐字节不变）；
④ 两档几何（真机 headless Chrome ＋ CDP：容器 390 与 1280 下零横向溢出、柱与线都在柱阵内、标签零截断、
窄档图区确实矮一档＝容器查询真在生效）；⑤ 皮肤纪律（四套皮肤下标记逐字节相同）。
