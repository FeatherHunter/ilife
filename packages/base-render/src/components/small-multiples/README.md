# small-multiples · 小倍数面板

**一句话**：同一个读数的若干**期间并排**成一根一根迷你柱（共用一套归一化刻度，横着比相对高低），
一条虚线给出这几期的均值，每根柱下面写着那一期的**绝对读数**。

**形态**：本件只落地**原型墙 no.68 的 C 档「期间并排迷你柱阵 ＋ 均值线」**
（出处＝`.scratch/ui-组件墙/新件/parts-数据与仪表.mjs`；2026-09 用户在墙上给这一格打 4 分，
A 档「每格一张面积 sparkline」与 B 档「对齐基线的多条 sparkline」没全过，故不落）。
形态键住 `SMALL_MULTIPLES_FORMS` 闭集（今天只有 `columns` 一格；`C` 是原型墙那一格的格号，不是接口名）
——日后 A／B 两档复看过了线，是在闭集里加一格，不是新开一件（形态是骨架，不是地址）。

它替掉的两种错法：**把 N 段拼成一张多线图**（线全缠在一起，谁是谁看不出来）与
**只给最后一期**（看不出这一段在涨还是在跌）。

## 何时用它（选型四条）

| 你要的 | 用 |
|---|---|
| 「同一个读数，这几期一期一根柱，横着比高低」 | **本件** |
| 「同一类东西各占多少」（一整块怎么分，没有期间轴） | `stacked-bar`（构成条） |
| 「一期之内的名次」（谁第一谁第二） | `rank-list`（榜单） |
| 「两个纬度切成格子的浓淡」（格内没有形状、读不出数） | `heat-grid`（热力格） |

用在哪：六个技能都用（同一个读数在多个期间并排）——卡路里（日均摄入逐周）／作息管家（睡眠时长逐周）／
记账（每周支出）／居家管家（每月消耗）。**任意期间轴**：哪几周、哪几段由调用方给，
本件不认「周」也不认「月」（只认 `label` 与 `value`）。

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `title` | `string` | 必填 | 卡头标题（`日均摄入 · 六周并排`）。**非空** |
| `periods` | `SmallMultiplesPeriod[]` | 必填 | 期间与读数（**2–8 期**，顺序就是横轴上的顺序） |
| `unit` | `string` | — | 读数单位（`卡`／`小时`）：写在均值那枚标注与无障碍名里。**建议写中文** |
| `stamp` | `string` | — | 卡头那枚期间范围（`W35 – W40`）；不给＝不出 |
| `form` | `'columns'` | `'columns'` | 形态闭集；闭集外报 `BlocksError` |
| `note` | `string` | 本件算出来的口径句 | 脚注一句人话；**给了就整句替换**那句口径 |
| `extraClass` | `string` | — | 附加类名（空格分隔，逐个过类名正则） |

**期间（`periods` 的每一个元素）**

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `label` | `string` | 必填 | 期间名（`第 35 周`／`W35`）：上屏在横轴，**永不 `…` 截断**（长了换行）。**不许与别的期间同名**（同名当场报错） |
| `value` | `number` | 必填 | 这一期的读数（**有限数**：`NaN`／`Infinity`／数字串一律拒；**负读数照收**——差值型读数就长这样，归一化只看这一组的最低与最高） |
| `now` | `boolean` | — | 是不是「本期」那一列；**最多标一期**（标两期当场报错） |

可选的文本字段（`unit`／`stamp`／`note`）**空串＝未给**（与全层 `optText` 同口径）。

## 契约与不变量（判据逐条断）

1. **一套坐标，只有一处算**：`scale.ts` 的 `barPct()` 把读数映射成柱高百分比（**下限 20%、上限 84%**，
   不做 0 起点）；**柱高与均值线都从它出**，每根柱下面那枚读数也出自同一个轴域
   ⇒ 读者按柱高比的相对高低，与底下那个数永远对得上。
   喂进这个映射的数**一律夹在轴域内**（`[最低, 最高]`）：越界（或轴域宽到算不出比值）不会画出框外的线。
2. **归一化写在明面上**：口径句里点名这一组数据的最低与最高（`柱高只在最低 1,690 与最高 1,940 之间归一化`），
   并写清「拿它比相对高低，不比绝对量」、绝对读数写在每根柱子下面。
3. **均值不是目标**：虚线给的是这几期的**算术平均**；口径句明写「「均值」不是「目标」」。
   要跟目标比，请调用方另给一个数（本件不替你判目标）。
4. **均值取整有口径，且「给线用的」与「给人看的」是两个数**：
   · **线**用**未量化**的算术平均算位置（量化过的均值可能落到轴域外——`0.001` 与 `0.002` 的均值量化成 `0`，
     虚线当场跑到柱阵下面去）；所以线永远压在「读数等于均值」的那根柱顶上；
   · **上屏那一枚**（标注与无障碍名）：读数**全是整数**时均值取到整数（`[1, 2]` → `均值 2`；
     原型那六周 → `均值 1,810`）；否则**至多两位小数、且至少两位有效数字**
     （`[1, 2.5]` → `均值 1.75`；`[0.006, 0.008]` → `均值 0.007`；`[0.001, 0.002]` → `均值 0.0015`）——
     两位小数会把小量级的真值抹成 `0` 或写成 `0.01`，那是十进位的整档丢失，不是舍入；
   · 柱下那几枚读数同一档位数：**非零的读数上屏都不写成 `0`**（小于 0.01 的那一档至少留两位有效数字）。
5. **一段读数完全相同时不除零**：全部相等时柱高一律画在中线（`flat` 分支），口径句改成「读数完全一样」，
   不画 NaN、也不静默画成一条压线的细条。
6. **色不是唯一信息**：均值线是**虚线**（线型）＋ 线上那枚标注写着「均值 …」（标注）＋
   卡头那句「虚线＝N 期均值」（字）；本期那一列是**贯穿柱阵的竖标**（形）＋ 轴上写着「本期」（字）
   ＋ 强调色（色）——三样同时在。
7. **色都从强调色系出**：柱与本期竖标＝「**无文字的点／格／条**」那一档，走 `accent` **实底**
   （对纸面 ≥3:1 的图形地板，四套实测 5.76／18.82／4.02／5.15）；「本期」那枚字走 `accent-text`（文本档）；
   卡头那枚期间范围走 `accent-text` 的字 ＋ `line` 的描边。
   **没有一处拿正文墨色当"面"**，也不写死任何色值。
8. **期间名与读数永不 `…` 截断**：全件没有 `text-overflow`／`line-clamp`／`nowrap`；
   长串走 `overflow-wrap: anywhere` 换行。
9. **三档几何**：容器宽 320／390 与 1280 下**零横向溢出**（`scrollWidth ≤ clientWidth`）、
   **柱、均值线与均值那枚标注都在柱阵框内**、标签零截断；柱阵与横轴标签行是**同一份列划分**
   （同一个 `gap` ＋ `flex: 1 1 0`），任何列数下标签都对着它那一根柱。
   标注**朝柱阵里长**：线在刻度中线（＝下限与上限的中点 52%）之上时画到**线下**、否则画在线上
   ⇒ 只要标注不超过半个柱阵区高，它的四条边就恒在框内。
10. **一根柱都不减**：这一档的「列」就是数据里的期间本身（减列＝删期间，那是改结构）。
    窄容器（`@container ≤ 460px`）只把间距收紧、图区矮一档，把宽度还给柱子。
11. **零 DOM、零可点元素、没有运行时段**：本件只产标记、不带脚本、不带 `tabindex`／`on*` 内联事件；
    所以**没有 `runtime.ts`**——纯静态图没有需要运行时才能发生的交互（这一件不折叠、不浮出、不切换）。
    调用方若把某一列包成入口，件里那条 `:focus-visible` 地板保证焦点看得见（见常见错法最后一条）。
12. **样式只有一份出口**：`smallMultiplesCss()` 是唯一的样式入口，全部规则 scope 在 `.<prefix>page-ui` 之下；
    不写 `:root`／`!important`／任何 `@media`（媒体查询只许判设备能力），颜色／圆角／字号一律经 `skinVar()` 读。
13. **各套皮肤下标记逐字节相同**：皮肤只换取值表，标记一个字节不动（换皮不换结构）。

## 常见错法

- **`periods` 只给一期** ⇒ 当场报错：一期谈不上「跨期怎么变」（那用 `summary-head` 给一个读数就行）；
- **给到 9 期以上** ⇒ 当场报错：窄容器里每列不到 42px，期间名与读数只能压字——
  请调用方先合并期间（要一次看几十期，用 `calendar-month` 或 `heat-grid`）；
- **两期同名**（`W35` 出现两次）⇒ 当场报错：期间名是这一列的**坐标**（写在轴上、也进无障碍名），
  两列同名，那张图就答不了「哪一列是谁」（柱还是画得出来，错的是它指代不了）。请改名，或先把这两期合成一期；
- **某一期没数就传 `0` 顶替** ⇒ 均值被拉低、柱阵多出一根假的「0」，整张图读错。
  本件**不认缺值**：那一期没数就别给这一期（宁可少一期，也别给一个假数）；要保留占位请在 `label` 上写明缺；
- **把 `value` 当"相对高度"传进来**（传 `0–100`）⇒ 本件按真实读数归一化，传相对值等于把口径在地图上抹掉。
  要给的是**绝对读数**，柱高由本件算；
- **自己先算好平均值再传一个"均值期"进来** ⇒ 均值线会把那一期也算进均值，读出来的是个假数；
- **柱高当绝对量比**：它比的是**相对高低**（同一组数据内），绝对量在每根柱下面的那枚读数里；
- **把每一列包成可点入口** ⇒ 触控命中盒按**列宽**算，够 44px 宽要**容器宽 ≥ 44×期数 ＋ 4×(期数−1)**
  （8 期 ⇒ ≥380px；真机读数：390 档列宽 45.3px ✓、320 档只有 36.5px ✗；两档的**高**都够——
  长期间名换行只会更高，56–146px）。
  条件不成立时，**「用横轴标签行做行内入口」也不算数**（320 档那行同样窄）——请改用 `calendar-month`，
  或先合并期间（≤4 期时 320 档也有 77px 宽）；
- **负数读数**：照收（差值型读数就长这样），归一化只看这一组的最低与最高——别当成"未给"或"缺值"处理；
- **拿它当"构成"**：一根柱只表示一个读数，构成（一整块怎么分）走 `stacked-bar`。

## 与原型的有意偏离（逐条留档）

原型＝墙 no.68 C 档（`.scratch/ui-组件墙/新件/parts-数据与仪表.mjs`，对照页 `_审-sm原型.html`）。
**已按原型改回的**：轴上两行的层级（读数 `ink`／700 是最重的一行、期间名 `ink-2`／600 退一档）、
卡头那枚期间范围（`accent-text` 的字 ＋ `line` 的描边 ＋ 30px 高的胶囊）。**仍然偏离的两条 ＋ 一条文字改写**：

| 原型 | 本件 | 为什么 |
|---|---|---|
| `.mx-mean{left:-9px;right:-9px}`：均值线两端各伸出柱阵 9px | 线正好跨度＝柱阵宽（`left:0;right:0`） | 「柱、线与标注都在柱阵框内」是本件的硬判据，线两端出框与它冲突；两端对齐首末柱，读者按柱阵边界读数 |
| 均值标注 `white-space:nowrap`、固定贴线右端上方 | 允许换行；线在刻度中线之上时画到**线下** | 本件不许 `…` 截断、也不许 `nowrap`（长单位要换行）⇒ 标注会变高，固定「只往上长」会顶出柱阵、压进卡头 |
| 说明段四处文字（含「深色那根是本周」这个颜色词） | 口径句改写：不出现颜色词；点明每一期的读数写在它那根柱子下面；末句改说「「均值」不是「目标」」 | 本件的「色不是唯一信息」口径：指代一列只许用**形＋字**，不许用颜色词 |

## 关系

- 与 `heat-grid` 的分工：热力格是**色阶**（只看浓淡、格内没有形状、读不出数）；
  小倍数每格是一根**有高度的柱**，且每格下面写着它自己的读数；
- 与 `calendar-month` 的分工：月历格按**日子**排；小倍数是**任意期间轴**；
- 与 `rank-list` 的分工：榜单是一期之内的名次；小倍数问的是**同一个读数跨期**怎么变；
- 与 `scatter-fit` 的分工：那是两个读数之间的**关系**（点云＋拟合）；本件只有一个读数、沿期间摊开；
- **本件暂不提供族汇总入口**（同批第二件落地后，由先成立的那件立汇总，照 `sheetCss()` 先例）。

## 判据（`test/small-multiples.test.mjs`）

① 渲染契约：槽位与枚数／**柱高与均值线是同一份真值**（逐柱按 `barPct` 的公式验算）／
**均值线永远在柱阵内**（读数极小、轴域极窄、和会溢出的那几档）／**均值取整口径逐档钉住**／
本期那一列的三样信息／转义面／**全部**非法入参分支（每个都断 `BlocksError`，含**两期同名**）；
② 样式与零 DOM 纪律（scope 恰一次、零 `@media`、零颜色字面量、零手写 `var(--ilife-…)`、零 `…` 截断写法、
竖标走 `accent` 实底）；③ 加法式（不开＝逐字节不变）；
④ 三档几何（真机 headless Chrome ＋ CDP：容器 320／390／1280 下零横向溢出、柱／线／**均值标注**都在柱阵内、
触控列宽读数、标签零截断、窄档图区确实矮一档＝容器查询真在生效）；
⑤ 皮肤纪律（四套皮肤下标记逐字节相同、竖标与柱取自皮肤取值表、图形对比 ≥3:1 逐套算）；
⑥ 文档与偏离留档（README 写着取整口径／同名拒绝／触控那条的成立条件，且门槛数字与真机读数相容）。
