# portion-gauge · 量感条

**一句话**：把「200 g」翻成能对着手比的量——**一条尺子读出这一份占一天上限的几成**（A 档 `gauge`），或者**一行一样食材把菜谱单位换算成营养库单位、再标出占一天几成**（B 档 `convert`）。

**形态**：本件落地**原型墙 no.69 的两档**（出处＝`.scratch/ui-组件墙/新件/parts-数据与仪表.mjs`）：

| 档 | 形态键 | 骨架 | 读法 |
|---|---|---|---|
| A | `gauge` | 量感条（占上限几成 ＋ 两条参照刻度） | 一眼比：这一份占一天上限的几成、离「一餐建议」还差多少 |
| B | `convert` | 换算三栏（菜谱单位 → 营养库单位 → 实物占比） | 一行一样食材：菜谱写的那一句 → 营养库认的那一句 → 占一天几成 |

形态键住 `PORTION_GAUGE_FORMS` 闭集（`convert`／`gauge`；`A`／`B` 是原型墙的格号，不是接口名）。`convert` 排在最前＝**缺省形态**（先落地的那一档，产物一个字节不动）。

A 档那一档的来历：原型逐格打分时它只拿到 3/3/3（B 档 4/4/4），当时没落；用户改口全部认可，原话是「**文本量太大了，原型里面写了好多文字，看起来就很混乱**」。所以补落的是**砍过字的那一版**，可见字只留 **72 个**的量级（一屏只留一层话、同一个数只印一次、读数一行说完）：

- **不写**「占一天上限」那句：轨道右端已经标着「一天上限 2 份」；
- **不写**头部「1 份」那枚胶囊：同一份量在「≈ 350 g」与「≈ 1 个拳头 ＋ 2 汤勺」里各印过一次；
- 留下的是一条尺子（量程＝0…上限）＋ 一档百分比大字 ＋ 两枚参照刻度值（一餐建议／一天上限，一高一低挂在自己那枚刻度上）。

## 何时用它（选型五条）

| 你要的 | 用 |
|---|---|
| 「这一份占一天该吃多少的几成、离建议还差多少」（一份量，一条尺子） | **`gauge`（本件）** |
| 「菜谱的份碗把等于营养库的多少克，再占一天的几成」（一样一样食材摊开） | **`convert`（本件）** |
| 选数量的输入控件（给输入框定个单位后缀） | `number-stepper`（数量步进，那是输入控件，本件是只读读数） |
| 「值＋单位」的横排行内文字（无形状、无换算、无占比） | `stat-inline`（行内读数） |
| 零到目标的格子刻度（不换算单位、不给实物参照） | `scale-bar`（刻度条） |

用在哪：原型点名三处——**私家大厨**（菜谱食材／跟着做）／**卡路里**（记一餐的份量）／**居家管家**（库存与用量）。

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `title` | `string` | 必填 | 卡头标题（`份量换算`／`这一餐的量`）。**非空**，全空白当场报错 |
| `form` | `'convert'` \| `'gauge'` | `'convert'` | 形态闭集；闭集外报 `BlocksError` |

| `gauge` | `PortionGaugeGauge` | `gauge` 必填 | 这一份的量感（量程、已用几成、参照刻度、换算那两句，见下表）；`convert` 形态不读它 |
| `stamp` | `string` | — | 卡头里那枚口径（`菜谱 → 营养库`）；不给＝不出 |
| `tail` | `string` | — | 卡头右端那句（`1 份 ＝ 350 g`／`≈ 350 g`）；不给＝不出 |
| `note` | `string` | 见下 | 脚注一句人话。**不给**：`convert` 用本件的口径句，`gauge` **不出脚注**（两条参照刻度在图上自己报了名，再写一遍＝同一件事印两遍）。给了就整句替换 |
| `missingCount` | `number` | `0` | 缺换算系数的食材有几样（非负整数；**0 或不给＝不出那一行**；屏上那个数走三位分组）。`convert` 用 |
| `extraClass` | `string` | — | 附加类名（空格分隔，逐个过类名正则） |

**一行（`rows` 的每一个元素）**

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `name` | `string` | 必填 | 食材名（`红烧肉`）：上屏在行头，**永不截断**（长了换行） |
| `recipe` | `string` | 必填 | 菜谱写的那一句（`2 份`）：已是给人看的样子，本件不拆它 |
| `grams` | `number` | 必填 | 这一行合计多少克（有限数，须大于 0） |
| `shareOf` | `string` | 必填 | 占一天里哪一项（`蛋白`／`碳水`／`纤维`）；写成一句话也成立，长句在宽档换行让位（占比条恒留最小宽） |
| `sharePct` | `number` | 必填 | 占一天的百分比（0 到 100；占比那句的字与占比条的宽度都从它出） |
| `kind` | `string` | — | 食材分档（`主料`／`主食`／`配菜`）；不给＝出处那句只有菜谱写法 |
| `basis` | `string` | — | 换算系数那一句（`1 碗 ＝ 150 g`）；不给＝右栏说明只有口径名 |
| `toLabel` | `string` | `营养库口径` | 右栏口径名（`生重`）；系数有名时写成 `生重（1 碗 ＝ 150 g）` |

**一份量感（`gauge` 的字段）**

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `name` | `string` | 必填 | 这一份叫什么（`红烧肉`）：上屏在卡头标题右边，也进无障碍名 |
| `usedPct` | `number` | 必填 | 已用占上限的几成（0 到 100）：那个大字与已用那一段的长度**都从它出** |
| `capText` | `string` | 必填 | 上限那个量（`2 份`）：屏上写成「一天上限 2 份」，收在尺子右端（**尺子的量程就是 0…它**） |
| `refText` | `string` | — | 一餐建议那个量（`1.2 份`）：屏上写成「一餐建议 1.2 份」。**与 `refPct` 成对给** |
| `refPct` | `number` | — | 建议那枚刻度落在尺子的几成处（0 到 100）；**与 `refText` 成对给** |
| `equiv` | `string` | — | 实物参照那一行（`≈ 1 个拳头 ＋ 2 汤勺`）；不给＝不出那一行 |

可选的文本字段（`stamp`／`tail`／`note`／`kind`／`basis`／`toLabel`／`equiv`／`refText`）**空串＝未给**（与全层 `optText` 同口径）。`refText` 与 `refPct` 只给一样当场报错（那句参照要么没地方挂、要么挂在编出来的位置上）。

## 契约与不变量（判据逐条断）

1. **同一份真值只印一次，两处读数不许走散**（这一条是本件的头号几何契约）：
   - `convert`：克数串只拼一遍（行头那句合计与换算右栏是**同一个串**），菜谱串只收一遍（出处句与换算左栏是**同一个串**），百分比只取一位小数（占比那句的字与占比条的宽度是**同一个数**）。**条那一轨有最小宽**（`PORTION_GAUGE_BAR_MIN_PX`）：长占比句在宽档只许换行让位，不许把条挤成 0 宽——条 0 长而那句写着 70%，两处读数就走散了。
   - `gauge`：**条宽恒由占比算出**——那个百分比大字、已用那一段的宽度、无障碍名里的那个数，三处出自同一个 `usedPct`；参照刻度竖线与它们那两行字的位置出自同一对 `refPct`／上限。判据从印出来的大字反推百分比，再把条宽逐点对账（变异自证：把条宽写成常量、把大字换成另一个数、把条压成 0 宽，三种变异都必须被这条判据抓住）。
2. **A 档的可见字只留一屏一层话**（用户砍字那一条的落点）：标准样例的可见字**不过 72 个**；「占一天上限」那句不写（轨道右端已标）、头部「1 份」那枚胶囊不写（同一份量别处印过）；同一个数（`58%`）在可见文本里**只出现一次**。判据按可见文本逐字对账，并带变异自证（塞回那句话、再印一遍那个数，都要红）。
3. **缺换算的整行不画，只报数**：缺系数的那几样不进 `rows`（给一行假数等于编换算），只在 `missingCount` 里报数，屏上写成 `还差 N 样没有换算`。`missingCount` 是 0 或不给＝不出那一行。
4. **本件不认 0 顶替**：`grams` 必须是大于 0 的有限数（0 克不是「一行菜的量」，当场报错）；缺换算的食材**整行不画**（第 3 条），本件页面上没有缺值位，也就没有 `—` 这类写法。
5. **色不是唯一信息，且只从 token 出**：`convert` 的占比填充是强调色**实底**（无文字的图形那一档）＋ 那句占比给字，缺换算那一行是提醒软底 ＋ 提醒字；`gauge` 的三级重量各靠**形**分开（余量底＝1px 发丝线、刻度＝6／9px 竖线、已用＝3px 强调色实底压在它上面），两枚参照刻度靠**线形**分开（一餐建议＝实线、一天上限＝虚线）。**没有一处拿正文墨色当「面」**，也不写死任何色值。
6. **本件不带可点元素、不带脚本**（没有 `runtime.ts`）：纯静态读数没有需要运行时才能发生的交互。调用方若把某一行／整条尺子包成入口，件里那条 `:focus-visible` 地板保证焦点看得见；`convert` 的换算框 `min-height: 44px`、`gauge` 的轨道高 `PORTION_GAUGE_RAIL_PX`（44px）保证命中盒够高，相邻两块之间是 8px 起。
7. **关键语义永不截断**：全件没有 `text-overflow`／`line-clamp`／`white-space: nowrap`；长串走 `overflow-wrap: anywhere` 换行（原型那一版给换算的数写了不换行，长单位在窄容器里会把框顶宽，这里改成换行）。A 档的两枚参照刻度值是**在流的两行**（不靠坐标硬摆），长了自己换行——既推不出轨道，也不会横滑。
8. **四档几何（真机 headless Chrome ＋ CDP 量出来的原读数）**：容器宽 320／390／620／1280 下**零横向溢出**，`scrollWidth` 逐格等于 `clientWidth`，每个文本槽**零截断**。`convert` 一侧：四套皮肤 × 五种样例＝每档 20 格，窄档（`@container ≤ 480px`）换算框与占比行改走单列（**一栏不减**）。`gauge` 一侧：四套皮肤 × 四种样例（常规／长串／只有上限／0 与 100 两档边界），大字与条宽逐点对上（差 ≤ 2 个百分点）。**宽档长串另有一档读数**（`convert` 的长占比句与 `gauge` 的长参照刻度值，各 32／64／128 字）：条恒有宽（≥ `PORTION_GAUGE_BAR_MIN_PX`）且填充与那句同源（旧写法 `minmax(0, 1fr) auto` 下真机读到 `gridTemplateColumns = "0px 473px"`、条与填充都是 0px）。
9. **样式只有一份出口**：`portionGaugeCss()` 是唯一的样式入口（A 档那半在 `style-gauge.ts`，由它汇总），全部规则 scope 在 `.<prefix>page-ui` 之下；不写 `:root`／`!important`／任何 `@media`（媒体查询只许判设备能力），颜色／圆角／字号一律经 `skinVar()` 读。
10. **各套皮肤下标记逐字节相同**：皮肤只换取值表，标记一个字节不动（换皮不换结构）。

## 数值字段与未知键（本批新立的口径，判据逐条断）

**两条数值闸**（每一处收数字的字段都过）：
1. **非有限**（`NaN`／`Infinity`／`-Infinity`）⇒ `badInput()` 抛 `BlocksError`；
2. **可加性溢出**：`|a| + |b| > Number.MAX_VALUE`（两笔同量级读数相加就成 `Infinity`，图上会写出 `1e+308`／`NaN`）⇒ `badInput()`。闸在 `fields.ts 的 reqMagnitude()`，上界常量 `PORTION_GAUGE_MAGNITUDE_MAX`（＝`Number.MAX_VALUE ÷ 2`）。
   - 判据是**相加会不会溢出**，不是"好不好读"——`1e21`／`1e-7` 这类**照旧合法**（本件有边界自证守着，别误杀）。

**表外的键一律拒**：顶层与**每个嵌套对象层**都查键（`portion-gauge` 的 `assertKeys`：**自有属性 ＋ 原型链双查**）。
理由：未知键静默吞＝把 `amount` 写成 `ammount` 那种笔误会让屏上静静少一块，而调用方看不到任何报错。这条口径由 `test/跨件不变量.test.mjs` 第 ③ 组守着。

## 常见错法

- **缺换算系数的那几样也塞进 `rows`**（编一个克数顶上）⇒ 整组换算读错。本件**不认缺值顶上**：那几样只在 `missingCount` 里报数；
- **`grams` 传 0 或负数** ⇒ 当场报错（0 克不是「一行菜的量」）；
- **`sharePct` 越界**（120 或负数）⇒ 当场报错（顶出轨道的条比不画更坏）；
- **三栏各算一遍**（行头的合计与右栏的数各拼一次）⇒ 两处迟早走散。同一份真值只在 `model.ts` 算一次，`render.ts` 只引用；
- **`gauge` 只给 `refText` 不给 `refPct`**（或反过来）⇒ 当场报错：那句参照要么没地方挂、要么挂在编出来的位置上，两条都要给；
- **`usedPct` 传越界值**（120 或负数）⇒ 当场报错（已用那一段会冲出轨道）；
- **给到 9 行以上** ⇒ 当场报错：一屏读不完，请调用方先按餐分组；
- **把某一行包成可点入口却不管命中盒** ⇒ `convert` 的换算框自带 `min-height: 44px`，`gauge` 的轨道高 44px，相邻两块间距 ≥8px（真机读数）；
- **占比项名写成一句话**（32 字以上）⇒ 条那一轨有最小宽（`PORTION_GAUGE_BAR_MIN_PX`），长句换行让位；不给最小宽的话，宽档（> 480px）里那条 `auto` 轨会按 max-content 吃光自由空间，把条压成 0 宽（条还在、读者按条读到的占比却是 0，而那句照写 70%）；
- **拿 `gauge` 当「多份食材的合计」**：一条尺子只说一份，多份食材摊开要读 `convert`；
- **拿它当输入控件**：选数量走 `number-stepper`，本件是只读的；
- **把 `stamp` 当成必填** ⇒ 不给就不出那一枚（它是口径，不是数据）。

## 与原型的有意偏离（逐条留档）

原型＝`.scratch/ui-组件墙/新件/parts-数据与仪表.mjs` 的 69（A／B 两档）。**按层规重写**（类名前缀、`skinVar()` 读皮肤、`@container` 判宽、槽位助手拼选择器），逐条偏离如下：

| 原型 | 本件 | 为什么 |
|---|---|---|
| B 档行头出处句写成 `主料 · 菜谱写「2 份」`（`·` 分隔） | 写成 `主料，菜谱写「2 份」` | 仓库的分隔符门（`test/separator-probe.mjs` R1–R3）对可见文本零豁免：`·` 一出现就红 |
| B 档口径句里有 `（份／碗／把）` 与 `；` | 写成 `（份，碗，把）`，长句拆成三句 | 同上：`／` 与 `；` 都是分隔符门的红线 |
| B 档换算的数写了 `white-space: nowrap`（左栏、右栏、占比句三处） | 三处一律换行（`overflow-wrap: anywhere`） | 窄档硬判据：长单位在 320 档会把框顶宽；关键语义永不截断 |
| A 档头部写成 `这一餐的量 · 红烧肉`（`·` 分隔），另有一枚 `1 份` 胶囊 | 拆成 `title`「这一餐的量」＋ `subject`「红烧肉」两个节点；**不设**那枚胶囊 | 分隔符门（`·`）＋ 用户砍字那一条：同一个份量别处印过，不再印一遍 |
| A 档百分比下面挂一句「占一天上限 2 份 · 比一餐建议的 1.2 份还差一点」 | **不写这一句**：58% 那一行只有那个大字 | 用户砍字那一条：轨道右端已经标着「一天上限 2 份」，同一件事印两遍 |
| A 档两枚参照刻度值是**绝对定位**在刻度上（`translateX(-50%)` ＋ `white-space: nowrap`） | 改成**在流的两行**（`text-align: center` ＋ 一侧内距，内距由 `model.ts` 算），长了自己换行 | 绝对定位 ＋ 不换行在窄档会把标签推出轨道（横溢），或者被压成一行一个字；在流的两行两头都不发生 |
| A 档轨道右端那枚刻度用 `left: 100%` | 用 `right: 0` 收口 | `left: 100%` 会把那 1px 描边推到轨道外面（真机 `scrollWidth` 会多出 1px） |
| A 档尺子上另写 0／1 份／2 份三枚刻度值 | 只留两枚参照刻度值（一餐建议／一天上限）；刻度竖线**只画线不写数** | 用户砍字那一条：同一个数不在图上再印一遍（0 与 2 份已经由上下两端的两句话盖住） |
| 旧 token（`--fg`／`--line2`／`--accent` 等墙稿变量） | 一律 `skinVar()` 读皮肤 token | 层红线：组件只读 token 名、不读值；旧 token 只在兜底链里出现 |
| 缺换算只是一句口径里的字（`还差 2 样没有换算` 无落点） | 落成独立的 `missing` 槽（提醒软底 ＋ 提醒字） | 照法条「语义档」那一档：提醒走 `warn`／`warn-soft`，且有处可断 |
| 右栏说明无名（`营养库口径`／`生重`混写） | 落成入参 `toLabel`（缺省 `营养库口径`）＋ `basis`（系数句） | 系数变了要写明是哪一版：口径名与系数句是两件事，分开给 |
| 占比行两栏是 `1fr` ＋ `auto`：长占比句按 max-content 吃光自由空间，把条挤成 0 宽 | 条那一轨给最小宽（`PORTION_GAUGE_BAR_MIN_PX`＝72px），长占比句换行让位 | 真机读数：481 档下 32／64／128 字的占比句把条压到 `0px`（那句照写 70%）——条在、读数却是 0，两处走散 |

## 关系

- `gauge` 与 `convert` 的分工：一条尺子说**一份**量（占上限几成、离建议多远），换算三栏说**一组**食材（每一样从菜谱单位翻到营养库单位再算占比）；
- 与 `number-stepper` 的分工：那是输入控件，选单位只是给输入框定个后缀；本件是只读读数；
- 与 `stat-inline` 的分工：那是「值＋单位」的横排文字，没有量感形状、没有换算、没有每日占比；
- 与 `scale-bar` 的分工：刻度条是零到目标的格子刻度，不换算单位、不给实物参照；
- **本件暂不提供族汇总入口**（同族第二件落地后，由先成立的那件立汇总，照 `sheetCss()` 先例）。

## 判据（`test/portion-gauge.test.mjs`）

① 渲染契约（`convert`）：骨架与行数／**换算链三栏同一份真值**（从印出来的占比句反推百分比，条宽逐点对账；克数串与菜谱串两处同引）／缺换算那一支／**旧档逐字节不变**（补 A 档之前的原产物逐字节对账）／转义面／**全部**非法入参分支（每个都断 `BlocksError`）；
①A 渲染契约（`gauge`）：骨架与槽位／**条宽恒由占比算出**（大字、条宽、无障碍名同一个数；变异自证三种）／**可见字不过 72 与同一个数只印一次**（变异自证）／不给建议那一支／两枚参照刻度值的位置／转义面／非法入参分支（含 `refText`／`refPct` 只给一样）；
② 样式与零 DOM 纪律（scope 恰一次、零 `@media`、零颜色字面量、零手写 `var(--ilife-…)`、零 `…` 截断写法、**窄档阈值只有一个来源**、**标记面与死声明门**：闭集里每个槽位都在标记里真出现、且样式段里有规则）；
