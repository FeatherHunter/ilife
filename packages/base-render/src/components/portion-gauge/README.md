# portion-gauge · 量感条

**一句话**：把「200 g」翻成能对着手比的量——一行一样食材，菜谱写的那一句（`2 份`）→ 营养库认的那一句（`700 g`）→ 实物占比（占一天蛋白几成）。

**形态**：本件只落地**B 换算三栏**（形态键 `convert`）——出处＝`.scratch/ui-组件墙/新件/parts-数据与仪表.mjs` 的 69（2026-09 用户逐格打分：B 档 4/4/4；**A 档量感条只拿到 3/3/3，不落**）。
形态键住 `PORTION_GAUGE_FORMS` 闭集（今天只有 `convert` 一格）——**加第二形态是在闭集里加一格，不是新开一件**（形态是骨架，不是地址）。

## 何时用它（选型四条）

| 你要的 | 用 |
|---|---|
| 「菜谱的份碗把等于营养库的多少克，再占一天的几成」 | **`convert`（本件）** |
| 选数量的输入控件（给输入框定个单位后缀） | `number-stepper`（数量步进，那是输入控件，本件是只读读数） |
| 「值＋单位」的横排行内文字（无形状、无换算、无占比） | `stat-inline`（行内读数） |
| 零到目标的格子刻度（不换算单位、不给实物参照） | `scale-bar`（刻度条） |

用在哪：原型点名三处——**私家大厨**（菜谱食材／跟着做）／**卡路里**（记一餐的份量）／**居家管家**（库存与用量）。

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `title` | `string` | 必填 | 卡头标题（`份量换算`）。**非空**，全空白当场报错 |
| `rows` | `PortionGaugeRow[]` | 必填 | 换算各行（**1–8 行**，顺序就是屏上的顺序，见下表） |
| `form` | `'convert'` | `'convert'` | 形态闭集；闭集外报 `BlocksError` |
| `stamp` | `string` | — | 卡头里那枚口径（`菜谱 → 营养库`）；不给＝不出 |
| `tail` | `string` | — | 卡头右端那句换算基准（`1 份 ＝ 350 g`）；不给＝不出 |
| `note` | `string` | 本件算出来的口径句 | 脚注一句人话；**给了就整句替换**那句口径 |
| `missingCount` | `number` | — | 缺换算系数的食材有几样（非负整数；0 或不给＝不出那一行） |
| `extraClass` | `string` | — | 附加类名（空格分隔，逐个过类名正则） |

**一行（`rows` 的每一个元素）**

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `name` | `string` | 必填 | 食材名（`红烧肉`）：上屏在行头，**永不截断**（长了换行） |
| `recipe` | `string` | 必填 | 菜谱写的那一句（`2 份`）：已是给人看的样子，本件不拆它 |
| `grams` | `number` | 必填 | 这一行合计多少克（有限数，须大于 0） |
| `shareOf` | `string` | 必填 | 占一天里哪一项（`蛋白`／`碳水`／`纤维`） |
| `sharePct` | `number` | 必填 | 占一天的百分比（0 到 100；占比那句的字与占比条的宽度都从它出） |
| `kind` | `string` | — | 食材分档（`主料`／`主食`／`配菜`）；不给＝出处那句只有菜谱写法 |
| `basis` | `string` | — | 换算系数那一句（`1 碗 ＝ 150 g`）；不给＝右栏说明只有口径名 |
| `toLabel` | `string` | `营养库口径` | 右栏口径名（`生重`）；系数有名时写成 `生重（1 碗 ＝ 150 g）` |

可选的文本字段（`stamp`／`tail`／`note`／`kind`／`basis`／`toLabel`）**空串＝未给**（与全层 `optText` 同口径）。

## 契约与不变量（判据逐条断）

1. **换算链三栏的数是同一份真值**（这一条是本件的头号几何契约）：克数串只拼一遍（行头那句合计与换算右栏是**同一个串**），菜谱串只收一遍（出处句与换算左栏是**同一个串**），百分比只取一位小数（占比那句的字与占比条的宽度是**同一个数**）。判据从印出来的占比句反推百分比，再把每一条的宽度逐点对账。
2. **缺换算的整行不画，只报数**：缺系数的那几样不进 `rows`（给一行假数等于编换算），只在 `missingCount` 里报数，屏上写成 `还差 N 样没有换算`。`missingCount` 是 0 或不给＝不出那一行。
3. **缺值写成 `—`**：本件不认 0 顶替（0 克不是“一行菜的量”，`grams` 须大于 0）。
4. **色不是唯一信息，且只从 token 出**：占比填充是强调色**实底**（无文字的图形那一档）＋ 那句占比给字；缺换算那一行是提醒软底 ＋ 提醒字（两样同时在）。**没有一处拿正文墨色当“面”**，也不写死任何色值。
5. **本件不带可点元素、不带脚本**（没有 `runtime.ts`）：纯静态读数没有需要运行时才能发生的交互。调用方若把某一行包成入口，件里那条 `:focus-visible` 地板保证焦点看得见，换算框的 `min-height: 44px` 保证命中盒够高。
6. **关键语义永不截断**：全件没有 `text-overflow`／`line-clamp`／`white-space: nowrap`；长串走 `overflow-wrap: anywhere` 换行（原型那一版给换算的数写了不换行，长单位在窄容器里会把框顶宽，这里改成换行）。
7. **四档几何（真机 headless Chrome ＋ CDP 量出来的原读数）**：容器宽 320／390／620／1280 下**零横向溢出**（四套皮肤 × 五种样例＝每档 20 格，`scrollWidth` 逐格等于 `clientWidth`），每一条的宽度与占比句的百分比逐点对上，窄档（`@container ≤ 480px`）换算框与占比行改走单列（**一栏不减**）。
8. **样式只有一份出口**：`portionGaugeCss()` 是唯一的样式入口，全部规则 scope 在 `.<prefix>page-ui` 之下；不写 `:root`／`!important`／任何 `@media`（媒体查询只许判设备能力），颜色／圆角／字号一律经 `skinVar()` 读。
9. **各套皮肤下标记逐字节相同**：皮肤只换取值表，标记一个字节不动（换皮不换结构）。

## 常见错法

- **缺换算系数的那几样也塞进 `rows`**（编一个克数顶上）⇒ 整组换算读错。本件**不认缺值顶上**：那几样只在 `missingCount` 里报数；
- **`grams` 传 0 或负数** ⇒ 当场报错（0 克不是“一行菜的量”）；
- **`sharePct` 越界**（120 或负数）⇒ 当场报错（顶出轨道的条比不画更坏）；
- **三栏各算一遍**（行头的合计与右栏的数各拼一次）⇒ 两处迟早走散。同一份真值只在 `model.ts` 算一次，`render.ts` 只引用；
- **给到 9 行以上** ⇒ 当场报错：一屏读不完，请调用方先按餐分组；
- **把某一行包成可点入口却不管命中盒** ⇒ 换算框自带 `min-height: 44px`，相邻两行的间距是 8px（触控地板那一档）；
- **拿它当输入控件**：选数量走 `number-stepper`，本件是只读的；
- **把 `stamp` 当成必填** ⇒ 不给就不出那一枚（它是口径，不是数据）。

## 与原型的有意偏离（逐条留档）

原型＝`.scratch/ui-组件墙/新件/parts-数据与仪表.mjs` 的 69（只取 B 档的 `t`／`html` 与 `.c-portion` 通用规则；A 档那半一条没搬）。**按层规重写**（类名前缀、`skinVar()` 读皮肤、`@container` 判宽、槽位助手拼选择器），逐条偏离如下：

| 原型 | 本件 | 为什么 |
|---|---|---|
| 行头出处句写成 `主料 · 菜谱写「2 份」`（`·` 分隔） | 写成 `主料，菜谱写「2 份」` | 仓库的分隔符门（`test/separator-probe.mjs` R1–R3）对可见文本零豁免：`·` 一出现就红 |
| 口径句里有 `（份／碗／把）` 与 `；` | 写成 `（份，碗，把）`，长句拆成三句 | 同上：`／` 与 `；` 都是分隔符门的红线 |
| 换算的数写了 `white-space: nowrap`（左栏、右栏、占比句三处） | 三处一律换行（`overflow-wrap: anywhere`） | 窄档硬判据：长单位在 320 档会把框顶宽；关键语义永不截断 |
| 旧 token（`--fg`／`--line2`／`--accent` 等墙稿变量） | 一律 `skinVar()` 读皮肤 token | 层红线：组件只读 token 名、不读值；旧 token 只在兜底链里出现 |
| 缺换算只是一句口径里的字（`还差 2 样没有换算` 无落点） | 落成独立的 `missing` 槽（提醒软底 ＋ 提醒字） | 照法条「语义档」那一档：提醒走 `warn`／`warn-soft`，且有处可断 |
| 右栏说明无名（`营养库口径`／`生重`混写） | 落成入参 `toLabel`（缺省 `营养库口径`）＋ `basis`（系数句） | 系数变了要写明是哪一版：口径名与系数句是两件事，分开给 |

## 关系

- 与 `number-stepper` 的分工：那是输入控件，选单位只是给输入框定个后缀；本件是只读读数；
- 与 `stat-inline` 的分工：那是「值＋单位」的横排文字，没有量感形状、没有换算、没有每日占比；
- 与 `scale-bar` 的分工：刻度条是零到目标的格子刻度，不换算单位、不给实物参照；
- **本件暂不提供族汇总入口**（同族第二件落地后，由先成立的那件立汇总，照 `sheetCss()` 先例）。

## 判据（`test/portion-gauge.test.mjs`）

① 渲染契约：骨架与行数／**换算链三栏同一份真值**（从印出来的占比句反推百分比，条宽逐点对账；克数串与菜谱串两处同引）／缺换算那一支／转义面／**全部**非法入参分支（每个都断 `BlocksError`）；
② 样式与零 DOM 纪律（scope 恰一次、零 `@media`、零颜色字面量、零手写 `var(--ilife-…)`、零 `…` 截断写法、**窄档阈值只有一个来源**）；
③ 加法式（不开＝逐字节不变）；④ 四档几何（真机 320／390／620／1280：零横溢、条宽与占比句逐点对上、窄档改走单列＝容器查询真在生效、零截断）；⑤ 皮肤纪律（四套皮肤下标记逐字节相同、缺换算那一行取自皮肤取值表）；⑥ 分隔符门（R1–R3 零命中）。
