# scale-bar · 刻度条

**一句话**：值／目标的比例形状，两形态——`cells`＝**条形码**（N 格，够几格实几格，能逐格数）/ `line`＝**细线**（一条填充轨）。

## 何时用它（选型三条）

| 你要的 | 用 |
|---|---|
| 「到了目标的几成」——一个数与一个目标比 | **本件** |
| 「哪几天有记录」——N 天的有无 | `renderDayStrip`（页面级横条族） |
| 「A ＋ B ＝ C」——两段构成一个整体 | `renderEquationBar`（页面级横条族） |
| 一排互不相关的量级（各占多少） | `renderDistributionRows`（区块层） |

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `value` | `number` | 必填 | 当前量（与 `goal` 同单位）；**可越界**（越界＝超了，不算错） |
| `goal` | `number` | 必填 | 目标量，**必须 > 0**（分母为零是调用方的错，不静默兜底） |
| `variant` | `'cells' \| 'line'` | `'line'` | 两形态 |
| `cells` | `number` | `24` | 条形码档总格数（4–64 的整数）；细线档忽略 |
| `leftLabel` | `string` | — | 刻度下左侧那句（`46% ｜ 860 / 1850 卡`） |
| `rightLabel` | `string` | — | 刻度下右侧那句（`差 990 卡`） |
| `extraClass` | `string` | — | 附加类名 |

## 契约与不变量

- **两形态根高一致**（刻度 22px ＋ 可选一行 18px）⇒ 同一页换形态不跳版；两形态的"空"都用 `var(--line)`、"满"分别用 `var(--fg)`／`var(--blue)`。
- **"有"与"没有"必须看得出来**：`value > 0` 而四舍五入到 0 格时仍点亮 1 格（吃了 5 卡不能画成没吃）；`value <= 0` 才是全空。
- **超目标只换色、不变形**：`is-over` 用语义色（`#a83228`，与同层"值位三档"一致），仍是满格／满轨，不画第二圈。
- 两端那两句话**由调用方给**，不给就不出——本件不替调用方编文案（免得同一句在页里说两遍）。
- 条形码逐格等宽（`flex:1 1 0`），总宽恒等于容器宽 ⇒ 窄屏不横滑。

## 常见错法

- 只给一个 `46%` 或一根无刻度的细条 ⇒ 读者没法"数"出还剩几格；
- 超目标时把填充条画到底就不管了（颜色不变，也不说超了多少）；
- 用本件当"多段构成条"（那是 `renderEquationBar` 的活，本件只有一段）。

## 关系

- 与 `summary-head` 配对最常用（头给数、条给形）；样式随 `sheetCss()` 一起挂。
- 本件只吃 `number`，**不认**「已给人看的串」——显示口径（取整／单位）归调用方。
