# missing-badge · 缺项徽章

**一句话**：逐项行里“缺的那一项”的落点 —— 缺项名 ＋ 为什么进不去 ＋ 状态字（缺／待补）。

**状态必须有字**：`缺`／`待补`必出，色只是第二样。命名一律全拼（不缩写）。

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `label` | `string` | 必填 | 缺项名（如“借给谁”） |
| `reason` | `string` | 可选 | 为什么进不去（如“这一笔没写对方”） |
| `state` | `missing \| pending` | `missing` | 状态（缺／待补） |
| `extraClass` | `string` | 可选 | 附加类名（空格分隔） |

<!-- 示例入参：皮肤矩阵判据拿它渲染本件，必须能直接渲染成功 -->

```json 示例入参
{ "label": "借给谁", "reason": "这一笔没写对方", "state": "missing" }
```

## 样式

`missingBadgeCss()`：发丝线小牌 ＋ 缺项名粗 ＋ 状态字 ＋ 原因弱文字。
颜色只经皮肤 token 读，不手写色值。

## 无运行时

本件不接事件（`runtime.ts` 不存在）；缺项行点不动，读数都在标记里。
