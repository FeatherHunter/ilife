# rating-row · 评分行

**一句话**：给一次记录打分 —— 标题（给什么打分 ＋ 上次对照）／一排**可聚焦的星按钮**／**一枚大数字读数**。空心星 `☆` 与实心星 `★` 是形状差，那枚数字是「4 与 4.5 的差别」的唯一出处。

**形态**：本件只落地工单点名的**形态 A「星级＋分数」**——出处＝原型墙 `.scratch/ui-组件墙/parts-09-选择与反馈.mjs` 的星级那一支（原型里它的键是 `C`；名册与本席工单把本件的落地形态写作 A，故形态键取 `stars`，见下「有意偏离」）。按层规重写：原型是一次性代码（无判据、无错误处理、读的是墙稿变量）。
形态键住 `RATING_ROW_FORMS` 闭集（今天只有 `stars` 一格）——**加第二形态是在闭集里加一格，不是新开一件**。

> **从原型搬到落地时有意偏离**：① 原型那一支把「星级」与「上次对照 ＋ 短评输入」并成一件；落地只收前两样——**短评输入归 `field-row`（字段行）**（一件只做一件事，接缝在"这段文字归谁"）。
> ② 原型用隐藏的原生 `<input type="radio">` ＋ `:has()` 画星；落地改成 `<button role="radio" aria-checked>` ＋ 运行时漫游 `tabindex`（工单要求"每颗星是可聚焦的按钮并带 `aria-label`"，且按钮的命中盒能写死在 44×44）。
> ③ 原型那条「上次位置」的刻度轨落地时去掉：刻度位置只能靠内联 `style` 给，而本层不许内联样式；「上次」改由 `prevNote` 一句话承担。

## 何时用它（选型三条）

| 你要的 | 用 |
|---|---|
| 给一次记录打分（给菜打分、满意度、优先级） | **本件** |
| 一整段自由文字（咸淡、火候、下次还做不做） | `field-row`（字段行） |
| 五个档位各带一句词（「很差／一般／还行／好吃／很棒」） | `radio-cards`（单选卡组：那些词是**选项**，不是刻度） |

判据一句话：**分数是一个数** → 用它；**选项各有自己的词** → 用单选卡组。

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `name` | `string` | 必填 | 机器键（事件 `detail.name`）。**非空**；同页内唯一 |
| `label` | `string` | 必填 | 给什么打分（如「给番茄炒蛋打分」）。**非空**：没这句，星星读不出在评什么 |
| `value` | `number \| null` | `null` | 分数。`null` ＝ 还没评过（读数写 `—`，与「0 分」区分）。**只收整数或 `.5` 档** |
| `max` | `number` | `5` | 满档（几颗星）：**1–10 之间的整数** |
| `prevNote` | `string` | — | 上次对照那一句（`上次 09-18 给了 7 分`） |
| `hint` | `string` | — | 读数后的补充（如「折合 8 分」） |
| `required` | `boolean` | `false` | 必评（`aria-required`） |
| `disabled` | `boolean` | `false` | 不可评：星落 `disabled` ＋ `cursor: not-allowed` |
| `disabledReason` | `string` | — | 禁用原因（**写出来**，不只染色；只在 `disabled: true` 时给） |
| `loading` | `boolean` | `false` | 加载态：读数**原地换字**、星不可点（`aria-busy`） |
| `loadingText` | `string` | `正在读取` | 加载态那句字（只在 `loading` 时给） |
| `error` | `string` | — | 错态那句字（写在控件旁边 ＋ `aria-describedby` 指它） |
| `form` | `'stars'` | `'stars'` | 形态键（闭集；闭集外一律 `badInput`） |
| `extraClass` | `string` | — | 附加类名（空格分隔，逐个过类名正则） |

**入参违规一律抛 `BlocksError`（`bad-input`）**，不静默兜底：静默降级会让调用方以为已经生效。

## 契约与不变量（判据逐条断）

1. **每颗星是可聚焦的按钮**：`<button type="button" role="radio" aria-checked="true|false" aria-label="4 分">`，住在 `role="radiogroup"` 里；漫游 `tabindex`（选中的那颗 `0`，其余 `-1`）＋ 方向键／`Home`／`End` 由运行时给。
2. **星星之外必须给数字读数**：那枚数字走 `font-num` ＋ `tabular-nums`，字号 ＝ 正文档 × `RATING_ROW_NUM_SCALE`（2.2）⇒ 三套皮肤下都 ≥ 正文 1.5 倍、都 ≥ 星字形的 1 倍。缺值写 `—`。
3. **选中态不只靠颜色**：① 空心星 `☆` → 实心星 `★`（字形换了）；② 那枚大数字（字）；③ 颜色（`accent`）只是第三重。皮肤「大字报刊」下强调色＝墨黑 ⇒ 前两重是换皮不塌的那两重。
4. **半颗只影响显示**：`value: 4.5` ⇒ 前四颗实心、第五颗**左半实心**（`width: 50%` 裁切）；点／键盘选的是**整星**。
5. **触控目标 ≥44×44**：每颗星的命中盒 `RATING_ROW_STAR_PX`（44）。
6. **状态矩阵**：`rest`／`:hover`（包在 `@media (hover:hover) and (pointer:fine)` 里，且**不是唯一通路**）／`:active`（`scale(.98)`，≤80ms）／`:focus-visible`（2px 可见描边）／`disabled`（`cursor: not-allowed` ＋ 写出原因）／`loading`（读数原地换字、盒模型不动）／`error`（写在旁边 ＋ `aria-describedby`）／`empty`（`value: null` ⇒ 读数 `—`，那正是"还没评"的样子）。
7. **窄宽两档**：容器宽 390 与 1280 下**零横向溢出**；窄档调整走 `@container`（读数另起一行、左对齐）。
8. **不截断**：标题／读数／上次对照一律**换行**；样式段里没有 `text-overflow`／`line-clamp`／`white-space: nowrap`。
9. **样式只经 `skinVar()` 读皮肤**；不写 `:root`／`!important`；不定义新 token 名；全部规则 scope 在 `.<prefix>page-ui` 之下。
10. **零 DOM／零内联脚本**：模块代码剥掉字面量与注释后不出现 `document.`／`window.`／`navigator.`（DOM 只出现在 `buildRatingRowJs()` 产出的文本里）；标记里没有 `<script>`、没有 `on*=`。

## 交互契约（运行时，`buildRatingRowJs()`）

| 动作 | 行为 |
|---|---|
| 点第 N 颗星 | 分数＝N（整星）；`aria-checked`／`☆★`／大数字**同一趟**刷新；派发 `ilife:rating-change` |
| 方向键 ←／→／↑／↓ | 移动并**随即选中**（`role="radio"` 该有的那一套）；`preventDefault`（页面不跟着滚） |
| `Home`／`End` | 到第一颗／最后一颗（同样随即选中） |
| 点已选中的那颗 | 什么也不发生、不派发（避免"点了但其实没改"触发联动） |
| 禁用／加载中 | 不响应（按钮自己也落 `disabled`） |
| 重复注入 | 只绑定一次（根上 `data-ilife-rating-runtime`） |
| 不跑脚本 | 星与读数按标记里画好的那一份显示（可读），只是不能改 |

事件（冒泡 `CustomEvent`，`detail`）：
```ts
'ilife:rating-change' → { name, value, prev }   // value 是新分数（整星），prev 是改前分数（可能是 null）
```

**清空不做成手势**：本件不提供"再点一次取消评分"这类隐藏手势（没人发现得了）；`value: null` 的入口在**入参面**（页面重渲染即可）。

## 常见错法（别这么干）

- ❌ 只给星星不给数字：读的人分不出「4 分」与「4.5 分」→ ✅ 那枚大数字是形态的一部分，不是装饰。
- ❌ 用 `<span>`／`<i>` 画星再挂 `onclick`：键盘到不了、读屏读不出 → ✅ 每颗星是 `role="radio"` 的**按钮**，带 `aria-label="N 分"`。
- ❌ 选中态只把星染成强调色：皮肤「大字报刊」下强调色＝墨黑 → ✅ 空心／实心（形状）＋ 大数字（字）。
- ❌ 用 `value: 0` 表达"还没评"：0 分与没评过是两件事 → ✅ `value: null`（读数 `—`）。
- ❌ 把「咸淡、火候」这类自由文字也塞进本件：那是字段行的事 → ✅ 文字归 `field-row`。
- ❌ 允许 `3.7` 这种分值：星星画不出来那个精度，画出来的和机器值对不上 → ✅ 只收整数或 `.5` 档（当场 `badInput`）。

## 关系

- 与 `radio-cards` 的分工：那件的每个选项各有自己的**词**（很差／一般／好吃）；本件是一条**刻度**（几颗星 ＋ 一个数）。
- 样式与运行时由页面按需挂（加法式：不调 `ratingRowCss()`／`buildRatingRowJs()`、不挂 `.ilife-page-ui` 的页零命中）。
- 评分落库归**技能命令**：本件只派发事件（页面接事件后自己决定要不要写）。
