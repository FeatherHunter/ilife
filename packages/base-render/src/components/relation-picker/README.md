# relation-picker · 关系选择器

**一句话**：从库里已经存在的实体里**选一个**——字段行读当前值，点开是「搜一行 ＋ 最近用过 ＋ 全部 ＋ 末行新建」；搜不到时末行就是把搜索词直接建成新的，不用退出去先建好再回来选。

它替掉的错法：几十个按拼音排、最常用的每次都得滚下去找；库里还没有的时候只能退出去先建好再回来选。

**形态**：本件落地**两档**——出处＝原型墙 `.scratch/ui-组件墙/新件/parts-交互与流程.mjs` 第 90 件（2026-09 用户逐格打分，两档 4/4/4），按层规重写（原型是一次性代码：无判据、无错误处理、读的是墙稿变量）。形态键住 `RELATION_PICKER_FORMS` 闭集（`overlay`／`inline`，英文键）——**加第三形态是在闭集里加一格，不是新开一件**；闭集外的值一律报 `BlocksError`。

| 形态键 | 原型 | 骨架 |
|---|---|---|
| `overlay` | A「浮层：搜索 ＋ 最近用过 ＋ 全部 ＋ 新建」 | 字段行一枚触发键，点开是一块顶层浮面（原生 `popover`）：搜一行 ＋「最近用过」一组 ＋「全部」一组 ＋ 末行「新建」 |
| `inline` | B「行内展开（不浮层）：先选源，选完收成一行读得出来的结果」 | 不浮层，整块在字段行下面推开：最近一排 ＋ 可搜的列表 ＋ 末行「新建」；选完收成一行结果（✓ ＋ 选了什么 ＋ 一枚真按钮「换」） |

用在哪：记账（选账户） · 居家管家（选位置／物品） · 私家大厨（选菜谱／主料） · 卡路里（选食品）。

## 何时用它（选型四条）

| 你要的 | 用 |
|---|---|
| 从库里越来越多的数据里**选一个已经存在的实体**，兼给「最近用过」与「搜不到就地新建」两条路 | **本件** |
| 一次勾一批（多选弹层 ＋「完成 N 项」） | `drawer-sheet` |
| 页面级的搜索框：搜完还得再去点结果行（作用域＝当前这一列） | `search-field` |
| 选项是写死的几个（不是从库里长的） | `radio-cards` |

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `id` | `string` | 必填 | 机器键（浮面 `id`、行内 `id` 与事件 `detail.id` 都拿它拼）。**非空、同页唯一、只许标识符字符**：同页摆多份本件时，每份给一个不同的值（浮面 `id` 与全部 `aria-*` 都由它派生） |
| `label` | `string` | 必填 | 字段标签（`账户`／`物品放在哪儿`）。**给了就不能只有空白** |
| `options` | `RelationPickerOption[]` | 必填 | 全部选项（顺序＝「全部」组里的顺序；**至少一项**） |
| `recentKeys` | `string[]` | — | 「最近用过」那几项的机器键（`options` 的子集，**至多 6 项**；顺序＝屏上顺序）。不给＝不出这一组 |
| `selectedKey` | `string` | — | 当前选中的机器键（必须命中一项；给了＝字段行读它的名字、列表里那一行是选中态） |
| `query` | `string` | — | 搜索框里的初值：渲染期就按它筛一遍（不给＝空，列出全部）。首尾空白一律去掉 |
| `allLabel` | `string` | `全部` ＋ `label` | 「全部」组名的字。给了就不能只有空白 |
| `readingLabel` | `string` | — | 读数列的列头（如`余额`）。给了＝`overlay` 下出列头行；给了就不能只有空白 |
| `newPrefix` | `string` | `没找到？` | 末行新建排前面那句。给了就不能只有空白 |
| `emptyText` | `string` | 按搜索词现拼 | 空态那句的定制版。给了就不能只有空白 |
| `hint` | `string` | — | 卡底那句提示。给了就不能只有空白 |
| `error` | `string` | — | 错态：写在输入框下边那一行，并由输入框的 `aria-describedby` 指到它 |
| `open` | `boolean` | — | 只在 `inline` 下有意义：选中有值时行内那块缺省收起，给 `true`＝硬摊开 |
| `form` | `'overlay' \| 'inline'` | `'overlay'` | 形态键（闭集；闭集外一律 `BlocksError`） |
| `extraClass` | `string` | — | 附加类名（空格分隔，逐个过类名正则） |

**行（`options` 的每一个元素）**

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `key` | `string` | 必填 | 这一行的机器值（点它时原样送出）。**只许标识符字符**，表内唯一 |
| `title` | `string` | 必填 | 名字（`招行储蓄卡`）。**非空、且不能只有空白**；命中词在这里被标出来；长了**换行**，绝不 `…` 截断 |
| `note` | `string` | — | 副语，一行一句人话（`上次 09-24，记了 3 笔`）。给了就不能只有空白 |
| `reading` | `string` | — | 行右端读数（余额／件数，**已经是给人看的样子**）。**永不 `…` 截断**。给了就不能只有空白 |

**入参纪律（两条，判据逐条断）**：

1. **上屏的文字全空白＝拒**（`badInput`）：`'   '` 会在屏上留一块**看得见的空白**。空串＝未给（与全层 `optText` 同口径），**只有空白＝拒**。**一处例外说清**：`query` 是**搜索词**（不上屏的字），首尾空白一律去掉、只有空白＝未给。
2. **入参表以外的键一律拒**；**引用必须命中**：`recentKeys` 的每一项与 `selectedKey` 必须在 `options` 里有这一项；`recentKeys` 至多 6 项、键不许重。

## 契约与不变量（判据逐条断）

1. **开与关不靠脚本**（`overlay`）：触发键带 `popovertarget`、浮面是原生 `popover`（`popover="auto"`）⇒ 运行时段一行都没跑到，浮面照样开、照样关；**点浮面外那一下**也是浏览器给的 light dismiss。`inline` 下行内那块渲染时就摆在那里（没选＝摊开，有选＝收起）。
2. **整行就是那颗按钮**：一行 ＝ 一枚 `<button>`。命中盒＝整行（≥52 高、通栏），相邻两行之间留 8px 缝；触发键、清空键、新建键、「换」与最近一排每一枚都 ≥44×44。
3. **零键帽**：标记与文案里没有方向键／`Tab`／`Esc`／快捷键这一路，也**没有把它们当通路**——搜索框可打字，但不点键盘也选得完（点行即选），`:focus-visible` 只是给真实键盘用户的无障碍地板。
4. **选中两头同时可见**：字段行读当前值（`data-ilife-relation-value`，运行时选中一变就重写它）、列表里那一行挂 `is-on` ＋ `aria-current="true"`；选中态是**整行选中**那一档（次要面底 ＋ 左侧 2px 主色标）＋ 实心 ✓（无文字的点＝主色实底）＋ 行尾「已选」二字（没选的写「选它」）——色之外还有形与字。
5. **输入即筛只改 `hidden`**：`data-ilife-relation-search` 是这一行的可搜底串（名字 ＋ 副语 ＋ 读数，小写），运行时段只翻每一行自己的 `hidden`，**不重排 DOM**（重排会把输入法打断）；一组的行全不露时，那一组的标题也收起来；新建键的值与字按当前词重写。
6. **脚注与空态是真读数**：脚注按「空输入／命中几条／一条没中」三档现算，空态那句把用户打的词夹在中间（`data-ilife-relation-query` 的 `hits` 也按同一个数派发）。**空输入时列的是常用去处**（「最近用过」排最前）。
7. **命中词不只靠颜色**：`<mark data-ilife-relation-hit>` 的形是下划线、字是加粗；重画走 `createElement('mark')` ＋ `textContent`，**不碰 `innerHTML`**（用户打的词永远进不了标签）。
8. **搜不到就地新建**：末行那枚键的值＝当前搜索词（`data-ilife-relation-create`），点它派发 `ilife:relation-picker-create`（`detail={id,value}`）；本件不写库，只报「要建什么」。
9. **样式只经 `skinVar()` 读皮肤**：源码里不写 `var(--ilife-…)`；不写 `:root`／`!important`；不新增 token 名；全部规则 scope 在 `.<prefix>page-ui` 之下。
10. **宽度只许容器判**：根本身声明 `container: ilife-relation-picker / inline-size`，窄档（本件 <560px）收的是行内左右内边距与那两道缝（**列一道也不折**——列表本来就是单列）；媒体查询只判设备能力（悬停增强、`prefers-reduced-motion` 的减动效），**一条视口宽度查询都没有**。名字与数量**永不 `…` 截断**（超长换行）。
11. **同页多实例分得开**（`id`）：浮面 `id`、行内 `id` 与全部 `aria-*`（`aria-controls`／`aria-describedby`）都按 `id` 派生（`wizard-shell` 同一处教训：同页两份实例若同名，单选组互踢、行内 `id` 重号）。
12. **加法式**：不挂本件事的页面零命中、逐字节不变；本件只读自己的类名（`ilife-block-relation-picker-*`），不碰公共选择器。
13. **用词纪律**：本件自己上屏的字里不出现 `·`／`；`／三段并列顿号（仓库分隔符门对可见文本零豁免）；调用方给的 `note` 里若有，由调用方负责。

## 常见错法

- **把入口做成隐式**（「按某个键出浮面」）——手机上等于没有这个功能；触发键必须是字段行里看得见的一枚键；
- **选中只换底色**——一行里要同时给出 ✓ 实心记号、整行描边与左侧标、行尾「已选」二字（没选的写「选它」）；
- **字段行与列表各读各的**——字段行读的值与列表里选中的必须是同一项（运行时选中一变，字段行那一格原地重写）；
- **`inline` 下选完还摊着**——选完必须收成一行读得出的结果（✓ ＋ 选了什么 ＋ 一枚真按钮「换」），「换」是一颗真按钮（44×44），不是一行带下划线的字；
- **拿它当多选**（一次勾一批）——那是 `drawer-sheet`；**拿它当写死的几个选项**——那是 `radio-cards`；
- **一页放两份不给不同的 `id`**：浮面 `id` 重号，点哪枚键开哪一块就分不清了。

## 接线（页面侧）

```html
<!-- 样式段与标记：relationPickerCss() ＋ renderRelationPicker(input)；外层挂 .ilife-page-ui 与皮肤类 -->
<script>/* buildRelationPickerJs() 产出的那段文本 */</script>
<script>
  document.addEventListener('ilife:relation-picker-select', (e) => {
    const { id, key, title } = e.detail;   // 浮面已收起（overlay）或已收成结果行（inline）
    if (id !== 'pay-account') return;
    saveAccount(key);                       // 真正写库归页面／技能命令
  });
  document.addEventListener('ilife:relation-picker-create', (e) => {
    const { id, value } = e.detail;        // 用户要建什么（当前搜索词）
    if (id !== 'pay-account') return;
    createAccount(value);
  });
  document.addEventListener('ilife:relation-picker-query', (e) => {
    const { query, hits } = e.detail;      // 要接服务端搜就在这里取
  });
</script>
```

**有意偏离原型的地方**：

| 原型里是 | 落地是 | 为什么 |
|---|---|---|
| 行间一条 1px 发丝线 | 行间 8px 缝 | 相邻触控目标间距 ≥8px（工艺书地板）；结构（搜索 ＋ 最近 ＋ 全部 ＋ 新建）一个字没动 |
| 选中行只有底色（A）／3px 左竖锚 | 次要面底 ＋ 左侧 **2px** 主色标 ＋ 实心 ✓ ＋ 行尾「已选」二字 | 「整行选中」那一档的法条口径（`选中态与皮肤语言.md` 第三节；原型写 3px，落地按法条收窄）；选中不只换底色 |
| 浮面画在页面里（假底页 ＋ 遮罩） | 浮面住**顶层**（原生 `popover`） | 开合／点外面关掉都不用脚本，**遮罩**由浏览器给（`::backdrop`）；与 `command-palette` 同一处手法 |
| 新建两枚键（「新建账户／新建并记这笔」） | 一枚键（把当前搜索词直接建成新的） | 第二枚「新建并记」是记账页自己的动作，不是选择器的活（铁律五：接口小）；要几个新建入口由页面在 `create` 事件后自己接 |
| 行尾「已选／选它」只在 B 有 | `inline` 列表里有，`overlay` 浮面里没有（浮面用 ✓ ＋ 整行选中态） | 浮面行已有四条轨（记号 ＋ 名字 ＋ 读数），再加一枚会把名字挤窄；两头可见由字段行那一头承担 |
