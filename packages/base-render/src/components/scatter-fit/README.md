# scatter-fit · 相关性散点

**一句话**：两个读数放在一张图上——点是一片云、趋势是一条线、带子是「大概率的范围」；
**三个形态**（`scatter` 散点＋拟合线／`bin` 分箱趋势带／`lag` 滞后相关）问的是同一个问题：
**这两个读数之间是什么关系**。

它替掉的两种错法：**只给一个相关系数**（看不出是结构，还是离群点拉出来的）与
**用两根并排柱冒充关系**（那是同一个指标的两个值，不是两个指标的关系）。

## 何时用它（选型四条）

| 你要的 | 用 |
|---|---|
| 「两个指标有没有关系、关系有多强」 | **本件** |
| 「同一指标左右两柱对照」 | `compare-columns`（双列对照，同族） |
| 「一个指标排序」 | `rank-list`（榜单，同族） |
| 「两个纬度切成格子的浓淡」 | `heat-grid`（热力格，同族）——它读不出单个点，也读不出一条趋势 |

用在哪：卡路里（摄入 vs 体重）／作息管家（睡眠 vs 训练）／记账（金额 vs 频次）。

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `title` | `string` | 必填 | 卡头标题（`体重 vs 每日摄入`） |
| `xName` | `string` | 必填 | 横轴那个读数的名字（刻度、图例与无障碍名都要用它） |
| `yName` | `string` | 必填 | 纵轴那个读数的名字 |
| `xUnit` | `string` | — | 横轴单位，**只写在第一枚刻度上**；不给＝刻度只有数字 |
| `yUnit` | `string` | — | 纵轴单位（同上） |
| `stamp` | `string` | — | 卡头那枚时间窗（`近 30 天`）；不给＝不出 |
| `form` | `'scatter'`／`'bin'`／`'lag'` | `'scatter'` | 形态闭集；闭集外报 `BlocksError` |
| `points` | `ScatterFitPoint[]` | 形态 `scatter` 必填 | 成对的读数（**1–120 条**；只有一条也照画，只是画不出趋势线） |
| `bins` | `ScatterFitBin[]` | 形态 `bin` 用 | 分箱（**2–8 箱**，每箱至少 5 个样本） |
| `lags` | `ScatterFitLag[]` | 形态 `lag` 用 | 滞后各档（**2–6 档**，错开天数严格递增、最大 5 天） |
| `note` | `string` | 本形态的口径句 | 脚注一句人话；**给了就整句替换**那条例行口径 |
| `extraClass` | `string` | — | 附加类名（空格分隔，逐个过类名正则） |

**文本字段的口径**：可选文本（`stamp`／`xUnit`／`yUnit`／`note`／`label`／`outlier`）**空串＝未给**
（与全层 `optText` 同口径，`outlier: ''` 不算点名）；但**全空白串一律拒**（`'   '` 会在屏上留一块空白，
与同层 `optExtraClass` 对空白串的口径一致）——必填的 `title`／`xName`／`yName`／箱 `label` 同办。

**点（`points` 的每一个元素）**——形态 `scatter` 用

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `x` | `number` | 必填 | 横轴值（有限数） |
| `y` | `number` | 必填 | 纵轴值（有限数） |
| `label` | `string` | — | 点名（如 `08-30`）：写进这一点的 `title` |
| `outlier` | `string` | — | **离群点的原因**（如 `08-30 聚餐：一餐 1,400 卡`）：给了就画成圈并写进图例 |

**箱（`bins` 的每一个元素）**——形态 `bin` 用

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `label` | `string` | 必填 | 箱标签（`＜5.5h`），**永不换行截断**（它是这一箱的坐标） |
| `low` | `number` | 必填 | 下四分位（P25） |
| `median` | `number` | 必填 | 中位数（须满足 `low ≤ median ≤ high`） |
| `high` | `number` | 必填 | 上四分位（P75） |
| `count` | `number` | 必填 | 这一箱的样本数，**至少 5** |

**档（`lags` 的每一个元素）**——形态 `lag` 用

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `step` | `number` | 必填 | 错开的天数（0 当天，整数 0–5，**严格递增**） |
| `r` | `number` | 必填 | 这一档的相关系数（−1…1） |

## 契约与不变量

**读数两条闸**：① 非有限（`NaN`／`±Infinity`／数字串）⇒ 当场报错；② **可加性溢出**——
`|a| + |b| > Number.MAX_VALUE`（两笔同量级的读数相加就成 `Infinity`，轴上会写出 `1e+308`）⇒ 同样报错。
判据是**相加会不会溢出**，不是"好不好读"：`1e21` 与 `1e-7` 这类照旧合法。
「轴域算不出来」（跨度溢出，住 `scale.ts` 的 `niceAxis()`）是**另一档**，两档都在。

- **坐标只有一处算**：`scale.ts` 的 `upPct()` 把数据映射成 3%…97% 的百分比（轴内距 3%），
  点的 `bottom`、区间条的 `bottom ＋ height`、拟合线与概率带的多边形**都从它出**；
  轴域（上下界与小数的位数）与**刻度文字**也从同一个轴域出 —— 而且**轴顶恒等于顶刻度**
  （`loNice ＋ (ticks-1) × step`，不是取整后的另一个数）⇒ 读者按刻度读点，读出来的就是那个读数。
- **相关系数与那句强度是算出来的**：最小二乘拟合 ＋ 皮尔逊 r（0.62 一档写「中等相关」，
  与原型墙同口径）。x 全相同／y 全相同／只有一个点时 r **无定义**，那时写 `—` 并说明原因
  （不编一个 0 出来），**并且不画拟合线与概率带**（一条常数线会被当成趋势），脚注也换成"只画点"的说明。
- **概率带＝80% 带**（残差标准差 × 1.2816 的 z 值，往拟合线上下各让开一半），样本 ≤ 2 时带宽为 0。
- **离群点由调用方点名**：`outlier` 写清原因，件里只负责画成圈（形）＋ 写进图例（字）；
  **本件不自己判「哪个点算离群」**——那是统计口径，不该藏在组件里。
- **分箱每箱至少 5 个样本**（`SCATTER_FIT_BIN_MIN_SAMPLE`）：不足的箱**当场报错**，让调用方先合箱，
  不画一根说明不了事的条。
- **滞后最大错开 5 天**（`SCATTER_FIT_MAX_LAG_DAYS`）；最强那一档是「有文字的选中面」：
  `accent-soft` 底 ＋ `accent-text` 字 ＋ `accent` 侧标，并再写一遍「最强」两个字。
- **色不是唯一信息**：刻度给数字、图例给形与字、点带 `title`、无障碍名写清点数／离群点数／相关系数。
- **窄档不靠横滑**：坐标框是「纵轴刻度列（`max-content`）＋ 图区（`minmax(0,1fr)`）」，
  分箱每列 `flex: 1 1 0`，散点的刻度行内容塞不下就**换行**（不把每一枚压成一列竖字）；
  会随调用方文本变长的那几个槽（`stamp`／`tail`）是 `flex: 0 1 auto` ＋ `min-width: 0` ＋
  词内可断行 ⇒ **内容再长也不撑宽容器**。窄容器阈值只有一处来源
  （`SCATTER_FIT_NARROW_PX`，两份样式文件读同一个常量），窄档只把图矮一档、点小一档，
  **不减列、不藏 `overflow-x`**。
- **本件没有可点元素、没有运行时段**：纯静态图（无 `runtime.ts`）；页面不带它时零命中、逐字节不变。
- **样式只有一份出口**：`scatterFitCss()` 是唯一的样式入口；它汇总同目录 `style.ts`（卡壳／坐标框／散点／图例）
  与 `style-forms.ts`（分箱段／滞后段）两份源码件——**拆分只为行数**（一次落三个形态，一段装不下，本包告警线 350；
  先例 `date-range` 的 `style-calendar.ts`），取值一个字节都没变。
- **用词纪律**：本件生成的字里不出现 `·`／`；`／并列顿号（仓库分隔符门对可见文本零豁免）。
  `xUnit`／`yUnit` 会进可见文本，**建议写中文**（写「公斤」而不是 `kg`），
  免得撞上渲染面文字门对英文裸词的那条。

## 常见错法

- **只给相关系数、不给点** ⇒ 看不出是结构还是离群点拉出来的（本件就是为此把点、线、带子一起画）；
- **点数不对**：`points` 空数组（一条都没有）当场报错；只有 1 条照画，但**画不出趋势线**（脚注会说明）；
  超过 120 条请调用方先聚合；
- **自己判离群点、把异常值悄悄删掉** ⇒ 本件要求点名（`outlier` 写原因），并在图例里逐个写出来；
- **拿 `bin` 当条形图用**：箱里的竖条是**下四分位到上四分位**，不是「这一箱有多少」——
  要"各箱多少"走 `rank-list` 或 `stacked-bar`；
- **形态与字段对不上**：选了 `form: 'bin'` 却没给 `bins`（或给了空数组）会当场报错，不静默降级；
- **一箱只放两三天**：样本太薄，本件当场拒收（先合箱，再画）；
- **滞后错开 ≥ 6 天**：样本会薄到说明不了任何事，本件不画；
- **拿全空白串当标题**：`title: '   '` 会在屏上留一块空白，本件当场拒收。

## 判据（`test/scatter-fit.test.mjs`）

① 渲染契约：三形态各自的槽位与枚数／**刻度与坐标同一份真值**（从**印出来的刻度**反推轴域，
再把每个点的坐标对回它自己的读数——轴域不整齐的样例也在里面）／r 算不出时**不出线与带**／
三形态的缺槽分支／转义面／**全部**非法入参分支（每个都断 `BlocksError`）；
② 样式与零 DOM 纪律（scope 恰一次、零 `@media` 宽度查询、零颜色字面量、零手写 `var(--ilife-…)`、
零键盘语汇、零可点元素、窄档阈值只有一处来源）；③ 加法式（不开＝逐字节不变）；
④ **三档几何**（真机 headless Chrome ＋ CDP：容器 **320**／390／1280 下零横向溢出、点全在框内、
刻度零截断；另带长口径／长轴名两种压力样例；起不来则退确定性几何判据并打印原因）；
⑤ 皮肤纪律（四套皮肤下标记逐字节相同、样式段不写死取值，真机上最强档取 `accent-soft`／`accent-text`）。

## 关系

- 与 `heat-grid` 的分工：那是矩阵浓淡（读不出单个点、也读不出趋势），本件按真实数值定位；
- 与 `compare-columns` 的分工：那是同一指标的左右两柱，本件问的是两个指标之间的关系；
- 与 `rank-list` 的分工：榜单把一个指标排序，本件不排序。
