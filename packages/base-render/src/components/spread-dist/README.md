# spread-dist · 分布与分位

**一句话**：一批读数摊开成形状——**一行一组、同一把尺子横着量**（箱体＝P25 到 P75、粗线＝中位、
圈＝离群点，A 档），或者**每天一根从最低到最高的竖条，中间的粗块是当天的中位数**（B 档），
或者**从 P10 到 P90 一档一格写着那个数，结论一句话在读数上面**（C 档）。

**形态**：本件落地**原型墙 no.65 的三档**（出处＝`.scratch/ui-组件墙/新件/parts-数据与仪表.mjs`，
2026-09 用户逐格打分：B 档 4/4/4、C 档 4/4/4；**A 档箱线第一轮 3/3/3**，
砍过文字之后这一轮复看**改口全认可** ⇒ 补落）：

| 档 | 形态键 | 骨架 | 读法 |
|---|---|---|---|
| A | `box` | 箱线（多组并排，横排） | 沿**分组**并排看一遍：哪一组的中间那批落在哪、谁拉得长、谁有离群点 |
| B | `range` | 逐日范围柱（中位＋区间，时间轴） | 沿**时间**逐日看一遍：哪天的读数散得开、哪天中间那批落在哪 |
| C | `quantile` | 分位尺（P10/P25/P50/P75/P90 各是多少） | 沿**分位**一次读完：一半落在哪、最上面那一档从哪起 |

形态键住 `SPREAD_DIST_FORMS` 闭集（`range`／`quantile`／`box`；**旧两档的键一个字都不许改**，
新档追加在后面；`A`／`B`／`C` 是原型墙的格号，不是接口名）。
**A 档的落地口径＝用户打 4 分的那一版原型（砍过文字的那版）**，逐条：
单位只印一次（卡头右端一个 `元`，刻度值不再逐枚带单位）／图例只有三项
（`P25–P75`／`离群`／`单笔`，**「中位数」那一条删掉**——行头已各印一次「中位 NN」，同屏重复的不留）／
**行头一行一档字号**（组名／笔数／中位同行同号，不再是"灰字组名 ＋ 大号中位"两行）。
**C 档的正例给三档**（`P10`／`中位`／`P90`）——用户打 4 分的那一版就是**三张卡并排**，`P25`／`P75` 是
**容量**（档数上限七档），不是默认样子：窄容器里五张卡要折成三行，读起来比三张卡挤。
三档问的是**同一个问题**——「这一批读数摊开是什么形状、分位在哪」——只是读法不同，
所以是**一件的三个形态**，不是三件（「形态是骨架，不是地址」）。

它替掉的两种错法（原型那一件的 `p` 那两句）：**只给平均值**（把离群点抹平，读不出「中间那批落在哪」）
与**用一张条形图硬扛分布**（一根柱只表示一个数，那是「几个值的对比」，不是一批读数的形状）。

## 何时用它（选型四条）

| 你要的 | 用 |
|---|---|
| 「几组读数并排比一比，各自中间那批落在哪、谁有离群点」 | **`box`（本件）** |
| 「这一批读数最低到最高散在哪、中间那批落在哪、一天一天怎么走」 | **`range`（本件）** |
| 「分位各是多少」（`P10`／`中位`／`P90` 这样几档读数） | **`quantile`（本件）** |
| 「一期之内的名次」（谁第一谁第二） | `rank-list`（榜单） |
| 「两个读数之间的关系」（点云＋拟合线） | `scatter-fit`（相关性散点） |
| 「同一个读数跨几期怎么变」（一期一根柱，柱高是那一期的量） | `small-multiples`（小倍数面板） |
| 「一整块怎么分成几份」（构成） | `stacked-bar`（构成条） |
| 「两个纬度切成格子的浓淡」（格内没有形状） | `heat-grid`（热力格） |

用在哪：六个技能都用。原型点名三处——**记账**（单笔金额分布）／**卡路里**（七天摄入波动）／
**作息管家**（入睡时刻分布）。横轴不限「周一到周日」：`label` 给什么就写什么（`09-12` 这类日期照收）；
A 档的组名也不限（`餐饮`／`工作日`／`深睡段`都由调用方给）。

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `title` | `string` | 必填 | 卡头标题（`本月单笔金额分布`）。**非空**，全空白当场报错 |
| `boxes` | `SpreadDistBox[]` | —（`box` 形态必须给） | 各组读数（**1–8 组**，顺序就是屏上的顺序；一组一行） |
| `days` | `SpreadDistDay[]` | 必填（`range` 是缺省形态） | 逐日读数（**3–12 天**，顺序就是横轴上的顺序） |
| `stops` | `SpreadDistStop[]` | —（`quantile` 形态必须给） | 分位各档（**正例三档**；容量 **3／5／7 档**，偶数档当场报错） |
| `form` | `'range'` \| `'quantile'` \| `'box'` | `'range'` | 形态闭集；闭集外报 `BlocksError` |
| `unit` | `string` | — | 读数单位（`元`／`卡`）：`range`／`quantile` 写进刻度与每一档的读数里，**`box` 只印在卡头右端一次**。**建议写中文** |
| `stamp` | `string` | — | 卡头那枚口径（`38 笔`／`每日 3 餐`）；不给＝不出 |
| `note` | `string` | 本件算出来的口径句 | 脚注一句人话；**给了就整句替换**那句口径 |
| `extraClass` | `string` | — | 附加类名（空格分隔，逐个过类名正则） |

**一组（`boxes` 的每一个元素 · 两种读法二选一）**

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `label` | `string` | 必填 | 组名（`餐饮`／`工作日`）：上屏在行头，**永不 `…` 截断**（长了换行）。**不许与别的组同名** |
| `count` | `number` | 必填 | 这一组有几笔（**正整数**）：上屏在行头（`18 笔`）。**画箱那一支要求 ≥ 5** |
| `median` | `number` | 必填 | 这一组读数的中位数（有限数）：行头印「中位 NN」，轨道上是那条粗线 |
| `low` / `q1` / `q3` / `high` | `number` | **画箱必填** | 五数概括（须的两端 ＋ 箱体的两端）：**要么全给、要么全不给**；须满足 `low ≤ q1 ≤ 中位 ≤ q3 ≤ high` |
| `outliers` | `number[]` | — | 只在**画箱**那一支许给：每一枚都必须落在 `low` 与 `high` **之外**（须里的点不是离群点） |
| `points` | `number[]` | **样本不足那一支必填** | 单笔读数：**每一笔点都点在尺子上**，个数必须正好等于 `count` |

**一天（`days` 的每一个元素）**

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `label` | `string` | 必填 | 日子（`周一`／`09-15`）：上屏在横轴，**永不 `…` 截断**（长了换行） |
| `low` | `number` | 必填 | 当天最低那个读数（有限数：`NaN`／`Infinity`／数字串一律拒） |
| `high` | `number` | 必填 | 当天最高那个读数；须满足 `low ≤ high` |
| `median` | `number` | — | 当天读数的中位数；**不给＝那一天只画区间**（中位块不出，`title` 里写 `—`） |

**一档（`stops` 的每一个元素）**

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `name` | `string` | 必填 | 分位名（正例 `P10`／`中位`／`P90`；也接受 `P25`／`P75` 这类写法）。**不许与别的档同名** |
| `value` | `number` | 必填 | 这一档那个数（有限数）；**必须随档名递增**（分位本来是单调的） |

可选的文本字段（`unit`／`stamp`／`note`）**空串＝未给**（与全层 `optText` 同口径）。

### 三个形态各一份示例入参

`box`（箱线 · **多组并排**）：

```js
renderSpreadDist({
  title: '本月单笔金额分布', stamp: '38 笔', unit: '元', form: 'box',
  boxes: [
    { label: '餐饮', count: 18, median: 58, low: 3, q1: 32, q3: 96, high: 190, outliers: [205, 260] },
    { label: '日用', count: 7, median: 128, low: 16, q1: 60, q3: 160, high: 300, outliers: [340, 378] },
    { label: '交通', count: 9, median: 12, low: 3, q1: 6, q3: 42, high: 62 },
    { label: '其他', count: 4, median: 240, points: [88, 150, 330, 466] },
  ],
});
```

最后那一组只有 4 笔：**不到 5 笔的组不画箱**（箱体的形状在这个样本量上是假的），
把 4 笔直接点在尺子上；`count` 必须正好等于 `points` 的个数（漏画一笔，行头那个数与屏上就对不上）。

`range`（逐日范围柱 · 缺省形态）：

```js
renderSpreadDist({
  title: '七天摄入波动', stamp: '每日 3 餐', unit: '百卡',
  days: [
    { label: '周一', low: 14, median: 38, high: 62 },
    { label: '周二', low: 18, median: 34, high: 58 },
    { label: '周三', low: 10, median: 52, high: 82 },
  ],
});
```

`quantile`（分位尺 · **正例三档，照用户打 4 分的那一版**）：

```js
renderSpreadDist({
  title: '单笔金额分位', stamp: '38 笔', unit: '元', form: 'quantile',
  stops: [{ name: 'P10', value: 18 }, { name: '中位', value: 58 }, { name: 'P90', value: 320 }],
});
```

正中那一档写 `中位` 时**不给说明句**（那句「一半的读数不超过它」已经在上面那句结论里了）；
写成 `P50` 才多一行「不超过它的读数占 50%」。两种写法都合法，说明句随档名走。

上面三段是给人读的三个形态；**机器吃的那一份是下面这一个**（皮肤矩阵判据拿它渲染本件，
必须能**直接**渲染成功）——按类型派生的样例给不出「`stops` 档数必须是奇数」这条约束（数组恒只给一个元素），
故本件显式写一份：

## 契约与不变量（判据逐条断）

1. **刻度与轴域是同一份真值**（这一条是本件的头号几何契约）：轴域由「最低那个读数」与「最高那个读数」
   撑成整档（轴底＝`floor(最低/步长)×步长`、轴顶＝`ceil(最高/步长)×步长`），**刻度枚数由这两头反算**；
   刻度**文字**、刻度**位置**、每根范围条的 `bottom`／`height`、每个中位块的 `bottom`
   **全都从这一个轴域出**（`scale.ts` 的 `upPct()` 是唯一的坐标映射）。
   判据**从印出来的刻度反推轴域**，再把每一根条与每一个中位块逐点对账 ——
   读者按刻度读一根柱，读到的是这根柱真正的数。
   **A 档同一条、只是横过来**：贯穿行区的网格线、尺子上那几枚刻度、每一行的须／箱体／中位粗线／点，
   全部读**同一个** `upPct()`；判据照样从印出来的刻度反推轴域，再把须的左端与宽度、箱体的左端与宽度、
   中位线、每一枚离群圈与单笔点逐点对账。真机读数：每枚刻度中心差 **0px／0.5px**（首末两枚贴端）、
   网格线与刻度逐枚对齐 0px、**行的中位线**与尺子读出来的位置差 **0px**。
2. **不做轴内距**：数据直接落在轴上（轴底刻度＝底轴、轴顶刻度＝轴顶）。柱是矩形，压到轴上不会像散点的圆那样
   出框，故不需要内距；首末两枚刻度各平移半个字高把**中心**对到上沿与下沿（真机读数：差 0px）。
   A 档的横轴同理：首末两枚刻度与网格线**贴端**（`is-first`／`is-last` 那条规则），
   中心差 0.5px，容器一根毫毛都不多长（0.5px 的居中会让最窄档多出 1px 横溢）。
3. **缺值写成 `—`**：某一天没给中位数时，那一格只画区间，中位数写 `—`，
   **不拿最低或最高顶替**（顶替＝把「中间那批落在哪」编出来）；脚注里也说这句。
   A 档同理：**样本不足 5 笔的组不画箱**（箱体的形状在这个样本量上是假的），
   只把每一笔点在尺子上，行头照实写「中位 NN」——不编一个箱出来。
4. **色不是唯一信息，且只从强调色系出**：范围条是强调色 22% 的**淡洗**（面）、中位块是强调色**实底**（条）
   —— 一深一浅两种形 ＋ 图例给字；分位尺正中那一档是「**有文字的选中面**」⇒ 底 `accent-soft`、
   字 `accent-text`、描边 `accent`（三样同时在）。A 档是**四种形**（箱体＝面、中位＝3px 粗线、
   离群＝空心圈、单笔＝实心点）＋ 图例三项，四种形不相同也看得清。**没有一处拿正文墨色当"面"**，
   也不写死任何色值。
5. **本件不带可点元素、不带脚本**（没有 `runtime.ts`）：纯静态图没有需要运行时才能发生的交互。
   调用方若把某一天／某一档包成入口，件里那条 `:focus-visible` 地板保证焦点看得见；
   命中盒的成立条件见「常见错法」最后两条（真机读数在下面第 7 条）。
   **A 档零可点元素 ⇒ 命中盒（≥44×44）与相邻间距（≥8px）两条不适用**：那是「有可点目标」才量得出的
   读数，没有目标就没有可量的地板（真机读数里逐档断的就是这一条：`a／button／[tabindex]／input…` 零命中）。
6. **关键语义永不 `…` 截断**：全件没有 `text-overflow`／`line-clamp`／`white-space: nowrap`；
   长串走 `overflow-wrap: anywhere` 换行（刻度列有 `max-width` 上限，长单位会把刻度换成两行而不是把柱子挤没）。
   A 档的刻度值同样有 `max-width: 7em` ＋ 词内断行 —— **绝不 `…`**。
7. **四档几何（真机 headless Chrome ＋ CDP 量出来的原读数）**：容器宽 320／390／620／1280 下
   **零横向溢出**（四套皮肤 × 十一种样例 = 每档 44 格，`scrollWidth` 逐格等于 `clientWidth`）：

   | 容器宽 | 柱区高 | 一列宽（7 天时） | 轴顶刻度中心差 | 轴底刻度中心差 | A 档刻度枚数／轨道高 | 根 `scrollW`／`clientW` |
   |---|---|---|---|---|---|---|
   | 320 | 128px | 30.6px | 0px | 0px | 4／30px | 320／320 |
   | 390 | 128px | 40.6px | 0px | 0px | 4／30px | 390／390 |
   | 620 | 150px | 73.5px | 0px | 0px | 4／30px | 620／620 |
   | 1280 | 150px | 167.7px | 0px | 0px | 4／30px | 1280／1280 |

   窄档（`@container ≤ 460px`）柱区与**刻度列一起**矮一档（150 → 128）——两处取同一个常量，
   高矮不同就等于刻度与柱子不是同一把尺（2026-09 实测过一次：柱区 128 而刻度列留 150，
   轴底刻度整整低了 22px）。**一列不减**（列就是数据里的天数本身，减列＝删一天）。
   A 档的轨道高**两档同高**（`SPREAD_DIST_TRACK_PX`）：一行一组、与容器宽无关；
   它随宽度变的是**横向**的那把尺子（百分比自己伸缩），故没有第二条窄档规则。
8. **样式只有一份出口**：`spreadDistCss()` 是唯一的样式入口（三段的正文分别住 `style.ts`／
   `style-quantile.ts`／`style-box.ts`，由它按行序汇总），全部规则 scope 在 `.<prefix>page-ui` 之下；
   不写 `:root`／`!important`／任何 `@media`（媒体查询只许判设备能力），颜色／圆角／字号一律经 `skinVar()` 读。
   档间距走皮肤自己的 `space`（大字报刊那套是 18px 对纸面的 16px）⇒ C 档（大字报刊）下留白自动多一层，
   不用写皮肤名分支。
9. **各套皮肤下标记逐字节相同**：皮肤只换取值表，标记一个字节不动（换皮不换结构）。
10. **分位尺的档数必须是奇数**（3／5／7）：**正中那一档就是中位**，偶数档没有正中。
    正中那一档带选中面（`is-median`）；档名是 `P<数字>` 时给一句实话「不超过它的读数占 n%」，
    档名不是（如 `中位`）就**不编**说明句。
11. **A 档一行一组、两种读法二选一**：五数概括（`low`／`q1`／`q3`／`high` 四个键**全给**才画箱，
    且要求 `count ≥ 5`）或单笔读数（`points`，个数必须正好等于 `count`，且要求 `count < 5`）。
    混着给、只给一半、样本量与读法对不上，**一律当场报错** —— 一行里同时有箱与散点，读者分不清在看哪一种。
12. **A 档的可见文本按用户砍过的那一版**：单位只印一次（卡头右端）；图例只有
    `P25–P75`／`离群`／`单笔` 三项（**没有「中位数」那一条**）；行头**一行一档字号**
    （组名／笔数／中位同号，没有"大号中位"那一层）；脚注**只说图例与行头没说过的**那一件
    （样本量决定读法），不把图例再说一遍。判据逐条钉住（含变异自证）。

## 常见错法

- **一组只给两三笔却要画箱** ⇒ 当场报错：不到 5 笔时箱体的形状是估计出来的，样本太少就是假的。
  那样只给 `points`（每一笔点上尺子）；
- **给了五数概括又给 `points`**（或只给五数里的一半）⇒ 当场报错：一行里要么是箱、要么是点，
  两种读法混在一行，读者分不清在看哪一种；
- **`outliers` 里塞了一个落在须内的读数** ⇒ 当场报错：须里的点不是离群点，画上去读者会把它当异常；
- **`points` 的个数与 `count` 对不上** ⇒ 当场报错：行头写着 4 笔、尺子上只点了 3 个，那是漏画；
- **两组同名**（`餐饮` 出现两次）⇒ 当场报错：组名是这一行的坐标（写在行头、也进无障碍信息）；
- **天数只给一两天** ⇒ 当场报错：一天谈不上「逐日波动」；要一个数用 `summary-head`，
  要跨期看一遍用 `small-multiples`；
- **给到 13 天以上** ⇒ 当场报错：窄容器里一列站不住，请调用方先按周聚合（那是 `small-multiples` 的活）；
- **某一天没数就传 `low: 0` 顶替** ⇒ 轴域被拉到 0，其余几天全挤成一撮，整张图读错。
  本件**不认缺值顶上**：那一天没数就别给那一天（宁可少一天，也别给一个假数）；
- **中位数拿 `(low + high) / 2` 凑一个** ⇒ 那不是中位数（那一天的分布偏一边时，这个数会骗人）。
  不知道就**不给** `median`，件里如实写 `—`；
- **`low` 与 `high` 传反** ⇒ 当场报错（比静默画成一根 0 高的条好）；
- **分位档数是偶数**（`P10 P25 P50 P75`）⇒ 当场报错：没有正中那一档；
- **分位读数不随档名递增**（`P25` 比 `P10` 还小）⇒ 当场报错：分位是单调的，反着走画出来是错的；
- **两档同名**（`P10` 出现两次）⇒ 当场报错：档名是这一格的坐标（写在格上、也进无障碍名）；
- **极端值硬塞进分位尺** ⇒ 尺子被一个 400+ 的单子拉到天上，其余几档挤成一条线。
  本件只画调用方给的那几档；极端读数请在别处点名（件里的口径句写明了这条）；
- **把每一天包成可点入口** ⇒ 触控命中盒按**列宽**算，够 44px 宽要**容器宽 ≥ 44×天数 ＋ 8×(天数−1)
  ＋ 纵轴刻度列宽 ＋ 8px**（刻度列至多 7em，中文单位那一档实测量到约 50px ⇒ 7 天时约 414px）。
  真机读数：**620 档列宽 73.5px ✓、1280 档 167.7px ✓、390 档只有 40.6px ✗、320 档 30.6px ✗**。
  条件不成立时请改用别的件（`rank-list`／`calendar-month`），或先按周聚合；
- **把 `stamp` 当成必填** ⇒ 不给就不出那一枚（它是口径，不是数据）；
- **拿它当「构成」**：一根条只表示一天的最低到最高，构成（一整块怎么分）走 `stacked-bar`。

## 与原型的有意偏离（逐条留档）

原型＝`.scratch/ui-组件墙/新件/parts-数据与仪表.mjs` 的 65（A／B／C 三档）。**按层规重写**（类名前缀、
`skinVar()` 读皮肤、`@container` 判宽、槽位助手拼选择器），逐条偏离如下：

| 原型 | 本件 | 为什么 |
|---|---|---|
| A 档把五数写在行内 CSS 变量里（`--lo/--q1/--md/--q3/--hi`，取值是原型手算的百分比） | 只给**值**（`low`／`q1`／`q3`／`high`／`median`／`outliers`），百分比由 `upPct()` 从**同一份轴域**算出来 | 工单硬要求「位置由值算出来」：原型那一版的百分比是手算好的常数，改一个读数就得重算一遍，且读者无法从尺子反推 |
| A 档那四行的组名／笔数／中位是**两行**（灰字一行 ＋ 大号中位一行） | **一行一档字号**（组名／笔数／中位同行同号） | 用户原话「文本量太大了，原型里面写了好多文字，看起来就很混乱」；砍过文字的那一版才是拿到 4 分的那一版 |
| A 档图例四项（含「中位数」一条）／单位写「单位：元」 | 图例三项（`P25–P75`／`离群`／`单笔`）、卡头右端只写「元」 | 同上：行头已各印一次「中位 NN」，同屏重复的删掉；单位只印一次 |
| A 档箱体／须／点是 `--accent2`／`--danger`／`--soft` 那几只旧 token | 一律 `skinVar()` 读皮肤（`accent` 系 ＋ `danger` 给离群圈），淡洗用 `color-mix()` 从 `accent` 算 | 层红线：组件只读 token 名、不读值；旧 token 只在兜底链里出现 |
| A 档「不到 5 笔只点不画箱」只写在口径句里 | 写进**校验**：画箱要求 `count ≥ 5`、只点要求 `count < 5` 且 `points.length === count` | 口径句是给人读的；形状上的事得由件当场拦下（编一个箱出来比不说更坏） |
| B 档**没有纵轴**（只有底轴与卡头一句 `单位：百卡`，柱高直接用 `--lo/--hi` 当百分比） | 补上纵轴刻度列：3–6 枚刻度，文字与位置都由**同一份轴域**算出来 | 工单硬要求「刻度与轴域必须是同一份真值，坐标映射要有唯一一处纯函数，判据从印出来的刻度反推」；原型那一版读者无法从柱高读出任何数值 |
| B 档横轴固定在 `repeat(7, 1fr)` | 天数由调用方给（3–12），列划分走 `flex: 1 1 0` ＋ 同一个 `gap`（横轴行与柱区共用） | 件不认「周」：`09-12` 这类日期也照收，列数得跟着数据走 |
| C 档只印**三档**（P10／中位／P90），把 P75 塞进脚注 | 印调用方给的**奇数档**（3／5／7），**正例仍是三档**（README 示例入参就是 P10／中位／P90） | 形态名就是那句问题「P10/P25/P50/P75/P90 各是多少」——只印三档时 P25 与 P75 没有落点，故把「印几档」交给调用方（容量到七档）；但**默认样子照用户打 4 分的那一版＝三张卡**，窄容器下五张卡要折成三行 |
| C 档档名写成 `P10 · 最便宜的 10%`（`·` 分隔） | 档名与说明句分成两个节点：`P10` ＋ `不超过它的读数占 10%` | 仓库的分隔符门（`test/separator-probe.mjs` R1–R3）对可见文本零豁免：`·`／`；`／并列顿号一出现就红 |
| C 档那三格没有选中面（`.mid` 用的是 `border: 1px solid accent` ＋ 软底） | 正中那一档＝`accent-soft` 底 ＋ `accent-text` 字 ＋ `accent` 描边 | 照法条「有文字的选中面」那一档（原件只差字色没走文本档） |
| 原型用 `--accent2`／`--soft`／`--danger` 等旧 token | 一律 `skinVar()` 读皮肤 token，淡洗用 `color-mix()` 从 `accent` 算 | 层红线：组件只读 token 名、不读值；旧 token 只在兜底链里出现 |
| 原型 B 档图例写「当天最矮／最高一餐」 | 改写「当天最低到最高」（C 档同理不出现「笔」这类字） | 件是通用的（金额／卡数／入睡时刻都在用），不写死「餐」；也避开 `/` 这个并列分隔符 |

## 关系

- 与 `scatter-fit` 的分工：那是两个读数之间的**关系**（点云＋拟合线＋概率带）；本件只有**一个**读数，
  并排比几组（`box`）、沿时间（`range`）或沿分位（`quantile`）摊开；
- 与 `small-multiples` 的分工：小倍数一期一根柱、柱高是**一个数**（比跨期高低）；
  本件一天一根**区间**（最低到最高 ＋ 中位），或一次读完几档分位，或几组并排各画一个**箱**；
- 与 `heat-grid` 的分工：热力格是色阶（只看浓淡、格内没有形状、读不出数）；
- 与 `stacked-bar` 的分工：构成条画的是一整块怎么分成几份，本件画的是一批读数的摊开；
- **本件暂不提供族汇总入口**（同批第二件落地后，由先成立的那件立汇总，照 `sheetCss()` 先例）。

## 判据（`test/spread-dist.test.mjs`）

① 渲染契约：三档各自的槽位与枚数／**刻度与轴域同一份真值**（从印出来的刻度反推轴域，柱／中位块／
刻度自己的位置逐点对账，A 档另把须／箱体／中位线／离群圈／单笔点逐点对账；常规、轴域不整齐、
全等值、12 位金额四种样例）／缺中位数那一支／**样本不足只点不画箱**那一支／转义面／
**全部**非法入参分支（每个都断 `BlocksError`，含**偶数档**、重名档、A 档两种读法的混用）／上下限自证／
**非有限轴域拒收扩到 A 档**（±1e308 与 `tickValues`／`rulerTicks` 的枚数夹取）；
② 样式与零 DOM 纪律（scope 恰一次、零 `@media`、零颜色字面量、零手写 `var(--ilife-…)`、
零 `…` 截断写法、刻度列有宽度上限、**刻度列与柱区同高**）／**A 档标记面**（各槽位逐槽点名 ＋
**死声明门**：声明了没上屏的槽、样式里写了闭集外的槽名，两条都当场红）／**行头一行一档字号**／
**单位只印一次**／**图例没有「中位数」那一条**（每一条都配**当场做的变异自证**）；
③ 加法式（不开＝逐字节不变；**旧两档的产物按 sha256 钉住**——新档只许加法）；
④ 四档几何（真机 320／390／620／1280：零横溢、首末刻度中心对到上沿与下沿、
窄档柱区矮一档＝容器查询真在生效、零截断；**A 档另有四条**：每枚刻度中心落在它那个值的位置、
网格线与刻度逐枚对齐、**行的中位线与尺子读出来的位置对齐**、轨道高＝常量、刻度值不压图例、
**零可点元素 ⇒ 命中盒与相邻间距两条不适用**；并配真机变异自证：**行区多一层内距**与
**末端刻度值折成竖排**两种坏写法都当场红）；⑤ 皮肤纪律（四套皮肤下标记逐字节相同、
正中那一档取自皮肤取值表）；⑥ 分隔符门（R1–R3 零命中）。
