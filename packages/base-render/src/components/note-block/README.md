# note-block · 备注块

**一句话**：记录旁边那段话 —— **不是账目、不是读数，是「当时为什么这么记」**。层次靠**竖线 ＋ 缩进 ＋ 底色块**；长备注默认收起（`<details>`，首行给一句摘要），带归属与可选时间。

**形态**：本件只落地**形态 A「竖线备注」**——出处＝原型墙 `.scratch/ui-组件墙/parts-11-加量池.mjs` 的 `.c-p6-note`。

**这一件是重做件**（原型 3/3/3，其中**引语形态 B 三套皮肤全 2 分**）。改掉的是什么：**引语形态整个砍掉**（一根短横线 ＋ 一句斜体话那个骨架不成立）；留下的骨架只用三样**零阴影、零圆角下也成立**的手段立层次——**竖线**（左缘）／**缩进**（正文相对归属）／**底色块**（正文自己的软底）。层次不再依赖"浮起来"。

## 何时用它（选型三条）

| 你要的 | 用 |
|---|---|
| 一段「当时为什么这么记」的话（可长可短、带归属） | **本件** |
| 账目行尾那一句小字 | `ledger-rows`／`entry-rows` 的 `note` 槽 |
| 一组要读的读数 | `metric-grid`（读数格） |

**与「编辑」的分工**：本件**不造编辑入口**。要改这段备注，值旁边挂既有的 `editable-value`（同一条「值即入口」的路）——两处各造一套编辑入口，迟早走散。

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `text` | `string` | 必填 | 备注正文。**非空**（去掉空白后不许是空）；换行按段拆成逐段 `<p>` |
| `owner` | `string` | — | 归属（「08-30 的备注」）；不给＝头上只有时间／语气 |
| `time` | `string` | — | 可选时间（「最后改于 09-25 20:14」） |
| `tone` | `'quiet' \| 'warn' \| 'danger'` | `'quiet'` | 语气档：竖线加粗 ＋ 底色块换档 |
| `toneLabel` | `string` | 非 `quiet` 时必填 | 语气字（「存疑」）：说清这个语气**是什么** |
| `summary` | `string` | — | 收起时那行摘要；不给＝本件从正文首行截一句（≤ `NOTE_BLOCK_PEEK_CHARS` 字） |
| `attachedTo` | `string` | — | 附着在哪条记录上（「09-25 体重」）；给了它，正文末尾出归属行 |
| `collapse` | `boolean` | 按字数自动 | 强制收起／展开 |
| `form` | `'note'` | `'note'` | 形态键（闭集；闭集外一律 `badInput`） |
| `extraClass` | `string` | — | 附加类名（空格分隔，逐个过类名正则） |

## 契约与不变量（判据逐条断）

1. **层次只用三样零阴影下成立的手段**：竖线（左缘 `border-left`）／缩进（正文 `padding-left` 与块的左内距）／底色块（正文软底）。样式段里**不出现 `box-shadow`**——投影一没，层次照旧。
2. **引语形态不存在**：`NOTE_BLOCK_FORMS` 只有 `note` 一格；闭集外的 `form`（含原型里那个引语档）一律 `badInput`。
3. **语气非无时必有语气字**：`tone` 不是 `quiet` 而没给 `toneLabel` ⇒ `badInput`。加上「竖线加粗」这一样形状差别，**色不是唯一信息**。
4. **长备注默认收起**：正文字数 > `NOTE_BLOCK_COLLAPSE_CHARS`（80）⇒ 走原生 `<details>`，收起那一排写齐**归属 ＋ 时间 ＋ 字数 ＋ 摘要**；`collapse` 可显式覆盖。
5. **正文一个字都不截**：只有**摘要那一行**会带省略号（`NOTE_BLOCK_ELLIPSIS`），正文逐段全出。
6. **收起那一排是触控目标**：`<summary>` 的 `min-height` ≥ `NOTE_BLOCK_TOUCH_PX`（44px）；`:focus-visible` 给 2px 可见焦点。
7. **零运行时**：展开／收起是 `<details>` 的原生行为，本件**没有** `runtime.ts`（没有必须靠脚本才成立的交互）；没有脚本时正文照样读得到（`<details>` 的降级就是「都展开」）。
8. **样式只经 `skinVar()`**：不写手抄的 `var(--ilife-…)`、不写 `:root`／`!important`、不新增 token 名；scope 在 `.<prefix>page-ui` 之下；宽度只判容器（`@container`）。
9. **状态矩阵按原生控件给**：`rest`／`:hover`（包在 `@media (hover:hover) and (pointer:fine)` 里，且不是唯一通路）／`:active`／`:focus-visible` 四档在样式段里逐条给出；`disabled`／`loading`／`error` **原生 `<details>` 没有这三态**（它不提交、不加载、也不出错），不硬造。

## 常见错法

- 用引语（一根短横线 ＋ 斜体）表达备注 —— 那套骨架在零阴影、零圆角的皮肤下读不出「这是一段备注」（本件已砍）；
- 用投影或大圆角把备注"抬起来" —— 小票纸与大字报刊两套皮肤的投影是 `none`，一换皮层次就塌；
- 语气只染一个色、不给那两个字 —— 皮肤把警告色压成墨黑之后，读者不知道这条带着什么；
- 长备注整段铺开、正文里用 `…` 截断 —— 该收起就收起（`<details>`），该写全就写全；
- 给本件再配一个编辑器 —— 编辑走 `editable-value`，本件只管**读**。

## 关系

- 用在哪：六个技能（记录旁边那段话）。
- 样式由页面按需挂 `noteBlockCss()`（加法式：不调它、不挂 `.ilife-page-ui` 的页零命中）。
- 与 `editable-value` 的接法：要改的备注，值旁边挂一枚 `editable-value`（`kind: 'text'`）；本件**不参与**编辑过程。
