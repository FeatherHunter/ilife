# cash-waterline · 现金水位

**一句话**：把「钱还剩多少、还能撑几天」画成随时间下去的水位——**形态 `waterline`**＝逐日水位柱（底线 ＋ 告急日点名）／**`bullet`**＝每周子弹图（实际 ＋ 底线刻度）／**`flow`**＝进出水三栏（构成 ＋ 够不够撑到月底）。

同一件三个形态都在原型墙上拿过 4 分（`.scratch/ui-组件墙/新件/parts-数据与仪表.mjs`，64 现金水位 A／B／C），故一并落地。

## 何时用它（选型四条）

| 你要的 | 用 |
|---|---|
| 「哪一天跌破底线」「账上的余量随日子怎么下去」——**沿时间读存量** | **本件 `waterline`** |
| 「每周结束时已经用掉多少、哪一周越过底线」 | **本件 `bullet`** |
| 「进／出／余各是多少、按这个花法撑不撑得到月底」 | **本件 `flow`** |
| 「这一笔钱怎么拆的」（沿**科目**从总额加减到明细） | `invoice-lines` |
| 「一整块怎么分」（一根横条里的占比，没有时间轴与阈值线） | `stacked-bar` |
| 「到了目标的几成」（两数之比，没有逐日余量形状） | `scale-bar` / `progress-list` |

用在哪：记账 · 本月总览／预算页。

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `title` | `string` | 必填 | 卡头标题（`本月可用余量 · 逐日`） |
| `stamp` | `string` | — | 卡头右端那句（`预算 6 000 元`／`4 周`）；不给＝不出 |
| `form` | `'waterline'｜'bullet'｜'flow'` | `'waterline'` | 形态闭集；闭集外报 `BlocksError` |
| `thresholdPct` | `number` | `30` | 底线（占预算的百分比，0–100） |
| `days` | `{label,pct,spend}[]` | 必填 | 逐日读数（1–31 天）：**缺省形态 `waterline` 的必填项** |
| `todayIndex` | `number` | — | 形态 `waterline`：今天那一格的下标（0 起）；不给＝不标今天 |
| `weeks` | `{label,inflow,outflow}[]` | — | 逐周读数（1–8 周）：**形态 `bullet` 要（该形态下必填）** |
| `budget` | `number` | — | 总预算（正数）：**形态 `bullet`／`flow` 要（该形态下必填）** |
| `inflow` | `{name,amount}[]` | — | 进项明细（1–8 行）：**形态 `flow` 要（该形态下必填）** |
| `outflow` | `{name,amount}[]` | — | 出项明细（1–8 行）：**形态 `flow` 要（该形态下必填）** |
| `elapsedDays` | `number` | — | 已经过了几天（整数 ≥ 1）：**形态 `flow` 要（该形态下必填）** |
| `remainDays` | `number` | — | 距这一段还剩几天（整数 ≥ 0）：**形态 `flow` 要（该形态下必填）** |
| `unit` | `string` | `'元'` | 钱的单位：只上屏，不参与算数 |
| `note` | `string` | — | 口径行；不给＝本件按形态写一句自己的口径 |
| `extraClass` | `string` | — | 附加类名（空格分隔，逐个过类名正则） |

**逐日读数（`days` 的每一个元素）**

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `label` | `string` | 必填 | 日期（`09-21`）：上屏在横轴与告急日点名里 |
| `pct` | `number` | 必填 | 当天结束时「预算 − 已花」占预算的百分比（0–100） |
| `spend` | `number` | — | 那天花了多少（≥0）；不给＝点名行里写 `—`（**不猜**） |

**逐周读数（`weeks` 的每一个元素）**：`label`（`第 3 周`，必填）／`inflow`（进，≥0，必填）／`outflow`（出，≥0，必填）。
**净额与累计已用由本件算**——调用方给净额或占比，本件一律不认（形状与读数必须同出一份真值）。

**进出水明细（`inflow`／`outflow` 的每一个元素）**：`name`（`餐饮`，必填）／`amount`（金额，**正数**，必填）。

**形态只吃自己那份读数**：`form: 'bullet'` 却给了 `days` ⇒ `BlocksError`（给错读数说明调用方拿错了骨架，本件不替你挑一个）。

## 契约与不变量

- **跌破底线＝严格小于底线**：`pct < thresholdPct`（正好压在线上不算跌破）。子弹图上换算成「已用」是同一件事：`已用 > 100 − 底线` 即余量跌破底线，**轨道上那根竖线就落在这个位置**。
- **告急日必须点名**：跌破底线的日子逐条写出来（日期 ＋ 那天花了多少 ＋ 余量），不是只把柱子染红——「几号跌的、那天花了多少」是这一件要回答的全部。
- **越过 100% 不缩回**：子弹图那一周的条形画到满格，**读数里照实点名**（`已用 136%`）。
- **判定写成字**：进出水三栏给 `✓ 撑得住`／`！ 撑不住` ＋ 差额；口径＝剩余额度 ÷ 近日均消耗（`出 ÷ 已过天数` 的日均 × 剩余天数）。
- **状态靠形 ＋ 字 ＋ 色三样**：跌破底线＝柱色 `danger`（色）＋ 点名那块逐日写日期与金额（字）＋ 点名行左侧 2px 侧标（形）；今天＝贯穿画布的竖游标（形）＋ 轴上的「今天」（字）＋ 强调色系（色）。
- **选中／强调一律走强调色系**：今天那一格是 `accent` 竖游标（游标被柱子盖住下半段，只从柱顶往上露出来），轴上的「今天」走 `accent-text`（文本档，对底 ≥4.5:1）；**没有一处拿正文墨色当"面"**。
- **横轴刻度是算出来的**：至多 6 枚（首尾必出、其余等间距），多了挤在一起就是压字；日期本身在点名那块里一个不少。
- **零 DOM、零可点元素**：只产标记，不带脚本；宽度只由 `@container` 判（阈 620px），**不写任何 `@media` 宽度查询**。
- **形态 C 在窄容器里改一列**（三栏并排会被压成三根窄柱，钱数没地方站）。
- **样式只有一份出口**：`cashWaterlineCss()` 是唯一的样式入口；它汇总同目录 `style.ts`（卡头／三形态共用的图例与点名那块／窄容器两处覆盖）与 `style-forms.ts`（三个形态各自的形状）两份源码件——**拆分只为行数**（一次落三个形态，一段装不下，本包告警线 350；先例 `date-range` 的 `style-calendar.ts`），取值一个字节都没变。

## 常见错法

- **只给一个"本月结余"数字**：看不出是哪几天花超了——那正是这一件要替掉的画法；
- **拿一条满格进度条冒充时间轴**：存量与消耗混成一个数，也就答不出「几号会跌破底线」；
- **把 `pct` 当"已花比例"**：本件口径是**余量**占预算（`pct` 越小越危险），方向反了整张图就读反了；
- **自己算净额／占比再传进来**：本件不认（`weeks` 只给进与出）——两处各算一次必然走散；
- **超支了把条形缩回 100%**：读数里必须照实写，缩回去等于把「已经超了」这件事藏起来；
- **把本件当"金额分解"**：沿科目拆一笔钱用 `invoice-lines`。

## 关系

- 与 `summary-head` 配对：头给结余那个数，本件给"这个数是怎么一天天走到这儿的"；
- 与 `progress-list` 分工：多目标的「已达到 ÷ 目标」用它；单条时间轴上的存量水位用本件；
- 与 `stacked-bar` 分工：构成条看"一整块怎么分"，本件看"存量还在不在底线之上"；
- **本件暂不提供族汇总入口**（同批第二件落地后，由先成立的那件立汇总，照 `sheetCss()` 先例）。
