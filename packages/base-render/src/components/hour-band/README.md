# hour-band · 时段带

**一天 24 小时摊成一条带**：每个时段按"当天第几分钟"定位，**长度就是「多久」**；
带下面一条整点刻度尺（0..23），再下面逐段列明细行（起止／在做什么／时长／补充读数）。
时段的空档由本件**算出来**并出一行「— ／ 其余时间未记录 ／ 时长」。
出处＝原型墙 `.scratch/ui-组件墙/parts-05-时间与分组.mjs` 的形态 A（2026-09 用户裁定）。

## 什么时候用它

| 你要的 | 用谁 |
|---|---|
| **几段时间在做什么**（24h 概览、运动时段、计划里的块） | **本件** `renderHourBand` |
| 一类一行的区间（睡眠／工作／运动各一行，行尾合计） | `renderRangeBar` |
| **每小时记了多少分钟**的 24 根柱子（复盘形状） | `packages/skill-schedule` 的本地件 `renderHourBand`（**不在公共层**） |
| 一格一天、值进格（7～14 天窗口） | `renderPunchStrip` |

> **`dup` 交代**：`packages/skill-schedule/src/shared/pageParts.ts` 里已有一个本地件 `renderHourBand`
> （＋ `hourCellsOf` ＋ `categoryColor`）：24 根柱子＝24 小时，柱高＝该小时已记录的分钟，柱色＝该小时主键。
> 它算的是「每小时记了多少分钟」（复盘用），形状是**柱**；本件算的是「几段时间在做什么」（概览用），
> 形状是**带**。两者概念相邻、结构不同，且那个件不在公共层 ⇒ **本件不替代它**，两份并存。

## 用法

```js
import { renderHourBand, hourBandCss } from 'base-paint/blocks';

renderHourBand({
  title: '5 月 14 日 周四',
  use: '作息管家 · 全天概览',
  summary: { label: '已记录', value: '19h40m' },
  intervals: [                       // 时刻＝当天第几分钟（跨午夜请调用方拆成两段）
    { from: 0, to: 400, label: '睡眠', tone: 3 },              // 段够宽 ⇒ 带上写 `6h40m`
    { from: 490, to: 540, label: '通勤', tone: 1 },            // 段太窄 ⇒ 带上不写，明细行照写
    { from: 540, to: 720, label: '工作 · 上午', tone: 2 },
    { from: 1140, to: 1210, label: '跑步', tone: 4, meta: '320 kcal' },
  ],
  legend: [{ tone: 1, label: '通勤／午休' }, { tone: 2, label: '工作' }],
  note: '空档由本件算出来',           // 不给＝不出
});
hourBandCss();                        // 样式段（页面自己按需注入；不挂＝零命中）
```

| 入参 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `title` | `string` | ✅ | 标题（不截断，长了换行） |
| `intervals` | `HourBandIntervalInput[]` | ✅ | 0 段＝空串 |
| `intervals[].from` / `.to` | `number` | ✅ | 当天第几分钟（`0..1440`，`from < to`） |
| `intervals[].label` | `string` | ✅ | 这一段在做什么 |
| `intervals[].tone` | `1 \| 2 \| 3 \| 4` | — | 深浅档，缺省 2 |
| `intervals[].meta` | `string` | — | 行末补充读数（如 `320 kcal`） |
| `use` | `string` | — | 用途说明 |
| `summary` | `{ label, value }` | — | 头部右端合计位 |
| `legend` | `{ tone, label }[]` | — | 深浅图例 |
| `note` | `string` | — | 脚注 |
| `form` | `'band'` | — | 形态键（闭集，本件只有这一格） |
| `extraClass` | `string` | — | 附加类名（空格分隔、逐个过类名正则） |

## 契约与不变量

- **零 DOM**：只产标记，无脚本、无内联事件；样式只走 `hourBandCss()`。
- **机器值是分钟，显示串算出来**：`HH:MM – HH:MM` 与 `6h40m` 都由本件算（几何与去重都要分钟；同一件事不出两个来源）。
- **空档显形**：时段没盖到的时间算出来并出最后一行「— ／ 其余时间未记录 ／ 时长」——没有它，带上的空白读不出来。**页头合计由调用方给**（怎么算、算不算未记录各域不同，那是口径不是形状）。
- **出界一律 `badInput`**：端点必须落在 `0..1440`，`from < to`；本件不裁剪、不做跨午夜推断。
- **段内时长字只在段够宽时上屏**（`HOUR_BAND_TEXT_MIN_FRACTION`）；时长永远有**明细行**兜底，语义不丢。
- **窄档不横滑、刻度不压字**：带与刻度尺都是 24 份（`repeat(24, minmax(0,1fr))`）；窄容器下刻度尺只留偶数点（每 2 小时一格）；明细行的起止与时长 `nowrap`（**关键读数永不写 `…`**）。
- **深浅从 token 算**：四档＝`color-mix(in srgb, accent N%, surface-2)`，不写死颜色 ⇒ 各套皮肤（含强调＝墨黑）下都是同一条"浅 → 深"。
- **本件是自己的容器**（`container-type: inline-size`）：给它一个**确定的宽度**；不要在 shrink-to-fit 的 flex 项里用 `auto` 宽度。

## 常见错法

- 拿它当**甘特图／日程编辑器**：本件是读数形状，不含拖动、不含选中、不含"计划 vs 实际"对照（那是另一形态的活）。
- 把跨午夜的睡眠写成 `{ from: 1320, to: 400 }`：端点立刻被拒 ⇒ 拆成 `[1320,1440]` 与 `[0,400]` 两段。
- 时段重叠：本件照画（空档按并集算），但读的人会把重叠读成"同时在做两件事" ⇒ 重叠请先合并。
- 只给 `intervals` 不给明细行的读数口径：明细行的时长是**算出来的**，别在 `label` 里再抄一遍时长。
- 段太窄还硬要写时长字：那会挤成一团 ⇒ 交给明细行（带上那个字是**增益**，不是唯一通路）。
- 把 24 根柱子那件事塞进来：柱高＝每小时记了多少分钟是 `skill-schedule` 本地件的形状，本件只画带。
