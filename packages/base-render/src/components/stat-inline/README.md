# stat-inline · 行内读数

**一句话**：一句话里嵌几个数 —— 「餐费 12 笔 · 合计 ¥2,140.00 · 占 49.9% · 较上月 +15.1%」。

**形态**：本件只落地**形态 A「分隔点行内串（可折行）」**——出处＝原型墙 `.scratch/ui-组件墙/parts-02-读数与账目.mjs` 的 `.c-si-dot`（2026-09 用户裁定落地的那一形态），按层规重写（原型是一次性代码：无判据、无错误处理、读的是墙稿变量）。
形态键住 `STAT_INLINE_FORMS` 闭集（今天只有 `dots` 一格）——**加第二形态是在闭集里加一格，不是新开一件**（形态是骨架，不是地址）。

## 何时用它（选型三条）

| 你要的 | 用 |
|---|---|
| 一句里嵌几个数（小结行／表头／脚注） | **本件** |
| 一组读数**成列**排（字段：值，值右对齐） | `key-value-list`（档案行） |
| 4–6 个**小读数并排成格** | `renderKpiCard`（区块层） |
| 一页的**唯一**主要读数（大数字 ＋ 分母） | `summary-head`（主数字头） |

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `items` | `StatInlineItem[]` | 必填 | 逐项读数（下表）。空数组＝本件一个字都不出 |
| `interpunct` | `boolean` | `true` | 项与项之间出不出分隔点（`·`）。表头／脚注想更密时可关 |
| `form` | `'dots'` | `'dots'` | 形态键（闭集；闭集外一律 `badInput`）。形态类走槽位表里的 `form-dots`（`ilife-block-stat-inline-form-dots`） |
| `extraClass` | `string` | — | 附加类名（空格分隔，逐个过类名正则） |

`items` 的每一项：

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `value` | `string` | 必填 | 值（**已是给人看的样子**：取整／千分位／单位归调用方）。**非空**；缺值写 `—` |
| `label` | `string` | — | 值**前**的标签（`合计`／`餐费`） |
| `unit` | `string` | — | 值**后**的字（`笔`／`元`／`天`） |

**缺值写成 `—`**（`STAT_INLINE_MISSING`）：空串不是缺值，是错。缺值的项照旧占一格（「退款 `—`」比整项消失更好读——读者知道这一项存在、只是没有数）。

## 契约与不变量（判据逐条断）

1. **值与其标签不许分家**：每一项是一个 `inline-flex` ＋ `white-space:nowrap` 的单元，窄档整行折行、项内绝不拆（拆了就会把数配错标签）。
2. **不截断**：整行靠 `flex-wrap` 折行，**永不 `…` 截断**（小结行、表头、脚注是结论位，最经不起截断）。
3. **窄宽两档**：容器宽 390 与 1280 下**零横向溢出**（`scrollWidth ≤ clientWidth`）。
4. **数字成列**：值位等宽字面 ＋ `font-variant-numeric: tabular-nums` ⇒ 换值／换页不跳位。
5. **分隔点是呈现**：分隔点 `aria-hidden`（读屏听到的是几段完整的话，不是一串逗号）；`interpunct:false` 时整槽不出、其余一字不差。
6. **各套皮肤下标记逐字节相同**：皮肤只换样式段（取值表），标记一个字节不动。
7. **零 DOM／零内联脚本**：模块代码剥掉字面量后不出现 `document.`／`window.`／`navigator.`；标记里没有 `<script>`、没有 `on*=`。
8. **样式只经 `skinVar()` 读皮肤**：组件里不出现手写的 `var(--ilife-…)`；不写 `:root`／`!important`；不定义新 token 名；全部规则 scope 在 `.<prefix>page-ui` 之下。
9. **响应式一律容器驱动**：折行靠内在尺寸 ＋ `flex-wrap`；本件**一条 `@media` 都没有**（它没有设备能力差异——本件不含可点元素）。

## 常见错法

- 把「合计 ¥2,140.00」拆成两行（值 ＋ 标签分家 ⇒ 读者把数配错标签）；
- 一行太长就 `overflow:hidden` 或 `…` 截断（小结行是结论位）；
- 各项之间拿 `|`／`/`／`、` 当分隔（本仓的分隔语汇是 `·`，别的写法各有各的语义）；
- 用本件排「一组读数成列」（那是 `key-value-list`：列对齐是本形态给不了的）；
- 涨跌幅靠颜色单独表达（色**不是**唯一信息：本件只排"数"，涨跌符号归调用方写进 `value`／`unit`）；
- 用 `value: ''` 表达缺值（应当给 `—`）。

## 关系

- `stat-inline` 是 `key-value-list` 的**行内**版本：要成列用 `key-value-list`，要一句话用本件。
- 常挂在别的组件的作用域里（`section-head` 的正文、`summary-head` 的脚行、表头、脚注）——本件只排一行，不替它们排版。
- 样式由页面按需挂 `statInlineCss()`（加法式：不调它、不挂 `.ilife-page-ui` 的页零命中）。
- 本件暂不提供族汇总入口（同族第二件落地后，由先成立的那件立汇总，照 `sheetCss()` 先例）。
