# entry-rows · 明细行

**一句话**：一条记录一行——`时间 ・ 类别 ・ 名称 ・ 数量 ………… 值 单位`（＋ 下一行的备注）。槽位各自独立，给哪几槽出哪几槽。

## 何时用它（选型三条）

| 你要的 | 用 |
|---|---|
| 一条记录一行、右侧要对齐一个值（金额／热量／里程） | **本件** |
| 一串"时间 ＋ 做了什么"、按时间轴连起来（左侧轴线 ＋ 圆点） | `renderTimelineRows`（页面级形状件） |
| 列数 ≥3、要表头与排序 | `renderDataTable`（区块层） |
| 只列"缺了哪几餐"这种汇总句 | 本件 `absentLine` 槽（那是"没什么"，不是一条记录） |

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `rows` | `EntryRowInput[]` | 必填 | 空数组且无 `heading`／`absentLine` ⇒ 空串 |
| `rows[].name` | `string` | 必填 | 这一条是什么 |
| `rows[].value` | `string` | 必填 | 值（**已是给人看的样子**） |
| `rows[].time` | `string` | — | 时间槽（`13:55`） |
| `rows[].badge` | `string` | — | 类别槽（餐别 `午餐`） |
| `rows[].measure` | `string` | — | 数量槽（`2000 g`） |
| `rows[].unit` | `string` | — | 值的单位（`卡`） |
| `rows[].note` | `string` | — | 备注：另起一行、缩进到名称列 |
| `rows[].facts` | `string[]` | — | 行下读数：一排小字，**逐项分开给**（分隔由列距承担，不要自己拼 `·`） |
| `heading` | `string` | — | 小标题（`吃了什么`） |
| `absentLine` | `string` | — | 缺记那一句（`早餐 ・ 晚餐 ・ 加餐 未记录`） |
| `extraClass` | `string` | — | 附加类名 |

## 契约与不变量

- 时间槽定宽（`ENTRY_ROW_TIME_MIN_WIDTH_PX`）＋ 等宽数字 ⇒ 逐条记录的时间竖排在同一列；值槽右对齐 ⇒ 热量逐条对齐；
- 记录之间是**点线**、与 `ledger-rows` 的 hairline 分得开（同页两族同时出现时不混成一片）；
- 备注占满一整行（`flex-basis:100%`）并缩进到名称列（`ENTRY_ROW_NOTE_INDENT_PX`），**行高随备注长出来**、不挤压上一行；
- 缺的槽**不留空位、也不拿占位符顶替**（不写「—」当"没填"）；
- 样式 scope 在 `.ilife-page-ui` 下；本件零 DOM。

## 常见错法

- 一条记录写成一整句（「13:55 午餐 百事可乐 2000g 860 卡」）⇒ 五个字段挤在同一段文本里，换一条就没法逐列对照；
- 用七列表格装"一条记录"（表头要重复、窄屏横滑、食物名竖排）；
- 备注塞进正文那句里，读起来像第二条记录；
- 把"缺了哪几餐"塞进 `rows`（它会被算成一条记录、还会带值位——那是 `absentLine` 的位子）。

## 关系

- 与 `ledger-rows` 同族：**明细＝一条记录**（点线分隔），**账目＝一页的读数**（hairline 分隔）。
- 样式随 `sheetCss()` 一起挂；单独用时可只挂 `entryRowsCss()`。
