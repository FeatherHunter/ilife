# undo-timeline · 改动时间线

**一句话**：**已经写进去的改动怎么退回来** —— 一列改动按时间往下排，每条写清三样：**谁改的**（动作句）、**动了什么读数**（前后两个数）、**能不能撤**（那一枚按钮）；撤之前还能把**影响面逐项摆开**（撤这一项会连带什么，勾哪几项就撤哪几项）。

**形态**：本件落地原型墙 `.scratch/ui-组件墙/新件/parts-交互与流程.mjs` 第 85 件里**用户三套皮肤都打 4 分**的两档（2026-09 裁定），按层规重写（原型是一次性代码：无判据、无错误处理、读的是墙稿变量）：
- **形态 `track`「一条轨」**：一列改动；每条带**动作**（撤销／恢复），并写出撤销会动到什么读数；
- **形态 `impact`「一次改动的回滚单（影响面清单）」**：针对**一次**改动，把影响面摊成可勾的清单。
两档共用同一条回滚单骨架：`track` 的每一行可以把它**就地摊开**（**一次只开一块**），`impact` 就是这张回滚单单独成件。

它替掉的两种错法（原型墙那一格的原文）：①「改错了只能凭记忆手动改回去」；②「撤销了不知道会连带动到哪几张报表、哪条预算」。

## 何时用它（选型四条）

| 你要的 | 用 |
|---|---|
| 「刚才那几笔改动想退回来，退之前先看清会连带什么」 | **本件** |
| 「一列往下走的**只读**台账轨（状态、时间、说明）」 | `status-row` |
| 「一件破坏性的事，**事前**问一句确定／撤销」 | `confirm-strip` |
| 「只读的步骤条」 | `step-flow` |

判据一句话：**改动已经写进去了，现在要退回来** → 用它。反过来说：还没动手、只是想问一句「确定吗」的，走 `confirm-strip`；只想看台账不想退的，走 `status-row`。

用在哪：记账（改错了回看与回滚）／私家大厨（批量改评分后的回滚）／居家管家（盘库批量）／备忘录（批量改分类）。

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `name` | `string` | 必填 | 机器键（事件 `detail.name`；行内 `id` 拿它拼）。**非空、同页唯一** |
| `form` | `'track'`／`'impact'` | `'track'` | 形态闭集（`track` 一条轨／`impact` 一次改动的回滚单）；闭集外报 `BlocksError` |
| `entries` | `UndoTimelineEntry[]` | 形态 `track` 必填 | 改动记录（至多 200 条）。**给空数组 ＝ 出设计过的空态**（不是留白） |
| `entries[].key` | `string` | 必填 | 一条改动的机器键（事件 `detail.key`）。**非空、清单内唯一** |
| `entries[].time` | `string` | 必填 | 时刻（`13:58`，照原样上屏）。**永不 `…` 截断** |
| `entries[].say` | `string` | 必填 | 动作句：**谁改了什么** |
| `change` | `UndoTimelineImpact` | 形态 `impact` 必填 | 一次改动的回滚单（那一形态的整个主体） |
| `title` | `string` | `改动记录` | 卡头标题 |
| `cap` | `string` | — | 卡头右端那句（`只留 30 天，共 12 条`）。**永不 `…` 截断** |
| `rollback` | `UndoTimelineRollback` | — | 页脚那枚整段回滚（不给＝页脚只有那句结论） |
| `openKey` | `string` | — | 渲染时就摊开哪一条的回滚单（**必须命中一条带 `impact` 的改动**） |
| `emptyText` | `string` | `这一段时间里没有改动` | 空态那句字 |
| `hint` | `string` | — | 卡底那句提示（也是「按不动」的说明） |
| `changeKey` | `string` | `change` | `impact` 形态下给这一块用的机器键（事件 `detail.key`） |
| `extraClass` | `string` | — | 附加类名（空格分隔，逐个过类名正则） |

**下表是 `entries[]` 一格里面**的字段：

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `state` | `'undoable'`／`'undone'`／`'locked'` | `'undoable'` | 三态：能撤／已撤／不能撤 |
| `readings` | `UndoTimelineReading[]` | `[]` | 动了什么读数（至多 6 条，**逐条摆开、段间不写分隔符**） |
| `note` | `string` | — | 读数下面那句补充（`不动任何合计，只动两个账户的余额分摊`） |
| `tag` | `string` | 按三态 | 状态片上那句话（能撤时是调用方给的「会连带重算…」） |
| `lockedReason` | `string` | — | **不可撤的原因**（`state: 'locked'` 时必填） |
| `impact` | `UndoTimelineImpact` | — | 影响面清单：给了 ⇒ 那枚按钮**先就地摊开这张回滚单**；不给 ⇒ 按下去直接派发撤销事件 |
| `go` | `string` | 按三态 | 那枚按钮的字（缺省 `撤销这次改动`／`恢复这笔`／`已不可撤`） |
| `busy` | `boolean` | `false` | 正在跑：字**原地换掉**（`正在` ＋ 按钮字）、宽度锁住、按钮按不动 |
| `error` | `string` | — | 这一条的错态那句字（写在按钮旁边 ＋ `aria-describedby`） |

`readings[]` 一格：`label`（读数名，可选）／`from`（改前的值，**必填**，带删除线）／`to`（改后的值，**必填**，加粗）。两个值都是**已经是给人看的样子**的串（取整与千分位归调用方）。

`impact`（回滚单）：`title`（**必填**，如「13:58 的那次改动」）／`note`（那句交代）／`rows`（影响面逐项，**至少一项、至多 50 项**）／`sumNote`（脚上那句结论的后半段）／`cancelLabel`（缺省 `取消`）。

`impact.rows[]` 一格：`key`（**必填**，机器键，清单内唯一）／`title`（**必填**，一句话后果）／`note`（副语）／`count`（行右读数，如 `3 条`，**永不 `…` 截断**）／`checked`（缺省 `true`：撤销＝回到改动前，默认都撤）／`locked`（勾不动）／`lockedReason`（**`locked: true` 时必填**）。

`rollback`（整段回滚）：`label`（**必填**，那枚按钮上的字）／`note`（旁边那句）。

**入参违规一律抛 `BlocksError`（`bad-input`）**，不静默兜底：形态闭集外、重键、空标题、三态闭集外、`state: 'locked'` 不写原因、没标 `locked` 却给了原因、勾不动那一行标成 `checked: true`、读数缺一半、影响面一项都没有、`openKey` 未命中带影响面的那一条、**数组里有洞**（`new Array(n)` 这种稀疏数组：`map` 会跳过洞、渲染那一头才抛 `TypeError`）——逐条当场报错，并点名到 `input.<路径>`。

而 `change` 只属 `impact` 形态、三态又各有各的必填项，故这里显式写一份：

## 契约与不变量（判据逐条断）

1. **撤销能用手点做完**：每一枚动作都是看得见的 `<button>`（命中盒 ≥44×44）；标记与文案里没有一处键帽／键名／方向键，也没有把开合或撤销挂在任何键盘通路上。`:focus-visible` 的 2px 可见焦点只留给真实键盘用户（无障碍地板，不是通路）。
2. **三态至少两重非颜色标记**：片上写着字（`已撤销，读数已还原`／`不可撤：<为什么>`）＋ 按钮上的字（`恢复这笔`／`已不可撤`，按不动）＋ 轨迹上那枚圆点的形（能撤＝实心强调圆／已撤＝空心细描边／不可撤＝空心加一道斜杠）；已撤那一条的**动作句还划掉**（形）。**色只是第三重**——本层皮肤「大字报刊」下强调色就是墨黑，只染色的三态在那里会塌。
3. **能撤／不能撤／已撤各有自己的动作**：能撤那枚派发撤销、已撤那枚派发恢复、不能撤那枚**按不动且写得清为什么**（状态片 ＋ `aria-describedby` 指过去）；没有说明的灰按钮不许出现在屏上。
4. **影响面先于撤销**：带 `impact` 的那一枚按下去**只摊开回滚单**（不直接动手）；**一次只开一块**，再点同一处＝收起，点那块之外的任何地方＝全部收起。回滚单里**逐项写清后果**、行右给读数、勾不动的写出为什么。
5. **页脚那句话与主按钮**：结论句与主按钮的字都**按勾了几项现算**（一处刷新：两处各算各的必然走散）；**一项都没勾 ⇒ 主按钮按不动**（字换成「一项都没勾」）。勾不动的那一行缺省不勾、也不许标成勾上——它撤不了，数进去只会让那句话骗人。
6. **本件不写库**：撤销／恢复／整段回滚／取消都只派发事件（真正落库归页面／技能命令）；主按钮**不自动收起**（页面按事件重渲染，或给那一行标 `busy`）。
7. **竖轨是一根通的线**：行与行之间不留缝（`gap: 0`），行的竖向内距**住在三格里、不住行上**（住行上，竖轨够不到内距那一段，行与行之间会空出 24px 没有线的缝）；横线**只画在文字那两列上**（画满整行会把竖轨切成一节一节）；首行从圆点起、末行到圆点止。
8. **触控地板**：按钮与勾选框命中盒 ≥44×44（勾选框的视觉盒 24×24，原生框铺满命中盒，视觉隐藏走 `opacity: 0`，**不是** `display: none`）；整行命中区 ≥56px；相邻触控目标间距 ≥8px。
9. **状态矩阵齐**：`rest`／`:hover`（包在 `@media (hover: hover) and (pointer: fine)` 里，且**不是唯一通路**）／`:active`（`scale(.98)`，80ms，**只碰 `transform`**）／`:focus-visible`（2px 可见焦点）／`disabled`（`cursor: not-allowed` ＋ 写出原因）／`busy`（原地换字：忙碌那枚字**住在正常那枚字里面**、绝对定位在它这块上、横向按按钮内距外扩 ⇒ 出流，一个字都不参与按钮的固有宽，换字不跳版）／`error`（写在那一行按钮旁边 ＋ `aria-describedby`）／`empty`（设计过的空态）。状态一律同步改写属性与文本，**不依赖 `transitionend`**；`prefers-reduced-motion` 下把过渡关掉。
10. **选中／强调照四档口径**：能撤那枚（**有文字的选中面**）＝底 `accent-soft` ＋ 字 `accent-text` ＋ 描边 `accent`，**不是**强调实底（正文级字压在 `accent` 实底上，neutral 那套只有 4.02，过不了 4.5 的文本地板）；勾选框（**无文字的点／格**）＝`accent` 实底 ＋ `✓`；勾上的那一行＝底 `surface-2` ＋ 左端 3px `accent` 侧标（行内主字仍 `ink`）。**任何一处都不拿 `ink` 系当面**。
11. **窄宽两档**：容器宽 320／390／620／1280 下**零横向溢出**、不出现横向滚动容器；时刻／条数／个数／金额／状态**永不 `…` 截断**（长了折行）。宽度只许听容器：本件 `container: ilife-undo-timeline / inline-size`，窄档走 `@container`（阈值 `UNDO_TIMELINE_NARROW_PX` 只有一处出处）；媒体查询只判设备能力。
12. **零 DOM／零内联脚本**：模块代码剥掉字面量与注释后不出现 `document.`／`window.`／`navigator.`（DOM 只出现在 `buildUndoTimelineJs()` 产出的文本里）；标记里没有 `<script>`、没有 `on*=`。样式只经 `skinVar()` 读皮肤，全部规则 scope 在 `.<prefix>page-ui` 之下。

## 交互契约（运行时，`buildUndoTimelineJs()`）

| 动作 | 行为 |
|---|---|
| 点能撤那枚（带影响面） | 就地摊开**这一条**的回滚单（一次只开一块；再点同一枚＝收起），按钮上 `aria-expanded` 跟着改 |
| 点能撤那枚（不带影响面） | 直接派发 `ilife:undo-timeline-undo`（`detail = { name, key, items: [] }`） |
| 点那一块之外的任何地方 | 摊开着的回滚单**全部收起**（点块里面不算外面） |
| 勾／取消一项 | 页脚那句结论与主按钮的字**原地重算**（按勾了几项），并派发 `ilife:undo-timeline-pick`（`detail = { name, key, items, count }`）；勾到 0 项时主按钮按不动 |
| 点「撤销这 N 项」 | 派发 `ilife:undo-timeline-undo`（`detail = { name, key, items }`，`items`＝勾上的那几项）——**不写库、不自动收起** |
| 点就地那一块的「取消」 | 收起 ＋ 焦点还给按它的那一枚按钮（焦点不掉在 `hidden` 的元素上） |
| 点「恢复这笔」 | 派发 `ilife:undo-timeline-restore`（`detail = { name, key }`）——逆操作本身也是一条新记录 |
| 点页脚那枚整段回滚 | 派发 `ilife:undo-timeline-rollback`（`detail = { name, label }`）；要不要二次确认归调用方（或直接用形态 `impact` 把影响面摊开） |
| 点 `impact` 形态页脚那枚「取消」 | 派发 `ilife:undo-timeline-cancel`（`detail = { name }`）——那张卡没有就地可收的块 |
| 重复注入 | 只绑定一次（文档根上的 `data-ilife-undo-runtime`）；每根上记一枚 bound 读数 |
| 不跑这段脚本 | 清单、勾选框与按钮照旧在屏上（原生复选照常勾），只是不派发事件、就地那块摊不开；`openKey` 那一条仍按渲染时那份状态摊着 |

事件都冒泡到文档，页面用 `document.addEventListener(…)` 接自己的处理，**不引入任何全局**。

## 常见错法

- ❌ 撤销做成「按某个键就退回去」——手机上等于不存在 → ✅ 每一枚动作都是看得见的按钮。
- ❌ 把「能不能撤」做成只换个颜色 → ✅ 片上的字 ＋ 圆点的形 ＋ 按钮上的字，至少两样同时在。
- ❌ 撤销直接动手、撤完才说会连带什么 → ✅ 带 `impact` 的那一枚先摊开影响面，勾了哪几项撤哪几项。
- ❌ 页脚写死「勾了 3 项」 → ✅ 那句话与主按钮的字都按勾了几项现算（勾到 0 项 ⇒ 主按钮按不动）。
- ❌ `state: 'locked'` 不带原因（屏上是一枚没人知道为什么按不动的灰按钮）→ ✅ `lockedReason` 必填。
- ❌ 把行的竖向内距写在行上（竖轨会断成一节一节）→ ✅ 内距住三格里，横线只画在文字那两列上。
- ❌ 拿合计／条数去 `…` 截断 → ✅ 折行；要短就调用方自己短。

## 关系

- 与 `status-row` 的分工：那是**只读**台账轨（一列往下走的状态）；本件每一行都带**动作**（撤销／恢复），并写出撤销会动到什么读数。
- 与 `confirm-strip`／`dialog` 的分工：那两件管**事前**的二次确认；本件管**事后**——已经写进去的改动怎么退回来。
- 与 `bulk-bar` 的分工：那件是「勾几条，一起改一个字段」（**改**）；本件是「把已经改掉的退回来」（**退**）。两件都在页面上时，批量动作的预演归 `bulk-bar`，撤销与恢复归本件。
- 样式与运行时由页面按需挂（加法式：不调 `undoTimelineCss()`／`buildUndoTimelineJs()`、不挂 `.ilife-page-ui` 的页零命中）。
- 动作只派发事件：**落库／重算归页面脚本与技能命令**，本件不写数据。
- 本件暂不提供汇总入口（同批第二件落地后，由先成立的那件立汇总，照 `sheetCss()` 先例）。
