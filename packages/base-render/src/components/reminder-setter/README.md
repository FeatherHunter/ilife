# reminder-setter · 提醒设置

**一句话**：给一条提醒设三件事——**什么时候响 ／ 提前多久 ／ 走哪条通知**，一行只做一个决定；日期与时间不走精确拖点，走两枚 44×44 的步进键夹一枚读数（手机上「点得到」）；设完底下**一行复述**读出现在设的是什么（`每天 2026-09-26 22:30`）。

**两档形态**（`REMINDER_SETTER_FORMS` 闭集里的两个键）：

| 形态键 | 场景 | 屏上长什么样 |
|---|---|---|
| `decisions`（缺省） | 给**一条**提醒把三个决定摊开设 | 抬头 ＋ 三行（什么时候响／提前多久／走哪条通知）＋ 一行复述 |
| `track` | **一天里好几条提醒、要看它们落在哪儿** | 一天那条刻度（每枚提醒＝一个 44×44 的点）＋ 小时数 ＋ 图例（一行一条）＋ 选中那条的决定面板 |

它替掉的两种错法：①「提醒只有一个小铃铛，点开只有一个时间格，重复与提前量根本没法设」；②「设了每天却按单次响，想提前提醒只能把时间提前十分钟，结果记的是错的时间」。

**一屏只有三层话**（2026-09-25 用户口径：原型里写了好多文字、看起来很混乱）：**它是什么**（抬头「「记体重」的提醒」）＋ **现在设的是多少**（选中态、两枚读数、唯一那行复述）＋ **能按什么**（三排可点项）。同一个数只印一次（机器读数住在根上的 `data-*`），读数一行说完。**原型里的旁白与口径句一句都不上屏**——「挑一次或重复，别混着猜」「可选，给容易忘的事留一道」「可多选，至少留一条；全关掉这条提醒就不存在」「免打扰时段（23:30–07:00）里会顺延…」这些话留在本说明书里，不进屏面。形态 `track` 更省一层：**没有抬头，也没有复述那一行**——图例那一行（序号 ＋ 时刻 ＋ 提醒名 ＋ 重复档）就是「现在设的是多少」；同一个时刻只印在那一条的图例里（面板里那一枚是步进键中间的**控件读数**）。

**形态**：两档都已在件里（出处＝原型墙 `.scratch/ui-组件墙/新件/parts-交互与流程.mjs` 第 89 件的 A 档与 B 档；用户 2026-09-26 给 B 档 4／4／4，按**砍过字那一版**落地——原型 398 字砍到 172 字：删三句口径旁白、删编辑面板上那行「选中：22:30 记体重」，图例那行已印同一件事）。形态键住 `REMINDER_SETTER_FORMS` 闭集（`decisions`／`track`，**格号 A／B 不是接口名**）——**加形态是在闭集里加一格，不是新开一件**；闭集外的值一律报 `BlocksError`。**`decisions` 那个键一个字都没动**（旧档的标记逐字节不变）。

## 何时用它（选型五条）

| 你要的 | 用 |
|---|---|
| 设一条**会响的东西**：什么时候响、重不重复、提前多久、走哪条通知 | **本件** |
| 选一段**区间**（× 月 × 日 到 × 月 × 日），选完就完事 | `date-range`（日期区间） |
| 一组**预设时间段**，用来**查**数据（近 7 天／本月） | `window-picker`（窗口选择） |
| 只读地看「还有多久到期」 | `due-row`（到期行） |
| 一次勾一批（多条待办各勾一下） | `multi-checks`（多项勾选） |

用在哪：备忘录的提醒（记体重／吃药）、作息管家的日程、记账的还款提醒、卡路里的喝水与补记提醒。

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `id` | `string` | 必填 | 机器键（事件 `detail.id` 就是它）。**只许标识符字符** |
| `title` | `string` | 必填 | 给哪条提醒设（如「记体重」）。**非空、且不能只有空白**；屏上写「「记体重」的提醒」 |
| `repeats` | `ReminderSetterOption[]` | 必填 | 什么时候响那一排（**2–4 档**，顺序＝屏上顺序） |
| `repeat` | `string` | 必填 | 现在选的是哪一档（须命中 `repeats` 里的一枚） |
| `time` | `string` | 必填 | 提醒时间 `HH:MM`（24 小时制）。**分钟要落在 5 分钟那一档上**（改法是步进键，落不到的点屏上点不出来） |
| `startDate` | `string` | 必填 | 第一次从哪一天 `YYYY-MM-DD`（必须是真实存在的一天） |
| `leads` | `ReminderSetterOption[]` | 必填 | 提前多久那一排（**2–4 档**） |
| `lead` | `string` | 必填 | 现在选的是哪一档（须命中 `leads` 里的一枚） |
| `routes` | `ReminderSetterOption[]` | 必填 | 走哪条通知那一排（**1–4 档**；形是方框＝这条可以多选） |
| `chosen` | `string[]` | 必填 | 勾上的通知档（`routes` 里的键，**0–4 个**；给 `[]`＝屏上照实读成「没有通知，不会响」）。**形态 `decisions` 用它**；形态 `track` 每一条各带自己的 `chosen` |
| `form` | `'decisions'`／`'track'` | `'decisions'` | 形态键（闭集；闭集外一律 `BlocksError`） |
| `extraClass` | `string` | — | 附加类名（空格分隔，逐个过类名正则） |
| `items` | `ReminderSetterTrackItem[]` | 形态 `track` 必填 | **形态 `track`**：这一天摆着的那几条提醒（**2–4 条**）。屏上顺序＝刻度上的先后（件按 `at` 升序自己排，调用方不用先排） |
| `picked` | `string` | 形态 `track` 必填 | **形态 `track`**：现在改的是哪一条（须命中 `items` 里的一枚 `id`） |

`title`／`time`／`startDate`／`repeat`／`lead`／`chosen` 这六样是**形态 `decisions` 的**（`track` 下不读它们；入参表是两档的**并集**，给在这儿不拒）。

**形态 `track` 里的一条提醒（`items[]` 的每一个元素）**

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `id` | `string` | 必填 | 机器键（事件 `detail.value`／`state.items[].id` 就是它）。**只许标识符字符**，一整天里唯一 |
| `label` | `string` | 必填 | 提醒名（如「吃药」）。**非空、且不能只有空白**；图例那一行印它 |
| `at` | `number` | 必填 | **一天里的第几分钟**（`0`–`1439`）。刻度上的位置与屏上那个时刻都由它算出来（`reminderSetterPlace()`／`reminderSetterClock()`）；**要落在 5 分钟那一档上**（改法是步进键） |
| `repeat` | `string` | 必填 | 这一条选的重复档（须命中 `repeats` 里的一枚） |
| `lead` | `string` | 必填 | 这一条选的提前档（须命中 `leads` 里的一枚） |
| `chosen` | `string[]` | 必填 | 这一条勾上的通知档（`routes` 里的键，**0–4 个**；`[]`＝图例那一行照实读成「没有通知，不会响」） |

**一档可选值（`repeats`／`leads`／`routes` 的每一个元素）**

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `key` | `string` | 必填 | 机器键（事件 `detail.value`／`state` 里原样送出）。**只许标识符字符**，同一排内唯一 |
| `label` | `string` | 必填 | 屏上那一档的名字（如「每天」／「提前 10 分钟」／「系统通知」）。**非空、且不能只有空白**；长了换行，绝不截断 |

**入参纪律（三条，判据逐条断）**：

1. **上屏的文字全空白＝拒**（`badInput`）：`'   '` 会在屏上留一块**看得见的空白**（无字提醒名／无字档名）。空串＝未给（与全层 `optText` 同口径），**只有空白＝拒**；**零宽字符那类不可见字符同样算空白**——`\u200b`、`\ufeff`、`\u00ad`、`\u200e`／`\u200f`、`\u2060` 都算；`String.prototype.trim()` 剥不掉它们（它们不是 Unicode WhiteSpace），件先把这一段剥掉再判。
2. **入参表以外的键一律拒**（顶层与每一档里都是）：多给的键（多半是打错名）不许静默吞掉。**自有的不可枚举键与原型链上继承来的键同样算**（只走 `Object.keys` 会漏掉这两类；件查的是自有的全部键名 ＋ `for…in` 整条链）。
3. **改不到的值＝拒**：时间的分钟不在 5 分钟格子上、日期不是真实存在的一天、选中的档不在那一排里、同一排里键重了、`chosen` 里的键不在 `routes` 里——一律报 `BlocksError`（给了也点不到的值，比不给更坏）。形态 `track` 还多两闸：`at` **非有限数与量级溢出**（`NaN`／`±Infinity` 与 `1e308` 那类——两笔同量级读数相加就成 `Infinity`）一律拒，且要**改得到**（整数分钟、落在 `0`–`1439`、踩在 5 分钟档上）；**两条提醒不许落在同一分钟**（同一时刻两枚点的命中盒会叠在一起，那一条按不准）。

## 契约与不变量（判据逐条断）

1. **一行一个决定**：三行——什么时候响 ／ 提前多久 ／ 走哪条通知；宽档左标签右控件（标签列宽上限 `REMINDER_SETTER_LABEL_PX`），窄档折成上下两段（标签仍在控件上面）。
2. **三排可点项都是真按钮**：整枚就是命中盒（≥`REMINDER_SETTER_TOUCH_PX` 高、相邻留 `REMINDER_SETTER_GAP_PX` 缝）；**没有拖拽、没有方向键、没有键帽**——手上一根手指就够。
3. **日期与时间「点得到」**：`22:30` 与 `2026-09-26` 各由**两枚 44×44 的步进键**（`−`／`＋`）夹着，一步 5 分钟、一步 1 天；跨零点绕回（`23:55` 再加一步是 `00:00`）；日期按 UTC 算（不随本机时区跳一天）。**读数永不截断**（样式段里没有省略手段）。
4. **选中态照法条**：有文字的选中面＝底 `accent-soft`、字 `accent-text`、描边 `accent`；**勾与方框走主色实底**（那上面只有一枚勾，没有正文级小字）。
5. **勾选槽位固定**：单选那枚的勾选位**未选也留** `REMINDER_SETTER_TICK_PX` 宽——勾上时不把档名顶歪，一排胶囊的左右沿齐平。
6. **状态不只靠颜色**：选中＝形（勾 ＋ 胶囊／实心方框）＋ 字（档名 ＋ 字重 700）＋ 色（软底）；单选是胶囊、多选是方框，**形状本身就是「这条可以多选」**。
7. **三个决定的隔线走发丝线**：`line` 那一档（比它更淡的线在 `neutral` 下几乎看不见，三块会摊成一片白纸）；卡自己带一层 `shadow`（`paper`／`broadsheet` 的取值本就是 `none`）。
8. **一条通知都不勾＝合法态**：`chosen: []` 时那行复述读成「没有通知，不会响」，**控件不变灰、也不弹解释**（本件没有任何按不动的控件：每一枚在任何状态下都点得动）。
9. **屏上是真读数**：机器读数住在根上的 `data-ilife-reminder-time`／`data-ilife-reminder-start`（**不从 DOM 文本反推**）；改完三处屏面一起重写（时间读数、日期读数、唯一那行复述）。
10. **复述那句口径只有一处**：`reminderSetterRecap()`（渲染期与运行时段**同一份源码**，运行时的 JS 文本里嵌的就是它）；步进同理（`reminderSetterStepTime`／`reminderSetterStepDate`／`pad2`）。
11. **松手才报数**：每次改动派发**一条**冒泡 `CustomEvent`（`detail` 见下）；本件**不写库**，写库归页面。
12. **窄档零横向溢出**：宽度只许容器判（本件自己声明 `@container` 容器；媒体查询只判悬停与减动效，**一条视口宽度查询都没有**）；窄档下时间与日期读数照原样换行，**不 `…` 截断**。
13. **加法式**：不挂本件的页面零命中、逐字节不变；换皮肤只换样式，标记逐字节相同。
14. **幂等**：`<html>` 上一枚 `data-ilife-reminder-runtime` 拦住重复注入；每张卡上记一枚 `data-ilife-reminder-bound` 读数。

**形态 `track` 的不变量（判据逐条断）**

15. **一天那条刻度**：一枚提醒＝一个 **44×44 的可点件**，落在哪儿由 `at` 算出来（`left: calc((100% - 44px) * place + 22px)`，两端各让出半个命中盒 ⇒ 最左／最右那一条也不会顶出刻度条）；刻度线由格宽（`100% / 24`）铺出来，**不摆 24 个元素**。
16. **点哪一条改哪一条**：刻度上那枚点与图例那一行**都是通路**（两处都挂 `data-ilife-reminder-part="pick"` ＋ `data-ilife-reminder-value="<id>"`）；点一下＝选中挪过去 ＋ 面板换成**它自己**的三个决定 ＋ 根上两个机器读数跟着换。
17. **一条提醒自己的三个决定住在它自己身上**：`data-ilife-reminder-at`（第几分钟）／`-repeat`／`-lead`／`-chosen`（空格分隔）挂在它那两处可点件上；面板上改完**回写**到这一条（写的是机器键，不是屏上那个档名）——切走再切回，刚改的还在。根上 `data-ilife-reminder-picked` ＋ `data-ilife-reminder-at` 是「现在改的是哪一条」的机器读数。
18. **时间＝两枚 44×44 的步进键**（面板里「时间」那一行，一步 5 分钟、跨零点绕回）：改完刻度上那枚点跟着挪（位置是 `at` 的函数）、图例那一行的时刻跟着改。
19. **图例那一行的尾一截照实读数**：这一条一条通知都没勾时读成「没有通知，不会响」（与 `decisions` 那一档**同一处口径**：`reminderSetterTrackTail()`）；时刻在屏上只印在图例那一行（面板里那一枚是步进键中间的控件读数）。
20. **触屏第一**：刻度上的点、图例每一行、三排可点项、两枚步进键，命中盒都 ≥`REMINDER_SETTER_TOUCH_PX`、相邻留 `REMINDER_SETTER_GAP_PX` 缝；**没有拖拽、没有键盘通路**（`:focus-visible` 只是真实键盘用户的地板）。

## 交互契约（页面侧）

```html
<!-- 样式段与标记：reminderSetterCss() ＋ renderReminderSetter(input)；外层挂 .ilife-page-ui 与皮肤类 -->
<script>/* buildReminderSetterJs() 产出的那段文本（两个形态共用这一段） */</script>
<script>
  document.addEventListener('ilife:reminder-setter-change', (e) => {
    const { id, part, value, state } = e.detail;
    // 形态 decisions：part ∈ repeat／lead／route／time／start
    // state ＝ { repeat, time, startDate, lead, routes }：改完之后的全量读数（按它落盘）
    // 形态 track：part ∈ pick／repeat／lead／route／time
    // state ＝ { picked, items: [{ id, at, time, repeat, lead, routes }] }：这一天全部几条的读数
    if (id !== 'rem-weight') return;
    save(id, state);
  });
</script>
```

**事件（`detail` 逐字段）**

| 事件 | 什么时候 | `detail` |
|---|---|---|
| `ilife:reminder-setter-change` | 换一次档／勾掉或勾上一条通知／按一下步进键／**点另一条提醒** | `{ id, part, value, state }`：`part` 是改的是哪一个决定（`repeat`／`lead`／`route`）或哪一格步进（`time`／`start`），形态 `track` 里还多一个 `pick`（点的是一条提醒：`value`＝那一条的 `id`）；`value` 是那一枚的机器键或新的 `HH:MM`／`YYYY-MM-DD` 读数，`state` 是**改完之后的全量读数**（`decisions`：`{ repeat, time, startDate, lead, routes }`；`track`：`{ picked, items: [...] }`；`state.repeat` 是**那一档的名字**——渲染期与运行时段读的是同一份事实） |

## 常见错法

- **把时间做成一个精确拖点或一个只能打字的格子**——手机上拖不准、打字要弹键盘；本件是两枚步进键夹一枚读数（点得到、看得见）；
- **把「至少留一条通知」写成一句话或把最后一枚勾灰掉**——屏上多一层话，或者留一枚按不动的控件；正确做法是**照实读出后果**（「没有通知，不会响」）；
- **在屏上加旁白**（「可选，给容易忘的事留一道」这种）——一屏只留一层话，说明住在 README 里；
- **把重复档做成自由文本**（`每天`／`每隔一天` 混着猜）——档名由调用方给成有限几档，机上只认机器键；
- **只改选中态不重写复述**——屏上写着「每天 22:30」而刚点的其实是「就这一次」，比没有读数更坏；
- **单选那枚不留勾选槽位**——勾上时档名被顶歪，一排胶囊左右不齐（这正是原型近两轮修掉的那一处）；
- **形态 `track` 里把三条提醒的数据摊成三个字段**（`time1`／`time2`…）——条数是变的；一条提醒的东西全部挂在 `items[]` 的同一个元素上；
- **形态 `track` 里把时刻写死成字符串**（`"07:00"`）——刻度上的位置要由数算出来，给 `HH:MM` 就得再解析一遍、还得自己防住 `8:00`／`25:00` 那类写法；给 `at`（一天里的第几分钟）一处算清楚；
- **形态 `track` 里忘了换面板**——点了另一条只挪高亮、下面还画着上一条的三个决定，用户改的是别人的提醒；
- **把「选中」只写成一种颜色**——形（点外那圈描边／实心点）＋ 字（图例那一行加粗、序号徽章）＋ 色要一起变（手机与电脑端同时在用）。

**形态 `track` 有意偏离原型的地方**（原型＝同文件 B 档；逐行指得出原型里的原文）：

| 原型里是 | 落地是 | 为什么 |
|---|---|---|
| 三枚点的位置写死成三个类（`.c-rem-at0800`／`-at1230`／`-at2230`） | 位置由入参 `at` 算出来，写进行内 `left`（`calc((100% - 44px) * place + 22px)`） | 原型是给一格演示用的静态稿；件里条数与时刻都是变的，位置必须是数的函数（且两端让出半个命中盒，窄档不顶出刻度条） |
| 点只有一枚 20px 的徽章 ＋ 18px 的圆点（命中盒 ≈ 20px） | 点＝**44×44 的可点件**（徽章与圆点住在它里面） | 触屏优先法条：点得到才算通路；图例每一行同样 ≥44 高 |
| `<i>` 摆 20 根刻度线 ＋ `.c-rem-track` 是一条 10px 的实心条 | 刻度条由 `background-size: calc(100% / 24)` 铺出 24 格刻度线 | 少 20 个只为装饰存在的元素（它们是 `aria-hidden` 的），窄档也少一次折行计算 |
| 编辑面板顶上有一行「选中：22:30 记体重」（`.c-rem-pickhd`） | **不落**——图例那一行已经印着同一件事 | 用户 2026-09-25 砍字（398 → 172）：同一件事印两处就是一屏两层话 |
| 面板里的 `重复`／`提前多久`／`通知` 是三个短标签 ＋ 一排胶囊 | 复用 `decisions` 那三行的标签（什么时候响／提前多久／走哪条通知）与三排槽位；另加一行「时间」（步进键） | 两档同一份话、同一套机器键（运行时段也只认一套）；改时间在原型 B 档里没有入口（点只能选，不能改），而「改某一条的时间」是这一档的主用途之一 |

**有意偏离原型的地方**（原型＝`.scratch/ui-组件墙/新件/parts-交互与流程.mjs` 第 89 件 A 档；逐行指得出原型里的原文，没原文的就不是偏离）：

| 原型里是 | 落地是 | 为什么 |
|---|---|---|
| 时间与日期是两枚 `<input type="text">`（打字填 `22:30`／`2026-09-25`） | 两枚 44×44 的步进键（`−`／`＋`）夹一枚读数，一步 5 分钟／1 天 | 触屏优先法条：日期与时间要「点得到」；打字把键盘当成了通路。步长写进常量，时间的分钟必须落在格子上（落不到的值屏上点不出来，故入参拒掉） |
| 三行标签下各有一句解释（「挑一次或重复，别混着猜」「可选，给容易忘的事留一道」「可多选，至少留一条；全关掉这条提醒就不存在」） | 一行都不上屏；「可多选」由**方框这个形**说，「至少留一条」由复述照实读出后果（`没有通知，不会响`） | 用户口径：原型里写了好多文字、看起来很混乱；一屏只留一层话 |
| 复述块是「设完是这样」＋一整句（`每天 22:30 提醒「记体重」；到点准时响一次；走系统通知。`）＋「下一次 09-25 22:30」＋一句免打扰说明 | **一行**：`每天 2026-09-26 22:30` | 读数一行说完；免打扰那句是旁白（它属于提醒引擎的规则，不属于这一屏） |
| 「下一次 09-25 22:30」由原型直接写死 | 改成 `每天 <起始日> <时间>`——**件算得出来的那一件事** | 下一次什么时候响要日历语义（每周几／每月某天／今天过了没），件拿的是**不透明档名**，算不准的读数不该印在屏上；起始日 ＋ 时间是件真算得出来的 |
| 抬头写「「记体重」的提醒 3 个决定」 | 只写「「记体重」的提醒」 | 「3 个决定」是元信息（数下面有几行），不是「它是什么」；一屏只留一层话 |
| 通知那三枚与单选一样是胶囊（靠文案「可多选」区分） | 多选走**方框**、单选走**胶囊**（形状分家） | 形状自己说得出「这条可以多选」，那一句文案才能从屏上撤掉 |
| 只有选中那枚写「✓」 | **未选的单选胶囊也留 14px 勾选槽位** | 原型近两轮的优化点：勾上时不顶歪档名，一排胶囊左右沿齐平 |
| 三块之间的横线写死 `1px solid var(--line2)`（更淡的那一档） | 走 `line`（发丝线）那一档 | 原型近两轮的优化点：更淡的那档在 `neutral` 下几乎看不见，三块会摊成一片白纸 |
| 卡片没有投影 | 卡加一层 `shadow` | 原型近两轮的优化点：`neutral` 那一套里它是一张平摊的白纸；零投影的几套皮肤本来就取 `none`，不吃损 |
