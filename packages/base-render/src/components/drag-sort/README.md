# drag-sort · 拖拽排序清单

**一句话**：一列步骤或事项，人来定第几位：**点把手拿起一行，再点另一行放下**（手机上同一套标记走得通）；拿起的那一行自己站起来，原位留一个虚线空槽，落点画一条粗线并写出放第几位。

它替掉的错法：顺序写死在数据里，人想换只能去改库；以及把拿起做成**隐式**（按住才拖得动，手机上等于没有备选）。

**形态**：本件只落地**形态 `lift`「拖拽中」**——出处＝原型墙 `.scratch/ui-组件墙/新件/parts-交互与流程.mjs` 第 83 件的 A 档（2026-09 用户三个形态逐格打分，A 档 4/4/4），按层规重写。形态键住 `DRAG_SORT_FORMS` 闭集（今天只有 `lift` 一格，**格号 A 不是接口名**）——**加第二形态是在闭集里加一格，不是新开一件**；闭集外的值一律报 `BlocksError`。同件 B 档「按钮排序」打分未过、**不落**。

## 何时用它（选型四条）

| 你要的 | 用 |
|---|---|
| 「第几位」还没定，正等人来排（做菜步骤、一天先做什么、心愿排期） | **本件** |
| 只改「完成没有」，顺序是数据里定死的 | `task-list`（勾选清单） |
| 分组折叠与展开，顺序同样定死 | `sub-list`（分组清单） |
| 按时间给出已完成与进行中（只读） | `step-flow`（只读步骤条） |

用在哪：作息管家的一天排序、私家大厨的做菜步骤顺序、备忘录的心愿排期。

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `id` | `string` | 必填 | 清单 `id`（同页唯一，事件 `detail.id` 就是它）。**只许标识符字符** |
| `title` | `string` | 必填 | 卡头标题（如「做菜步骤」）。**给了就不能只有空白** |
| `hint` | `string` | 点把手拿起一行。放下时点另一行。 | 卡头右端那句拿法。空串＝未给＝用缺省那一句 |
| `items` | `DragSortItem[]` | 必填 | 清单各行（**2–30 行**，顺序就是屏上的顺序） |
| `liftedKey` | `string` | — | 拿起态：被拿起那一行的机器键（须命中一行没锁定的）。不给＝谁也没拿起 |
| `dropAt` | `number` | ＝被拿起的那一位 | 落点位（1 起的位，≤行数）。**不给 `liftedKey` 时不许给** |
| `form` | `'lift'` | `'lift'` | 形态键（闭集；闭集外一律 `BlocksError`） |
| `extraClass` | `string` | — | 附加类名（空格分隔，逐个过类名正则） |

**行（`items` 的每一个元素）**

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `key` | `string` | 必填 | 机器键（事件 `detail` 原样送出）。**只许标识符字符**，清单内唯一 |
| `label` | `string` | 必填 | 名称（如「五花肉切 3 cm 方块」）。**非空、且不能只有空白**；长了**换行**，绝不截断 |
| `note` | `string` | — | 副语，一行一句人话（如「约 5 分钟，主料」）。给了就不能只有空白 |
| `meta` | `string` | — | 右端读数（如「5 分」，已经是给人看的样子）。给了就不能只有空白 |
| `locked` | `boolean` | `false` | 锁定时这一行拿不起来（把手 `disabled`，**必须同时给 `why`**） |
| `why` | `string` | — | 锁定的原因，写在名称格那一位。**不能只有空白** |

**入参纪律（两条，判据逐条断）**：

1. **上屏的文字全空白＝拒**（`badInput`）：`'   '` 会在屏上留一块**看得见的空白**。空串＝未给（与全层 `optText` 同口径），**只有空白＝拒**。
2. **入参表以外的键一律拒**：多给的键（多半是打错名）不许静默吞掉。

## 契约与不变量（判据逐条断）

1. **拿起态三样齐**：`liftedKey` 指着哪一行，那一行挂 `is-up`（往上挪 2px ＋ 强调描边 ＋ 左侧 2px 主色侧标 ＋ 次要面底），它后面跟一个虚线空槽（写出哪一步空着），落点位前面画一条 3px 粗线（写出放第几位）。三样都带字，不只靠颜色。
2. **点选是主通路**：每一行一枚 44×44 的把手按钮——**点一下拿起**（松手那一下拿起，不是按下就拿起：按下就拿起会被同一手势的 `click` 立刻取消掉）、**再点哪一行都放**（点名称格、读数格、空槽都算那一行；把手只是「拿」的入口）、点「取消放回」或点被拿起那一行自己＝放回原位。拖拽只是同一份状态的另一条路。行间留 8px 缝。
3. **一块一次**：同一次只拿起一行、全页只挂一块（另一块正拿着时点这一块，先把那一块收掉）；错开的两块之间用**按下时那个根**绑定，同一个 `id` 渲染两张也不会串。
4. **零键盘语汇**：标记与文案里没有长按／双击／方向键那一路，也**没有把它们当通路**——每一行都点得到，`:focus-visible` 只是给真实键盘用户的无障碍地板。
5. **序号与名称永不截断**：长了换行；位置读数（第 n／m 位）每一行都写，放下后整列重写。
6. **落点粗线通栏**：3px 实线的左沿＝右沿＝行沿（右端不短一截），写「放这里（第 n 位）」的那枚胶囊**压在线上**。
7. **松手才报数**：拿起／放下／取消各派发一条冒泡 `CustomEvent`（`detail` 见下）；本件不写库，写库归页面（拿到放下后的全序 `keys` 按新顺序重渲染，或什么都不做）。
8. **锁定的行说得清为什么**：把手 `disabled`（`cursor: not-allowed`），原因写在名称格那一位；锁定的行拿不起来，也不是落点。
9. **文案只有一处定义**：会过屏的每一句住 `DRAG_SORT_TEXT`（`attrs.ts`），渲染期与运行时段都从那一份烘（改一句两边一起变）。
10. **样式只经 `skinVar()` 读皮肤**；**宽度只许容器判**（根自己声明容器，窄档按本件自己的宽度折行；媒体查询只判悬停与减动效）。
11. **加法式**：不挂本件事的页面零命中、逐字节不变。

## 常见错法

- **把「按住拖」做成唯一通路**（把手不是按钮、点不动）——手机上等于没有这个功能；把手必须是看得见、点得到的按钮；
- **拿起态三样缺一样**（只有高亮那一行，空槽与落点线都不画）——读者不知道原来的位在哪、放下会落在哪；
- **三样只靠颜色区分**（高亮行只换个底色）——色不是唯一信息，形（位移／虚线／粗线）与字（状态句／空槽句／落点句）至少再给一样；
- **序号或名称截断**（`…`）——排到第几、是什么事，截掉一个字都不行；
- **放下后不重写位置读数**——第几位的读数过期，比没有读数更坏；
- **拿它当勾选清单**（只改完成没有）——那是 `task-list`；**拿它当只读步骤条**——那是 `step-flow`。

**有意偏离原型的地方**：

| 原型里是 | 落地是 | 为什么 |
|---|---|---|
| 卡头写「长按左边的把手拖动」 | 写「点把手拿起一行。放下时点另一行。」 | 长按不是手机上的东西；点选是主通路，拖拽只是另一条路（触屏优先法条） |
| 行间 1px 发丝线分隔 | 行间 8px 缝，每行 1px 发丝框 | 相邻触控目标间距 ≥8px（工艺书地板）；拿起态要看得出哪一行站起来了，整行框比无线更稳 |
| 拿起行描边与侧标 4px 级 | 描边 1px ＋ 左侧 2px 主色侧标 | 「整行选中」那一档的法条口径（`选中态与皮肤语言.md` 第三节） |
| 每行只写序号 | 每行都写「第 n／m 位」位置读数 | 工单点名「位置读数更清楚」；挪完了不看把手也知道到哪儿了 |
| B 档的上移下移两颗按钮 | 本形态没有那两颗按钮；备选是点选拿起放下 | B 档打分未过不落；点选已满足「看得见的备选」 |
