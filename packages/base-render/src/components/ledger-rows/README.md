# ledger-rows · 账目行

**一句话**：一页的读数逐项列成"账"——`标签 …………… 值 单位`，标签靠左、值靠右、中间点线相连（读的时候不串行）。

## 何时用它（选型三条）

| 你要的 | 用 |
|---|---|
| 值是**一列**、要竖着比、行数不定（目标／剩余／条数／覆盖） | **本件** |
| 值是**一排并列的格子**（拍摄时间／标签／文件名） | `renderFactStrip`（页面级形状件） |
| 「改前 → 改后」两列对照 | `renderChangeRows`（区块层） |
| 带表头、列数 ≥3 的表 | `renderDataTable`（区块层） |

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `rows` | `LedgerRowInput[]` | 必填 | 一行一条；空数组出不了一个字 |
| `rows[].label` | `string` | 必填 | 人话短标签（`目标`／`餐别覆盖`） |
| `rows[].value` | `string` | 必填 | 值（**已是给人看的样子**） |
| `rows[].unit` | `string` | — | 单位（`卡`／`g`／`天`），小一号跟在值后 |
| `rows[].kind` | `'item' \| 'total'` | `'item'` | `total`＝合计行（上一条实线 ＋ 加粗） |
| `heading` | `string` | — | 小标题（`账目`）；字距由样式段统一，**调用方不要自己加空格** |
| `leader` | `'dots' \| 'none'` | `'dots'` | 引导线 |
| `extraClass` | `string` | — | 附加类名 |

## 契约与不变量

- 值列**右对齐 ＋ 等宽数字**（`tabular-nums`）⇒ 逐行竖读时单位在同一列；
- 引导线是**零高度的下边框**（`flex:1` 撑开、抬到基线），开关它不改任何行的行高；
- 行距与 `entry-rows` 同档（padding 6px 0）⇒ 两件混排时行高一致；
- 相邻行之间一条 hairline，**首行不带**；`total` 行换成一条实线（比 hairline 重一档）＋ 字加粗；
- 样式 scope 在 `.ilife-page-ui` 下；本件零 DOM。

## 常见错法

- 一行里用冒号串「标签：值」，多行排下来右边的值参差不齐（列没对齐 ⇒ 没法纵向比数）；
- 用表格装"只有两列、第二列是值"的清单（表头、斑马纹、列宽规则全是多余的）；
- 同一页里「目标／剩余／记录条数」各占一张 KPI 卡（三张卡说三行字）；
- 小标题自己写「账 目」（加空格充字距）——字距归样式段。

## 关系

- 与 `entry-rows` 同族不同职：**账目＝一页的读数**，**明细＝一条记录**。同页同时出现时刻意用两种分隔（hairline ↔ 点线）分开。
- 样式随 `sheetCss()` 一起挂；单独用时可只挂 `ledgerRowsCss()`。
