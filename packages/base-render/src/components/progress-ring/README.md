# progress-ring · 进度环

**一句话**：一块「已完成／目标」的环——**形态 A**＝半环（180°）＋ 环下大字 ＋ 右侧读数；超目标时换色并补一句人话。

## 何时用它（选型四条）

| 你要的 | 用 |
|---|---|
| 「到目标的几成」＋「还差多少」——一个数对一个目标 | **本件**（环 ＋ 分母 ＋ 右侧读数） |
| 只要那根条、不要环（列表里密排） | `scale-bar`（刻度条，同族） |
| 「一块怎么分成几条」 | `stacked-bar`（构成条，同族） |
| 表格里的百分数、一排互不相关的量级 | `renderDistributionRows`（区块层） |

用在哪：卡路里（热量预算／目标进度）／记账（预算）／居家管家（盘点）。

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `title` | `string` | 必填 | 卡头标题（`今日热量预算`） |
| `stamp` | `string` | — | 卡头右端那句（`3 月 14 日 · 周六`）；不给＝不出 |
| `value` | `number` | 必填 | 已完成量，**必须 ≥ 0**；**可以大于 `goal`**（那是超目标态，不算错） |
| `goal` | `number` | 必填 | 目标量，**必须 > 0**（它就是分母与弧长标尺） |
| `unit` | `string` | — | 单位（`千卡`／`元`／`件`）：只上屏，不参与机器口径 |
| `rows` | `{label,value}[]` | — | 右侧读数（`还能吃 420 千卡`）；不给＝环独占整排 |
| `note` | `string` | — | 脚注那句人话（未超目标时用）；不给＝本件按读数算一句 |
| `overNote` | `string` | — | 脚注那句人话（**超目标时**用）；不给＝本件按差额与百分比算一句 |
| `form` | `'arc'` | `'arc'` | 形态闭集（本件只落地形态 A）；闭集外报 `BlocksError` |
| `extraClass` | `string` | — | 附加类名（空格分隔，逐个过类名正则） |

`rows[].value` 收「已经是给人看的样子」的串；缺值写成 `—`（`PROGRESS_RING_MISSING`），**不许写 0、不许留空**。
`value`／`goal` 是**数**：千分位由本件做，取整与单位口径归调用方。

## 契约与不变量

- **弧长与读数同一份真值**：半环弧长 `PROGRESS_RING_ARC_LEN` ＝ π×70 ＝ 219.91，
  填充弧的 `stroke-dasharray` 是 `「ratio × 219.91」 「219.91」`，而环下那枚胶囊写的百分数就是 `ratio`。
  **画出来的弧长 ÷ 整条弧长 ＝ 那句百分数**——判据断的就是这条等式，不是"看起来差不多"。
- **超目标只换色、形状不变**：`is-over` 让弧画满（与同族 `scale-bar` 的"满格"同一条口径），
  填充弧换危险色、百分数胶囊换危险软底、脚注那句换危险色**并带差额与百分比**（色不是唯一信息）。
- **环是内联 SVG，大字是 HTML**：环宽 100% 自适应（上限 `PROGRESS_RING_MAX_DIAMETER_PX` ＝ 280px），
  大字与右侧读数走同一套字号阶梯 ⇒ 容器变窄时读数不随 SVG 一起缩放。
- **零横向溢出**：`flex-wrap` ＋ `minmax(min(190px,100%),1fr)` ＋ 每处 `min-width:0`；
  宽度只由 `@container` 判（阈 420px），**不写任何 `@media` 宽度查询**（视口宽 ≠ 组件宽）。
- 数值一律 `font-variant-numeric: tabular-nums`；金额／日期／百分数**永不 `…` 截断**。

## 常见错法

- **只报一个百分数**（`75%`）⇒ 读者看不出"还差多少"：分母与 `rows` 才是这一件的另一半；
- **把大字写进 SVG `<text>`**：字号随 SVG 一起缩放，窄容器里读数先糊（本件的写法是 HTML 叠在环下）；
- **超目标时把弧画到底就不管了**：颜色不变、也不说超了多少（本件三处同时说话：色 ＋ 胶囊 ＋ 那句人话）；
- **拿本件当构成条**：环只有"已完成／目标"一根弧，多段构成归 `stacked-bar`。

## 关系

- 与 `summary-head` 配对：头给"今天吃了多少"，环给"离目标还有多远"；
- 与 `scale-bar` 同族（形状与比例）：**要能逐格数**用 `scale-bar`，**要一块整体印象**用本件。
