# streak-badge · 连记徽标

**一句话**：**"你已经连着做了 N 天"那一句话**——`前词 · 数（放大成读数）· 量词`，一行几个、强弱三档。

## 何时用它（选型四条）

| 你要的 | 用 |
|---|---|
| 一句话的连记战绩／本月覆盖／上次断点，有轻重之分 | **本件** |
| 一整排"这 7 天记了没记"的格子 | `punch-strip`（打孔格带） |
| 一个比例形状（吃了几成／预算用掉多少） | `scale-bar`（刻度条）／`progress-ring`（进度环） |
| 一笔在途的事走到哪了（分期／保修） | `status-row`（状态台账行） |
| 一行一条、可勾选 | `task-list`（勾选清单） |

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `badges` | `StreakBadgeItem[]` | 必填 | 徽标逐个；空数组且无 `absentLine` ⇒ 空串 |
| `badges[].strength` | `'strong' \| 'mid' \| 'weak'` | 必填 | 强弱档：**它决定形状**（实底／描边空心／无框底线） |
| `badges[].label` | `string` | 必填 | 前词（`连续记录`／`本月`／`上次断在`） |
| `badges[].value` | `string` | 必填 | 数（`37`／`21 / 30`／`08-14`）：等宽 ＋ 永不截断 |
| `badges[].unit` | `string` | — | 量词或尾巴（`天`／`天有记录`） |
| `heading` | `string` | — | 小标题（`连记`） |
| `absentLine` | `string` | — | 空态那一句（`还没有连记记录`）：它是"没什么"，不是一个徽标 |
| `form` | `'row'` | `row` | 形态键（闭集；本件只落地形态 A「一行几个徽标」） |
| `extraClass` | `string` | — | 附加类名（空格分隔） |

## 契约与不变量

- **强弱三档靠形状分**（色只是第三样）：`strong` 实底 ＋ 反白字 ＋ 字重 800；`mid` 1px 描边空底 ＋ 字重 700；
  `weak` 无框、只有一条 2px 底线 ＋ 字重 600 ⇒ 「大字报刊」皮肤下强调色＝墨黑也分得出轻重。
- **数只收"已经是给人看的样子"的串**：连记天数、分母、日期格式**归调用方**（本件不算数、不换算）。
- 读数 `white-space:nowrap`（数不许被 `…` 截断）；前词可以换行（`overflow-wrap:anywhere`）。
- 缺值写成 `—`（`STREAK_BADGE_MISSING`）：不许写 0、不许留空。
- 本件**零 DOM、零动效、零可点元素**（没有可卡住的中间态，也不装作能点）。
- 窄档由**容器**决定（`@container ilife-streak-badge`，断点 `STREAK_BADGE_NARROW_MAX_PX`＝380）：
  容器窄了一个徽标一行，不看视口宽。

## 常见错法

- 三个徽标只换颜色（读者分不出哪个是"当前战绩"、哪个是"上次断点"）⇒ 档位必须换个形状。
- 把数写进句子里（「连续记录了 37 天」）⇒ 数要单独一槽，几个徽标竖排才对得齐。
- 断签也画成同一个实底徽标 ⇒ 用 `weak`（无框底线）——读起来是注脚，不是战绩。
- 拿本件当进度条使（要"还剩百分之多少"的形状）⇒ 那是 `scale-bar`／`progress-ring` 的活。
