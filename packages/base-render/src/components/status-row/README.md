# status-row · 状态台账行

**一句话**：一笔还没走完的事，**一行**——`轨道点 ・ 名称 ・ 阶段徽标 ……… 金额`，第二行 `补充 ……… 到期日`。

## 何时用它（选型四条）

| 你要的 | 用 |
|---|---|
| 一笔事有**阶段**（已还 3 期 → 本期待扣 → 未开始），要一眼看出走到哪了 | **本件** |
| "还剩几天"要放大成读数、每行还要带一个动作 | `due-row` |
| 一串"时间 ＋ 做了什么"按时间轴连起来（左侧轴线 ＋ 圆点） | `renderTimelineRows`（页面级形状件） |
| 只要"标签 →点线→ 值"两字段、没有阶段 | `renderLedgerRows`（账目行） |
| 清单里一行一条、可勾选 | `task-list` |

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `rows` | `StatusRowItem[]` | 必填 | 台账逐行；空数组且无 `absentLine` ⇒ 空串 |
| `rows[].name` | `string` | 必填 | 这一笔事是什么（`手机分期 · 第 4 期`） |
| `rows[].phase` | `string` | 必填 | **阶段字**（`本期待扣`／`已还 3 期`／`已过期`）——状态必须带字 |
| `rows[].tone` | `'neutral' \| 'active' \| 'ok' \| 'warn' \| 'danger'` | `neutral` | 档位：徽标与轨道点的**形状**跟着它走 |
| `rows[].amount` | `string` | — | 金额／主读数（`¥620.00`）：右对齐 ＋ 等宽 ＋ 永不截断 |
| `rows[].amountUnit` | `string` | — | 金额单位（`元`）：小一号跟在金额后 |
| `rows[].meta` | `string \| string[]` | — | 第二行补充（`招商信用卡 · 自动扣款`）：数组＝逐段一枚 |
| `rows[].due` | `string` | — | 到期日（`10-18`／`2027-06-18`）：等宽 ＋ 永不截断 |
| `rows[].dueNote` | `string` | — | 到期日后的注脚（`还剩 23 天`）；给了它必须同时给 `due` |
| `rows[].dueTone` | `'neutral' \| 'active' \| 'ok' \| 'warn' \| 'danger'` | 跟 `tone` | 到期日自己的档位（已完成的事也可能当年逾期过） |
| `heading` | `string` | — | 小标题（`在途的事`） |
| `count` | `string` | — | 右侧计数（`4 笔在途`）：**本件不数数**，数由调用方给 |
| `absentLine` | `string` | — | 空态那一句（`没有在途的事`）：它是"没什么"，不是一行 |
| `foot` | `string \| string[]` | — | 脚注（`共 4 笔`／`在途 ¥5,900`）：数组＝逐段一枚 |
| `form` | `'ledger'` | `ledger` | 形态键（闭集；本件只落地形态 A「单行台账」） |
| `extraClass` | `string` | — | 附加类名（空格分隔） |

## 契约与不变量

- **状态＝字 ＋ 形 ＋ 色**：`phase` 必填（色不是唯一信息）；五档档位的形状差异逐档写在样式段里
  （轨道点：空心圆／双环实心／实心圆／空心方／双线菱；徽标：无框底线／空心框／实底色块／框＋底块／双线框）
  ⇒ 「大字报刊」皮肤下强调色＝墨黑，本件仍分得开。
- **永不截断**：`name` 与 `meta` 允许 `overflow-wrap:anywhere` 换行；`amount`／`due`／`phase` 一律
  `white-space:nowrap` 且不写 `overflow:hidden`（金额、日期、状态是三样不许被 `…` 吃掉的东西）。
- **缺的槽不留空位**：只给 `name`／`phase` 时，金额、第二行、脚注一个字都不出（不写占位符顶替）。
- 计数（`count`）与脚注（`foot`）里的数**不由本件算**：本件不汇总、不格式化金额。
- 样式 scope 在 `.ilife-page-ui` 之下；只经 `skinVar()` 读皮肤；本件**零 DOM、零动效、零可点元素**。
- 窄档由**容器**决定（`@container ilife-status-row`，断点 `STATUS_ROW_NARROW_MAX_PX`＝460）：
  容器窄了金额与到期日各占一整行，不看视口宽。

## 常见错法

- 三种阶段只给三个颜色的小圆点、不给字 ⇒ 色盲与黑白打印下全塌（本件把字设为必填就是拦这个）。
- 一笔分期摊成三行正文（「已还 3 期」「第 4 期待扣 ¥620」「后续 8 期」）⇒ 读不出这是同一笔的哪一段；
  正确做法是让它成为台账里**三行**（每行一个阶段），或一行里用 `dueNote` 说清下一步。
- 金额夹在句子中间（「还剩 ¥3,720 未还」）⇒ 同页多笔时对不齐、比不出大小；金额住 `amount` 槽。
- 把"没有在途的事"塞进 `rows`（会被算成一行、还会带上值位）——那是 `absentLine` 的位子。
- 让本件去算合计或换算单位（本件只收"已经是给人看的样子"的串；算错了没法在标记层分辨）。
