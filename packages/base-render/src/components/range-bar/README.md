# range-bar · 区间条

**一条轴上摆起止区间，长度就是「多久」**：每类一行（泳道），轨道上的区间按百分比定位，
行尾那枚合计是该类的总时长／总天数；段够宽时，段里再写一遍时长字（写在卡面小牌上，换皮也读得清）。
出处＝原型墙 `.scratch/ui-组件墙/parts-05-时间与分组.mjs` 的形态 A（2026-09 用户裁定）。

## 什么时候用它

| 你要的 | 用谁 |
|---|---|
| **起 → 止**的区间，读得出"多久"（睡眠／日程区间、分期期间、腌制发酵时长） | **本件** `renderRangeBar` |
| 值／目标的**比例**形状（一条轨、一个值） | `renderScaleBar` |
| 24 小时摊开成**一条带**（哪几段在做什么、段里写时长） | `hourBandCss` 那件（`hour-band`） |
| 一格一天、值进格（7～14 天窗口） | `renderPunchStrip` |

## 用法

```js
import { renderRangeBar, rangeBarCss } from 'base-paint/blocks';

renderRangeBar({
  title: '5 月 14 日 周四',
  use: '作息管家 · 一天里的区间',
  domain: { min: 0, max: 1440 },        // 轴：一天里的分钟
  axis: ['0', '6', '12', '18', '24'],   // 刻度写法归调用方（本件不猜时间／日期的格式）
  summary: { label: '非空闲', value: '16h00m' },
  lanes: [
    { label: '睡眠', mark: '●', total: '7h20m', intervals: [
      { from: 0, to: 400, text: '6h40m', tone: 3 },     // 段够宽 ⇒ 段里写时长
      { from: 1400, to: 1440, tone: 3 },                // 跨午夜：调用方拆成两段
    ] },
    { label: '工作', mark: '◆', total: '7h30m', intervals: [
      { from: 570, to: 720, tone: 2 }, { from: 810, to: 1110, tone: 2 },
    ] },
  ],
  note: '跨午夜的两段请调用方自己拆',   // 不给＝不出
});
rangeBarCss();                          // 样式段（页面自己按需注入；不挂＝零命中）
```

| 入参 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `title` | `string` | ✅ | 标题（不截断，长了换行） |
| `domain` | `{ min, max }` | ✅ | 轴的范围，必须 `min < max`；区间必须落在它里面 |
| `lanes` | `RangeBarLaneInput[]` | ✅ | 0 条＝空串 |
| `lanes[].label` | `string` | ✅ | 类别名（如「睡眠」） |
| `lanes[].intervals` | `RangeBarIntervalInput[]` | ✅ | 这一类的区间（逐条 `from < to`、在轴内） |
| `lanes[].mark` | `string` | — | 类别名前那枚记号（如 `●`；不只靠颜色的第二路） |
| `lanes[].total` | `string` | — | 行尾合计（**是时长永远读得到的兜底**） |
| `intervals[].from` / `.to` | `number` | ✅ | 起止（同一单位：作息＝分钟，记账＝日期序数） |
| `intervals[].text` | `string` | — | 段内时长字（如 `7h20m`）；**只在段占到轴长 `RANGE_BAR_TEXT_MIN_FRACTION` 以上时才上屏** |
| `intervals[].tone` | `1 \| 2 \| 3 \| 4` | — | 深浅档，缺省 2 |
| `axis` | `string[]`（≥2 枚） | — | 轴刻度；不给＝不出刻度（泳道照旧） |
| `use` | `string` | — | 用途说明 |
| `summary` | `{ label, value }` | — | 头部右端合计位 |
| `note` | `string` | — | 脚注 |
| `form` | `'lanes'` | — | 形态键（闭集，本件只有这一格） |
| `extraClass` | `string` | — | 附加类名（空格分隔、逐个过类名正则） |

## 契约与不变量

- **零 DOM**：只产标记，无脚本、无内联事件；样式只走 `rangeBarCss()`。
- **长度＝多久**：区间的位置与长度都是轴上的百分比 ⇒ 一眼看得出"多久"，不用读者自己减。
- **出界一律 `badInput`**：本件不裁剪、也不做跨午夜／跨月推断——裁剪出来的长度是假的（读者会当真时长）。
- **刻度行与泳道是两张同模板的网格**（`.ax` 与 `.lanes` 各一副 `54px minmax(0,1fr) 66px`；泳道用 `display:contents` 把三个槽直接落进泳道网格）⇒ 轨道宽恒等、刻度两端对得上轨道两端。**别把刻度行塞进泳道那张网格**：那会把每条泳道的三个槽推错列、轨道被压进第一栏（判据量"左侧越界 11px"抓到过）。
- **左右两栏定宽**：定宽是"两张网格列宽恒等"的前提（`auto` 会按各自内容算，两边就错开了）。
- **段内时长字只在段够宽时上屏**：窄段写了必然挤成一团或被裁；时长永远有**行尾合计**兜底，语义不丢。
- **窄档不横滑、刻度不压字**：轨道是份数（`minmax(0,1fr)`）、区间是百分比；刻度标签 `flex-wrap` ＋ 8px 列距 ＋ `nowrap`（判据量两两不重叠）。
- **合计换行不截断**：合计栏定宽，装不下就折行（**不写 `…`**，也不 `nowrap` 顶出栏外）。
- **深浅从 token 算**：四档＝`color-mix(in srgb, accent N%, surface-2)`，不写死颜色 ⇒ 各套皮肤（含强调＝墨黑）下都是同一条"浅 → 深"。
- **本件是自己的容器**（`container-type: inline-size`）：给它一个**确定的宽度**；不要在 shrink-to-fit 的 flex 项里用 `auto` 宽度。

## 示例入参

本件**唯一一份**示例入参（皮肤矩阵判据拿它渲染本件、必须能**直接**渲染成功）：

## 常见错法

- 拿它当**甘特图／日程编辑器**用：本件是读数形状，不含拖动改起止、不含选中（拖动是另一形态的活）。
- 把跨午夜的睡眠写成 `{ from: 1400, to: 400 }`：`from < to` 一关就报错 ⇒ 拆成 `[1400,1440]` 与 `[0,400]` 两段。
- 段太窄还硬要写时长字：那会挤成一团 ⇒ 交给行尾合计（段内字是**增益**，不是唯一通路）。
- 用柱子画单点（9 点一根柱）：柱子没有长度，长短差被画成高度差 ⇒ 用区间。
- 同一类里区间重叠：本件照画（不做并集），但读的人会把重叠读成"同时在做两件事"——重叠请先合并。
