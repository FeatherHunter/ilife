# prompt-box · 提示框

一段拿得走的提示文本：标题 ＋ 等宽正文 ＋ 一枚复制按钮。
落点是「填参数 → 生成提示 → 复制出去」这条链的可视化一端。

只落一种形态（`card`）：标题在上、正文居中、按钮在下。

## 入参

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `text` | `string` | 必填 | 提示正文（非空；换行与空格原样保留） |
| `label` | `string` | 可选 | 标题；不给＝只出正文与按钮 |
| `copyText` | `string` | `复制` | 复制按钮的字 |
| `hint` | `string` | 可选 | 按钮旁那句小字（用法说明） |
| `form` | `card` | `card` | 形态键（闭集） |
| `extraClass` | `string` | 可选 | 附加类名（空格分隔） |

<!-- 示例入参：皮肤矩阵判据拿它渲染本件，必须能直接渲染成功 -->

```json 示例入参
{ "label": "复制提示给 AI", "text": "请加载技能，按周复盘上周的饮水记录", "hint": "点复制后粘贴给 AI" }
```

## 运行时

`buildPromptBoxJs()` 产出 JS 文本：点复制按钮 → 把同一张卡里正文的文字交出去 →
派发冒泡事件 `ilife:prompt-copy`（`detail = { label, chars, ok }`）。
页面按 `ok` 写回执；落库归页面自己，本件不写库。

## 样式

`promptBoxCss()`：单列纵排卡；正文等宽、软底；按钮 44 高、胶囊、强调底。
颜色只经皮肤 token 读，不手写色值。
