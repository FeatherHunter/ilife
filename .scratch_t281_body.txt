## 验收命令

```
pnpm build && pnpm gen:check
node --test packages/skill-calorie/test/photo-shape-read-<票号>.test.mjs
node packages/skill-calorie/scripts/gen-photo-baseline.mjs --check
```

用例：① 两条命令真跑，产物都以 `<!doctype html>` 起、含复制区与 `data:image/`；② 对比页保留老实物口径（并排 ＋ 间隔天数 ＋ 跨标签警告文案）；③ 缺照片／传入不存在的 id 时按既有缺失阻断口径（exit 4，不回半页）；④ **变异自证**：去掉内嵌必红；⑤ 每条用例另断言 `data.output` 是绝对路径且该文件在盘上。
