#993 · base 只走公开接口

一句话：用 base 对外开的那扇门，不翻窗、不抄作业

门在哪：包 base-paint 的 src/index.ts 转出的名字 + package.json 的 exports 五把钥匙。

门长这样

  • 根门（base-paint）：renderPage、escapeHtml、buildSharedHelpersJs、renderStatusBadge、pageUiCss、renderChipRow、fillTemplate 等。
  • 子门（base-paint/blocks 等）：块件如表格、读数卡、键值行，只能走 /blocks 这把钥匙，根没有就不硬闯。
走门（对）：import { renderPage, escapeHtml } from 'base-paint'；徽章行 import { renderChipRow } from 'base-paint'。
翻窗（错）：直引深路径 src/components/xxx/inner.ts；或把人家的转义、样式抄一份放自己目录（比如自写 esc、手写整套 CSS）。抄的那份迟早和原份走散，同一件事算出两个结果。

落到我们两页

  • 纸、头、账行、明细、复制：全部从门里拿（sheet-frame 纸、summary-head 头、账行明细行、复制运行时），不自写第二套。
  • 7222 的口径（符号即方向、转账双笔、分类三级）是记账自己的事，留在 skill-bill，不搬进 base。
  • 所以“只走公开接口” = 新两页的漂亮全靠门里的零件拼出来，拼法是我们的，零件是公用的。

违反的样子叫抄，铁律一能力自治。有缺的零件就先说缺什么，不自己造第二套。
