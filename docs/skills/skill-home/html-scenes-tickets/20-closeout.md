## 目标

① **发一批产物**：把 70 份产物按人读得懂的名字复制进**同一个产物目录**（`.scratch/<本票号>/`，工作区内——本机视觉工具只吃工作区内文件），墙页与产物同目录；
② **出墙**：按 **8 个域**成对出（手机 390 宽／桌面 1280 宽），格高一致；格数＝册子条目数（**70 格**，少一件要在索引页「有意不出」一节交代）；`link` 域本图不做、无产物，**不出墙**（用户 Q6 答的「9 域」按此订正为 8 域：9 个域里 `link` 只留登记位）；
③ **出链路总览页**：一行一场景（序｜域｜场景标题｜prompt｜唤醒词｜命令｜绝对产物路径），绝对路径文本可点即跳转；
④ **机检与机审全绿**：`pnpm test` 绿、样式与文案判据件六列 **0 命中**；
⑤ **生成器自检走两面**：正例 exit 0、反例 exit 1 并点名；
⑥ **vision 逐页复核记录 ＋ 综合分 ≥90/100**：每页记「看了哪一页、什么症状、改了什么」，低于 90 就改完再评；
⑦ **交维护者终审**：墙 ＋ 逐格缺陷清单 ＋ 自检退出码三样一起交，等一句「过」；
⑧ **端到端**：70 条场景各跑一次真命令链（唤醒词 → 命令 → 落盘），回执里的**绝对路径逐条能打开**——这是 Destination 的第 ① 条判据，不许只交「页好看」。
