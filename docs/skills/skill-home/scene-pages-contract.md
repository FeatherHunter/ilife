# 场景页契约（地图 #797 票 2 结论固化，规格单 #846 实施）

本契约让 11 张域票并行做出 70 条场景的真页面而不互相覆盖、不重复裁决。
它只定硬约束，不写页面内容；页面内容归 11 张域票，路由与内容资产实施归票 3，唤醒词归属归票 22。

事实源：`packages/skill-home/src/help/scenarios.yaml`（73 条场景，含联动 3 条）；
信息结构来源：`docs/skills/skill-home/pages-ledger.md` 表一（49 行老模板，减联动 3 行得 46 族）；
唤醒词结论引用：`docs/skills/skill-home/wakeword-spec.md`（本契约不重复裁决词的归属）。
机器附录：`docs/skills/skill-home/scene-pages-contract.appendix.json`（46 族／70 场景／命名／必需块／写集／共用位，一次发布，多方消费）。
单接缝检查：`docs/skills/skill-home/check-scene-contract.mjs`（文档加附录作为一个整体校验）。

## 层与冻结顺序

契约分三层冻结，后层不等前层即可开工的票先走：

- L0 先冻（形状加写集加共用位所有权加锁上限）：8 个能力目录加标准件、按页族文件切写集、共用位归票 3、联动只留登记位、锁上限 10 分钟。票 3 前半凭本层先开工。
- L1 次冻（两层解析函数签名加 46 名表）：`(命令，场景预设）` 到页族的解析签名与 46 个页族名。等票 22 输入，可与 L0 并行准备，不阻塞票 3 前半。
- L2 后冻（命名函数加必需块表）：产物命名函数与必需块机器附录。票 6 与票 8 只消费附录，不阻塞开工。

层与层之间不回头改前层；真装不下走补丁流（见页族节），不前置全量拆分论证。

## 形状

能力目录取自 HELP 一级分组，共 8 个，`link` 只留登记位、不建目录：

`items`／`space`／`outfit`／`stats`／`express`／`receipt`／`family`／`setup`。

每个能力四件标准件，照卡路里先例（`packages/skill-calorie/src/diet/` 的 `index.ts` 能力门／`commands.ts` 命令声明／`routes.ts` 路由声明）：

- `src/<域>/index.ts`：能力门，对外转出不超过五个，跨能力调用只走这道门。
- `src/<域>/commands.ts`：命令声明权威源，加一条命令只改本文件加它那个子功能文件。
- `src/<域>/routes.ts`：路由声明，顺序权威只住声明里的顺序一位。
- `src/<域>/pages/<页族>.ts`：每页族一页模块，一族一个装配件。

`link` 域（联动总览／记到卡路里／记到记账）只在登记表里留一行，不建 `src/link/` 与 `templates/link/`，不留空壳目录与空页面。

## 页族归属与两层解析

46 个页族名先按老模板名冻结为装配边界，一族等于一模板加一页模块（一对文件）。信息结构差异先在族内用 `mode` 条件块消化，不前置拆分。

46 名表与每族服务的场景清单见机器附录 `families`（派生自册子表一，减联动 3 行）。族数 46 覆盖 70 条场景，落在 8 个域（物品管理 19／空间与位置 4／穿搭出行 5／统计总览 4／快递购物 4／票据凭证 4／家庭协作 2／开始使用 4）。

解析是两层函数，不得用今天的 1:1 映射（`src/render/templates.ts` 的一个命令到一个模板表达不了多场景）：

- 签名：`(命令，场景预设）` 到页族。命令是 `home.*` 命令（如 `home.item.update`），场景预设是路由带的参数（如 `{op:"qty"}`）。
- 同一命令挂多场景时靠预设区分；同一页族可由多个（命令，预设）到达（多对一），但一个（命令，预设）只到一个页族（确定性）。
- 哪些唤醒词落到哪一族由唤醒词层规格裁，本契约只引用它的结论（变体与无场景词只作宿主场景行的别名附注，不占新格与新行；双词场景 SM3-4 在链路总览页印组合名 `带物品／归物品`，路由仍是两条词各走各的预设到同一族）。

补丁流：脚手架或域票发现真装不下，提案回写本契约，契约按次记录变更理由（哪一族分合、为什么），只触发受影响域票重跑自己的判据。脚手架 shaping 不了的族，回写到本契约形成明确的人工 shaping  backlog，不在票内私自放宽。

## 产物命名与交付回执

默认产物命名只用稳定版一种算法，全图唯一，不许另起算法（规则全档见 `naming-chain-precedent.md` §一）：

`<命令中文名>_<戳>.html`

- 命令中文名取场景清单 `html.command_cn`（如 `录物品`、`移物品`、`查购买记录`）；戳取落盘时刻时间戳，同场景并发不互盖。
- **场景 id 不进文件名**（#859 命名纪律裁决）：`1-1`／`SM6-1` 这类场景 id 只住事实源与机器附录，不得出现在产物文件名或运行期值里；文件名主体就是面向用户的命令中文名本身——说「查快递」落 `查快递_<戳>.html`，词、命令、文件名同一套词。
- 唯一性靠门兜底：70 行的命令中文名两两不重（重了即红，绝不静默互盖），由 `check-scene-contract.mjs` ④ 与包内 `test/naming-discipline.test.mjs` 各判一次。
- 唤醒词不进文件名（括号、`/`、空格是非法规避项，改词也不改名）。可读性在链路总览页印唤醒词别名解决。
- 非法字符清洗：文件名主体里的 `\`／`/`／`:`／`*`／`?`／`"`／`<`／`>`／`|` 与首尾空格一律替换为 `_`。
- 真实例（戳以 `<戳>` 占位）：`录物品_<戳>.html`、`移物品_<戳>.html`、`查购买记录_<戳>.html`。
- 唯一实施点是命名函数（票 4 在产出侧实施，票 7 在清单侧只从 `manifest.json` 的 `file` 字段读文件名，不自己算名字）。

链路总览页每行印唤醒词别名（含组合名与变体附注），只作附注，不另起行列与页面（上限与折叠由链路页实施票定）。

交付回执每份带绝对产物路径加字节数，字节数等于盘上实际大小，对不上即红；缺件大声失败并点名缺的文件名。

## 必需块与机器附录

每族的必需块等于册子表一对应行的字段、操作、空态与异常态、状态词表，发布一次，多方消费，不手抄第二遍：

- 附录 `requiredBlocks` 按族给出四组：`fields`（该显示的字段）／`operations`（该有的操作）／`empty`（空态、异常态与拦截态文案）／`status`（状态词表，无则空数组并注明）。
- 判据件（票 6）消费它做结构检查（内容有没有，不是文件在不在、好不好看）；脚手架（票 8）在生成时登记每族的必需块，不手抄转录；种子数据（票 5）按它备齐每族要展示的字段。
- 每族的空态、异常态与拦截态按附录实施，不即兴发挥；敏感口径（证件号码脱敏、密码永不进 HTML）按附录保留。
- 墙生成器缺件大声失败并点名；链路总览页把绝对路径同时印成文本与 `file:///` 可点链接，带复制路径与 `<noscript>` 兜底。
- 域票的第一步是跑脚手架，不手抄样板；逐页留视觉复核记录，墙按手机 390 与桌面 1280 双端成对出。
