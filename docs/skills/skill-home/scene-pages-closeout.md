## 五 · 交付链缺口：本票当场补齐（补票 #872）

指的那份 HTML **922 字节、无 `data-block=`**（21 张平铺模板的分节页），而同一条场景的族页是

按地图「变更协议」当场补票：**#872**（已挂为地图 #797 子票）。

### 改了什么（#872）

- 新增 `packages/skill-home/src/render/familyPage.ts`：`renderFamilyHtml(key, params, env) → 整页 HTML 或 null`；
  命令键 → 候选域目录表（`home.care.*` 同时挂 family 与 setup 两个域的族，族名跨域唯一故确定性）；
