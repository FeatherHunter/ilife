# t778 对抗式复核（从第一性原理出发，复核本席自己的收口 B）

票：[#778](https://github.com/FeatherHunter/ilife/issues/778)。复核对象＝本席本轮的产出（墙、打分、清单、证据、新票 #871）。
复核方式：先立第一性原理，再对每条自述要读数；**自述不算证据**。

## 〇 第一性原理：这张票的目的不是「出墙」，是「让维护者一次看完就能签收」

由此推出四条该被复的地方：① **效度**——判据量的是不是那件事；② **信度**——同一个判据重跑稳不稳；③ **覆盖面**——我量的面与人的实际判读面是不是同一个；④ **稳健性**——最终结论是否依赖某个可争议的数。
下面 F1–F9 逐条给读数；「尚成立」的也照写，别只挑毛病。

## F1 效度（本票最该被记住的一条）：分数是「判读面 ＋ 每次调用形状 ＋ 问句」的联合读数，**不是页面的属性**

同一页（第 1 格）在不同器具下的读数：

| 器具 | 读数 |
|---|---|
| 免打分量尺（「这一页几分」）＋ 整页长图 390×4163 单图 | 68 |
| 同上，改问「整批之一、只回数字」 | 78 |
| 五维量尺 ＋ 整页长图（一次两页四图） | 93 |
| 五维量尺 ＋ 首屏 390×820／1280×860（一次一页两图，即终审口径） | 84 |

- 量尺与调用形状一动，同一页可以在 **68–93** 之间移动；这**不是评委随机**（见 F2），是器具差异。
- ⇒ **「≥90」只有在器具钉死时才有意义**：换面就能拿分。终审口径已钉在 `t778-终审打分.md` §一（判读面＝首屏 390×820／1280×860、一次一页两图、问句逐字不变）；**复评必须照那个面跑**，否则读数不可比。
- ⇒ 由此得一条给维护者的判断建议：**门槛的判决应压在「核实成立的缺陷」上，而不是压在 86 与 90 的差上**（差 3.56 分小于器具摆幅）。

## F2 信度：同面重跑稳（±4 以内）

拿终审口径重跑四个锚点页（同问句、同判读面、新的一次调用）：

| 格 | 首跑 | 重跑 | 差 |
|---|---|---|---|
| 9（只看食材） | 95 | 91 | −4 |
| 22（筛选炊具） | 75 | 75 | 0 |
| 46（体检） | 68 | 68 | 0 |
| 47（批量改回执） | 91 | 91 | 0 |

⇒ 同器具重跑在 ±4 内，「86.44」这个数本身稳；不稳的是跨器具比较（F1）。

## F3 效度上限：我在两维上把底交给了机器事实，这一步对分数是加分方向

终审问句里写明「双端自适应／文案精炼两维以机器事实为底（溢出 0／可点件 ≥44px／分隔符 0／英文裸词 0／重复句 0），只扣图上真看到的」。**已知这套机器读数的判水面窄**：`t768-质量门.mjs` 的「重复句」只判可见文本里 ≥8 字整行重复，判不到「结论条与上方摘要同义」这类冗余（第 26 格就是例子）。
⇒ 我等于在最该看文案的那一维上，让评委先向机器让了一步。**已如实写进打分件 §一／§七**，不暗改口径。

## F4 覆盖缺口：我打的是首屏，人会往下滚

墙格高 820／860，人可以在格子里继续往下滚看整页；**48 个分数只覆盖首屏**。第 6 格的重复块（D 类缺陷）是靠「整页长图那一轮 ＋ 源码复查」才钉住的，不是靠首屏分。
⇒ 首屏分**不代表整页**。要补的话：对超过一屏的页再出一档「下滚一屏」图做第二遍抽样，本席未做，如实挂在这里。

## F5 把最大的一条系统性症状变成读数，结果判它**不成立**（连带查出探针自己的一个假读数）

终审在 13＋ 页上重复报「390 端徽章断行参差」。用 CDP 实量（`docs/skills/skill-chef/t778-徽章实测.mjs`）：

- **第一版探针（错）**：把整页所有徽章件按 top 聚类，跨分区混算 ⇒ 全批报「6 页行距不均」，差 202–255px。核到产物才看出那是**做菜页每一步各自的「本步用料」徽章**（分布在不同分区），不是同一行折行——**假读数**。
- **改法**：先按**父容器分组**再在容器内聚类行。重跑：

```
搜索筛选/＜13 页＞        徽章 14 枚／折行容器 1 个  最差行距差 0px  → 行内齐、行间等距
查看/＜8 页＞            徽章 15 枚／折行容器 1 个  最差行距差 0px  → 行内齐、行间等距
做菜/＜6 页＞            徽章 21 枚／折行容器 1 个  最差行距差 0px  → 行内齐、行间等距
共 52 页；判「行距不均」的 0 页
```

⇒ 「折成两行」是事实、「参差」是印象：容器内两行左缘一致、行距差 0px（13 页搜索筛选两行左缘同为 31px）。按 `#682` C3-12，该条**核不成立**（清单里原记「视」，已按本读数改判）。
⇒ 附带教训（与墙生成器那次的假绿灯同族）：**判据自身的有效性也要核**——跨分区聚类会让「参差」凭空出现；若照第一版读数行事，会凭空开 6 页的缺陷票。

## F6 整批复评 78 的处置：我用论证推翻了评委，这**不能算「核过」**

打分件 §四 以「它判的是墙脚手架／总索引」为由折掉它的两条，只留「形状语言」一条并说与实况不符。对抗地说：这是**本席的解释**，不是读数。

## F8 人滚墙的成本（**这一条要请维护者裁**）

桌面墙＝48 行单列 × 格高 860 ≈ **4.1 万 px** 的滚动；手机墙 3 列 16 行 ≈ 1.4 万 px。合验收墙 §6.3（宽产物整体缩、单列排），但「人滚一遍」的实际代价高。
⇒ 可选：按页族拆 3–4 张墙（§6.3 原文允许「几十格是舒适区，带大图按页族拆几张；嫌小就调大那个 600，能并排的列数会跟着变少」）。**拆法属墙的形制**，票面已定「双端各一张」，本席不擅改，等裁。
