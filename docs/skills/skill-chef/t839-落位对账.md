## 第二步 · 结构设计

- 目录名取 HELP 一级分组英文 id（沿票 1 `history/` 先例）；中文 label 只住产物落点（`chef-scenes.ts` 的 `dir`，不动）。

  6 卡对 4 卡；其余 5 域各 1 条读声明写 `shape`）；无自有 key 的 4 域为空数组＋注释。
- `routes.ts` 恰好一个声明数组（`order/wakeWord/key/cli`）；`order` 取 WAKE_TABLE 1-based 下标；
  跨域 key 用字面量引用（与票 1 `HISTORY_ROUTES` 先例同形：路由行只映射短语→key 名，不定义形状标题示例，
  故不算第二份定义）；`relation`／`setup` 行 `key: 'tbd'`＋`order: 0`＋空 `cli`；`data` 仅 `备份` 一行
  （`体检` 的短语→key 映射票 1 已在 `history` 声明，一事一处）。
- `run*.ts` 签名 `(handle, params)`（`write` 系多传 `op`、`query` 系多传 `kind`：key 内路由键由注册表一次算好下传，
  run 不重算）；分支体逐字节搬。`update/add` 按 op 切分、`history/data` 按 kind 切分——key 内多域共享是唯一的
  域票写集重叠，不切则票 8/9、票 10/11 同写一文件，并发前提不成立。
- 注册表（`cmd_read.ts`）只留：参数解析／预检／配置体检与 HELP 早拦／信封打印／8 路 key→run 映射／
  write-op 路由／query-kind 路由（判定原文逐字保留，非法报文 exit 2 原文）。`fail`／`note` 引用 `shared/slots`。
- `gen-cli.mjs` 加 `CHEF_DOMAIN_KEYS`（按域键表）：票面反例要求“点名该域”，扁平键表指不到域，

## 第三步 · 写代码（决策＋对抗式审查）

1. write 声明住 `add` 不住 `update`。对抗：两域共享一 key，事实只能住一处；默认 op=add、6 卡对 4 卡，
   录入是该 key 的主要面。update 路由行引用 key 名（票 1 先例：路由不算第二份定义）。
2. query 按 kind 切分到 `data`，但 `体检` 路由行不进 `data/routes.ts`。对抗：初版写了两行，
   对账脚本报“一体检两声明”——短语→key 映射一事一处，`data` 只声明增量（`备份`），kind 切分由注册表做。
3. `recipeDetail` 与 5 写原语追加下沉。对抗：初版把它们留了共享，对账 G 门报“单域用户”——
   `recipeDetail`→view、`addRecipe/addIngredient/addStep`→add、`updateRecipe/deprecateRecipe`→update，
   留守的只剩多域件。器械先红后绿，见读数。
4. `today()` 随 `recordHistory` 入 history，`todayStr` 消除。对抗：两处同表达式分住两模块是既有重复，
   搬迁顺手合一（行为同值），`db.ts` 不再转出日期原语。
5. `fail` 唯一定义地收进 `shared/slots.ts`。对抗：run 里的 `fail(2)` 是可达用户错误路径（update 空补丁、
   search 缺条件），改 throw 会多出“口径失败：”前缀、stderr 不等价；`cli/config.ts` 既有 local 不动（出范围），
   不新增第三份。
6. `gen-cli.mjs` 动了（报备说 scripts 不动）。对抗：票面反例“点名该域”扁平表做不到，加按域块是唯一满足法；
   三要件不变，改动 20 行内，交付对账记偏差（见第五步）。
7. `history/{commands,routes}.ts` 一字不动。对抗：类型统一（票 1 deferred）值得做，但报备承诺了零改动；
   承诺优先，统一留给后续域票顺手摆正（生成器读文本，类型名不影响派生）。
