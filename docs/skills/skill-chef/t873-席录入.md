## 三 反例（改坏必红／还原一致）

**反例做法**：把本席最关键的一处改动——**备料表三列 → 两列**——在产物字符串上**改回三列**（源码一字不动：改的那一处由探针在产物上还原），
用同一个截图器（`t778-截图.mjs --viewport-only`）在**同一次浏览器运行**里出两态的两档首屏图，落 `.scratch/t873-录入/实图/`。

| 步 | 状态 | 产物（sha256 前 16 位／字节） | 该页复评读数 | 判 |
|---|---|---|---|---|
| 反例（备料表还原成三列） | `.scratch/t873-录入/实图/录入/改前.html` | `f4eb9490dc6d1da5`／94808 | 17/15/**16**/14/17 = **79** | 未变红（与改后 78 同档） |
| 还原（逐字回绿） | `.scratch/t873-录入/实图/录入/改后.html` | `ddaa6678ae94c518`／94675 | 17/15/**17**/13/16 = **78** | 与改前同档 |

**判据两行机器读数**：

```
反例（三列还原）  第 36 格 五维 17/15/16/14/17 = 79   ← 未红
还原（两列）      第 36 格 五维 17/15/17/13/16 = 78   ← 与反例同档
```

**这条反例的结论要照实写**：**「改坏必红」在本页不成立** —— 变的那一处（三列／两列）在本会话的尺子上**小于采样抖动**（同页同图极差 16 分，见 §二末条）。
两态产物里「说明列」这一处是**唯一**差别（机器核对：当前 `data-label="说明"` 无、反例 3 格有；两态的「量词小字」「动作行缩进」「两列各半」都相同），
故这一条**不是「反例没跑到」**，而是**尺子分辨力不足**。本席按派单册 §四 第 6 条「或做一个等价的最小回退」执行完毕：
回退做了、两行读数都在、判「红」的结论照实写「未红」。

**另有两条能红的机器读数（不受尺子抖动影响，同一处的账）**：

```
两态同一处（备料表）的 DOM 读数：改前 3 列 → data-label="说明" 命中 3 处；改后 0 处（列头只剩 食材／用量）
两态两档横向溢出：改前 0／0、改后 0／0（这一处不是溢出类缺陷，机器门在改前就是绿的）
```
