# 老私家大厨 20 个 HTML 模板盘点（分区与顺序）

盘点对象：`D:\2Study\StudyNotes\SKILLS\私家大厨\templates\`（含子目录 `修改\`、`历史\`、`开始使用\`、`录入\`、`搜索筛选\`、`派生\`），共 20 个 `.html`。
数据来源脚本：`D:\2Study\StudyNotes\SKILLS\私家大厨\scripts\`。
盘法：逐页实读模板文件的 `<h1>/<h2>/<h3>`、`<div class="...">` 区块与注释，逐页实读渲染脚本里的 `TEMPLATE_PATH` 与实际注入点；本文件只记录读到的原文，读不到写「未找到」。

## 读法（三条判定规则）

1. **分区**＝页面上按顺序出现的版式单元（`<section>`／`<div class="card">`／带名字的容器）。嵌在同一个阶段容器里的卡片各算一行，分区名照模板里的可见标题或注释原文写。
2. **页面族**：过程型＝用户在流程中一步步操作／确认；结果型＝主体是查询结果／列表／详情／统计；回执型＝主体是「刚刚做了什么」的结果确认。一个模板有多个模式（`payload.mode`）时，按模板里排在最前的那个模式（＝默认入口模式）判，并在理由里注明其余模式。
3. **页面形态**：是否带 `<!DOCTYPE html>`／`<html>`／`<body>`。带＝整页文档；不带＝片段。（20 个模板全部实读首尾各一遍。）

### 两条跨全体的实读口径（先记在这里，下文不再重复）

- 老件模板**不用 `{{...}}` 占位符**：20 个模板里搜 `\{\{` 零命中；数据注入统一走 HTML 注释占位符 `<!--INJECT-DATA-->`（数据）、`<!--INJECT-08-->`（08 共享动作层：复制数据／复制日志双按钮 + 5 状态），由渲染脚本替换。
- `cooking_mode.html` 是唯一例外：它的数据不走占位符，而是渲染脚本 `cooking_render.py:114` 用 `window.__RECIPE__ = {...}` 替换模板里的 `<body>`（该文件只有 `<!--INJECT-08-->`，没有 `<!--INJECT-DATA-->`）。
