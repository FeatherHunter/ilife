## Question

链路总表要「prompt → 唤醒词 → 命令 → HTML 绝对路径」一页可点，且 50 条唤醒词各自都有产物；但今天绝对路径回执**只有 HELP 有**（`delivery` 只由 `chef.help.lookup` 产生），其余 7 键默认不落 HTML、`--html` 也不回显路径；且产物按配置推算会落在**副本库**的父目录下。这批产物怎么跑出来、册子怎么记、链路页怎么让人点开？

## 目标

1. 写**批量驱动器**：读唤醒词表 ＋ 卡表 → 逐条真跑（副本库 ＋ 副本配置）→ 每条落一份产物 → 收集绝对路径、exit、bytes、sha256 → 落 `manifest.json`。
2. 出**链路总表页**（照 `docs/skills/skill-calorie/t369-链路总表.mjs`）：50 行，每行 prompt／唤醒词／命令／参数／产物绝对路径（可点）；页顶写明「链接指向验收副本」。
3. 出**产物册子**：`manifest.json` 同时是收口 B⑬的墙清单来源；两侧**共用同一套 slug 规则**（用②定下的命名），禁各算一套。
4. **覆盖对账**：打印 `词 50／卡 48／缺 0`；任何缺项点名并 exit 1。
5. **合并册子片段**：把 7 张域票交的 `t<票号>-册子片段.json` 合并成全量册子（同一份产物只记一格），并做覆盖对账——① 50 条唤醒词条条有产物；② 48 张卡逐卡有落点。
6. **点击实测**：在真实浏览器里打开链路总表页，**点绝对路径的 URL 真能打开那份 HTML**，逐行核；不许只写路径不实测。

## 验收命令

- 正例：`node tooling/run-locked.mjs --ticket 777 -- node docs/skills/skill-chef/t777-链路总表.mjs` → 打印 `词 50／卡 48／链接 N 条／缺失 0` 且 exit 0
- 反例（必跑）：故意改坏 `manifest.json` 里一个文件名 → 脚本必须 exit 1 并点名那一份
- 反例（必跑）：从唤醒词表删一条 → 覆盖对账必须报缺并 exit 1

- 正例（点击实测）：`node docs/skills/skill-chef/t777-链路总表.mjs --open-check` 逐行打开链接并打印 `可打开 N／死链 0` 且 exit 0
- 反例（必跑）：故意把一行路径指向不存在的文件 → `--open-check` 必须 exit 1 并点名那一行

## 不许动的东西

- **不碰真库**（全部跑副本）；隔离通道写明 `CHANNEL-PENDING-#756`，不抢 `#756` 的裁定。
- 不改命令面（不加「回执带路径」的新字段）——路径由驱动器自选 `--html` 决定。
- 链路页不得用相对路径跨目录引用（会死链）；不得加 `loading="lazy"`。
