# t873 派单册：48 页逐页推到 ≥90 的席位规则与量尺

票：[#873](https://github.com/FeatherHunter/ilife/issues/873)（地图 [#765](https://github.com/FeatherHunter/ilife/issues/765) 票 22 收口 C）。
本件是**每一席的公共简报**：席位开跑前先读完本件，再读自己那一节的页清单。缺项照「退票」处理。

## 一 目标与现状

- **目标**：48 页**逐页**在**冻结器具**下五维总分 **≥90**；每页原扣分项**逐条有销账读数**（改了哪处、改后读数）。
- **改前基线**：`docs/skills/skill-chef/t873-开工基线.md` §一（48 页全部 <90，均值 **79.5**，区间 68–88）。
  各维均值：信息层级 17.1｜双端自适应 17.6｜文案精炼 **15.19**｜视觉生动 **13.1**｜风格一致 16.5。
- **主因（基线 §三 的原话，按收益排序）**：
  1. **视觉生动**（全场最低）：整页近乎纯文字、缺图缺色彩锚点、「卡片＋灰底」为主；
  2. **文案精炼**：同义复述／模板腔（结论条与下方摘要说同一件事）、单字胶囊过碎；
  3. **双端自适应**：390 宽下的挤压／贴边／硬换行／标签竖排；桌面端大段留白与内容居中挤压；
  4. **信息层级**：区块之间只靠文字层级，**缺形状件**（分隔、分组、图标位）承担层级——与第 1 条同源。
- **刻度先读**：这把尺比 #778 首跑**严约 5 分**，且**未改过的页也会落在 <90**。⇒「<90」只说明差距，
  不自动说明「这页坏了」；**销账表必须同页改前/改后同尺两跑**，不许拿本尺读数直接比 `t778-终审打分.md` §二 的旧数。
- **88–92 是器具抖动带**：落在这段的页要**两次独立复评都 ≥90** 才算过。

## 二 量尺（唯一器具，冻结 2026-09-21，逐字照抄，不许另写一套）

法官＝ `vision_describe`。判读面＝每页两张**真渲染首屏**：`<NN>-<slug>-390v.png`（390×820）与
`<NN>-<slug>-1280v.png`（1280×860）。**每页一次调用、两张图**；**不要带 `json: true`**
（本会话开着「结构化预识别」，带上会被路由接管、拿不到五维）。

问句（逐字，只有 `<页名>`／`<唤醒词>` 两处占位随页替换）：


**总分口径**：取**五维之和**（评委自报 `total` 与五维之和不符时，按五维之和记，并在证据件里注明）。

## 四 每席的动作序列（照做，别自创流程）

1. **读数先取**：从 `t873-开工基线.md` §一 摘出本席那几页的五维与总分，从
   `t778-逐格缺陷清单.md` 摘出**本席那几页**的症状与核实结论（那是改前的扣分项清单）。
2. **改源头**：
   - 页内排版／文案／形状的改动落在**本席写集**里的**渲染件**（`src/<域>/**` 或驱动器）；
   - **不许改数据语义**：库里「连写无句读」的正文只许在排版层断句／分段，不许改写内容；不许改库、不许加 schema；
   - **不许放宽判据**：不改 `t768-质量门.mjs` 的列、不改 `t778-终审扫描.mjs` 的字样表、不许把墙／册子／清单改成能自绿的形状。
3. **编译**（**必须持锁**，且**只**编本包）：
   ```
   node tooling/run-locked.mjs --ticket 873 -- node node_modules/typescript/bin/tsc -b packages/skill-chef
   ```
   编译红在**别人写集里的文件**上＝别席正在改，等 60 秒重试；红在自己写集里＝自己修。
4. **重出本席产物 ＋ 出双端首屏图 ＋ 跑机器质量门**（一条命令，持锁）：
   ```
   node tooling/run-locked.mjs --ticket 873 -- node docs/skills/skill-chef/t873-席跑.mjs <域中文名>
   ```
   域中文名＝本席那一格的域：`搜索筛选`／`查看`／`录入`／`做菜`／`修改`／`历史`／`数据管理`／`派生`／`采购`／`开始使用`。
   落点 `.scratch/t873-<域>/`（`<域>/*.html` ＋ `manifest.json` ＋ `shots/*-390v.png`／`*-1280v.png` ＋ `质量门.json`）。
5. **逐页复评**（本席自己做，用 §二 的问句与调用形状）：每页一次调用、两张图；记下五维与总分。
   落 88–92 的页**再跑一次独立复评**，两次都 ≥90 才算过。
6. **反例（每席必跑）**：把本席某一条扣分项**改回去**（或做一个等价的最小回退），
   → 该条读数必须**变红**（该页复评 <90，或机器质量门变红）；**还原后逐字回绿**。
   两行机器读数写进证据件。
7. **写证据件** `docs/skills/skill-chef/t873-席<域>.md`（模板见 §六）。
8. **提交**（持锁，只提交自己声明过的路径）：
   ```
   node tooling/run-locked.mjs --ticket 873 -- git add <本席路径…>
   node tooling/run-locked.mjs --ticket 873 -- git commit -m "feat(873): <域>席 <做了什么> ＋ <改到的文件／跑过的判据>" -- <本席路径…>
   ```
   提交前 `git diff --cached --name-only` 必须**只含本席声明的件**。
