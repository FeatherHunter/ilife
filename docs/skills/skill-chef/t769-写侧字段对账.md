## §0 本表的判据

### 0.1 结论三值的定义

| 结论 | 判据 |
|---|---|
| **可落** | 本卡要读或写的表与列，老库全有；本卡当前要读写的路径不撞老库的任何约束；且新技能（`packages/skill-chef/src`）已有对应读写路径，或本卡本就不碰库。 |
| **需降级** | 表与列老库全有，但新技能当前没有对应的读写路径（缺命令、缺列读取、缺能力），本期只能限定范围提供或分期。 |
| **必须立票** | 卡要写的列在老库上带着与新技能写入契约直接冲突的约束（实列为 `NOT NULL` 而写入路径传 `NULL`），或卡要写的那张表根本没有写侧契约可依；不改 schema 就落不进去 ⇒ 必须立 schema 票。 |

「老库现状」列只取四类值并附读数：**有** / **无** / **类型不符** / **索引缺失**。
