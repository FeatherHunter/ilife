## 二、卡 slug 规则（48 卡全局唯一）

1. slug＝卡 id（`scenario_id`，小写下划线，ASCII 字母数字下划线，全局唯一）。
   例：`view_full_recipe`、`shopping_generate`、`data_export_backup`。
2. 卡 canonical 产物相对路径：`<域中文名>/<slug>.html`。
   例：`查看/view_full_recipe.html`、`采购/shopping_generate.html`、`数据管理/data_export_backup.html`。
3. 文件名主体只含 slug（不含中文，不含域前缀）；域信息由目录承载，不进文件名。
4. 唯一性由 `t767-对账.mjs` 强判：48 卡 slug 去重缺口必须为 0，否则 exit 1 并点名。
5. slug 一经收口即冻结；改名＝改卡 id（等同于改场景身份），须另立票。

## 三、词产物路径（50 行不重复路径，供收口链路总表用）

地图裁决 8：13 条新表多出词各出各的产物（同一命令不同参数 → 内容不同，模板相同不算冗余），
链路总表 50 行＝50 个不重复路径。规则如下（收口票执行，本票只定规则）：

1. HELP 词 4 条（私家大厨HELP／菜谱HELP／查帮助／能做什么）不另出业务产物，复用已交付的 HELP 文件。
2. 其余 46 词：每个词至少对应一张卡的 canonical 产物（见对账表 §一）。
   参数与 canonical 相同的词复用 canonical 文件；参数不同的词另出文件，
   文件名＝`<slug>--<唤醒词>.html`（例：`查看/view_full_recipe--看菜.html`），与 48 个 canonical 文件名无交集。
3. 纵向票按此规则出产物，收口票按此规则收链路总表；任何票不得另起一套目录或命名。

## 四、与既有产物的关系

- HELP 文件命名（`私家大厨_HELP_<时间戳>.html`、`私家大厨_速查表_<时间戳>.html`）由共用件 `saveHtmlFile` 定，
  不在本规则内，两者无交集。
- 老件 20 个模板的中文目录（`修改/` 等 6 个子目录）仅作对照，不作新产物目录依据。
