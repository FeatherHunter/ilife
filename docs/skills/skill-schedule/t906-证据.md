## 一、一句话结论

`packages/skill-schedule/src/render/copyArea.ts` 一行改动（`title` 只收声明、不透传给公共层 `renderCopyBlock`），
61 件产物里**复制区那行小标题归 0**（改前 61 处），而**复制区三件照旧**（三格式菜单 ＋ 复制日志，61/61 页齐）、
**页内跳转一颗锚点没坏**（278 个目录项，死锚点 0）；复评 **61/61 过线**（均分 98.93／最低 95，与改前逐页同分）。

## 二、改哪一行

```diff
--- a/packages/skill-schedule/src/render/copyArea.ts
+++ b/packages/skill-schedule/src/render/copyArea.ts
-  return renderCopyBlock({
-    ...(input.title === undefined ? {} : { title: input.title }),
+  return renderCopyBlock({
+    dataFormats: formatsOf(input, envelope),
```

- **公共层一字未动**（`base-render/src/blocks.ts` 的 `renderCopyBlock` 照旧渲染 `title`）：它是六家技能共用件，
  删它会顺带改掉卡路里／备忘录／居家的产物 —— 本票只治作息这一家。
- **`title` 字段与 30 处调用点原样保留**：它是「这一区装的是哪一份文本」的语义声明，将来公共层要把它渲染到别处
  （页头／工具条说明位），一处接线即生效。件头与该字段注释把「声明收下、这一版不落屏、为什么」写清了。

**为什么判据不写在公共层**：`renderCopyBlock` 自带的「同名去重」只认 `title === '复制数据'` 那一种
（`ACTION_BAR_DEFAULTS.copyDataLabel`，见 `blocks.ts` #336 注释）；作息这四种字面都不是它，故照出 ——
本票要删的正是作息这一家的四种。
