## 五、老侧 HELP 页的移动端手法（可 1:1 移植）

| # | 手法 | 要点 |
|---|---|---|
| 1 | viewport | `width=device-width, initial-scale=1, viewport-fit=cover`（`viewport-fit` 是 `env(safe-area-inset-*)` 生效的前提） |
| 2 | 缩放抑制 | `html { -webkit-text-size-adjust: 100% }` |
| 3 | 单断点 | `@media (max-width: 640px)` 整块降级（字号、内距、图标尺寸） |
| 4 | 重排而非缩放 | `.cat-meta { width: 100%; justify-content: flex-start }`——计数胶囊从右侧挤到下一行左对齐 |
| 5 | 免溢出三件套 | 每行 `flex-wrap: wrap` ＋ 关键项 `flex: 1 1 <basis>` ＋ `min-width: 0`；图标／徽章 `flex-shrink: 0` |
| 6 | 长文本 | `.sc-prompt { white-space: pre-wrap; word-break: break-word }` |
| 7 | 安全区 | toast／底部条 `bottom: calc(12px + env(safe-area-inset-bottom, 0))` |
| 8 | 能力降级 | `@supports not (backdrop-filter: blur(1px))` → 工具栏退实底 |
| 9 | 数字对齐 | `font-variant-numeric: tabular-nums` |
| 10 | 触摸目标 | 可点件 `min-height: 44px`（视觉尺寸不变） |
| 11 | 折叠 | 原生 `<details>` 三层（域／唤醒词／场景），默认全折叠，`summary > * { pointer-events: none }` |
| 12 | 搜索 | 逐级 `classList.toggle('hidden')`，命中自动展开祖先；无命中插「无匹配」 |
| 13 | 圆角裁切 | 卡片 `overflow: hidden` ＋ `border-radius`，子层背景不溢出圆角 |

公共层 HELP 壳（`packages/base-render/assets/help-template.html`）另加了 500／501／820 三档、`height:100dvh`、`scroll-snap` 横滑、sticky 搜索、44px 触摸目标与 `prefers-reduced-motion`——新仓页面走公共层就能直接拿到这些。
