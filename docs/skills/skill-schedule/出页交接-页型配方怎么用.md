- **口径住能力目录**：`src/query/queryDocs.ts`（今天总结／周视图的数据装配）、`src/plan/planDocs.ts`（查日程：空档推算）。新家族的口径就落**它自己那个能力目录**的 `*Docs.ts`。

## 四、四条已踩过的坑（别重演）

1. **多根产出**：`renderDistributionRows`／`renderChips` 是「**行即件**」（不返容器）——直接当一个块往页里塞，会挂不上任何页级标记；本包的做法是外面套一层容器（见 `queryDocs.ts` 的 `distRows` 包装）。
2. **可选的色位不给就全蓝**：`renderDistributionRows` 的 `color` 不给＝落 `--blue`（#782 首版就这样七条全蓝被人抓出）。分布行上色走 `pageParts.categoryColor(key, order)`，由**页型函数**做。
3. **公共层的宽块满铺**：`pageUiCss` ⑧ 条会把读数卡／表／图表块／详情区／列表行放满壳宽；作息这三张页人裁的是**正文单一内容列**（`docPage.ts` 的 `BODY_SINGLE_COLUMN_CSS` 已统一压回中列）。新页**沿用这个口径**，要改先问人。
4. **`renderChartBlock({kind:'gauge'})` 满宽失控**（宽高比近 1:1，880 列里渲出一屏高表盘）——要表盘得自己给窄容器，或改用读数卡 ＋ `bar` 进度位。

## 五、断点与样式纪律
