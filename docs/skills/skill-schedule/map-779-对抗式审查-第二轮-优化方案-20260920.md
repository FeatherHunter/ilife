# 对抗式审查·第二轮：审「我的修法」，并按第一性原理重排（2026-09-20）

> 上一步：`map-779-对抗式审查-20260920.md`（审地图本身，20 条缺陷）。
> 本步：先**打我自己的五刀**，再按第一性原理给出优化后的方案。只写本件与地图评论，未动票面。

## 一 先打我自己的五刀

### 刀 1「改 8 张票的命令形」——治了症，没治病

改 8 处字符串是必须的，但**根因是票面手抄了工具的参数形**。命令的权威形在脚本自己的用法头里，票面抄一遍就多了一个定义地（铁律二）。
**更好的刀**：票面只写**一条**命令 `node docs/skills/skill-schedule/t<票号>-探针.mjs`，由探针内部去调 `measure-responsive.mjs --dir …`／`audit-separators.mjs`。这样参数形只错一次、改一次，且票面回到「一条判据一张票」。

### 刀 2「域票判据换单位 ＋ 清单加 fields[] 与冲突检测」——方向对，但有**最大的隐藏缺陷**

我把「哪个场景走哪条命令、出哪一族页、要不要出页」交给了 `【清单】` 票，而它是一张 **research（AFK）** 票。**研究票只该复述事实，不该做设计裁定**：老侧 fixture 里有 `scenario_id`／标题／prompt，但**没有**「新侧走哪条命令、出不出页」这一列——那一列是要人来定的设计，交给 AFK 票等于无人裁。
附带两处过度：`fields[]` 按**场景**（85 行）抽，是把同一个模板的字段抄 85 遍；**必现块按家族给 18 条就够**（老侧 18 家族＝18 种 payload 形状）。

### 刀 3「交付面从骨架挪进形状票」——我在修「焊两件事」时又焊了一次

形状票是**设计探索（HITL）**，把「全 7 键缺省落盘的交付契约」塞进去，正是我批评 `【骨架】` 的那个毛病。
**更好的切法**：交付面自己一张票。它是纯粹的行为改变（`main()` 里加一条缺省落盘分支 ＋ 产物落点分家 ＋ 命名），不依赖结构搬家，也不依赖页设计，判据就一条：一条命令真跑 → `delivery.path` 是绝对路径、字节相符、落在 `schedule_html/` 根。

### 刀 4「加两条边 ＋ 地图写一句串行」——多了一条没用的边，纪律写错了地方

- 「`【链路页】`←清单」是**多余的串行化**：清单在**域票逐域回写之后**就完备了，链路页的输入自然齐。依赖边只该加在「没它就无法开始」处——**域票 ← 清单**才是真边。
- 「地图 Notes 写一句同包串行」——纪律写进 Notes 等于指望执行者读散文。**写进任务清单的执行序列 ＋ 每张域票的红线**才落地。

### 刀 5「域票各带小墙 ＋ 交一份代码层审美记录」——把不可机判的东西做成了必交作业

「符合 UI 设计师审美」不可机判，做成「每票交一份记录」必然退化成空话。
**可判定化的窄刀**：把它折成**一条能红的判据**——页内件的字号／间距／色值不许出现裸字面量，只许取公共层 token 或该族样式件常量（扫源码即可判真假）。人裁那部分归收口票的滚墙，不再另设人裁点。

## 二 第一性原理（这套方案只从这六条推出来）

1. **验收单元必须与交付单元同构**。Q2 裁「墙的格＝场景」，则每张票的判据都要按**场景**驱动，不能按唤醒词。
2. **一个事实一个定义地**。清单是名字与字段的唯一来源，探针从清单读、票面不抄参数形。
3. **能机判的才叫判据**；不可机判的（好看）只留**一次**人裁——人是最贵资源，中间不许再加人裁点。
4. **最贵的是窗口长度**。票要能一窗收工；能 AFK 的先跑；能降维的降维（85 个场景 → 18 个家族 → 几种页型）。
5. **风险尽早暴露**。最薄的一条端到端（落盘 → 一页能看 → 一格能进墙）要在铺开之前跑通。
6. **同一时刻只有一个写者**（本包共用生成物）。串行是刻意的设计，不是疏漏。

## 四 与旧图的差异（七条）

1. `【骨架】` **拆**成 `【结构】` 与 `【交付面】`——两件不同风险的事各归各票（刀 3）。
2. `【清单】` 从「设计裁定」降级成「事实复述」；**设计裁定回到域票**（刀 2）。
3. 必现块按**家族 18 条**，不按场景 85 条（降维）。
4. **新增 `【种子】`**：Q6 裁定的隔离种子库在原图里没有主（漏项）。
5. `【形状】` 的产物从「三张页」升级成「**三张样本 ＋ 页型配方表**」——把 60 页的设计压成几种页型裁一次。
6. 「代码层审美」从「交记录」改成「**一条能红的窄判据**」（刀 5）；小墙留在域票，总墙留收口。
7. 依赖面**只加必要的边**：域票 ← 清单（真前置）；**不加** 链路页 ← 清单、收口 ← 清单（多余串行，刀 4）。

## 五 残余风险（不修，理由写明）

1. **七张域票串行** → 图的总时长被拉长。不修的理由：共用生成物使并行写必冲突（原理 6）；缩短只能靠把域票再切小，而那会让每票的「形状自洽」变差。图上写明「串行是刻意的」。
2. **`【形状】` 仍是 HITL 且挡着七张票** → 人一忙，图停。不修的理由：不可能在没有形状裁定的情况下铺 60 页（那正是原图要防的返工）；已把它降重（选件＋三张样本，不是发明视觉）。
3. **每张域票能否一窗收工**只有第一张跑完才有读数 → 留出口：域票「做不完就按页族再切一刀」。
