## §五 一处如实记：夹具文案的两次读数（`fts5`／`CLI`）

**第一跑**（照 `.scratch/t833/probe-init.mjs` 的旧夹具文案）机审报 `RESULT: 32/34 FAIL … ⑥2`：`首次使用.html` 与 `首次使用-向导.html` 各 3 处英文裸词 —— `装 fts5 扩展后重跑`（×2）与 `装飞书 CLI`。

查证过程与结论（**不静默换字**）：

1. **这两串都不在产物代码里**，它们是 `memo.init` 的输入载荷（AI 现写、本页只透传渲染）。实测：同一页换一份全中文载荷，`⑥` 由 1 件变 0 件（`①0 ②0 ③0 ④0 ⑤0 ⑥0`，见 `.scratch/t834/读数/init-clean-probe/`）。
2. `fts5` 那串是 **#833 已判定的「Python 时代示例文案」债** —— [t833-人核档.md](t833-人核档.md) §「按『Python 时代文案』的口径把它在人核夹具与驱动里改成中文说法（装全文搜索扩展后重跑），那一分已收」。本驱动器第一版是沿旧夹具**踩了回去**，属夹具文案回归，已改回中文。
3. `装飞书 CLI` 一条：`t833-证据.md` §五把它记成遗留出口（「全仓三处公开面同名的品牌叫法，改它＝跨公开面的改名」）。本批夹具同样按规范中文文案出（`装飞书命令行工具`／`未安装飞书命令行工具`），并在 §十 把它作为**判据面口径**的遗留出口另开票。

两跑读数都留档，不挑好看的那支写：**改前 ⑥ 2 件／6 处 → 改后 ⑥ 0 件**。

## §六 渲染面探针：把 `t867` §八 那条缺口量出来

`t867-读数链契约.md` §八 自己登记了一条已知缺口：**静态面 ≠ 载荷渲染面** —— 产物把内容放在页内 `payload` 里、由页内脚本渲染，四件读数里靠静态读的那部分先剥掉 `<script>` 整段，于是「用户看见的那一页」从没被量过；落点写着「待地图定」。

收口这一批把这条缺口**量出来并留档**。新件入仓 `docs/skills/skill-memo-ilife/t834-渲染面探针.mjs`：把页丢进无头浏览器跑完脚本，再对**渲染后的 DOM** 复用 `t867-dom-probe.mjs` 那一套（同一个 `visibleText`／文本节点归一／候选函数），并且**先剔掉行内 `display:none` 的整块**（复制载荷那一大段 `<pre id="receipt" style="display:none">` 属载荷位，不剔就是噪声）。

| 读数 | 静态面 | 渲染面 |
|---|---|---|
| `english`（H7 入口） | **4 处** | **58 处** |
| `dupFacts`（H3 入口） | **5 处** | **46 处** |
| 其中被「页内导航链接 ↔ 章节标题同串」解释掉 | — | 5 处 |

**两把尺量的不是同一个量**，58 ＋ 46 逐类去向（哪一类落在哪个位置、为什么按判据不进列）写进 `t834-人核档.md` §四：载荷位（复制载荷那一大段）／允许清单（记录号 `#N`）／数据位（`kv` 的远端标识、`rows` 的内部状态值、每张卡自己的创建时刻与分类徽章）。

**本件同时翻出两条只有屏上看得见、两列机器门都读不到的缺陷**（详见 §九）：

- `备忘录同步.html` 状态行那枚 `·` 是 **CSS `::before{content:"·"}` 生成的字**，不在 DOM 文本里 ⇒ 分隔符探针与英文字符判据都读不到；
- `完成心愿-向导.html`／`心愿排期-向导.html` 的时刻行 `·` 是 **运行时 JS 写的 `textContent`** ⇒ 静态面读不到；且 U+00B7 不在 ASCII 标点集里 ⇒ 渲染面探针也读不到（本探针只收 ASCII）。
