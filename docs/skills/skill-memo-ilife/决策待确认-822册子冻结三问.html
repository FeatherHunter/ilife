第一性推导 · 为什么只能这样

D2 页是交互需要 → Q1：备忘录采集在同一次 prompt 填空完成（20 带采集但仅 5 真缺槽位）。采集页无独立理由；读类查看与回执是同一页。故 34＝30 结果＋4 向导过程，64/54 排除。

F2 样式一处＋老实物 3 族 → Q1 归并：6 模板天然 3 族（查询／向导／报告，wish 两份类集相同）＋复制区 6 份各写一遍（基线 7 处同句）。16 条无基准收进通用回执族，16 次设计收成 1 次，否则 D5 最低页分不可控。

F3＋D4 单前缀 → Q2 目录：216 件已扁平（#220），新旧同生命周期。另开层让链路总表处理双前缀，无质量收益。

对抗结论：三问任一反向（64 双份／20 采集页／冻全文件名／另开层／本票定 CSS 实现）都会让 D5（逐页 ≥90）或并发写集先红。故维持 Q1A/Q2A/Q3A。
