### 1.3 推荐照抄哪一件 —— 及「它缺什么、要补什么」

**推荐：`docs/skills/skill-calorie/scene02-验收墙/gen-wall.mjs`。**

理由（都是可核的）：

1. **它是仓内唯一一件把收口四件事做在一个文件里的**：造册复制（`--stage`）＋ 出墙（可出任意宽高）＋ 出索引（含「有意不出产物及其原因」与「本批机器读数」两节）＋ 自检（`--check`）。见 `scene02-验收墙/gen-wall.mjs:16-20, 265-293`。
2. **名字只在一处算**：发布名＝清单 `manifest.json` 的 `rows[].file`，墙／索引／自检都只读它，件头逐字写明这条纪律（`scene02-验收墙/gen-wall.mjs:25-27`）。这正对仓规 §6.1 第 2 条（`视觉验收墙.md:102`）。
3. **假绿灯已经补掉**：`selfCheck()` 里 `dropped` 与 `dead` 一起判，缺件逐条点名并以 exit 1 收场（`scene02-验收墙/gen-wall.mjs:226-247`）。
4. **两种尺度都覆盖**：390×820（3 列、1:1）与 1280×860（1 列、整体缩到 600 显示），缩的是显示不是视口（`:126-128`）。
5. **清单带 BOM 会告警并剥掉**，不静默炸在 `JSON.parse`（`:62-65`）。
6. **有活样板与实测读数**：同目录 `manifest.json`（83 行记录）、`逐格缺陷清单.md`、`交付验收包.md`、`视觉验收墙.md`，还有一件**可复跑的正反断言脚本** `t280-断言-自检正反两面.mjs`（见 §6.3）。

**它缺什么、要补什么（备忘录这批动手前先补）**：

| 缺项 | 现状 | 补法 |
|---|---|---|
| 发布名规则是「唤醒词 ＋ `.html`」，**同一唤醒词出两份产物会撞名** | `scene01-验收墙/gen-wall.mjs:23`、`scene02-验收墙/manifest.json:5` | 备忘录若有一词两页（如「记一条」的预检页与回执页），发布名要加形态前缀：`<唤醒词>-预检.html`／`<唤醒词>-回执.html`。**改的是册子那一列的算法，不是生成器** |
| 生成器不校验清单字段以外的东西（不核字节） | `scene02-验收墙/gen-wall.mjs:69-73` 只查 `seq/kind/wake/file` 四字段非空 | 照 `t532-清单.mjs:123-126` 补一条字节校验（盘上字节 ≠ 清单 `bytes` 也算缺件），能抓住「文件被换过」 |
| 没有禁惰性加载的**断言**（只有「不写」） | 对比 `t541-墙生成器.mjs:136` 有正则拦截 | 抄 `t541-墙生成器.mjs:134-136` 那三行 |
| `stage()` 只复制、不校验源目录里的产物是不是**完整 HTML** | `:78-90` | 抄各 `run-all` 的探针：第 0 字节 `<!doctype html>`、结尾 `</html>`（`t532-run-all.mjs:171-178`） |

### 4.5 最小可改的生成器骨架（≤30 行 JS）

诉求：**prompt → 唤醒词 → 命令 → HTML 绝对路径，点击跳开**。取三者之长：册子只读（名字一处算）＋ 同目录相对链接（可搬）＋ 绝对路径同时印出来（可复制）＋ 自带死链自检。

```js
// 链路总表：prompt → 唤醒词 → 命令 → HTML 绝对路径（一页可点）
// 用法：node gen-chain.mjs <产物目录> [输出名=链路总表.html]
import { existsSync, readFileSync, statSync, writeFileSync } from 'node:fs';
import { join, resolve } from 'node:path';

const DIR = resolve(process.argv[2] ?? '.');
const OUT = process.argv[3] ?? '链路总表.html';
const rows = JSON.parse(readFileSync(join(DIR, 'manifest.json'), 'utf8')).rows;   // 册子是唯一权威

const esc = (s) => String(s ?? '').replace(/[&<>"]/g, (c) => ({ '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;' }[c]));
const cells = rows.map((r) => {
  const abs = join(DIR, r.file);
  const ok = existsSync(abs);
  const size = ok ? Math.round(statSync(abs).size / 1024) + ' KB' : '缺件';
  // 链接走同目录相对路径（整批可搬）；绝对路径单独印出来给「手动打开」兜底
  return `  <tr><td>${esc(r.seq)}</td><td>${esc(r.prompt ?? r.wake)}</td><td><b>${esc(r.wake)}</b></td>`
    + `<td><code>${esc(r.key)}</code></td>`
    + `<td><a href="./${esc(encodeURI(r.file))}">${esc(abs)}</a><br><span class="d">${esc(size)}</span></td></tr>`;
}).join('\n');

const page = `<!doctype html><html lang="zh-CN"><head><meta charset="UTF-8">
<meta name="viewport" content="width=device-width,initial-scale=1"><title>链路总表（${rows.length} 条）</title>
<style>body{font:14px/1.7 -apple-system,"Microsoft YaHei",sans-serif;background:#f5f5f7;padding:24px}
table{border-collapse:collapse;background:#fff;width:100%}th,td{border:1px solid #e4e7ec;padding:7px 9px;text-align:left;vertical-align:top}
a{color:#007aff;word-break:break-all}code{font-size:12px}.d{color:#86868b;font-size:12px}</style></head><body>
<h1>链路总表 · ${rows.length} 条</h1>
<table><thead><tr><th>#</th><th>prompt（你会说的那句）</th><th>唤醒词</th><th>命令</th><th>产物 HTML 绝对路径（点即开，与本源同源）</th></tr></thead>
<tbody>\n${cells}\n</tbody></table></body></html>
`;
writeFileSync(join(DIR, OUT), page, 'utf8');

const refs = [...page.matchAll(/(?:src|href)="([^"#]+\.html)"/g)].map((m) => m[1]);
const dead = refs.filter((r) => !existsSync(join(DIR, decodeURIComponent(r))));
console.log(`链路总表 ${OUT}：${rows.length} 行；链接 ${refs.length} 条；缺失 ${dead.length} -> ${dead.length ? dead.join('、') : '可发'}`);
process.exit(dead.length === 0 ? 0 : 1);
```

**要改的只有三处**：`manifest.json`（册子名，若不同）／`OUT`（输出名）／`r.prompt` 这一列（备忘录册子里要有 `prompt` 字段；`scene02` 的册子没有，它的 prompt 是从路由表现算的 —— 见 `restage.mjs:69-72`）。
**写法出处**：`esc`／`refs`／`dead`／`process.exit` 抄 `t369-链路总表.mjs:21, 91-94`；相对链接＋绝对路径并列抄 `restage.mjs:82`；「册子是唯一权威」抄 `t268-链路总览.build.mjs:21-23`。
