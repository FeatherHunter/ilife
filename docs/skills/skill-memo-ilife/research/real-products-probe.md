### ⚠️ 一条要记住的：`memo.sync` **退出码 4 但仍出页**

```
ERR 4: 合成写没达成（本地侧已落，远端侧见回执 remote 那一格）
```

这不是缺陷 —— 是 `#657`／`#658` 定的「**ensure 型合成写**」契约：本地侧成了、远端侧没成 ⇒ **非零退出，但页面照出**（回执里 `remote` 那一格说明原因）。本机没有 lark-cli，所以远端侧必然没成。

⇒ **sync 域的域票要按这条契约验收**：退出码非 0 不等于「页面没出」，两件事要分开判。
