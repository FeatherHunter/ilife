## 二、复述门要的五件事（本家落点）

**① kind→本家例映射表**（5 种各一例＋缺省回落）

| kind | 本家例（场景｜字段） | 机器值形态／校验 | 落地控件 |
|---|---|---|---|
| `text` | `记备忘`｜`内容` → `内容:{{content}}` | 任意非结构串，必填只判空 | `<input type=text>` |
| `select` | `记备忘`｜`分类(选填)` → options＝备忘／心愿／打卡／情绪日记 | 必须命中一项；空串仅选填 | `<select>` |
| `date` | `按时间搜备忘`｜`开始日期` → `开始日期:{{start}}`（hint「格式 YYYY-MM-DD，如 2026-07-01」） | `YYYY-MM-DD` 真实日期 | `<input type=date>` |
| `number` | **本家零实例** | —— | —— |
| `week` | **本家零实例**（前瞻位） | —— | —— |
| 缺省回落 | 缺 `kind` ⇒ 按 `text` 渲染（REPORT §3.3；本家 30 张卡全部显式标注，回落位无实例但在闭集校验里钉着） | —— | —— |

**② 复制格式**：点复制拿到的＝**代值后 prompt 全文**（空值落 `___`，不留 `{{}}`）＋末尾 `label: value` 行——但本家 30 张卡的正文参数行**就是** `标签:{{name}}`，代值后正文已含同行，`buildPrompt` 的同行去重（#970 用户验收那条）把追加块吃掉，故实际复制串＝代值全文本身；必填缺失时**拦在复制前**并弹 toast（实测文案 `请先填写：内容`），不复制半成品。

**③ C 案收边**：桌面弹层 560px 居中收边（27 张卡逐张实测 560），手机贴底全宽（实测 390＝视口宽）。两档都是共享模板的既有实现，本票一行未改。

**④ 双空位拆分**：**本家零实例**——老骨架 30 场景 60 条参数行，一行两空位（`____ ~ ____`）0 条（见上表读数）。规则仍先行登记（PROMPT-REWRITE §0.1 末行：一律拆两个字段），本家没有可拆的。

**⑤ select 命中／number 去单位／date-week 归 ISO 在本家的落点**：
- select 命中：10 条，options 全部中文词面（分类 4 项／重复类型 5 项／提醒状态 2 项），机器值必须命中一项；
- number 去单位：**无实例可落**（本家没有数量参数；`笔记 ID`／`心愿 ID` 这类标识走 `text`，按 REPORT §2.3「记录定位不硬校验」）；
- date 归 ISO：7 条（开始日期／结束日期／排期日期），格式与例子只住 `hint`，正文里**零裸 ISO 日期**（生成器与 `t974-help-rewrite` 双重断言）；
- week：零实例，值形态与校验按 REPORT §3.2 登记待用。
