Q4 授权命令面：新增还是寄生？已决 · 新增 memo.auth

前因：授权三步（init／qr／poll）要挂在出口上。寄生是塞进 memo.sync 加参数，新 key 是单立 memo.auth（要动三处登记＋HELP 生成链）。

关键信息：寄生零登记成本但语义别扭；新 key 语义一次讲清，成本是多一次生成链重出（与 Q3 同一次验证即可覆盖）。

结论（已批）：新增 memo.auth。授权和同步是两件事，硬塞在一起以后难讲清楚；登记成本是一次性的。

新增 · 利

  • 语义干净，HELP 可独立说明
  • 以后自检／诊断有地方挂

新增 · 弊
