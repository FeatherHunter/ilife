## §1 五维尺与过线（唯一口径）

权重：**D1 15 ／ D2 20 ／ D3 25 ／ D4 15 ／ D5 25**（合计 100）。过线：**逐页 ≥90，且每维 ≥ 满权 80%**（D1≥12／D2≥16／D3≥20／D4≥12／D5≥20）。

| 维 | 量什么 |
|---|---|
| D1 结构纪律 15 | 内容列收得住；数值列等宽数字；缺值统一形状；色只用令牌 |
| D2 信息层级 20 | 主角元素有视觉存在感；同级标题一致；无一片灰小字；间距成 4／8 倍数 |
| D3 分隔符与文字纪律 25 | 分隔符探针节点级读数直接判 ＋ §3 落地 |
| D4 跨宽自适应 15 | 三档零溢出是回归门（破一格即红，不算成绩） |
| D5 手机端与 HELP 同档 25 | §2 数值表逐条 |

硬扣分（从逐维合计里直接扣）：H1 分隔符串并列 −2／H2 内部标识符或裸代码 −3／H3 同一事实一页重复 −2／H4 符号顶替文字 −1／H5 窄屏溢出 −5／H6 点击区 <44px −1／H7 露英文或半角标点 −1。
**H6 只在触摸档扣**（390／768 档，或明确打开粗指针）：44px 是触屏要求，桌面档不硬扣。

算式：`页分 = max(0, Σ逐维分 − Σ硬扣分)`，逐页算、逐页判。判分引擎是公共层唯一算式（权重、下限、硬扣分、触摸档、折算系数全冻结；包路径、读数目录、实例名单走按域配置）。

## §2 手机端数值表（只写行为，断点只写禁令）

| 项 | 改后要达的线 |
|---|---|
| 触摸区 | 触摸档可点元素命中区 ≥44×44px，零不足（1440 档 40px 一并抬到 44px） |
| 字号 | 正文类 ≥12px；行高 ≥1.4（正文 1.5 保持） |
| 安全区 | 视口覆盖声明必须加；至少左／右／下三向避让；页脚留白保持 |
| 窄屏表格 | 首选卡片化（列头写数据标签，窄屏塌列）；横滚加提示只算保底；不许压成串 |
| 页内定位 | 长页必须有页内目录或锚点；带标识的区块吃定位避让 |
| 图片容器 | 明确宽高比 ＋ 最大宽约束 ＋ 内容适配方式说清；不许裸图撑破容器 |

禁令：**零字面色值、零新断点**——断点只许用仓内既有集合（400／640／820／1001／1200）；验收在通用帮助模板的两档（500／820）量行为。

## §3 形状化对照表（语义 → 形状）

可见文本出现 `；`／`｜`／`·` 即设计债，按语义换形状。出口只许公共层既有形状，不自造。

| 碰上什么语义 | 换成什么形状 | 备忘录实例 |
|---|---|---|
| `·` 串并列标签／状态词 | 徽章列 | 查询结果的状态、分类胶囊行 |
| `·` 串多实体并列 | 卡片格 | 查询结果一条一卡 |
| `·` 串单实体的多字段 | 键值行 | 笔记详情、心愿快照行 |
| `；` 串两句并列 | 结论条／事实条 | 向导确认页的判语加补充 |
| `、` 串枚举 | 事实条／小表 | 报告页的同类列举 |
| `~` 范围 | 一律写「至」或换条 | 时间范围、数量范围 |
| `｜` 串多列并列 | 小表或卡片化 | 二维数据进表，窄屏走卡片化 |

复制区说明行 7 处同一句、操作按钮组 6 份各写一遍：收成公共层共用件（走串行公共层小票，不在本图）。

## §4 四门跑法（每门都有牙齿）

| 门 | 命令形态 | 绿线 | 变异自证 |
|---|---|---|---|
| 分隔符门 | 单产物或页群目录，节点级为准 | 有命中 exit 1、无命中 exit 0、用法错 exit 2 | 塞一处并列必红、还原必绿 |
| 响应式门 | 页群目录，三档 390／768／1440 | 摘要行零溢出且 exit 0 | 超宽元素、无兜底大图各一条必红 |
| 版式读数 | 页群目录，三档（触摸处数／字号／触屏三件／断点集） | 只出读数不判红绿，阈值按 §2 人核 | —（读数器，不是门） |
| 新建六列机审 | 页群目录（版式位、白名单、口径按本域重写） | 摘要行全绿且 exit 0 | 同分隔符门的两行 |

跑在每张域票的交付门里。账单域六列机审本图不用（版式位与白名单全是账单特例）。三档零溢出是回归门，拿它报成绩按虚报处理。

## §5 边界（并行安全）

本票独占写集：基准文档与判分复制件（公共层仅口径，本票不出代码）。域票不许改公共层；缺件另开公共层小票，且小票走串行窗口（同一时刻只允许一张在跑，由编排者排窗口）。

## §6 对抗审查（每条对 MAP 目标）

| 决策 | 攻击 | 是否成立 | 结论 |
|---|---|---|---|
| 全搬底座 | 溢出全绿，搬了弄红回归门 | 不成立 | 搬的是装配链不是宽度行为；回归门逐票跑，红了即拦 |
| 单引擎直升公共层 | 阻塞 8 张域票 | 不成立 | 先复制跑、本票只定口径；引擎落成走串行小票，不卡域票开工 |
| 表格首选卡片化 | 横滚更便宜 | 不成立 | 卡片化窄屏可读性质变，横滚只保底；目标是效果不是便宜 |
| 新建六列机审 | 人核顶上省事 | 成立一半 | 过渡期人核顶上，但无门终审无尺；新探针必须有 |
| 共用件进公共层 | 包内先收更快 | 不成立 | 包内收是第二处定义，违 F2；快但错，不取 |
