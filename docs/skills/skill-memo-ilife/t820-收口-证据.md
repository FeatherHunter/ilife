## 三 本轮（r12）改了什么

都对准终审（`验收-r11/视觉终审-打分.md`）点名最重的两条系统扣分：

1. **摘要不再把「记录号」当「条数」念**（H3 覆盖面最大；也是第一轮人审点过的「数字语义不明」）。写侧 message 尾号是记录号，`已记一条：18` 读起来像「记了 18 条」，且同一个号在卡里还印两遍。上屏剁掉尾号 ⇒ `已记一条`；**原始 message 一字不改**（复制日志与载荷仍是机器面原样）。覆盖 19 张回执页。
2. **「值（说明）」不再把说明塞进值格**（D3，16 页同位置）：值格只留 `不适用`，说明拆成下一行整宽灰字；`factHtml()` 同时服务「这次的结果」与「处理结果」⇒ **两块同一形状**（原先后者是另一套 `<dl><dt><dd>` 行型）。
3. **向导页「AI」→「助手」**（H7，2 页屏上露英文）：`templates` 下「发给 AI」5 处清零（区块标题／区块说明／两处 toast／另一处）。
4. **人核档两条过期条目更新**：`完成心愿-向导`／`心愿排期-向导` 的 english 行原依据是「`AI` 在允许清单里」，第 3 条撤掉 `AI` 后候选归零，两条按新口径重写，读数链因此重跑通过。
