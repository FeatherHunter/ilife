## §一 `english` 与 `dupFacts`：采纳机器候选，四页各 0 处

四页的静态候选都是 0 处（装配器输出），逐页判「采纳候选」。**复核过为什么是 0**：

- 可见文本里没有 ASCII 字母与半角标点（本域 4 件的正文面逐件实测命中 0）；
- 没有同一串文字在一页出现两次（唯一的真重复「备忘录回执」已在本票修掉，见 §二）。

## §二 本票修掉的一处真重复（H3）

出处＝静态 `L49`（改前）＋ 渲染后 实测眉头与页题同串。
