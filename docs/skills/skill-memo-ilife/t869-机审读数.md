## 一 跑法与出口

```powershell
node tooling/run-locked.mjs --ticket <票号> -- node docs/skills/skill-memo-ilife/t869-机审.mjs --dir <页群目录>
node docs/skills/skill-memo-ilife/t869-机审.mjs --dir <页群目录> --json <落点>      # 逐件读数落盘（可选）
node docs/skills/skill-memo-ilife/t869-机审.mjs --dir <页群目录> --quiet            # 不打逐行明细（可选）
```

- 退出码：**0 全绿；1 有命中或缺件；2 用法错**（不给 `--dir`／`--dir` 不是目录／目录里一件名单产物都没有／名单文件读不出 `files`）。
- 摘要行固定一行，形如：

```text
RESULT: 7/7 PASS ①0 ②0 ③0 ④0 ⑤0 ⑥0 缺件0 名单=批目录
```

`RESULT:` 后面依次是「全绿件数／受审件数」、`PASS`／`FAIL`、六列各自命中的**件数**、缺件件数、名单模式。逐列汇总、逐行明细与「名单对册子」那一行都在这行之前打印。

**名单只消费、不手抄**：名单来自 `t856-manifest.json` 派生的 `t856-audit-list.json`（由 `t856-gen-audit-list.mjs` 产出；34 件，排除手机墙／桌面墙／总索引／链路总表）。两种模式：

| 模式 | 什么时候是它 | 判据差别 |
|---|---|---|
| **批目录** | 目录里有 `t856-audit-list.json`（这一批自己声明了该有哪些件） | 名单点名的件逐件必须在；缺一件即红并点名（`notShipped` 里的名字按豁免算） |
| **页群目录** | 目录里没有名单 json，名单退回仓内 `t856-manifest.json` | 只审「名单 ∩ 目录」，缺件不判（本目录不是整批），只报「命中 N／名单 M」 |

另有两条守门：**名单对册子**（名单里出现册子没有的名字＝手抄名单与册子漂了，红并点名）与**名单外件不打**（墙／索引／链路／对照／老样只报数、不进判据——它们不是产物）。

盘上实例名也认：`搜备忘.html` 与 `搜备忘_20260921_192606.html` 都算名单里那一件（造册前的盘上名字）。时间戳只接在主体后面，所以 `备忘改分类-批量` 不会冒充 `备忘改分类`。

## 三 三处按备忘录域重定的口径（本票的实质活）

### 3.1 文案面三分（静态位置四分 ＋ 载荷按键路径三分）

静态可见文本按**最内一个带 class 的元素**（单遍标签栈扫描，照 `t417-query-audit.mjs` 的 `locateSeps()` 口径；属性值里能带换行，故不用「下一个 `>`」反推）归到五位：

| 位置 | 备忘录类名（对着 7 份模板与真产物读出来的） | 判据 |
|---|---|---|
| 版式位 | `badge`／`badges`／`detail-badge`／`pill`／`chip`／`lead`／`subtitle`／`hint`／`kpi`／`kpi-hint`／`kpi-label`／`hm-empty-hint`／`hm-toast-title`／`hm-toast-detail`／`hm-error-title`／`status-title`／`status-sub`／`status-desc`／`status-meta`／`fact`／`facts`／`meta`／`small`／`notice`／`err-list`／`caption`／`data-table-caption` ＋ 公共层 `ilife-block-chip`／`-kpi-card-title`／`-fact-strip-label`／`-media-caption`／`-timeline-note`／`-copy-block-title` | ⑤ 进红；⑥ 进红 |
| 标题写法位 | `hero`／`eyebrow`／`page-shell-eyebrow`／`page-shell-title` ＋ 裸 `h1`／`<title>` | `·` 允许保留一个（逐处照打）；⑥ 照判 |
| 数据位 | `rows`／`kv`／`content`／`item-content`／`note-content`／`wish-content`／`data-panel`／`detail-body`／`item-head`／`note-head`／`wish-head`／`item-id`／`note-id`／`wish-id`／`item-list`／`item`／`note`／`wish`／`data-table-cell`／`param-form-input`／`param-form-label`／`param-form-required`／`sr-only` | 不进判据（旁证） |
| 载荷位 | `pre-block-code`／`copy-btn`／`copy-menu`／`cmd`／`hm-actions`、`data-t` 属性值 | 不进判据 |
| 正文位 | 其余（`panel`／`toolbar`／按钮标签／无 class 的段） | ⑤⑥ 照判 |

载荷（`<script id="payload">` 里那份 JSON，**运行时渲染成页面的源**）按键路径三分——这是 `t827-search-证据.md` 记下的「门件盲区」（分隔符探针剥掉整段 `<script>`，载荷里那些 `·` 扫不到）：

| 路径 | 位置 | 判据 |
|---|---|---|
| `payload.message`（没有就是 `data.subtitle`） | 副标题 | 版式位：⑤⑥ 进红 |
| `data.scene.snapshot.title`／`data.title` | 页标题 | 写法位：`·` 允许一个；⑥ 照判；④ 不算份 |
| `data.scene.snapshot.summary[]` | 卡片副行／事实条 | 版式位：⑤⑥ 进红 |
| `data.scene.snapshot.sections[].heading` | 章节标题 | 正文位：⑤⑥ 进红 |
| `data.scene.snapshot.sections[].rows[]`、`data.items`／`item`／`rows`／`errors`／`list` | 明细行与明细字段 | 数据位：不进判据 |
| `data.meta`／`copy_log`／`generated_at`／`scene.scene_id` 等 | 载荷 | 不进判据（复制日志正文不上屏，判它等于判错对象） |

**一处如实记的偏离**：`t407` 把**所有**表格单元格剔出英文那一列（理由是单元格里的值取自库内那一行）。本件只剔**回显型**单元格（键值行／明细行／回显槽位，它们由载荷或运行时填），**模板里写死在表格里的页面文案照判**——首次使用报告那张环境检查表里的「装飞书 CLI」「装 fts5 扩展，重建索引」正是地图点名过的「Python 时代文案」同族债，剔掉就把门判瞎了。

### 3.2 标题写法口径

眉头（`eyebrow`／`hero` 的上眉行）与页标题（`hero`／裸 `h1`／`<title>`／载荷 `title`）允许保留**一个**分隔符：逐处照打、进 ⑤b 读数、**不进红**（照 `t407-v8-style-audit.mjs` 里那条整改裁定的原话：页面标题与眉头允许保留一个分隔符）。章节标题与其余可见文案**不豁免**。基线里那处 `备忘录 · 初始化报告`（载荷 `title`）今天照打在这一列，符合预期。

### 3.3 旁证：符号顶替文字（⑤c）

`→`／`←`／`~`／`～` 出现在文案面时，单列一节打出（今天真产物上 2 处，都在备忘域的卡片副行：`原分类 备忘 → 目标 (待选)`）。**不进本件的红**：`t849-视觉基准.md` §3 把「`→` 写「到」、范围符写「至」」归五维尺 H4 扣分，判据住判分引擎（[#868](https://github.com/FeatherHunter/ilife/issues/868)）；本件只给读数，免得同一笔债两处收。
