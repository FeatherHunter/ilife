## 二 清单字段契约（定稿草案）

清单**必须入仓**（`gen-wall.mjs:60` 逐字：「清单须入仓，别让墙猜文件名」）。字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| `rows[].seq` | ✔ | 序（`gen-wall.mjs:70` 校验） |
| `rows[].kind` | ✔ | 页型，如「结果型·列表页」／「过程型·向导页」／「结果型·报告页」 |
| `rows[].wake` | ✔ | 唤醒词 |
| `rows[].file` | ✔ | **就是最终发布名** —— 全仓**只此一处算**，别处不许再拼（两侧不一致＝全墙集体死链） |
| `rows[].check` | ○ | 「这一格该确认什么」（每格标签用） |
| `mf.notShipped[]` | ○ | 索引页单列的「有意不出产物及其原因」 |
| `mf.readings` | ○ | 索引页「本批机器读数」段，原样上屏 |

**一条真实样例行**：

```json
{ "seq": 1, "kind": "结果型·列表页", "wake": "搜备忘",
  "file": "搜备忘.html", "check": "列表条数、分类过滤、页内导航" }
```

### ⚠️ 发布名的撞名点必须在这一步解决

生成器把 `file` 当唯一键，**清单里名字不重复就没问题**；会撞的是**「发布名 ＝ 唤醒词 ＋ `.html`」这条规则本身** —— 备忘录的 `备忘改分类` **一词两场景**（`memo_change_category_single` 单条 与 `memo_batch_change_category` 批量）。**这条归 #822 定**（推荐：只有那一对加形态后缀，其余 28 条不变）。

## 四 链路总表的形制（照卡路里的做法）

**一页静态表，按页族分节**，每行七列：

| 序 | prompt 示例（带复制按钮） | 唤醒词 | 命令 | 参数 | 页型 | 产物绝对路径（点直达） |
|---|---|---|---|---|---|---|

- **链接走同目录相对路径**，而**显示文本写绝对路径**（这样双击本页也点得开、搬目录也活）
- 末尾**死链自检**：缺链 **exit 1**，全通 exit 0
- `prompt` **只出现唤醒词、不出现命令**（「命令不上 HELP 页面」那条只管 HELP 交付面；**这是技术导航页，命令列要上**）

## 六 两个坑（写死在票面里，别再踩）

1. **总索引的「机器读数」段会陈化** —— `gen-wall.mjs:36-44` 自己写了：「清单每行 `check` 里嵌的字节字样**不会跟着刷新**，单格核字节请直接量文件本身」。⇒ **权威读数以 `manifest.json` 的 `readings` ＋ 盘上实测为准**，不要读清单行内字样。
2. **格数对得上** —— 墙页的格数 vs 清单条目数必须相等；少任何一件都要在索引页的「有意不出」一节里有交代。
