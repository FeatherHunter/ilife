## 实证：现有锁抓不到什么

`packages/skill-memo-ilife/test/help-file-228.test.mjs` 的 15 条是**载荷级**断言（断言 JSON 里有这个键、那个计数）。后果：

2. **其中的「步骤文案命中整页 HTML」那条是恒真断言**：载荷 JSON **本身就嵌在整页 HTML 里**，所以「在 HTML 里搜到该字符串」等于「在载荷段里搜到」——**它不能证明这些字真的被渲染出来**。

> **本条要说的是：那次是"人工验过一次"，没有变成"以后每次都会验"的锁。**
