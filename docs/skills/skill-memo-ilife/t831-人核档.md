## 静态候选与渲染面的关系（本族必须写清的一条）

本族页面是**载荷渲染**：正文由页内 `<script id="payload">` 那份 JSON 在运行时渲染上屏，静态可见文本里几乎什么都没有
（这正是 [#867 证据件 §六](https://github.com/FeatherHunter/ilife/issues/867) 登记的那处缺口「静态面 ≠ 载荷渲染面」）。
⇒ 上面 `english`／`dupFacts` 两列的「采纳候选」不等于「静态没看见就是 0」，本档对**渲染面**另做了一遍人核，逐条如下：

- **english（H7）**：把 3 页的载荷字符串逐个打出来核（生成器：`node .scratch/memo-831/dump-payload.mjs <产物>`），
  可见文案里没有 ASCII 字母，也没有半角标点；出现的半角字符只有日期时间（`2026-09-21 21:38:11`）与记录号（`#3`），
  两者都在 `t869-机审.mjs` 的允许清单里（日期／时间／记录号 `#数字`）；分类与子分类之间用的是**全角**分隔符（`情绪日记／开心`）。
- **dupFacts（H3）**：3 页逐页比对渲染面文案 —— 页题、回执结论行、四行键值、复制区说明行各出现一次；
  「已记一条：3」与「笔记编号 3」共享同一个数字但**不是同一句话**（一句是这次动作的结论、一句是对象身份），
  按 §3「同事实一页一处」不算重复，不扣。同族先例（#826／#828／#829）同判。
- 本条已通报 [#867](https://github.com/FeatherHunter/ilife/issues/867) 证据件 §六那处缺口的落点归属（读数链票已关，缺口的收口归地图 #820）。

## 这份档已知的缺口（如实声明，不伪造）

`d1`／`d2` 的取值来自**一次**视觉模型通读（390 与 1440 两档整页截图）＋ 上面的静态／读数旁证。
所用的视觉后端**不按 JSON 契约回值**（问它结构化问题，它回自己的版式摘要），故这一遍**不是可复现件**：
⇒ `d1`／`d2` 的 0 值按「乐观上界」记（与 `t827-人核档.md` §未取、`t828-判分读数/人核档.md` §四 同款声明口径），终审 [#835](https://github.com/FeatherHunter/ilife/issues/835) 另判。
其余各列不是上界：`d3`／`d4`／`d5` 与 H1／H2／H4／H5／H6／H7 全部来自机器读数（`sep.json`／`resp.json`／`fmt.json`，本票现产）。
