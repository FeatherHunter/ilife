## 二 清单字段契约

清单**必须入仓**（墙生成器逐字：「清单须入仓，别让墙猜文件名」）。字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| `rows[].seq` | ✔ | 序（生成器校验） |
| `rows[].kind` | ✔ | 页型，如结果型·列表页／过程型·向导页／结果型·报告页 |
| `rows[].wake` | ✔ | 唤醒词 |
| `rows[].file` | ✔ | **就是最终发布名** —— 全仓**只此一处算**，别处不许再拼 |
| `rows[].check` | ○ | 「这一格该确认什么」（每格标签用） |
| `mf.notShipped[]` | ○ | 索引页单列的「有意不出产物及其原因」 |
| `mf.readings` | ○ | 索引页「本批机器读数」段，原样上屏 |

命名规则：`file ＝ 唤醒词（＋一词多场景时加形态后缀）＋ .html`。唯一撞名对：`备忘改分类`（单条）与 `备忘改分类-批量`（批量），其余 28 条取唤醒词原样。清单生成时做唯一性校验，重复 `file` 即失败。

### 替代说明（对 #822 §二／§六／§八的一处变更）

#822 冻的是「`file` 存主体、墙按主体前缀匹配时间戳实例（5 行小改）」。本票经 grill 两轮＋负责人认可 v2，改为「`file` 存最终名、造册时按主体取最新时间戳实例复制为 `file` 名、墙精确匹配、生成器不动」。理由：前缀匹配是模糊匹配，主体前缀碰撞即全墙错配；库目录的时间戳实例仍沿 #822 规则，时间戳只活在库侧，墙批目录内只认 `file` 精确名。#822 的 34 格／4 族／扁平目录不受影响。

## 三 双墙规格（照仓规 §6.3）

| 项 | 值 |
|---|---|
| 手机墙 | **390 × 820，3 列** |
| 桌面墙 | **1280 × 860，1 列** |
| 宽产物缩放 | `SCALE = W <= 500 ? 1 : Math.min(0.5, 600 / W)`（缩显示不缩视口，媒体查询仍按 `W` 生效） |
| 每格 | **一件真产物，不塞缩略图**（`iframe` 跑真 HTML） |
| 每格标签 | 编号 ＋ 点开整页的链接 ＋ 一句「这一格该确认什么」 |
| **不许加** `loading="lazy"` | 加了下半页格子永远空白（另有断言守） |
| 清单**不许带 BOM** | 读出来会 `Unexpected token` |

**规模**：34 格先单张（手机一张＋桌面一张）。拆墙触发线预冻：单格过大或整墙过重（单格大于 5MB 或整墙大于 80MB）即按 4 页族拆墙＋总索引聚合，不重议形状。

## 四 链路总表的形制（照卡路里的做法）

**一页静态表，按页族分节**，每行七列：

| 序 | prompt 示例（带复制按钮） | 唤醒词 | 命令 | 参数 | 页型 | 产物绝对路径（点直达） |
|---|---|---|---|---|---|---|

- **链接走同目录相对路径**，**显示文本写绝对路径**（双击本页也点得开、搬目录也活）
- 末尾**死链自检**：缺链 **exit 1**，全通 exit 0
- `prompt` 只出现唤醒词、不出现命令（「命令不上 HELP 页面」只管 HELP 交付面；这是技术导航页，命令列要上）

## 六 两个坑（写死，别再踩）

1. **总索引「机器读数」段会陈化** —— 清单行内嵌的字节字样不会跟着刷新，单格核字节直接量文件本身。权威读数以清单 `readings` ＋ 盘上实测为准，不要读行内字样。
2. **格数对得上** —— 墙格数 vs 清单条目数必须相等；少任何一件都要在索引页「有意不出」一节交代。
