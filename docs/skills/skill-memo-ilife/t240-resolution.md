## 一、这笔债是什么，为什么必须还

「命名与落盘」有一条口径：产物名 `<主体>_<YYYYMMDD_HHMMSS>[_N].html`（本地时区）、同秒 `_N` 递补**从 `_2` 起**、`wx` 独占创建、绝不静默覆盖、回执给绝对路径与**实际落盘**字节数。

`#224` 判「甲」时，备忘录把这套东西**自持**在包内（`src/help/memoOutput.ts`）——于是它成了全仓**第 4 份**同逻辑实现（前 3 份＝饼干记账、卡路里、老作息世代）。仓规把这件事定性得很直白：`docs/agents/structure.md:23` 铁律一逐字「**把对方那份抄一遍放进自己目录，不算走了接口**——抄的那份迟早和原份走散，走散之后同一件事会算出两个结果」。

判「甲」是为了**保关键路径不断**（当时共用件票 `#237` 还在人工审批闸门后，且它阻塞大厨那张图），代价是挂一笔**可查的债**。本票就是还债，完成判据由票面钉死：

> 备忘录落盘走共用件、自持件已删；`#230` 那套 CLI 级用例全绿；产物名与落盘路径与迁移前逐字相同。

## 三、形状决策：为什么删件、落盘只留在出口

三个候选：

取乙的理由（按仓规原文，不按口味；**三处口径已按对抗式复审 A 更正**，见 §九）：

1. **铁律五的判据**（`structure.md:57`）：「删掉一个转发函数，外面说不出少了什么，那它就是白占一层」。判据适用，但**不是自动判决**——同一条判据逐字也命中 `packages/skill-bill/src/output.ts:39-48`（同样薄两态、同样只有一个内部消费者），而 `#237` 迁移时**保留**了它。备忘录这一案的差别要说清：**那 8 行不在包 `exports` 里、只有一个内部消费者、体内没有任何本技能特有的策略**。对照：大厨的对照件内含 `reuseMs` 与空载荷 guard（`packages/skill-chef/src/help/output.ts:51-64`），卡路里那份背着三态交付与只读回退（`packages/skill-calorie/src/output.ts:190-222`），备忘录两者都没有。
2. **它在本包定过的形状里没有位置**（措辞已按复审更正）：`t225-structure-design.md` 的 A 组清单（`:59-69`、`:160-162`）确实没有「交付件」这一项；但 t225 **没有把落盘块指定给 `cmd_read.ts`**——A5 行只写「命名与落点的**值**（3 个导出）」＋理由栏一句「落盘那一小块自持」，§2.3 的依赖图把它画成 `cmd_read.ts` 底下的**独立节点**。最强支持是 B1 行（`:79`）「新增 `dispatchHelp`（命名值 ＋ 建 HTML ＋ **交付**）」——**接近定案，不是逐字定案**。加上 `#229` 自己把它报成「偏差 1：件名与票面未指名」（`t229-export-report.md:228`）、以及裁决 16 的先例（不铺面、今天的对外面是零），删件即归位。

## 四、行为逐字不变（机械证据，不是声明）

比对面 ＝ 迁移**前后各跑一次同一支探针**（`%TEMP%\t240-probe.mjs`；只经真 spawn 跑出口；七组用例：缺省支／速查支／`q` 支／`--html` 支／两条落盘失败／退出码矩阵／并发 6 次）。

**归一化后两份 JSON 完全逐字相同**（把时间戳 `YYYYMMDD_HHMMSS` 与探针标签归一后，`Compare-Object` 为空集、`-ceq` 判 True）。关键读数（左＝迁移前，右＝迁移后，逐项相等）：

| 面 | 读数 |
|---|---|
| 缺省支 | `exit 0`／`备忘录_HELP_<stamp>.html`／扁平 `memo_html/`／**131976 B**／sha `059321FA…AFC3E`／回执字节数＝实盘字节数／`delivery` 追加在既有五字段之后 |
| 速查支 | `exit 0`／`备忘录_速查表_<stamp>.html`／6476 B／sha `76E85B27…`／片段（非整页） |
| `--html` 支 | 同路径跑两次 ⇒ 同一路径、目录里仍只有 1 件（无 `_2`）、内容为覆盖写、**不写默认目录** |
| `q` 支 | 不落盘；连 `SKILLS_DB_PATH` 都不建 |
| 落盘失败（默认支） | `exit 5`，`ERR 5: 落盘失败：ENOTDIR: not a directory, mkdir '…'` ——**逐字相同** |
| 落盘失败（`--html`） | `exit 5`，`ERR 5: 落盘失败：EEXIST: file already exists, mkdir '…'` ——**逐字相同** |
| 退出码矩阵 | `2,2,2,2,2,2,2,3` ＋ 缺 `SKILLS_DB_PATH` `1` ——全同 |
| 并发 6 次 | 6 份两两不同／6 件落盘／槽位＝本体・`_2`…`_6`／**绝不出现 `_1`**／六份内容 sha 相同 |
| 跑完不建库 | `<db>/memo` 与老家的 `<db>/memo.db` 都不存在 |

**比对窗口干净**：前后共用层指纹逐位相同（`dist/helpShell.js` `A99EBC13…`、`dist/output/saveHtml.js` `D82C2634…`）——排除了「比对期间别家会话动了共用层」这条干扰。

一句话：产物**名**、**路径**、**字节**、**哈希**、**退出码**、**失败消息**、**并发槽位**，逐项不变。

**比对口径的强度（复审 B 复核后补写）**：产物内容**不含落盘时刻**——`YYYYMMDD_HHMMSS` 在产物文本里出现 **0 次**（时间戳只在文件名里）、`C:\` 形式的绝对路径 **0 次**，故两版产物的**整文件 SHA-256 直接相等**（`059321FA…AFC3E`，131976 B），**不是**「长度相等」这种弱口径（复审 B 演示过：等长篡改 `手册`→`手冊` 能骗过 `bytes` 比较，骗不过 SHA）。`delivery.bytes === statSync(path).size` 是另一条独立的绑定（回执与磁盘对死）。

### 「逐字不变」的适用范围（如实划清，按复审 A 的 B3 更正）

- **缺省支与速查支**：产物名、落点目录、字节、哈希**逐字相同**（上表即实证）。
- **`--html` 支**：**合法文件名**（含中文）逐字相同（实测 `我的帮助.html` 原样落）；但**含 Windows 非法字符／超长**的路径**不再逐字**——共用件对 `file` 也做安全化（非法字符 `/ : * ? " < > |` → `_`；另按 180 码点截断），旧实现是把用户给的串**逐字**交给 `writeFileSync`。本席亲跑复刻两版：
  - 新：`--html …\报告?.html` ⇒ **exit 0**，落 `报告_.html`；
  - 旧（复刻 HEAD 版 `memoOutput.ts:117-121` 的 `resolve`→`mkdirSync`→`writeFileSync` 同一路径）⇒ **`ENOENT` 失败**（Windows 下 `?` 非法，旧行为是退出码 5）。
  - 这是 `#237` 的**有意口径**（共用件自己的用例专门锁了 `a/b.html → a_b.html`），记账／大厨迁移后同形；回执给的是**实际落盘**的路径，不是静默改写。要恢复「非法字符即失败」得改共用件的对外契约（牵动四家），**不属本票**。
- **另有两处口径微差，方向都是更严或更实**：① 文件名的取样时刻由「分派开头」外移到「写盘前」（跨秒边界可能差 1 秒；载荷不吃时间 ⇒ 不会出现「页面时间与文件名不一致」，本席已核 `helpFile.ts:189-190`）；② 回执 `bytes` 由「输入串的期望长度」改成「**写后回读实测**」，并新增「截断即抛 `EIO`」的校验（正常路径同值）。

### 「四条口径相同」是错的：实现差异共 6 处（复审 B 逐行比对，逐条收敛到同一可观察结果）

| # | 维度 | 自持件（已删） | 共用件 | 对这个主体／这条落点的影响 |
|---|---|---|---|---|
| 1 | 回执 `bytes` | **期望值**（写前算） | **写后回读** ＋ 不符即抛 `EIO` | 实测同值（131976）；语义更严 |
| 2 | `mkdirSync` 位置 | **递补循环内**，其 `EEXIST` 被当成「候选撞名」⇒ 空转 1000 次 | **循环外**，原样抛 | 退化场景实测：两侧都 exit 5；差在耗时（110ms→62ms）与消息（「重试超限」→ 裸 `EEXIST`）——**这是修好，不是回归**（`t240-latent-eeexist-note.md` 记的正是这个病灶） |
| 3 | 主体清洗 | 无（主体原样拼） | 非法字符→`_`、去尾点尾空格、180 码点截断 | **对 `备忘录_HELP`（8 码点）与 `备忘录_速查表`（7 码点）零影响**（实测） |
| 4 | 确切文件名清洗（`--html`） | 不做清洗，逐字交 `writeFileSync` | 做清洗 ＋ 截断 | **行为差异**，见上方「适用范围」；回执给实际落盘路径 |
| 5 | `resolve()` 归一 | 落点算式里一次 `resolve` | `resolve(dir)` ＋ `join` | 等价（实测相对 `SKILLS_DB_PATH` 仍得绝对路径回执——#83 R-1 没丢） |
| 6 | `onExists` | 无此参数（行为＝递补） | **缺省 `'succession'`** | 现源码**不传** ⇒ 走递补 ⇒ 实测一致。⚠️ 这一处**是承重参数**：显式传 `'overwrite'` 会让产物退化成固定名（本票变异 A 实测过），已在出口件注释里写明 |
