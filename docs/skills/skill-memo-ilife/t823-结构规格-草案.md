## 一 目标 `src/` 树（照卡路里的形状 ＋ 仓规铁律四）

```
src/
  index.ts                包门（导出面收窄）
  config.ts               ★ 边界：本图不碰
  memo/                   备忘域（HELP 一级分组）
  search/                 查找域
  remind/                 提醒域
  wish/                   心愿域（**已是达标样板，原样保留**）
  checkin/                打卡域
  mood/                   情绪域
  sync/                   同步域（飞书链）
  init/                   初始化域
  shared/                 跨域共用件（信封／路径／错误／批量／页资产）
  render/                 渲染框架位（html／templates／errors／index）
  cli/                    命令解析与分派框架位（readArgs／delivery／registry／health）
  help/                   HELP 渲染与资产（scenes/ 8 域切片已在此）
  db/                     库连接（只读层，禁 DDL）
  triggers/               唤醒词表与路由（**生成物的源**）
```

**每个域目录的最小三件**（照卡路里）：`index.ts` 门 ＋ `commands.ts` 声明（恰好导出一个数组）＋ `routes.ts` 路由；有页面的域另加自己的页面件与文案件。

## 五 搬迁批次（每批硬判据：编译绿 ＋ 产物字节不变）

1. **批次 0 建骨架**：只建目录与三件空壳，不动任何逻辑；全量测试绿。
2. **批次 1 样板域**：`wish/` 已是达标形状，先把它对齐到「三件 ＋ 页面件」的目标形状，作为后续各域的样板。
3. **批次 2 拆框架位**：`cli/cmd_read.ts`（569 行）拆成 `readArgs`／`delivery`／`registry`；`health.ts`（614 行）按体检项分件。
4. **批次 3+ 逐域搬家**：一次一个域，搬完即跑门；**每批产物字节不变**（照 #704 的批次搬家口径）。
5. **收尾**：撤 `src/policy/index.ts` 的转发、收窄包门导出、补行数台账。

**并发**：批次 3+ 的逐域搬家**天然可按域并行**（写集互斥），但**同一时刻只能有一批在跑编译与生成物重导**（走 `run-locked.mjs`）。
