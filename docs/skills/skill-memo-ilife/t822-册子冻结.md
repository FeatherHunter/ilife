# #822 册子冻结：34 格 ＋ 4 族 ＋ 1 共用件 ＋ 主体命名 ＋ 扁平目录

性质：本票的冻结结论。输入是册子输入表（30 场景 × 页型声明）与现状链路表；推导起点是地图的四条唯一住处（唤醒词表／样式／产物名／域目录各一处）加备忘录三个物理事实。独占写集：册子 JSON ＋ `t822-*.md`。本票不出代码。

第一性推导：产物是落盘实例（文件名主体加时间戳），册子只冻主体算法；页是交互需要（结果给人看 versus 过程必须点），HELP 的类型标签不是文件数，备忘录采集在同一次 prompt 填空完成；名字须唯一加稳定加可读，且只在一处算；目录是命名空间加生命周期，新旧同命；形状是实现复用单元，老实物 6 模板天然成 3 族。

## 一 份数

34 格：30 结果页（每场景一份）加 4 预检确认页（4 条向导场景各加一张过程页）。

64 格作废：10 条读类场景的查看与回执是同一份页，数了两遍。54 格否决：20 条采集多为同一次填空，链路仅 5 真缺槽位，多 20 页只是同一张填空表换字段。若命令面裁定要求确认独立成页，计入向导过程，不新增类。

## 二 命名规则（只在一处算）

28 条主体等于唤醒词原样；唯一撞名对加形态后缀：备忘改分类（单条）与备忘改分类-批量（批量）。4 张过程页加向导后缀：备忘改分类-批量-向导、完成心愿-向导、心愿排期-向导、首次使用-向导。

时间戳规则沿既有格式：主体_时间戳.html。清单 file 字段存主体，墙按主体前缀匹配时间戳实例。发布脚本与墙共用同一份算法。唤醒词均为中文常用字，无需符号转义表；若新增符号，补表仍落此处。

## 三 目录

沿已关票据裁决：扁平落备忘录产物目录，与既有 216 件并排，不另开层。新主体沿既有中文前缀习惯。册子 JSON 与生成器入仓；墙与链路输出走 scratch 批目录，不入仓。

## 四 形状族清单

列表查询族管 9 格；向导族管 4 格（3 份老模板同形参数化）；报告族管 2 格（状态卡加数据面板）；通用回执族管 19 格（无基准 16 条加 3 向导结果，只参数化标题与字段，不单独设计）。共用件 1 块单列：复制区按钮排加说明行（一处定义，34 格复用）。渲染实现待视觉基准票定，本表只定归属。

## 七 对抗结论（每条是否帮地图四条达成）

34 反向（64 双份或 54 采集页）会让墙容量与打分先红，否决。16 条各设计会让最低页分不可控，收成通用族通过。冻全文件名会让时间戳下自检必红，改冻主体通过。另开层让链路双前缀而无质量收益，维持扁平通过。本票定样式实现会与视觉基准票写同一处，改 What 与 How 切分通过。
