一句话链路：用户说的话（含唤醒词） → 唤醒词（最长匹配） → 命令（唯一出口 bill-cmd-read） → 结果型 HTML（落盘，点右列链接即开）。查询域没有过程型采集页：缺参即阻断（exit 2／4，不出页）；只有真取到数（含零行空态）才出结果型页。下表 18 行＝17 词＋1 附带空态。

一、过程型 vs 结果型（本图只有后者）

过程型采集页是写入域的概念（t407：缺槽位时出采集页，建表不写行）。本图查询域不存在这一支——src/query/read.ts 头注释写明“查询缺参就是缺参，阻断即错误回执，页面只在真取到数时出”。

结果型页本图有三样：①列表页（16 词：时间页 5＋区间页 6＋条件页 5，经 queryListDoc：结果胶囊＋KPI 行＋数据表／空态＋复制区）；②详情页（查账单详情，经 queryDetailDoc：结果胶囊＋金额卡＋状态卡＋字段表＋复制区）；③空态页（零行走 renderEmptyBlock，附带第 18 行）。阻断（空查询／空区间／无此号）不出静态产物，由 t417 程序锁逐条断言。

三、有意不出产物及其原因

  • 过程型采集页（缺槽位时的人机采集页）：查询域没有这一型：缺参即阻断走错误回执（exit 2／4），只有真取到数（含零行）才出结果型页。过程型是写入域的概念（t407 采集页），本图 17 词全部是结果型。
  • 阻断回执（空查询 exit 2／空区间 exit 4／无此号 exit 4）：有意不出静态产物：阻断即 stderr＋exit 码，由 t417 程序锁逐条断言（5 条阻断），墙上只收结果型页。
  • 其余 5 域（分析／目标／账户／联动／开始使用）61 词：归各自 map（雾区），不在本图 17 词范围内。
