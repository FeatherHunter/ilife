## 丙、仍留的差异（报负责人裁，未自行处理）

- **标题形状**：判地是固定句（「改好了」／「已撤销」／「已恢复」），产物是数据句（「备注已改为 改过」／「已撤销记录 2」／「已恢复记录 2」）。按裁决第四条「随数据变的取值保留」先**不动**（编号是数据；`t410` 另有「纸头须印记录编号」的断言）；**判不准，列出来问**。
- **复制区三格式说明文案**：判地「自己看或发给助手／存档用／表格用」↔ 产物「纯文本 自己看，发助手都行／JSON 以后查账用／CSV 表格打开看」——住**共享件**（`shared/copyArea` ＋ base-paint 复制区），16 页与别域一同受影响、**不在本票写集**；列出来等裁。
- **9–10px 纵向错位**：三页现在与 13 页同带（1.0089–1.0105），与 #1117 已报同源（记档、不单开票）。
- **x26 条件块**（疑似重复）：数据驱动的正确行为，**不参与像素判据**，不许关。

**`▾` 口径更正（负责人 2026-10-04 复验）**：判地是**可见文本里的字面** `▾`；产物是 **CSS `::after { content: "▾" }` 出的字面**（x02 产物 `▾` 命中 4、`content:"▾"` 命中 3；#525 第二轮口径），**渲染上等价**。八件套第 8 条禁的是**用 border 画的三角**——实测 `border-*: Npx solid transparent` 命中 **0**，规则未被违反。早先「16 页 `▾` 命中 0」是本席探针**剥掉 `<style>` 之后**的读数，属**假阳性，作废**。
