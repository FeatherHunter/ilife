t407 写入域 16 条唤醒词链路总览

一句话链路：用户说的话（含唤醒词） → 唤醒词 → 命令 → 过程型采集页 → 结果型回执页。表里 16 行＝16 条唤醒词，每行两列页面链接都可点开。

一、流程说明（这条链怎么走）

过程型：采集页

  • 用户说一句话，句子里带唤醒词（例如「记退款」）。这条话进到技能，按最长匹配命中唯一一条唤醒词，取出这一条的命令（记退款→bill.record.add，并带上 kind=refund）。
  • 命令要求的那几格必需槽位缺了（记退款缺 category、amount；撤销／恢复缺 id），就出采集页：页面明示缺哪几格槽位，给出「复制 prompt」区（把补齐的话原样交给 AI）与「复制数据／日志」区。
  • 用户照采集页把缺的槽位补齐，再把那一段 prompt 交给 AI，重跑同一条命令。
  • 采集页不写库：这一支会建表，但不写行（页面自己的说明写的是「只读：本页不写库，只采集」）。

结果型：回执页

  • 槽位齐了（并且金额方向对得上：记支出要负数、记收入要正数），命令就跑进写库那一步。
  • AI 跑一条：bill-cmd-read <命令> --params '<JSON>' --html <路径>。
  • 落一张回执整页（不是片段），并回答这张页的绝对路径，用户双击即看。
  • 写库只发生在回执这一步：写库成功后才有回执页；采集页那一步一行也不写。

一句话记牢：采集页＝缺槽位时的过程页，建表不写行；回执页＝槽位齐了、真写库之后的回执整页。两页都是同一目录 D:\ilife\docs\skills\skill-bill\ 下的成品 HTML，下面的链接用的是相对文件名，双击即开。

二、命令原文模板（可直接复制）

bill-cmd-read bill.record.add --params '{"kind":"refund"}' --html D:\ilife\docs\skills\skill-bill\t407-页-记退款-回执页.html
bill-cmd-read bill.record.add --params '{"kind":"expense","category":"餐饮","amount":-35,"note":"午饭"}' --html <绝对路径>
bill-cmd-read bill.record.update --params '{"op":"undo"}' --html <绝对路径>
bill-cmd-read bill.record.update --params '{"op":"restore"}' --html <绝对路径>
bill-cmd-read bill.record.update --params '{"id":1}' --html <绝对路径>

形状记法：bill-cmd-read <命令> --params '<JSON 对象>' --html <绝对路径>。参数口径：kind 取 expense／income／photo／batch／refund／reimburse／reimburse-done／lend／borrow／collect／repay／installment；op 取 undo／restore，不给 op 就是改字段（改记录）。

本机 pwsh 5.1 的坑：内联 JSON 的内层双引号会被吃掉（'{"kind":"refund"}' 到命令行里可能变成 {kind:refund}，--params 当场报「须为 JSON」）。建议把整条命令写进一个 .ps1 文件再跑，例如：

# 存成 run-refund.ps1 之后：pwsh -File run-refund.ps1
$p = '{"kind":"refund","category":"餐饮","amount":-35,"note":"午饭"}'
bill-cmd-read bill.record.add --params $p --html 'D:\ilife\docs\skills\skill-bill\t407-页-记退款-回执页.html'
