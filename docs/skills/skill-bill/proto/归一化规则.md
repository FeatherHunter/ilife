# 归一化规则（六条，写死）

`../1073-proto-same.mjs` 按这六条把两页归一化后逐字节比较。它回答**「哪里不一样」（字符级定位）**，
不回答**「看起来一不一样」（像素级）**。

> **它是辅助定位，不是还原判据。**
> #1079／#1080 只在像素已经有差异时用它缩小范围。**它绿而像素不绿，照样算红。**

规则由 #1073 票面写死。执行席**不许改、不许加、也不许删**；改规则属于改判据，必须另开票由人裁。

> **2026-10-03 的一次裁定与施工**：#1085 裁定「金额正则改宽 ＋ 遮蔽面扩到载荷文本」，#1111 施工落地（口径见下「规则 2 的两次修正」）。探针电池随施工入仓为 [`../1073-proto-same-selftest.mjs`](../1073-proto-same-selftest.mjs)（20 条）。

## 用法

```
node docs/skills/skill-bill/1073-proto-same.mjs <实际件目录> <判地原型目录> <manifest.json> [--domain <域>] [--kind <kind>]
```

两侧都按 `manifest.json` 的 `rel` 解析，所以**两个目录的目录形状必须一致**。
全绿打印 `N/N 结构同构` 并 exit 0；否则 exit 1，打印**每一页的第一个不同字符位置**、
**所在行**、以及**两侧归一化输出在该位置前后各 200 字**（`⟪此处不同⟫` 标出分界）。

`--kind` 默认 `proto`（那 95 张）。`frozen`／`spec`／`superseded` 也能比。

## 六条规则

| # | 规则 | 作用范围 |
|---|---|---|
| 1 | 删运行期属性：`data-*-id`／`data-generated-at`／`data-seq`／`data-ticket-no`，以及 `id="r-<数字>"` | 标签的属性表 |
| 2 | 数值占位：金额与数量 → `#N#`（后随 `元\|笔\|个月\|天\|条` 时一并吞掉单位）；日期时间 → `#D#`；百分比 → `#P#` | 可见文本 ＋ **载荷文本**（`<script>` 字符串字面量、多行属性值）；`class`／`style`／`id`／`on*` 不碰 |
| 3 | 枚举值占位：分类名 → `#CAT#`／账户名 → `#ACC#`／场景名 → `#SCENE#` | 文本节点 ＋ `<script>` 载荷整段 ＋ 多行属性值（口径见下） |
| 4 | class 去 hash 后缀 `-[0-9a-f]{6,}` | `class` 属性值 |
| 5 | CSS 声明排序：每个选择器内声明按字典序重排，选择器块按字典序重排 | `<style>` 体 ＋ `style="…"` 内联样式 |
| 6 | 折叠空白：连续空白 → 单空格；标签之间的纯空白删除；`>` 与 `<` 之间的换行删除 | 可见文本节点 |

执行顺序＝条号顺序 1→2→3→4→5→6。

## 票面未写死处的实施口径

规则要落到 HTML 上就得先回答「作用在哪些字符上」。票面只对规则 2 写了范围，其余按**最窄的读法**取：

- **「可见文本」**＝不在 `<script>`／`<style>`／`<title>`／注释里的文本节点。
  `<title>` 不渲染，不是可见文本，**逐字保留**。
- **「载荷文本」**（2026-10-03 #1085 裁定、#1111 施工扩面）＝ ① `<script>` 里的**字符串字面量**
  （脚本代码本身不遮——`setTimeout(…,1600)` 这类是结构）；② **多行属性值**（值里含换行或
  `&#10;`／`&#xA;`；本仓这个形状只有承载复制日志的那一个属性）。规则 2 与规则 3 都作用在这两个面上。
  `class`／`style`／`id`／`on*` 一律不进遮蔽面。
  **为什么**：执行时刻这类「同一次执行必然变化、且不参与渲染」的字符原本落在遮蔽面外——真跑产物与
  冻结原型一比就红（95/95 张原型带运行时时钟串）。仓库里 `gen-page-fingerprints.mjs` 早就把时钟串
  换成 `<TS>` 再取指纹，本件只是把同一条口径补齐。
- **规则 3 的范围**＝文本节点 ＋ `<script>` 载荷，**不碰属性值与 `<style>`**。
  票面只对规则 2 写了「只替换可见文本」，规则 3 没有范围限定；
  而枚举取值表本身就住在 `<script>` 载荷里（原型把真跑载荷原样内嵌成 `var F={…}`），
  排除 `<script>` 会让规则 3 够不着它自己点名的那些值。
- **规则 6 的「标签之间的纯空白」与「`>` 与 `<` 之间的换行」**在 HTML 里是同一件事：
  夹在两个标签之间的纯空白文本节点，删掉。文本节点**内部**的首尾空白票面没写要删，**不删**
  ——宁可少归一化，不多归一化。
- **CSS 选择器含空格与 `>`**（`.a > .b`）不进规则 6：规则 6 只作用在可见文本节点上。

## 规则 3 的取值表从哪来（不许手写）

从**判地原型件**里机械抽，逐项：

| 占位 | 取值来源 | 抽取式 |
|---|---|---|
| `#CAT#` | 判地件里所有 `"category":"…"` | `/"category"\s*:\s*"((?:[^"\\]|\\.)*)"/g` |
| `#ACC#` | 判地件里所有 `"account":"…"` | `/"account"\s*:\s*"((?:[^"\\]|\\.)*)"/g` |
| `#SCENE#` | `manifest.json` 里本次参与比较的条目的 `wake` | 清单字段 |

替换顺序：所有值拉平成一张表，**按长度降序**；同长时 `CAT` > `ACC` > `SCENE`。
长串优先保证「餐饮/外卖/午餐」不会被「餐饮」抢先替换。

取值表随 `--domain` 收窄而收窄：只比一个域时，只有该域出现的枚举值进表。
**后果**：实际侧出现一个判地件里从来没出现过的分类名 → **不会被替换 → 报红**。
这是刻意的保守方向——没见过的值就是真差异。

## 规则 2 的两次修正（2026-10-03，#1085 裁定、#1111 施工）

**改之前的两处毛病**：

1. **金额正则的整数部分只吃三位**：票面写死的 `-?\d{1,3}(,\d{3})*(\.\d+)?` 不覆盖四位及以上的整数，
   `8000.00` 被拆成 `#N##N#`，而 `1,234.50` → `#N#`。同一个值因有无千分位逗号而掩蔽结果不同，
   与规则 2「金额与数量 → `#N#`」相矛盾。
2. **遮蔽面只到可见文本**：执行时刻那类串落在两个面外——`<script>` 载荷（88/95 张原型）
   与承载复制日志的多行属性（7/95 张）。真跑产物用当刻时钟、冻结原型用录制时刻，两者必然不同
   ⇒ 结构比对**每一页都会红**，而这道门是 #1079／#1080 的第二道门。

**改之后的口径（现读数）**：

| 输入 | 现读数 | 改前 |
|---|---|---|
| `35.00` | `#N#` | `#N#` |
| `8000.00`／`1200.50`／`-1123.00`／`3000 元` | `#N#`（各一枚） | `#N##N#` |
| `1,234.50` | `#N#` | `#N#` |
| `100%` | `#P#` | `#P#` |
| `2026-10-02 12:00:00` | `#D#` | `#D#` |
| `2026-10-02 05:03:44`（`<script>` 字面量里） | `#D#` | 原样（假红） |
| 多行属性值里的 `&#10;2026-10-02 · 版本 2.0` | `&#10;#D# · 版本 #N#.0` | 原样（假红） |
| `2 笔` | `#N#` | `#N#` |
| `9月工资` | `#N#月工资` | `#N#月工资` |
| `12:00:00`（无日期） | `#N#:#N#:#N#` | `#N#:#N#:#N#` |
| `2026-10`（年月） | `#N##N#` | `#N##N##N#`（两种都仍被遮蔽，不产生假红） |

**已知残余**：`-?\d[\d,]*` 会把含逗号的连续数字串整段吞掉（`1,` → `#N#`、`12,34` → `#N#`、
`1,2345` → `#N#`）。方向是「遮得更狠」，与「金额是数据、不参与结构比对」的取向一致；真正兜底的是
像素判据与样本集（#1079 要求样本数值与原型逐项对上）。若将来发现它遮掉了本该报红的差异，另开票由人裁。

**变异自证**：把金额正则改回三位数 → 探针 `规则2e` 立即变红（其余仍绿）；把遮蔽面缩回可见文本 →
探针 `规则2f`／`规则2g` 立即变红。两行读数原样落在 [`../1073-规则2修正证据.md`](../1073-规则2修正证据.md)。

## 自护栏

`normalize()` 里有一条断言：**非空原件归一化后不得变成空串**。

这不是摆设——2026-10-03 出过一次真事故：拼接函数读错了字段（`g.s` vs 字符串），
所有页的归一化输出都成了空串，于是**任何改动都「结构同构」**，脚本永远绿。
只跑「原型目录自比」是抓不到这种错的，必须有「不该同构的改动必须红」的探针。
