# 归一化规则（六条，写死）

`../1073-proto-same.mjs` 按这六条把两页归一化后逐字节比较。它回答**「哪里不一样」（字符级定位）**，
不回答**「看起来一不一样」（像素级）**。

> **它是辅助定位，不是还原判据。**
> #1079／#1080 只在像素已经有差异时用它缩小范围。**它绿而像素不绿，照样算红。**

规则由 #1073 票面写死。执行席**不许改、不许加、也不许删**；改规则属于改判据，必须另开票由人裁。

## 用法

```
node docs/skills/skill-bill/1073-proto-same.mjs <实际件目录> <判地原型目录> <manifest.json> [--domain <域>] [--kind <kind>]
```

两侧都按 `manifest.json` 的 `rel` 解析，所以**两个目录的目录形状必须一致**。
全绿打印 `N/N 结构同构` 并 exit 0；否则 exit 1，打印**每一页的第一个不同字符位置**、
**所在行**、以及**两侧归一化输出在该位置前后各 200 字**（`⟪此处不同⟫` 标出分界）。

`--kind` 默认 `proto`（那 95 张）。`frozen`／`spec`／`superseded` 也能比。

## 六条规则

| # | 规则 | 作用范围 |
|---|---|---|
| 1 | 删运行期属性：`data-*-id`／`data-generated-at`／`data-seq`／`data-ticket-no`，以及 `id="r-<数字>"` | 标签的属性表 |
| 2 | 文本节点数值占位：金额与数量 → `#N#`（后随 `元\|笔\|个月\|天\|条` 时一并吞掉单位）；日期时间 → `#D#`；百分比 → `#P#` | **只替换可见文本，不碰属性值** |
| 3 | 枚举值占位：分类名 → `#CAT#`／账户名 → `#ACC#`／场景名 → `#SCENE#` | 文本节点 ＋ `<script>` 载荷（口径见下） |
| 4 | class 去 hash 后缀 `-[0-9a-f]{6,}` | `class` 属性值 |
| 5 | CSS 声明排序：每个选择器内声明按字典序重排，选择器块按字典序重排 | `<style>` 体 ＋ `style="…"` 内联样式 |
| 6 | 折叠空白：连续空白 → 单空格；标签之间的纯空白删除；`>` 与 `<` 之间的换行删除 | 可见文本节点 |

执行顺序＝条号顺序 1→2→3→4→5→6。

## 票面未写死处的实施口径

规则要落到 HTML 上就得先回答「作用在哪些字符上」。票面只对规则 2 写了范围，其余按**最窄的读法**取：

- **「可见文本」**＝不在 `<script>`／`<style>`／`<title>`／注释里的文本节点。
  `<title>` 不渲染，不是可见文本，**逐字保留**。
- **规则 3 的范围**＝文本节点 ＋ `<script>` 载荷，**不碰属性值与 `<style>`**。
  票面只对规则 2 写了「只替换可见文本」，规则 3 没有范围限定；
  而枚举取值表本身就住在 `<script>` 载荷里（原型把真跑载荷原样内嵌成 `var F={…}`），
  排除 `<script>` 会让规则 3 够不着它自己点名的那些值。
- **规则 6 的「标签之间的纯空白」与「`>` 与 `<` 之间的换行」**在 HTML 里是同一件事：
  夹在两个标签之间的纯空白文本节点，删掉。文本节点**内部**的首尾空白票面没写要删，**不删**
  ——宁可少归一化，不多归一化。
- **CSS 选择器含空格与 `>`**（`.a > .b`）不进规则 6：规则 6 只作用在可见文本节点上。

## 规则 3 的取值表从哪来（不许手写）

从**判地原型件**里机械抽，逐项：

| 占位 | 取值来源 | 抽取式 |
|---|---|---|
| `#CAT#` | 判地件里所有 `"category":"…"` | `/"category"\s*:\s*"((?:[^"\\]|\\.)*)"/g` |
| `#ACC#` | 判地件里所有 `"account":"…"` | `/"account"\s*:\s*"((?:[^"\\]|\\.)*)"/g` |
| `#SCENE#` | `manifest.json` 里本次参与比较的条目的 `wake` | 清单字段 |

替换顺序：所有值拉平成一张表，**按长度降序**；同长时 `CAT` > `ACC` > `SCENE`。
长串优先保证「餐饮/外卖/午餐」不会被「餐饮」抢先替换。

取值表随 `--domain` 收窄而收窄：只比一个域时，只有该域出现的枚举值进表。
**后果**：实际侧出现一个判地件里从来没出现过的分类名 → **不会被替换 → 报红**。
这是刻意的保守方向——没见过的值就是真差异。

## 已知缺陷：规则 2 的整数部分只吃三位

票面写死的金额正则是 `-?\d{1,3}(,\d{3})*(\.\d+)?`。三位数组不覆盖四位及以上的整数，于是：

| 输入 | 归一化结果 | 说明 |
|---|---|---|
| `35.00` | `#N#` | 一枚占位符 |
| `8000.00` | `#N##N#` | **两枚**占位符（`800` ＋ `0.00` 各占一枚） |
| `1,234.50` | `#N#` | 带千分位逗号时反而正常（一枚） |
| `1200.50` | `#N##N#` | 同 `8000.00` |
| `100%` | `#P#` | |
| `2026-10-02 12:00:00` | `#D#` | |
| `2 笔` | `#N#` | 单位一并吞掉 |
| `9月工资` | `#N#月工资` | 票面的单位表只有「个月」没有「月」，按写死实现 |
| `12:00:00`（无日期） | `#N#:#N#:#N#` | 票面的日期正则要求前面有 `\d{4}-\d{2}-\d{2}` |

**方向是保守的**（多报差异，不会漏报），但同一个数值因有无千分位逗号而产生不同枚数的占位符，
会在真跑产物与原型金额不同时多报一处差异。

## 自护栏

`normalize()` 里有一条断言：**非空原件归一化后不得变成空串**。

这不是摆设——2026-10-03 出过一次真事故：拼接函数读错了字段（`g.s` vs 字符串），
所有页的归一化输出都成了空串，于是**任何改动都「结构同构」**，脚本永远绿。
只跑「原型目录自比」是抓不到这种错的，必须有「不该同构的改动必须红」的探针。
