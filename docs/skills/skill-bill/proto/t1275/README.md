## 补丁清单（9 处，构建脚本逐条打印）

数据侧（改 `<script id="help-data">` 里的场景）：

页面侧（`proto-1275.js`，只在真模板函数跑完之后做 DOM 手术）：

## 原型里「假」的部分（实施时由别票落地）

- `kind:'period'` 是**新控件种类**，模板现在没有它 → 原型的渲染由页面补丁扮演；装控件是 #1269 的活。
- 筛选下拉（方案 A）同理：模板的 `select` 分支没有「输入筛选」这一层，原型由页面补丁扮演；归 #1269。
- 账本／分类／账户的候选**不是假的**：就是生成期注入的真值（#1270 第二刀）。打开页面时不再查库——查库发生在生成 HELP 那一刻。
- 点整行开选择器、筛选下拉、折叠口径：都是新规则提案，属共享模板（`packages/base-render`），要用户点头才动。
