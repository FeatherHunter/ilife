# t903 页面落点与命名（口径件）

本件是**饼干记账非 HELP 命令产物**的落点与命名口径，由票〔【裁定】饼干记账页面产物的落点与命名〕定稿。

谁读它（三个调用方，指名）：

- **实现票**——出口补缺省落点支时，目录、文件名主体、分家写法一律照本件；
- **探针**（交付面常驻判据）——断言落点用；**但探针不自己拼时间戳、也不按名字找文件**：落点以回执给的 `delivery.path` 为准（见 §六.3）；
- **下游消费者**（链路页／验收墙／面板）——不自己算名字，读回执里的 `delivery.path`。

**本件不抄逐键清单**（哪些命令算出来叫什么，不在这里列第二份）。页名的值由代码现算；抄一份清单就是立第二个事实源，改代码不改清单即成陈化。要看清单就现跑，或读 §七 的举例。

## 一、落点与命名通式（逐字）

```
<库目录>/<产物目录>/<文件名主体>_<YYYYMMDD_HHMMSS>[_N].html

<库目录>     ＝ 配置文件 ~/.ilife/bill.yaml 的 db.dir；空串 ＝ 数据目录 ~/.ilife/data/
<产物目录>   ＝ 同文件的 html.dir（默认 biscuit_accountant_html）
<文件名主体> ＝ 饼干记账_<页名>
<页名>       ＝ 本次这一页的唤醒词；写入／账户／目标三域的「一场景两页」再加 _采集页 或 _回执页
```

四处拆开说清：

1. **时间戳**＝`YYYYMMDD_HHMMSS`，**本地时间**；**扩展名**＝`.html`；**同秒递补**＝`_2`／`_3`…
2. 以上三件 ＋ 回执形状（`mode`／`path`／`bytes`，`path` 恒绝对、`bytes` 恒写后回读的实际字节）**全部由共用落盘件 `base-paint/save-html` 的 `saveHtmlFile` 钉死**，本技能不自己拼、不自己补。
3. **不吃复用窗口**：走共用件缺省的独占创建 ＋ 同秒递补。`reuseHours` 只对 `bill.help.lookup` 的两支产物生效，语义不变。
4. **`--html <路径>` 优先**：逐字使用、覆盖写、缺父目录自动建（既有语义不变）。它与缺省落点交付的是**同一份正文**，差别只在落点。

## 二、`<页名>` 怎么算

**页名 ＝ 这一页自己已经在用的那个唤醒词**——不是命令的代表词。

- **按本次参数算**：带 `date` 就落 `查某天`、带 `range:"week"` 就落 `查周`、带 `start`＋`end` 就落 `查区间`。判据是「页面自己怎么自称」：页面的正文标题与复制载荷里用的就是这个唤醒词，取命令代表词会让同一份产物上出现两个名字、而文件名那个是错的。
- **写入／账户／目标三域是「一场景两页」**：过程页（还缺东西、要补齐或要确认的那一页）页名加 `_采集页`；结果页（写库成功那一页）页名加 `_回执页`。**只有这三域带后缀**；查询、分析、开始使用、`bill.link.submit` 都是一场景一页，不带后缀。
- **页型的两个词是代码里的固定词表**，不取页面上的文案：四个域的页面 `<title>` 用词本来就不齐（`采集页`／`补齐槽位`／`改账户确认`／`写库回执`），查询域的 `<title>` 更是根本没有页名。取文案会让「改一次文案」变成「改一次文件名」，同一场景前后落出不同主体的文件。

## 三、命名的一处定义地与接口

**唯一定义地＝一个薄命名模块**（实现票新建，照作息同一位置同名）。它持有三件：

1. **技能名前缀**——引用页面标识件里已有的技能名常量，**不写第二个字面量**；
2. **页型两词**（`采集页`／`回执页`）；
3. **「页名 → 文件名主体」的拼装**。

**接口（谁给什么）**：**出页处交出「本次这一页是谁」**——唤醒词 ＋ 页型（页型只有那一处分支知道：`collect` 还是 `receipt`）。交付层**不复算**：

- 页型往外看只剩二手信号（回执对象在不在），**二手信号不是契约**——任何「写库成功但没有回执对象」的路径都会静默把结果页命名成过程页，而没有任何门会红；
- 唤醒词在域里已经算过一次（渲染进正文标题），交付层再算第二次就是同一件事两处算，走散只是时间问题。

⇒ 命令声明的产物形状增加一格「本页是谁」；域里**不重写**技能名前缀与页型那两处字面量（取命名模块给的）。

## 四、与 HELP 的分家

**同目录分家，靠保留名**：页面与 HELP 都落 `<库目录>/<产物目录>/` 根，HELP 的落点一字不动。

两个**保留名**不得与任何页名相同：`饼干记账_HELP`、`饼干记账_速查表`。

判据（机器可判，见 §六.4）：业务页名集合 ∩ {`HELP`, `速查表`} ＝ ∅。今天成立（业务页名只来自 15 条非 HELP 命令的词条），但这是**当时读数**，所以写成判据而不是写在注释里。

## 五、为什么落点选这里（决策记录）

- **同目录**（不另起子目录、也不把 HELP 挪走）：HELP 是这张图上唯一一条已有真产物的交付面，挪它要重开 HELP 交付那条冻结口径；分家只要名空间互斥就成立，不必动目录。⇒ 配置面零改动。
- **带技能名前缀**：目录里躺着 110 个老文件，其中业务页面的名字与「不带前缀」那一套**完全同名**；前缀是过渡期唯一一眼可辨、且机器可判的新旧标记，同时把「HELP 与页面分家」变成名空间事实。**已知代价**：与另外五家（业务页面不带前缀）及老实物的形状都不同——这是维护者权衡后接受的。
- **每次都落新的**：HELP 类吃复用窗口、其余 HTML 一律新落，这条在本仓已有裁决；页面的价值就在「这一眼」，复用会让「第二次数变了」拿到旧文件。

## 六、判据（可机器判）

1. **缺省即落整页**：非 HELP 命令原样调用（不给 `--html`）就落一份能直接打开的整页。
2. **回执即真相**：stdout 顶层 `delivery{mode,path,bytes}`，`path` 绝对路径、`bytes` 等于磁盘真实字节。
3. **探针只认路径**：落点断言以 `delivery.path` 为准；**不许按名字去找文件**（目录里有同名老文件）。
4. **保留名不相交**：页名集合 ∩ {`HELP`, `速查表`} ＝ ∅。
5. **主体与页面同源**：`delivery.path` 的文件名主体去掉技能名前缀与页型后缀后，等于该页正文标题里的唤醒词。
6. **同一份正文**：给 `--html` 与不给 `--html` 拿到的正文相同，只差落点。
7. **变异自证**：改坏落点通式（例如去掉页名或换掉页型后缀）必红，改回必绿，两行机器读数写进证据件。
8. **不动外观**：快照门与页面指纹门一件不变（本线只改「落哪、叫什么」）。

**验收命令（可原样执行；`<戳>` 是落盘时刻、写不死，由回执消解）**：

```powershell
$tmp = "<临时目录>"; $env:USERPROFILE = $tmp; $env:HOME = $tmp
node -e "const{execFileSync}=require('node:child_process');const{existsSync,statSync}=require('node:fs');const e=JSON.parse(execFileSync(process.execPath,['packages/skill-bill/dist/cli/cmd_read.js','bill.record.today'],{encoding:'utf8'}));const d=e.delivery||{};const n=(d.path||'').split(/[\\/]/).pop();console.log(!!d.path&&existsSync(d.path)&&statSync(d.path).size===d.bytes&&/^饼干记账_查今天_\d{8}_\d{6}(?:_\d+)?\.html$/.test(n)&&d.path.replace(/[\\/][^\\/]+$/,'').endsWith('biscuit_accountant_html')?'真':'假')"
```

**定稿前基线（2026-09-22 真跑，隔离家目录）**：`exit 0`；stdout 只有五字段 envelope、**无 `delivery`**；产物目录 `…\.ilife\data\biscuit_accountant_html\` **根本不存在**（临时树里只有 `bill.yaml` 与 `biscuit_accountant.db`）⇒ 现在跑**假**。

## 八、与老实物的关系

老实物那 110 个文件（`查区间_<戳>.html`／`月度汇总_<戳>.html`／`饼干记账_HELP_<戳>.html` …）**不迁移、不改名、不清理**；新页面只往外增。所以目录里会有同名老文件——这正是 §六.3 要求探针只认回执路径的原因。

老实物自己的规则是「业务页面不带技能名前缀、只有 HELP 带」，本件**有意不沿用**：理由见 §五。
