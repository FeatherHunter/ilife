## 二、26 条原话（逐字，未经任何改写）

```
1.查某天和查账单 两者都是选择日期 是否是重复场景？
2.查某天的详情页的日期选择框不明显，不好看

5. 查某周查某月的详情页需要支持周和月的选择器
6. 查任意时间段的开始和结束日期选择器的入口不好看，右侧一个小箭头应该是明显能看出来是选择日期的
7.查账单详情，这个场景需要优化，一般用户很难知道某个记录的 id。
8. 详情页必填写字段不填写需要有醒目的 ui 动画效果 提醒下
9.查某分类的账的详情页，分类支持在已有分类中选择，并额外支持一个新建分类能力。账户也是支持在已有的选择，也支持新建 账本也是如此。技术是 help html 需要支持这种已有类型的参数，让 ai 构造时提供自己有已有的分类，并且根据 type help html 知道应该提供新建的按钮（可以通过开关设置，不提供新建能力） 这部分需求我们需要对齐
10. 查标签 详情页的标签是预置的，可以多选一。因为目前 help html 有一天复用机制，因此我们只保证一天前的标签都在
11 查账户流水 的 账户提供所选一，时间提供 月度，周度，日期的不同选择器。提供不同区间的选择器，因为可能查某个时间段内的流水
12 查某账本的记录 没太看懂是查什么的，此外时间选择器应该提供 周 月 年 以及提供区间的选择器 可以到某天，也可以是某个区间
13 查未还欠款 需要提供选择
14. 查进行中的分期 看起来 选项很少
15. 关于页面底部的文本 饼干记账 v2.0是 ok 的 但是后面不要写 help 模板 v4 应该写当前饼干 skill 的版本号
16. 设月度预算 月份提供选择器
分类提供所选一和新建
17.查看预算执行，需要提供月度选择器
18.储蓄目标的截止日期提供日期选择器
19.新增账户 的 类型支持多选一
20.修改账户支持选择已有账户，或者独立输入
21.从账户到账户都应该是已有的选择的。也允许自定义输入
22. 从备份恢复的详情页 允许从已有备份中选择。
23. 列映射底部的 hint 提示需要可以滚动 不然看不全，或者有更好的交互方式
24 开始使用这个模块需要增加 场景关于 设置当前配置 json 里面的字段的能力的场景。比如 db 文件所在的电脑路径等
25. 买东西联动 需要分类多选一
26.吃饭联动 需要支持类型多选一
```
