## 七、存疑与未能核实项

1. **票面日期与会话日期系统性错位（约 8 小时）**。例：#1276 的落地报告评论 <https://github.com/FeatherHunter/ilife/issues/1276#issuecomment-6129838404> 正文自称「条目24 返工落地（**2026-10-13**）」并引「你 2026-10-13 的两条裁定」，但其 GitHub `created_at` ＝ `2026-10-12T18:05:44Z`（＋0800 ＝ 2026-10-13 02:05:44）；它引用的落地提交 `a4784b5e` 的 author date 也是 `2026-10-13T02:04:01+08:00`。**同一「2026-10-13」在两处指不同钟点**。本报告一律以 GitHub／git 的机器时刻换算 +0800 为准；票面正文里的日期只作字符串引用，不作时序依据。**这条错位未被任何票面记录承认过，需用户确认口径**（若以票面写死的日期为准，则 #1276 的 ④ 变成「先确认后落地」，判定会翻转）。
