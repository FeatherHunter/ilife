### 第三步 · 写代码（改了什么，一行一因）

1. `rangeAnchor`：显式 `today`（`normalizeDate` 校验，非法即 exit 2）＞ `BILL_TODAY`（`YYYY-MM-DD` 才认，否则机器时钟）＞ 机器时钟 UTC 日。种子日期只活在参数／环境里。
2. `weekWindowFrom／monthWindowFrom`：周一..锚点／月初..锚点（UTC，未来不计）。旧 `weekRange()／monthRange(当月)` 整周／整月（含未来）退出查询侧。
3. `condValue`：`undefined／null`→无此条件；空串／全空格／非串→`POLICY_BAD_INPUT` exit 2。堵住「前者判有、后者判无」的全量穿透。
4. `viewRecordRange`：分类先过 `validateCategory`（单段即 L1 放行；未知 L1 走 `POLICY_BAD_CATEGORY` exit 2——失败路径按票面要求**不断言**，只锁成功三级）；周月支叠加条件时同样先校验；账户／账本支只 `fetchAll` 过滤，KPI 照 `calcKpi`（转账除外），载荷无 `balance`（余额仍走 `bill.account.query`）。
5. 进口行：增 `normalizeDate／validateCategory`，撤 `weekRange／monthRange`（本域不再引用；`policy` 本体不动）。
