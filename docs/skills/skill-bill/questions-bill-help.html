先对齐 4 条原理（你确认即锁死）

  1. P1 快照：HELP 是静态文件，一天复用一次。凡“已有/预置/所选一”都是生成时刻快照，一天内新建的查不到，只能“快照+手动输入兜底”。
  2. P2 校验：真校验在 skill 侧。HELP 的复制/阻断/toast/动画只为少跑一趟，不能替代校验。
  3. P3 类型：查看（只读）不应有新建；采集（写入）才有新建；选择（改存量）才有选已有。查询页加新建都是例外，要单批。
  4. P4 归一：时间/分类/账户/账本/标签本质是归一成固定格式，picker 只是可视化，不能发明新语义。
这 4 条如无异议，后面即按此收敛。如有异议请直接说哪条不对。
