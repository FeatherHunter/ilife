# #1084 笔数口径裁定：查询域页头的笔数与对账行的笔数

**裁定日期**：2026-10-03　**裁定人**：负责人（FeatherHunter）　**执行票**：[#1110](https://github.com/FeatherHunter/ilife/issues/1110)（口径落地）　**来源票**：[#1084](https://github.com/FeatherHunter/ilife/issues/1084)

## 一、裁定

| 项 | 裁定 |
|---|---|
| 口径 | **选项 C**：页头走收支口径（转账不计），对账行走全行集口径（转账计入），**两处各自点名** |
| 范围 | **8 页**：查今天、查昨天、查某天、查周、查月、查分类、查账户、查账本 |
| 注记时机 | **只在窗口含转账时出现**；含转账数为 0 的窗口三处笔数逐字保持现状 |
| 工程配套 | 规则抽成一处共用实现；不变量「对账笔数 − 页头笔数 ＝ 转账数」进回归测试 |

裁定依据是负责人的目标：**批准的原型逐字落地为命令生成的 HTML**——升级后说唤醒词，拿到的就是新 UI。原型样例数据里没有一笔转账，所以"含转账窗口怎么显示"是原型留下的唯一空白；本次只填这处空白，不动原型已规定的任何一笔。

## 二、三个选项的利弊与选择理由

| 选项 | 做法 | 优点 | 缺点 | 结论 |
|---|---|---|---|---|
| A | 页头也读全行集口径（含转账） | 页上只有一种笔数，无需理解两个口径 | 页头会写「共 4 笔」而支出只算 3 笔，笔数与金额对不上；**"收支笔数"这个读数从页面消失**；查账本转账页会写成「2 笔，支出 0.00 元」而明细列 2 行 | 可用但次优 |
| B | 对账行也读收支口径（不含转账） | 页头与对账一致，笔数与金额永远对得上 | **对账段不再覆盖转账行**——转账的钱无人核对，对账失去意义；查账本转账页会出现「对账 0 笔、明细 2 行」的自相矛盾 | **出局（功能缺损）** |
| **C** | 页头标收支口径、对账标全行集口径，各自点名 | 两个读数都保留，差异有名字不是有矛盾；改动只落在文案；无转账窗口与原型逐像素一致 | 同一页仍有两个数，需要读注记 | **采纳** |

**选择理由（第一性原理）**：页头回答「这个窗口我花了几笔」，必须与支出金额同口径；对账行回答「这个窗口每行都对得上吗」，必须覆盖全部行（含转账）。转账是同一笔钱换口袋：**必须进对账（否则钱对不上），必须出收支统计（否则虚增支出）**。两个数回答两个不同问题，统一任何一个都是丢信息。

**注记为什么必须条件出现**：常显会改动含转账数为 0 的页面字面，使 17 张批准原型全部失效——而那正是本次要落地的东西。所以注记的出现条件本身就是判据。

## 三、两处文案的确切写法

转账数 K ＝ 窗口内满足 `isTransfer` 的行数（判地唯一：`src/shared/kpi.ts` 的 `isTransfer`，账本为「转账」或分类以「转账/」开头）；M ＝ 窗口行数；N ＝ 收支笔数（`kpi.count`）。

### 3.1 店头副题（H2）

**K ＝ 0 时逐字不动**；**K > 0 时在笔数后插入「（不含转账）」**：

| 页 | K ＝ 0（现状，逐字不动） | K > 0 |
|---|---|---|
| 查今天 | `今天共 N 笔，支出 X 元` | `今天共 N 笔（不含转账），支出 X 元` |
| 查昨天 | `昨天 N 笔，支出 X 元` | `昨天 N 笔（不含转账），支出 X 元` |
| 查某天 | `共 N 笔，支出 X 元` | `共 N 笔（不含转账），支出 X 元` |
| 查周 | `本周共 N 笔，支出 X 元` | `本周共 N 笔（不含转账），支出 X 元` |
| 查月 | `本月共 N 笔，支出 X 元` | `本月共 N 笔（不含转账），支出 X 元` |
| 查分类 | `{分类}共 N 笔，支出 X 元` | `{分类}共 N 笔（不含转账），支出 X 元` |
| 查账户 | `{账户}共 N 笔，支出 X 元` | `{账户}共 N 笔（不含转账），支出 X 元` |
| 查账本 | `{账本}账本 N 笔，支出 X 元` | `{账本}账本 N 笔（不含转账），支出 X 元` |

### 3.2 对账 CHECK 行

**K ＝ 0 时逐字不动**；**K > 0 时在笔数后插入「（含转账 K）」**。分隔符照各页原样：

- 查今天（半角分隔）：`编号 {ids} / 共 M 笔 / 异常：无` → `编号 {ids} / 共 M 笔（含转账 K） / 异常：无`
- 其余 7 页（全角分隔）：`编号 {ids} ／ 共 M 笔 ／ 异常：无` → `编号 {ids} ／ 共 M 笔（含转账 K） ／ 异常：无`

### 3.3 不改的两处

- **主数字眉标**（`本页支出 · 共 N 笔` 一类）：与 H2 同值、紧随其后，不另加注记。
- **明细表、落点 LEDGER、占比 SCALE、复制区**：一字不动。

### 3.4 实例（查账本选「转账」账本：N ＝ 0、M ＝ 2、K ＝ 2）

- 改前：H2 `转账账本 0 笔，支出 0.00 元`；对账 `共 2 笔`；明细 2 行 → 页头与明细打架。
- 改后：H2 `转账账本 0 笔（不含转账），支出 0.00 元`；对账 `共 2 笔（含转账 2）`；明细 2 行 → 页头说清"为什么 0"，对账说清"2 笔是什么"。

## 四、不变量（进回归测试）

**对账笔数 − 页头笔数 ＝ 转账数**，且：含转账数为 0 的窗口字面**不含**「不含转账」「含转账」两个注记。
