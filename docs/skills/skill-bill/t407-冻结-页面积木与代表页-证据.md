### 5.1 记成遗留的事（base 缺什么，本票不硬塞）

1. **动作条场景按钮没有禁用档**：`ActionBarButton` 只有 `label`／`kind`／`actionId`，没有 `disabled`；置灰那枚「⛔ 先补齐（N 项）」靠「不给 `data-t` ⇒ 点击委派早退」实现真阻断（外观用 `ghost`）。base 若补 `disabled`，本件可换过去。
2. **动作条场景按钮不带复制文本**：`renderActionBar` 的 `buttons` 渲染出的按钮不带 `data-t`（`controls.ts` 的 `sceneButtonHtml`），能带文本的只有复制位那两枚。回执页的退出口因此是两枚并列：危险色出口标记（`red`）＋旁边一枚能复制的撤销指令（`ghost`）。施工图想要的「一枚危险色按钮直接复制撤销指令」要等 base 补这一档。
3. **没有「心法」表**：本仓与 base 都没有分类心法数据，摘要行的分类那格改报「一级＝X（L1/L2/L3 三级）」＋一行口径；心法表由哪一张票补未定。
4. **`名目` 没有库列**：`bills` 表的列是 id／category／amount／time／account／ledger／currency／note，没有名目；落在 L3 或备注里，提示写明。要不要为名目加列／加字段由维护者定。
5. **错误回执只接了一半**：`errorReceipt`（改名后）已冻好并接在缺项阻断条上；施工图第一节末给它列的另三种情形（JSON 异常／缺 id／参数不合法 → 整页替换）今天仍走 stderr ＋ 非 0 退出码（`test/record-write.test.mjs`「id 有值但不是记录编号」那条钉着），整页替换是后票的事。**这条债写在 `errorReceipt.ts` 件头**（不装作做过；本件已是共用位内部件，名字不出本位）。
6. **候选单选件仍未冻**：本票只做了「分类／账户／账本三枚选择器」（走 `renderParamForm` 的 `options`），施工图第三节第 1 行的候选单选（带「为什么是它」徽标）留给记退款那批页。
7. **顺手发现并修掉的一处「有标签没按钮」**（原来那个词按 `docs/agents/wording.md` 改掉了）：`promptCopyArea` 原先只给 `copyText` 不给 `actionId`，而 base 的 `renderPreBlock` 只在给了 `actionId` 时才渲染复制按钮（`blocks.ts:729-736`）——所以两张旧样张上的「复制 prompt」一直是**有标签可点、按钮没渲染出来**。本票补上 `actionId`，重跑页上 `copy-btn` 各 4 枚（prompt ＋ 数据 ＋ 日志 ＋ 退出口那枚）。
