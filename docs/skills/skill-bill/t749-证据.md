## 五、范围外发现（如实记，均**非本票引起**，附读数）

1. **`t689 判据甲：页面指纹账本` 每天必红**（本票跑到的红之一）。
   - 根因：指纹归一化只覆盖「日期＋时刻」（`2026-09-21 12:00:00` → `<TS>`），
     而采集页的**来源行**里有一个**不带时刻的日期**：实测页面原文 `数据来源 记账库（只读） 时间 2026-09-21 共 0 条`。
   - 时间线：账本最后一次重录于 `2026-09-20 00:09:16+08`（提交 `f10c394c`）⇒ 只有本地日期还是 09-20 时才对得上；
     本地 09-21 零点一过就红，而本席第一处编辑在 09-21 08:26 ⇒ **红在改之前**。
   - 旁证：另一席（#763）08:27 跑同一道门，红的是**同样那 5 张**（`.scratch/t763/log-gen-fp.log`）。
   - 冻结时钟读数：把时钟钉在账本重录那天（`FAKE_NOW_ISO=2026-09-20T00:09:16`）⇒ 差异集变成 6 张（多出 `恢复-采集`），
     证明差异集是**时钟的函数**，与落点算式无关。
   - 处置：**不重录**（重录＝把日漂移盖成假绿，明天照样红；本票也没有改版式，不符合重录的声明条件）；
     建议转票修归一化口径（把「今天 ±1 天」的裸日期也换成 `<TS>`）后重录一次。
2. **`t417 查周` 逢周一必红**（本票跑到的另一条红）。
   - 根因：那条用例的种子是「今天 2 笔 ＋ 昨天 1 笔」，窗口＝**周一..今天**；今天是周一 ⇒ 窗口只含今天 ⇒ `total=2 < 3`。
   - 现场读数（`.scratch/t749/probe-t417.mjs`）：`查周：start=2026-09-21 end=2026-09-21 total=2（t417 的断言是 >=3）`、
     `查月：total=3`（同一次现场，月窗照常不红）。与落点算式无关。
   - 建议转票：种子改「今天 2 笔 ＋ 昨天 1 笔 ＋ 本周内再 1 笔」或断言改成按窗口天数算。
3. **`plugin-bill-ilife/test/skills-provider.test.mjs` 陈旧 import**（插件侧那条红，见另一件的证据）：
   `import { WAKE_TABLE } from 'skill-bill/policy'`，而包门（`HEAD` 与当刻都）没有 `./policy` 这一键 ⇒
   `ERR_PACKAGE_PATH_NOT_EXPORTED`。属「公开面收窄」那一批的遗留，建议转票。
