## 怎么用这张清单

1. **一条词一件**：开你那一行那个文件，把它 `collect`／`receipt` 两格从通用装配体换成本场景的装配体
   （`collectBody`／`receiptBody` 是现成的起手样，抄它的块序列改）。
2. **别碰别行**：`src/record/collect.ts`／`receipt.ts`／`scene.ts` 是分派位，本票已定死，三族都用不着改；
   真要加一件（例如「记还款」），在 `scene.ts` 的 `SCENES` 加一行 ＋ 新建那件文件，两处。
3. **共用件在 `src/shared/`**：候选单选 `candidatePick.ts`、逐行可编辑表 `rowEditorTable.ts`、
   diff 表 `diffTable.ts` 已冻好，直接用；缺的块记成遗留，别写在这三件里。
4. **行为照施工图第二节那一行给**（每件文件头已抄一行），别自己加块。

## 落点判定（`sceneFor`，四条）

1. `kind` 非空且认得 → 该 kind 那一件（上表前 12 行）；
2. `op` 是 `undo`／`restore` → 那两件；
3. 命令名是 `bill.record.update` → 改记录那一件；
4. 其余 → 记一笔那一件（无 `kind` 的通用词，也是认不得的 `kind` 的兜底）。

  落点在各自场景件；三族窗口自己排。
