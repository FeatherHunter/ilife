## 一、全局页面积木（每张页都有的，只定一次）

| 块 | 作用 | 用哪个 base 组件 | 导入路径 |
|---|---|---|---|
| 页壳与页头 | 眉标／标题／副题／正文四件套，一页只一次 | `renderPageShell`（`pages` 的 `printable` 留给回执页） | `base-paint/blocks` |
| 类型徽章 | 报「这一页是哪条唤醒词、哪一型」，金额符号即方向（支出负数、收入正数）写在这里 | `renderStatusBadge`（`ok`／`warn`／`danger`／`empty` 四档） | `base-paint` |
| 结论摘要行 | 金额、方向、三级分类＋心法、账户、账本一眼看完 | `renderKpiCard` ＋ `renderKpiGrid`；一行口径另用 `renderCaliberLine` | `base-paint/blocks` |
| 字段卡（采集输入） | 静态标签＋输入框／选择器；分类三级＋心法、账户、账本、时间、备注 | `renderParamForm`（每字段必给 `name`、`label`、`required`） | `base-paint/blocks` |
| 只读明细段 | 回执页的账单本体（ID／金额／分类／账户／账本／时间／备注） | `renderDetailSection`（少行数用 `renderListRows`） | `base-paint/blocks` |
| 数据表 | 只读回显：diff 表、分摊预览表；零行时自动改走空态 | `renderDataTable` | `base-paint/blocks` |
| 复制指令块 | 把字段拼成一段交回 AI 的整段命令，逐字可见可复制 | `renderPreBlock`（`copyText` 带该段文本） | `base-paint/blocks` |
| 动作区（三颗按钮） | 复制 prompt／复制数据／复制日志；缺数据时不空转 | `renderCopyBlock` ＋ `buildDataText`／`buildLogText` ＋ `bindCopyAction` | `base-paint/blocks`、`base-paint` |
| 对账信息折叠区 | 折叠收「对照账本／重复检测依据／分摊与标签说明」 | `renderDisclosure`（原生 `details／summary`，不写脚本） | `base-paint/blocks` |
| 空态 | 候选为空、无记录可改、无三要素时给一句下一步 | `renderEmptyBlock`（本体 `renderEmptyState`） | `base-paint/blocks`、`base-paint` |
| 错误回执 | JSON／状态异常、缺 id、参数不合法时的顶层回执，替换整页正文 | `renderFeedbackBlock`（含 `renderErrorReceipt`；提示条走 `renderToast`） | `base-paint/blocks` |
| 样式与整页装配 | 样式资产只此一份；16 张页共用，页内不写 CSS | `blocksCss` ＋ `buildStyleSheet` ＋ `fillTemplate` | `base-paint/blocks`、`base-paint` |
