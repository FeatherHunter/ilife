## 四、与票面清单的两处偏差（都已落进上表，具名登记）

1. **新增了两件票面没点名的文件**：`test/helpers/freeze-clock.cjs`（`node --require` 预载件——钉钟必须住在
   能被 `--require` 载入的 `.cjs` 里，`.mjs` 用不了）与 `docs/skills/skill-bill/t726-验收.mjs`（可复跑脚本，
   票面「交付物路径」已写「可复跑脚本随证据入仓」，只是没点名字）。两件都在 `test/**`／证据目录内，
   不碰任何别席路径。
2. **写库开关的处置比交接注释更进一步：`assertWritablePath` 整个删掉，不是「只留非 tmp 一律拒」**。
   依据＝#675 的解决评论逐字：「那五个开关原本的作用是『往非临时目录写库必须先被显式打开』……
   删掉之后默认从『不安全就不写』变成**照写**，所以替代护栏是：① 测试一律用 `ILIFE_CONFIG_DIR`
   指向临时目录……② 测试基座里强制设置它，缺了直接报错」。若按「非 tmp 一律拒」保留并挂在写路径上，
   用户配好的数据目录（`~/.ilife/data` 之类，本来就不是 tmp）会被自己的守卫挡死——那是把配置机制打回
   不可用。四家 #695 的处置同向（`docs/skills/skill-chef/t695-证据.md` 等逐字记「删掉 `assertWritablePath`
   与 `*_FORCE_PROD`」）；#718 保留的那一份只服务运维／迁移 CLI（「真实 DB 零触碰」），记账没有那类 CLI。
