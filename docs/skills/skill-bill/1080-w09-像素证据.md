## 4. 每处非零差异的解释

### 4.1 主因：累计纵向漂移（全页）

用「每行墨迹数」当一维信号，逐 20 行窗找最优整数位移（`.scratch/1080-setup-w09/probe.mjs drift`）：

| 窗口 y | 最佳位移 d | 读法 |
|---|---|---|
| 0–20 | 0 | 桌与纸边对齐 |
| 20–1400 | **+2（恒定，只在个别窗跳 ±1）** | 店头之后整段下移 2px，**之后不再累计** |
| 页高合计 | **+4px**（1621 vs 1617） | 复制区那一段还有 2px |

（本席那一版 dist 的旧读数：0–20 为 0，20–120 为 **+2**，200–220 涨到 **+4**，220–240 涨到 **+7**，
240–1400 恒定 **+7／+8**，页高 **+14px**。Lead 修掉 §4.2 第 3／8 两条之后，累计漂移整段消失。）

**+2px 的来源已定位**：`packages/skill-bill/src/shared/docPage.ts:166` 的
`.ilife-sheet-head { text-align: center; padding: 2px 0 0; }`——原型 `.shop-head` **没有内距**。
这一条把整页顶下去 2px；后面 5px 出在主数字块与它的小字上。

漂移本身就是最大的一处差异：**全页文字因此逐行落在不同的像素行上**，抗锯齿全变。
把漂移按窗扣掉再比（逐 120 行窗对齐，`probe.mjs shiftdiff`）：
本席那一版 **0.1234 → 0.0756**；**当刻盘上 0.0834 → 0.0408**。
