## 二、老 Python 的页面装配骨架

### 装配函数与调用链

写入域只有一个 HTML 渲染入口：`scripts/render_write.py`。它由 5 个装配函数组成，全部返回 `{"status","data","message"}` 三件套：

- `build_payload`（`scripts/render_write.py:149`）—— `expense` / `income` / `photo` / `reimburse` 四种采集页。
- `build_batch_payload`（`scripts/render_write.py:232`）—— 批量录入确认页。
- `build_flow_payload`（`scripts/render_write.py:290`）—— `refund` / `reimburse_done` / `collect` / `payback` / `lend` / `borrow` 六种复合确认页。
- `build_installment_payload`（`scripts/render_write.py:466`）—— 记分期确认页。
- `build_update_payload`（`scripts/render_write.py:514`）—— 改记录 diff 确认页。

统一调用链：

```
main (scripts/render_write.py:577)
  └─ records = _load_history()            (scripts/render_write.py:613)
  └─ 分支派发                              (scripts/render_write.py:616/633/645/662/671/697)
       └─ build_*_payload(...)             (scripts/render_write.py:149/232/290/466/514)
            └─ envelope(...)               (_base_render.py:83)
       └─ _write_html(payload, template_path, out_name, args.out)  (render_write.py:714)
            └─ template_path.read_text(encoding="utf-8")           (render_write.py:719)
            └─ inject_base(template, payload)                      (render_write.py:720 → _base_render.py:37)
            └─ write_html(html, out)                               (render_write.py:722 → _base_render.py:72)
```

### 模板渲染方式

**不是模板引擎，是「读模板文本 + 贴共享资源 + 挂信封数据」三段式**：

1. 模板路径是模块级常量，写死在文件头（`scripts/render_write.py:41-45`），5 份模板对应 6 个分支（`render_write.py:627/639/655/665/681/707`）。
2. `inject_base` 把公共层资源按占位替换进模板文本：`assets/base.js`、`assets/base.css`（`_base_render.py:49-50`）、图表辅助（`_base_render.py:64`）。
3. 领域数据不直接写进 HTML，而是由 `envelope` 挂到 `data.scene` 与 `data.copy_log`（`_base_render.py:103-114`），页面里的 JS 自己读。所以字段名、行文本全是 Python 侧拼好的字符串（如 `render_write.py:200-220` 拼 `summary`/`sections`）。
4. 落盘用 `utf-8-sig`，即 ADR-0002 要求的 BOM（`_base_render.py:73-75`）。

### `prompt_template`／复制文本从哪来

- 场景级 prompt 正文住在 `scenes/write.yaml` 的 `prompt: |` 块里（如 `scenes/write.yaml:24-32` 记支出、`scenes/write.yaml:236-241` 撤销），格式规则写在文件头注释 `scenes/write.yaml:4-8`（head 一行 + 字段区，head 固定为「请加载「饼干记账」技能,帮我<场景人话>(唤醒词:<唤醒词>):」）。
- 页面上的「复制数据」文本由 `envelope` 现场拼：`总结`＝调用方传的 `summary` 列表，`分节`＝`sections` 列表，一起塞进 `data.scene.snapshot`（`_base_render.py:103-107`）；`data.copy_log` 另存 `thinking` / `data_structure` / `call_chain`（`_base_render.py:108-114`）。写入域每次都显式传 `data_structure="biscuit_accountant.db bills 表（待用户确认后 INSERT/UPDATE）"`（`render_write.py:223/272/351/415/506/569`）。
- AI 侧复述口径由 `SKILL.md:730` 规定：写入类确认页只能由渲染脚本产出，禁止 AI 手写 HTML；拍账单另有一条硬约束 `SKILL.md:244`。

### 回执数据从哪个函数取

采集页本身不写库。用户确认后交回 AI，AI 调 `scripts/write/cli.py`，**写库与回执文本都在这个文件里**：

- 新增：`cmd_add`（`scripts/write/cli.py:28`）→ `validate_record`（`scripts/write/cli.py:32`）→ `add_bill`（`scripts/write/cli.py:44`）→ 文本回执 `print(f"✓ 已记录：…")`（`scripts/write/cli.py:53`）。
- 修改：`cmd_update`（`scripts/write/cli.py:57`）→ `validate_amount/category/time`（`scripts/write/cli.py:75-80`）→ `update_bill`（`scripts/write/cli.py:95`）→ 文本回执（`scripts/write/cli.py:97`）。
- 撤消／恢复：不经渲染脚本（`scenes/write.yaml:235,249` 的 `html.template` 写死字符串「文字回执」）。

### 两条路各自经过哪几个函数

**过程型（采集）**：`main`(`render_write.py:577`) → `_load_history`(`:613`) → `build_payload`(`:149`)／`build_batch_payload`(`:232`)／`build_flow_payload`(`:290`)／`build_installment_payload`(`:466`)／`build_update_payload`(`:514`) → `envelope`(`_base_render.py:83`) → `_write_html`(`render_write.py:714`) → `read_text`(`:719`) → `inject_base`(`:720`) → `write_html`(`:722`) → 落到 `html_paths.html_path(command_name)`（`render_write.py:285-287`）。这条路只产出**采集页**，不落库（`render_write.py:223` 明写「待用户确认后 INSERT」）。落库与文字回执在用户确认之后走 `write/cli.py:cmd_add`(`:28`)/`cmd_update`(`:57`)。

**结果型（回执）**：老侧写入域**没有**独立的回执页装配函数。撤消／恢复直接 `write/cli.py:cmd_undo`(`:103`) → `get_by_id`(`:106`) → `undo_bill`(`:110`) → `print`(`:112`)；`cmd_restore`(`:118`) → `get_by_id`(`:121`) → `restore_bill`(`:128`) → `print`(`:130`)。采集路径下的「结果」也只是 `write/cli.py:53/97` 的两行 `print`，没有模板、没有 `envelope`。**判据（本件与兄弟件同用）**：页面在报告一件**已经发生**的事（已落库的结果、可撤销出口）＝结果型回执页；页面在收集或确认一件**尚未发生**的事、只输出一段交回 AI 的命令文本＝过程型页（字段只读回显也叫过程型，**只读回显不等于结果型**）。**边界（写入域内部 vs 跨域）**：写入域**内部**确实没有独立的回执页装配函数——`scripts/render_write.py` 全文只有 5 个装配函数（`:149`／`:232`／`:290`／`:466`／`:514`），产的都是采集页与确认页；但**跨域看**并非如此：老侧成形的「结果型回执页」不只在查询域与分析域（`references/路由表.md:22-61` 输出形式一律 HTML），**联动域另有一份**——装配入口 `scripts/link/cli.py:263 build_receipt_payload` ＋ 页面 `templates/联动/receipt.html`，同一份页服务买东西与吃饭两个场景（`references/路由表.md:70-71` 给这两条的输出形式写的是「HTML 表单+回执」；`scripts/link/cli.py:452-457` 按 `scene` 取 `purchase`／`meal` 两值）。写入域全程输出形式写的是「文字回执」（`references/路由表.md:7-21`）。
