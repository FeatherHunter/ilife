## 三、怎么判 ＋ 怎么汇（一条命令，不用手工转抄）

**判**：逐格左右对照（左＝判地原型、右＝真跑产物），看**版式与件套**（块序、块位、行数、字级、按钮与复制区形态）。
- 格内 **满意** ＝ ok；**不满意** 会弹**必填原因**的框，填完 ＝ 不ok ＋ 原因原文；**没点的格 ＝ 未判**（本器不推断、不默认 ok）。
- 三面墙两侧**数据不同**（口径①）：query／write／analysis 的横幅逐字写着「两侧数据不同」——判版式与件套、**不比数值**。

**汇**（三步，替掉原来那 87 格手工转抄）：

```
① 墙右上角「导出清单JSON」→ 存成 docs/skills/skill-bill/verdicts/<墙名>.json
② node docs/skills/skill-bill/1081-verdict汇入.mjs          # 一条命令：写六份逐格结论的判定列 ＋ 94 行总账的 verdict 列
③ node docs/skills/skill-bill/1081-95check.mjs docs/skills/skill-bill/1081-95页-ok总账.md   # 看三行读数
```

- 怎么导出、JSON 什么形状、不 ok 的格怎么点去处（`verdicts/if-not-ok.json`）：见 `docs/skills/skill-bill/verdicts/README.md`。
- **#1078 那 24 格不用再导**：`1078-24页-verdict.json` 已是机读件，本器直接读它（每格的**人原话来源**登记在本器常量 `HUMAN` 里；没登记的域**报红**，不许转抄）。
- 不 ok 缺原因或缺点去处 ⇒ 本器**报红并点名**（票面红线）；没来源的格一律保持 `未判`。
- **溯源表**：`node docs/skills/skill-bill/1081-verdict汇入.mjs --source` ⇒ 写出 `docs/skills/skill-bill/1081-verdict溯源.md`（逐行：seq｜verdict｜来源件:行｜用户原话片段；没来源的写「未判（无来源）」）。**签字时看的就是这一份**——它是「这 94 行到底是谁判的」的唯一凭据。
- **结论列也是可追溯的一句**：总账里 ok／不ok 的行，结论列写「来源＝件:行 用户原话…（日期，判于当刻产物）」；未判的行写「未判（无来源）；待填：结论件」。
