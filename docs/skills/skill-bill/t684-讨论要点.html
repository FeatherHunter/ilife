结论正本：#684 正文的「决定」与「判据（改写后）」两节；规格单＝#721。本页三条待确认已于同日定下（判据改写留存／不另开搬运票、规格即工作单／越线口径先实测），细节见正文「进度：100%」节。
终态一句话：搬运完成后只剩三种书写位——8 份能力声明（词条＋场景＋域元数据）／8 份 commands.ts（命令事实）／1 份薄合并件；一条唤醒词在 src/ 下的手写位置恰好 1 个，且写不出第 2 个；内容由摘要锁守，老仓只读对照，生成器链只管命令注册表。

三条公理 全部结论都由它们推出来

公理 1一件事只有一个书写位；能算出来的，不许写。
公理 2派生件是缓存——算得贵、或消费者要另一种表示，才配存在；否则它是同一件事的第二份真相。
公理 3判据必须对「病」发红：计数不是判据，结构上写不出来才是。

实体模型 它决定了下面全部答案

域（label / icon / order）
 ├─ 词条（phrase / key / preset / needs / carries）
 │    └─ 场景 ×0..n（id / title / status / prompt_template / types）
 ├─ 二级组（id / label）→ 场景
 └─ 命令（key / shape / title / example / run）   ← 与场景是两种事实，不合

决定 D1–D10

D1域声明只装消费者要读的字段⟲ 改判

装：词条 phrase/key/preset/needs/carries；场景 id/title/status/prompt_template/types；域元数据 id/label/icon/order；二级组 id/label。

老侧事实（result、html.template、command_cn、data_source、老位置 id）一律不进 src：差异表的左列是老行为，它已冻结（老技能退休为只读对照），不需要机器可读位也不会陈化；放进 src 只会造出一个没有任何消费者计算的字段。

D2路由并进域声明

WAKE_TABLE 与 routeWakeword 由各域声明合并得出；policy/wakewords.ts 作为跨域词表的形态消失。

依据：一个词的两条属性（路由到哪／卡片长什么样）同住一处。调用方零改——同名转出。

D3声明的实体形状

场景的 wake_word 是投影、不写；命令的 title 与场景的 title 是两种事实、各自保留（实测：老 71 条里已声明命令的 4 条，卡名与命令名 4/4 不同名）。

D4判据 1 改成结构性判据，不计数

一条唤醒词的字面量只准出现在它所属那份域声明里，其他 src/** 手写件出现即红。

理由：计数判据要人解释边界——照字面 grep 是 15～71 处，全是页面文案与别的词 prompt 里的子串；结构性判据无法被解释出去。

D5代表词与场景词都不声明，派生⟲ 改判

commands.ts 的 wakeWord 与 SCENES[i].wakeWord 都撤掉：前者按 key 算，后者按 preset.kind／op 算。SCENES[i].kind/op 保留——那是「这件文件认哪些值」的处理方声明，与 preset 的一致性用一条断言钉住。

副产品：某条命令若一条词都算不出来，派生 fail-closed 即报「用户到不了它」。代价：要动 commandSpec.ts 的必填字段与 gen-cli.mjs 的字段门——按 #682 台账 A5-5／A5-4，这是本包内的事，不等 #686。

D6HELP 资产改为运行期合并，删掉 962 行生成物⟲ 改判

src/triggers/wake-assets.ts 保留路径与导出，内容变成一只手写的薄合并件；scripts/gen-wake-assets.mjs 随搬运器退役。

理由：这个派生物的产出只是「几个数组按序拼起来」——算得不贵、消费者也不要另一种表示；它唯一剩下的功能是「证明自己没被手改」，而文件不存在就没东西可手改。

后果：① 「手改派生件必红」在这条线上无对象，鉴别力转由内容摘要锁承担；② 本包超 350 告警线的件从两件减到一件。

D7域序与元数据

域声明自带 order（合并件按它排，缺号／重号 fail-closed）——不用中央名单、不用目录扫描（扫描出的是字母序，与实物域序 71 个位置全不同）。label／icon／二级组随域声明住。

4 条 HELP 短语住 help 位自己一份同形声明（无场景）⇒ 终态是 8 份声明（7 域 ＋ help），不是 7 份；防自指的规则只写一处。

D8搬运与对账

· 「逐字节一致」按值层逐字段逐字判，不按字节流（老 HTML 那段 JSON 带自己的缩进与转义）。

· 老 payload 不进仓：摘要锁已把值集钉死，原件永远在老仓只读对照。

· 搬运器＝一次性取证工具，落 docs/skills/skill-bill/ 归档（可跑、不在管线），不落 packages/skill-bill/scripts/——防「重搬覆盖已改好的手写声明」。

· 搬运完成后，判据 4 从「待达成」变成「回归护栏」（今天已绿）。

D9越线风险与排序⟲ 改判 ×2

越线：analysis 域 25 场景可能越 350。先实测；若越线，首选承认「数据件不适用逻辑件的行数线」并写进包规，次选才是按二级组拆件——按二级组切一个域的目录，是优化代理指标、牺牲真目标。

排序：搬运排在 #689／#690 之前——搬运唯一的证据是「与老权威 0 差异」，任何并行内容改动都会污染这条读数；那两票此刻未开工。
