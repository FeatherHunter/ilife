## 3 设计方案：这一页该长成什么样

一句话：**把这张页从「结果报表」改回「采集页」。** 现在的版面在首屏把八张卡片（5＋3，其中 4 张的值是占位符）和一排重复的胶囊摆出来 —— 那是回执页的语法，用在采集页上就只剩空卡。改成「**首屏只有要填的两个格 ＋ 一句方向提示**，其余全部降级」。

### 3.3 重排（改块序）

**目标版式**（`template-flow.ts:289–309` 的 `content` 数组重排）：

```
① 页头：记账｜写入域 · 记借入 · 「两个格，填完就能记」（不再重复「还差 3 项」）
② 一行「借入 = 钱进来」方向条 —— 把 caliber 句（#借入 向对象借 #未还）从正文句提成一个形状化的流程条，
   三段各自成胶囊：`#借入` → `#向（对象）借` → `#未还`，箭头承担分隔（**替代**现在那串 #标签散在行文里）
③ 【主区】两个必填格（向谁借 / 借入金额）置顶，可见的框 + 44px 触摸区
④ 【次区】其余槽位（分类固定 / 时间 / 账户 / 账本 / 备注 / 期限）折进「还有别的要改吗」折叠区，
   默认收起 —— 值已经在库里给了默认的不该抢首屏
⑤ 同人未还 0 笔 ＋ 提示：压成一行灰底 note（现在它是一个 880px 宽的大块）
⑥ 缺项：只留一处（表变成两列 `缺哪一项 | 为什么`，第 3 行加行标记），并把它与「照抄那条」并成**一个**折
⑦ 动作：主按钮一颗（蓝实心「补齐了，说一遍试试」）＋ 次按钮一颗（`复制数据`）；
   `复制日志` 降为页脚一行 12px 文字链 —— 它现在与「复制数据」等宽等价（缺陷⑨）
```

**为什么这样比现在好看**：
- 首屏从「八张卡＋一排重复胶囊＋四段散文」变成「两个格 ＋ 一条方向条」，用户不必滚 3.3 屏就看见该干什么（对应**用户第 5 条**：把 `；`／`·`／散标签简化掉的 UI，现在被真正的形状补回来）。
- 信息一条不少：所有值仍在页上，只是按「要不要你管」分了层（对应**用户第 4 条**：层次本身就是去冗余）。
- 桌面端不再有孤卡，手机端不再有 5 张 113px 高的空卡连成 565px（对应**用户第 1、2 条**与**第 3 条**的审美）。
- 方向条让「借入」与「借出」在版面上第一次真的长得不一样 —— 现在这两页除了几个字几乎无法区分（借入图 2760px／借出图 2720px，唯一结构性差别是那一行该删的悬空胶囊）。
