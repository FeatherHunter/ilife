## 3 设计方案：这一页该长成什么样

**现在这页的病，一句话**：同一份事实被说了四遍（读数卡第一组／读数卡第二组／表单／复制载荷），四遍用了四种记法，而真正要填的那 9 个格子是**看不见的**。手机整页 2720px ＝ 3.2 屏，第一屏 844px 只装下了页头、3 个胶囊和 5 张读数卡（其中 3 张写着「未给」），第一个能打字的格在 1.57 屏处。

**改成三层**：一句状态 → 一张汇总 → 一张看得见的表。整页从 3.2 屏收到 ~2 屏。

### ① 页头：把「分隔符」换成「版式层级」（改公共层 `blocksCss()` 两条）

- 删掉 `.ilife-block-page-shell-eyebrow > span + span` 的 `border-left`（产物 1138-1142），也删掉 `.ilife-block-caliber > span + span` 的 `border-left`（产物 1212-1215）。眉标改成两级字重：`记账` 12px/600/`--fg3`，`写入域` 12px/600/`--blue2`，中间只留 8px 空隙——**分隔由版式出，不由竖线出**（用户第 5 条）。
- 页脚三个事实从「一条灰线上三段并列」改成**三个小格**（`数据来源｜记账库（只读）`／`时间范围｜不限`／`条数｜0`），每格一行小标签（11px/`--fg3`）+ 一行值（13px/`--fg`）。理由：`时间不限` 和 `共 0 条` 是两种不同口径的数据，用间距分不开，用竖线分又是债，给它们各自的标签位才是设计。
- 副题「还差 3 项，缺的在下面标出来了」里的「下面」在手机上要滚 1.57 屏。改成一条**进度尺 + 计数**：`3 项必填没给` 后面跟一条 8 段的细进度条（已定 5 段实蓝、缺的 3 段空心），一屏之内就把「差多少、差在哪」说完（改 `pageParts.ts` 的副题产出一处）。

### ② 读数卡：只留「值」，不留「说明」；必填缺项与可留空缺项**必须不同形**（改 `template-flow.ts` 的块序列）

- 第一组 5 张卡（金额／分类／账户／账本／时间）合成**一张「这一笔长这样」的汇总卡**：左列字段名、右列值、每行 32px，5 行 ≈ 160px。替掉现在 390 档那 532px（D2／D3 也一并消失：一张卡不需要栅格列数）。
- 值的字重就是状态：
  - 已定（`分类 借贷 › 借出`、`账本 借贷`）→ 15px 常规 `--fg`，前面一个实心圆点；
  - 有缺省、可以留空（`账户 默认账户`、`时间 今天 12:00`）→ 直接显示**缺省值**，不再写 `未给`（这一条治 D5）；
  - 真缺、卡住写库（`金额`、`借给谁`）→ 15px/600 `--fg`，前面一个空心方框 + 右侧一个 `必填` 小标。
  一眼就能读出「差 3 项」到底差哪三项，不用滚到底下开折叠区。
- 第二组里的 `借出金额` 与第一组的 `金额` 是同一个字段 → **删掉一张**；`同人未还 0 笔` 是查询结果不是字段 → 从读数卡挪到提示块里当一句话（治 D8 的一半：同一个事实不再两个块各说一遍），或者干脆只留 `0 笔` 这一个数，口径句只出现在提示块。
- 读数卡的说明句（`不填就记到默认账本` 之类）**从卡片里删掉**：它们与表单格里的说明是同一份字节（D6），只在表单格出现一次即可。卡片区因此从「96px×5 的三行卡」变成「32px×5 的清单行」。

### ③ 表单：让格子看得见（改公共层 `blocksCss()` 的 `.ilife-block-param-form-input` 一条）

- `background: var(--bg)` → `background: var(--card)`（白），并加 `border: 1px solid var(--line)`；焦点态保留现在的白底＋蓝框＋蓝光。**一行改动，全族所有表单页同时从「隐形格」变成「看得见要填的表」**（D1）。这是这一页最值钱的一条：一个采集页的画面上必须先看得见「这里能打字」。
- 390 档两列：短字段并排（`借给谁`／`金额`，`期限`／`账户`，`分类`／`账本`，`币种`／`时间`），长字段（`备注`）通栏；1280 档保持现有两列，但把最后一行补满（`备注` 通栏），不要再出现「左列有格、右列空着」的那道口子。
- 段头：`<span class="ilife-status-badge …">第 1 段　借给谁：未给对象</span>` 换成**有数字位的分组头**：`①` 序号字形（`--fg3`，24px）+ 段名（15px/600 `--fg`）+ 右侧状态小字（12px），三者各占一个位置，`：` 与 U+3000 全部退场（D14）。三段之间的层级就出来了。
- 表单格里的说明句降到 12px/`--fg3` 并**移到标签右侧同一行**（不占一格高度），格与格之间就能收成一屏。

### ④ 复制载荷：13 行墙 → 四段可照做的清单（改公共层 `pre-block` 的底色与边框）

- `.ilife-block-pre-block-code` 现在没有 border、底色 `--soft` 与 `--bg` 只差 ΔB=8。两条改法二选一：①`background: var(--card)` ＋ `border:1px solid var(--line)`；②沿用 `--soft` 但加一条 3px 的 `--blue` 左边框——仓内 `.ilife-block-conclusion`（产物 1216-1219）已经是这个手法，**照着已有先例改，不新造样式**。总之要让它有个看得见的边界（D10）。
- 载荷**文字一个字不改**（硬约束 4），改的是**分行形状**：把 13 行分成四小节，每节一个 12px 小节标 —— `缺口`（三行缺项）／`唤醒词`／`参数`（借给谁、期限、借出金额、分类、账户、账本）／`标签`（备注与流转两行），小节之间留 8px。同样 13 行，读起来从「一堵墙」变成「四段照着念的清单」（用户第 5 条：串在一行的东西要给形状）。
- 折叠区里那份缺项表（3 列 × 3 行，其中第 1、2 列是同义词：`分类｜分类｜这一项没给`、`金额｜金额｜这一项没给`）——第 1 列与第 2 列合并成一列，改成「缺项 / 为什么写不进去」两列，或者干脆用三行卡片替掉表格。同一轮里顺手治掉。

### ⑤ 动作区：主次分清（改 `copyArea` 形状件一处 + `pageUi` 一条按钮宽度）

- `复制给助手：这一句可以直接复制` → 标签只留 `复制给助手`，并**从 ghost 提到 primary**（这页唯一要做的事情就是它）；`复制数据`／`复制日志` 降到次级，1280 档不再各占 436px，改成靠右的一排 120px 小按钮（`pageUi` 里已有 44px 触摸区规则，宽度不受影响）。
- 390 档两个工具按钮并排各 175px 是合理的，保留。

**为什么这样比现在好看**（对应用户六条）：
- 第 3 条（审美）：现在最丑的三处——看不见的输入框、桌面末行孤卡、三段同形段头——都落在这一层被治掉；
