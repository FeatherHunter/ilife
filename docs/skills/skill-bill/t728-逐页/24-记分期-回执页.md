## 2 缺陷清单

### 缺陷 1｜明细表把表头当行标，每行都印一遍，且那一遍是全场对比度最低的一段字

- **在哪**：`#sec-detail`「写进去的项与值」那张表，390 档每一行的**每一格左边**。产物字节：`data-label="哪一项"` 出现 8 次、`data-label="记成什么"` 出现 8 次（`t410-页-记分期-回执页.html:2213` 那条被折叠的正文里可 grep）。
- **证据**：
  - 390 档表体 8 行的行高逐个实测 `56,57,57,57,57,57,57,57`（共 491px 高）；每格是「12px 灰标签 ＋ 值」，`td::before` 的 `content: attr(data-label)` 把列头抄进每一格。
  - 那一遍标签取 `var(--fg3)` = `rgb(134,134,139)`；实测对比度：压在条纹行底色 `#f5f5f7` 上 **3.33:1**、压在卡片白底上 **3.62:1**，都低于 WCAG AA 对正文的 4.5:1。同一格里真正的值对比度是 **15.46:1** —— 也就是说「没用的那半句」比「有用的那半句」清楚得多地占了版面。
  - 对照：1280 档同一格 `::before` 走的是 `pageUi` 的 640 档那条（`--fg3`，12px），而**桌面档**的列头 `<th>` 走 `blocks.ts` 的 `--fg3`。 实测 390／1280 两档的字体与色值见下表：

  | | 390 档 | 1280 档 |
  |---|---|---|
  | `td::before` 字号 | 12px | 12px |
  | `td::before` 颜色 | `rgb(134,134,139)`（`--fg3`） | `rgb(110,110,115)`（`--fg2`） |
  | 对比度（底：条纹 `#f5f5f7`） | **3.33:1** | 4.66:1 |

  390 档那一遍是本页**唯一一处**低于 4.5:1 的常规文字。
- **严重度**：高
- **归属**：全族共用（公共层）—— 规则住 `packages/base-render/src/pageUi.ts` 的 ⑥ 段（`td::before { color: var(--fg3); font-size: 12px }`）+ `packages/base-render/src/blocks.ts` 的 `block-data-table` 640 档（`td::before { color: var(--fg3) }`）。共用底 §5 已把「逐行重复表头」记为已查实缺陷，本席补的是**它的第二半**：那一遍不只是多余，它还是页面上最浅、最不合规的一段字。

## 3 设计方案：这一页该长成什么样

### 3.1 一条主轴：把「八连片」打散成「三组一件事」

现在八张同形卡竖排，读者要自己从中挑。改法是**按事实性质分组，组内紧凑、组间留白**：

| 组 | 收哪些 | 形状 |
|---|---|---|
| ① 这一笔 | 金额、分类、账户、账本、时间 | **一行主卡**（金额放大到 28px + 分类／账本／时间走「标签: 值」的双列紧凑行，不用卡） |
| ② 这次写入 | 状态、记了几笔 | 两枚窄胶囊并排（24px 高），不占卡位 |
| ③ 本型的参数 | 分期参数 | 只在**有值**时出；缺值并进 ④ 的提示条 |

- **改哪一个件的哪一条**：
  - `packages/skill-bill/src/write/template-installment.ts:288-298` 的块序列：把 `renderKpiGrid([...summaryCards, receiptStatusCard, rows, periods])` 拆成「① 的网格 ＋ ② 的两枚 `.ilife-block-chip` ＋ ③ 的条件块」。
  - `packages/base-render/src/blocks.ts` 的 `.ilife-block-kpi-card-grid` 加一条 **`grid-auto-rows: auto`（或删掉 `1fr`）**：只让同一行内的卡等高，不再把整格八张统一拉高。
- **为什么比现在好看**：省掉约 570px 竖向空白（缺陷 2 的账），且图 8 张同形卡造成的"看不出哪个重要"被金额一张主卡直接解决。对应用户六条的第 3 条（UI 设计师审美）与第 4 条（不冗余）。

### 3.2 明细表：窄屏从「每行抄表头」换成「两列小表 + 不抄表头」

- **改哪一个件的哪一条**：`packages/base-render/src/pageUi.ts` 的 ⑥ 段，`td::before` 那一组（第 148-155 行）：
  - 现在是 `content: attr(data-label)` **每格都印**。改成只在**每行的第一格**印（`tr > td:first-child::before`），或者干脆不印——列头已经在 `<caption>` 之后的 `<thead>` 里、且窄屏可以保留一行 `thead` 当行内的组标。
  - 同时把 `color: var(--fg3)` 抬到 `var(--fg2)`（390 档 3.33:1 → 4.66:1，过 AA）。
