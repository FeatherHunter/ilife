## 3 设计方案：这一页该长成什么样

**总纲一句话**：这一页现在回答的是「系统做了哪些动作」，它应该回答「你刚记下了什么」。做法是把 8 张状态卡压成 **1 张记录凭证**、把危险出口从「整页最大色块」降回次级、把「同一件事说三遍」的各处各留一处。

### 改法 A｜块序重排（改 `template-expense.ts` 的 `blocks[]`，240–282 行）

现在：`[读数卡×8] → [口径行] → [重复提示] → [明细表] → [对账折叠] → [退出口] → [复制区] → [来源脚注]`。
改成：`[记录凭证] → [重复提示] → [明细表] → [来源脚注] → [退出口＋复制区]`。

- 重复提示是这一页**唯一需要用户做判断**的东西，现在压在第 1.42 屏（y1196），提到第 1 屏内；「数据来源／时间／共 N 条」与明细表是同一组（这一笔的事实与它的出处），现在被扔在末屏（y2410）。
- 为什么好看：读者第一屏就拿到「记了什么＋要核一眼什么」，不用先滚过一屏系统自述。对应用户第 3、5 条。

### 改法 B｜8 张卡 → 1 张记录凭证（改 `summaryRow.ts:78-93` 与 `template-expense.ts:253-257`）

- 切三带：**主带**＝金额 `+8000.00` 放到 34px（凭证的主角，方向字「收入」做单位件，用既有 `.kpi-card-unit`）；**事实带**＝分类／账户／账本／时间 四格两列（标签 `--fg2` 12px 在上、值 `--fg` 13px 在下）；**元信息带**＝`已保存`／`1 笔`／`7 项` 三枚胶囊（`renderChipRow`），不再各占一张 93px 的卡。
- 只改**分组与取值**：`summaryCards()` 拆成 `primaryCard()` 与 `factStrip()`，渲染仍走公共层已有的 `renderKpiGrid` / `renderListRows` / `renderChipRow` —— **公共层零改动、零新 CSS**。
