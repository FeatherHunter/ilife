范围：`t407-代表-记支出-采集页/回执页.html` ＋ `t407-页-<唤醒词>-采集页/回执页.html`（15 条唤醒词：记收入、记报销、拍账单、批量录入、记退款、报销到账、记借出、记借入、记收回、记偿还、记分期、记一笔、改记录、撤销、恢复），共 32 页。只新建本件；未改任何已有件，未碰 `packages/`，未做 git 写。判据：只判「这句话读起来对不对」；「该用 UI 设计代替分隔符」那一半归另一条路。

## 一、抽取口径与覆盖

- **做法**：只抽可见文本，不整读 HTML。脚本 `.scratch/t407-extract.mjs`（最小 node，无依赖），产物落 `.scratch/t407-text/`：32 份 `.txt` ＋ `_索引.tsv`。审查读的是这 32 份 `.txt`。
- **剥法**：① 删 `<!--注释-->`、`<style>`／`<script>` 整块（JS 里的 `OK_MSG` 一类常量不算文案）；② 块级标签边界记成换行，行内标签（span／strong／code…）不换行，免得切断句子；③ 剥掉全部标签本身——属性随标签一起消失，`data-t`、`data-fmt`、`data-key`、`class` 都不进正文；④ 解 HTML 实体，逐行去空。
- **`data-t` 复制载荷不算可见文案**（它是「复制 prompt」按钮的载荷副本，与同页可见段落重复）。正文那一份照样抽到——所以「复制 prompt」里的话也在审查范围内。
- 用户可见的属性文本单列一节：`placeholder` 与输入框 `value`（按钮的 `value` 不算）。
- **覆盖：32／32 页页页抽到，无缺席。** 正文可见文本合计 **31092 字**；最少 465 字（改记录-回执页），最多 1630 字（拍账单-采集页）。逐页行数／字数／属性条数见 `.scratch/t407-text/_索引.tsv`。
- 边界：本件不出浏览器渲染截图，故「标题＋标签是否真的挨在一起」这类按 DOM 先后判（见第四节）。

## 三、已知疑似项（逐条判）

1. **徽章 `记支出 · 支出（金额取负数） · bill.record.add · 待补槽位 · 未写库（已阻断）`** → **该改**。徽章是给用户看的，「`bill.record.add`」「待补槽位」「未写库（已阻断）」三处都是内部话，用户读了不知道要做什么。**命令名不该出现在用户可见处**（本仓读者是记账人，不是开发者）。最小改法：徽章只留 `记支出 · 还差 1 项分类`，命令名只留在「复制 prompt」那段指令里。
2. **改记录采集页顶部 `三形态之一：缺记录编号 · 先挑一条`** → **该改**。「三形态」是内部说法，用户不知道另外两种是什么、为什么自己是「之一」。最小改法：`改记录 · 先挑一条记录`。
3. **退款／到账／借出／借入／收回／偿还／分期 采集页金额格 `0.00` ＋ 说明 `零（本仓不记零）`** → **该改**。读不通：格子里摆着 `0.00`，说明却说「零（本仓不记零）」——先说这是零、再说本仓不收零，自相矛盾；「本仓」又是内部词。最小改法：值改 `未给`，说明改 `还没给`。
4. **批量录入采集页底部按钮 `补齐后重跑同一条命令`** → **该改**。这不是给用户看的话：页面上从没指明「哪一条命令」，用户无从「重跑」；而且同页这句话已重复 6 次。最小改法：按钮改 `补齐了再说一遍「批量录入」`（要把命令名给 AI 看，就放「复制 prompt」）。

## 四、没能确认的事

- 本件只读抽取出来的文字，**没有在浏览器里逐页真渲染**。第三节第 3 组（标题＋同名标签连读）是按 DOM 先后判的；视觉上是否真挨着、有没有换行隔开，要真渲染或另一条路的截图才能钉死。
- 徽章里是否**有意**保留命令名（比如这一页也打算给开发者看）——我只按「普通记账人」这一个读者判；若要给双读者，改法要换。
- 采集页字段卡「时间」显示裸日期 `2026-09-14` 而同格说明写 `12:00:00`：到底是显示截断还是缺省口径没想好，从文字判不出来，只能标为可疑。
- 回执页字段卡的 `缺省＝…` 是**有意**示范缺省口径，还是从采集页整段搬过来忘了改——动机无法从文字判断。
- 「退款」被列进收入侧一级名目（记收入采集页正文）是否口径正确，我没有账目分类表的权威来源，只能标为可疑。
- 代表-记支出 回执页页头 `记一笔 · 回执` 与徽章 `记支出` 不一致，是笔误还是有意分工，需要负责人裁。
- `data-t` 复制载荷里带 `【bill · record.add】` 命令名，按本件口径不算可见文案；但「复制日志」贴进对话框就会露出来，这算不算「上屏」，请负责人裁。
