#993 · 摘要形状

摘要形状 = 两页共用同一张“答案卡”

一句话：回执和详情的首屏长一个样，差异只在尾巴。

拿 7222 举例，摘要长这样

已改为建设银行储蓄卡 (0709)，-40.80

-40.80 支出

餐饮 / 咖啡奶茶 · 生活 · 2026-10-01 15:30:00 · 编号 7222

回执尾巴这次改了：账户 → 建设银行储蓄卡 (0709)。
详情尾巴全部字段：币种人民币 · 备注分行（套餐 / 加购 / 实付加粗 / 自提）· 创建时间 · 删除时间 —。
  • 标题即结论，不再是“改记录”这种动词。
  • 金额全页唯一大字，账户分类只用正文字号。
  • 副题只留编号与时间，徽章口径收到页脚。

为什么是这个形状

  • 现在回执 8 卡、详情 2 卡加长表印两遍，用户要学两套排版。
  • 改成同一摘要，用户只学一次：摘要 + 尾巴。
  • 回执尾巴只讲“改了什么”1 行；详情尾巴讲“全部字段”且只印一遍。
  • 撤销不在菜单里藏，在摘要下独立一颗按钮常显。
