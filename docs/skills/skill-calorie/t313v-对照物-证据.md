## 1. 结论

- **自洽**：`--dump` 生成快照后**立刻再跑一次比对**，16 个面**全部** `DEEP-EQUAL=yes`、`SUMMARY … diffFaces=0 diffs=0 surfaceMissing=0 surfaceExtra=0`、exit 0（同一份代码自己对自己）；`--dump` 那次打出的 `snapshotSha256` 与随后比对载入时报的 `sha256` **逐字相同**。
- **反向探针六连全动**（副本全在 `.scratch/t313v/`，冻结件 sha256 探针前后**逐字节未变**）：
  - 门③（面深比对）：改**字段值**／**字段名**／**删记录** 三类**自洽伪造件**（改完**重算自哈希**）→ 全 `DEEP-EQUAL=no`、**exit 1**；
  - 门①（快照自哈希）：**只改值不重算**自哈希 → `SNAPSHOT-TAMPERED FAIL`、**exit 3**；
  - 门②（导出面清点）：桩模块**少** `routesFor` → `SURFACE-MISSING routesFor`、**exit 1**；桩模块**多**一个导出 → `SURFACE-EXTRA …` 警告 ＋ `DEEP-EQUAL=yes`、**exit 0**（不判红）。
- 冻结件与 dist 指纹（写快照那一刻）：`dist/triggers/routing.js` sha256 `cf9b15a42f832cd67227f7e2d7da1479a0caf7a33898c1c13df5ecb836d3edbc`；快照 sha256 `d4da337219ea98f61ee6d3a42c10898fbedd017004806c90a8b2281eb6eb02da`。
