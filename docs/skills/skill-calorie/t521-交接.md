## 二、出页与验收怎么跑（复制即用）

```powershell
# 出页（落盘自己的文件，不需要持锁）
node docs\skills\skill-calorie\t268-链路总览.build.mjs

# 验收队列（每条各自持锁、各自留 RUN ticket=521 runId=… 存根）
node .scratch\t521\闸门.mjs *> .scratch\t521\gates2.log
```

`闸门.mjs` 九步：改前页三档溢出（期望 exit 1）→ 改后页三档溢出（期望 0）→ 改前页分隔符（期望 1）→ 改后页分隔符（期望 0）→ 自检（期望 0）→ 变异改坏一处 → 判据抓真中点（期望 1）→ 判据抓实体中点（期望 1）→ 还原再跑（期望 0）。末尾打 `闸门汇总 steps=9 mismatch=0`。

**队列里没有出页这一步**（编排者口径：落盘自己的文件不占锁），所以跑验收不会改页面 mtime，视觉席的当刻截图不会作废。

## 五、已知的坑（前任踩过的）

- **PowerShell 5.1 写中文文件会变花码**：写中文一律用 `write` / `edit` 工具，不要 `Get-Content` / `Set-Content` 往返。视觉席第一版就卡在这里。
- **长命令必须重定向到日志再只读尾几行**，别让 `run-locked` 的中文告警把控制台刷满（它会把 `WAIT-OWNER-ALIVE` 写进 stderr，`*>` 一起收）。
- **`job_kill` 杀不掉 node 子进程**：杀完要用 `Get-CimInstance Win32_Process ... CommandLine -match` 查一遍，把 `闸门.mjs` 与它下面的 `run-locked` 一起 `Stop-Process`，否则它会一直在后台等锁、抢到后把页面重写一遍。
