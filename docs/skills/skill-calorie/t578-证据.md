## 二、六项债逐条改法（一句话一条，冻结面一个字没动）

1. **副标题复述／过长**：`headlineOf`（取摘要、按 `：` 切、单条再切括号）→ `subtitleFor`：
无改动／复制完成／批量记运动／已更新运动／已删除运动／已记运动。
记录号／日期／条数／区间／括号后果句由操作头／计数卡／来源卡／删除方式卡各说一遍。
旧 13 页副标题 `已删除 2026-09-12~2026-09-12 运动 5 条（软删除……）`（59 字）→ `已删除运动`。
2. **同一批记录重复陈述**：来源卡 `记录数 共 N 条` 整格撤——它恒等于计数卡那个数
（两边同源 `rows/pairs.length`），同一批条数两卡各说一遍；条数只由计数卡说，
窗口只由来源卡说。当日累计 `运动条数 N 条` → `N 条（当天）`，与计数卡裸 `N 条` 逐字区分。
3. **页面自相矛盾**：`影响行数 N 行` 与计数卡 `N 条` 同数两名——两处题被三件既有关票判据钉死，
数与题都不动，口径行增一句 `影响行数的「行」与计数卡的「条」是同一件事：
本次写库实际改动的行数`。单日窗口 `A → A` 收成 `A`（同日不展区间，也是一种自矛盾）。
4. **无信息量空值行**：`cellText` 空 `—` → `（空）`（改前旧空值）；`numText` 空 `未设置` →
`（空）`；明细表另走 `detailCell`／`detailNum` 空白格（备注没有就不占位）；
复制 `目标日期` 空即整行不出。操作头 `记录号 未设置` 与对账表 `记录编号／未设置`
是共用件冻结面（本票禁区），机读 surgical 剔除，见 §六遗留。
5. **区间写法 `~` 对 `→`**：区间拼法收口到 `sportUi.rangeText()`（同日一日，跨日 `A → B`，
`~` 不上屏）；副标题不再含区间（`edit.ts` 摘要里的 `~` 只进机器面复制载荷，不上屏，
`edit.ts` 不在本票写集，一字未动）。
6. **明细卡层级**：明细表 `caption: '逐条明细'` 撤——折叠标题是这一卡唯一的题，
列头即表的题；删多条的删除方式由副标题括号搬进计数卡（一页只一位说话人）。

冻结面复核（三件既有关票 47 用例全绿，见 §三）：变更行类名、`本次明细`／`改前 → 改后`／
`删除前快照`／`逐条明细` 各题、`新增条数`／`批量计数`／`目标日期`／`命中条数`／`删除条数`、
`口径：影响行数` 首行、`sui-facts` 来源键值、`只算` 措辞、字段胶囊、`无改动`、
导航 ≥3 锚点、四态头、复制区三格式——以上断言的每一字都在产物里（t578 判据④ 另钉一遍）。
