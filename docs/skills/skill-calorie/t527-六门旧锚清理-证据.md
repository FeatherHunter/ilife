## 三、顺带查出的三条**真缺陷**（产品侧，均已修）

1. **GIF 页「文件大小 0 KB」**：`gifDoc.ts` 用 `Math.round(bytes/1024)`，几百字节的 GIF 被舍成 0 KB——
   读数在说假话。改 `(bytes/1024).toFixed(1)`（与小尺寸下的既有口径一致）。
2. **GIF 明细表「备注」列上屏原始标记**：单元格先转义再上屏，而 `noteSegments()` 产的是标记串 ⇒
   用户看到字面 `<span class="phu-seg">早起</span>`。改走纯文本（分段形状归回执页那种 div 槽）。
3. **候选卡逐张抄文件名**：`pickerDoc.ts` 的卡片又长出了 `.phu-file` 行，与 #474 已裁定的
   「候选行不抄文件名」相反（文件名归快照键值行；看不见图时由占位原因行点名）。撤掉该行。
