# t276 营养表 → `calorie.diet.add` 映射说明（命令侧）

> 识别在模型侧（本仓 `vision|mmx|ocr` 命中 0，无识别实现）；本票只做命令侧：营养表读数落到现成写命令的参数上。确认页本身归预检确认页票（#277），不在本票。
> 对地图目标的帮助：拍营养表 2 条不用新增命令，照这张表填参即有命令可跑。

## 映射表（营养表字段 → `calorie.diet.add` 参数）

| 营养表读数 | `calorie.diet.add` 参数 | 说明 |
|---|---|---|
| 食品名 | `foodName`（必填） | 照抄识别出的食品名 |
| 能量（千卡） | `calories`（必填） | 取“每份”值 |
| 蛋白质（克） | `protein`（必填） | 取“每份”值 |
| 碳水化合物（克） | `carbs`（选填，缺省 0） | 取“每份”值 |
| 脂肪（克） | `fat`（选填，缺省 0） | 取“每份”值 |
| 份量（克） | `grams`（选填，缺省 100） | 包装标“每份 xx 克”即填 xx |
| 识别备注 | `note`（选填） | 建议带“营养表识别”以便 `hasNote` 筛选 |
| 补记日期 | `date`（拍营养表补记一餐必填，`YYYY-MM-DD`） | 与 `补记饮食` 同一形状 |
| 补记时间 | `time`（选填，`HH:MM:SS`） | 与 `补记饮食` 同一形状 |
| 餐别 | `meal`／`mealOverride`（选填，须为早餐／午餐／下午茶／晚餐／夜宵之一） | 不填由时间自动推断 |

钠／糖／纤维等标签字段暂无 `food_log` 列承接（`listMeals` 取数列以 `fetch/diet.ts:289` 为准），不硬塞参数；需要进食品库的走 `calorie.product.import`。

## 路由落点

- 拍营养表记一餐 → `calorie.diet.add`（`src/diet/routes.ts` `order:13`）
- 拍营养表补记一餐 → `calorie.diet.add`＋`date`／`time`（`order:14`）
