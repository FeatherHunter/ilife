## 一 · 判据口径（全票共用，先冻住）

**只观察这六样**（其余一律不作证据）：**读法**：读本票只需 §一 ＋ §三.N（N 为你那张票的序号）＋ §四。

1. 真出口的退出码；
2. 落盘文件首行 `<!doctype html>`、含 `charset`、含内联样式且长度 ≥ 2KB、无外链（无 `http://`／`https://`／` src=` 指向仓外）；
3. **剥掉标签后的可见文本**（去 `script`／`style`／注释）里出现的字串与数值（数值须有限）；
4. 回执给出的绝对路径存在且可读；
5. 门的红绿读数；
6. 命令自治探针 `UNACCOUNTED` 计数。

**写法要求**：每条判据写成「跑哪条命令 → 看哪个读数 → 等于什么」；每条判据配**负向对照**（改坏一处必红、还原必绿，两行机器读数）。
**禁用**：把活派给用户（用户只做肉眼验收，不进任何判据）；负向判据（如「目录里只有 HTML」）；「文件里出现某串字符」当内容正确的证据。
**行数口径**：一律节点口径 `readFileSync(f,'utf8').split('\n').length - 1`（同一份文件用 `Get-Content` 数会差几个数）。
**期望值来源**：只认三种——① 手算式；② **变更前 git 快照**；③ 需求原文。**不许**拿新实现自己的输出当期望值。
