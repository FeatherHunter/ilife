## §1 裁决：分母统一到「有记录的天」

- 裁决：热量趋势页与多指标趋势页的达标／均值分母统一到**有记录的天**（与 `ea7cdc9` 新口径一致）。
- 理由：① 同一指标两页各说一套，读者无法对账（90 天窗 11/90＝12% vs 11/11＝100%）；
  ② 空白日不按 0 算已是两页图例共识（`connectNulls` 跨空连线），分母含空白日等于一页两套口径；
  ③ 取数层已有现成件（`seriesCount`／`seriesAvg` null 跳过），多指标页的日均热量／运动早已走该口径，
  达标率是最后一处旧口径。——故不保持两套，无需票面级保留理由。
- 逐页分母台账（改后）：热量趋势日均／工作日均／周末均／首末值＝有记录的天（副文案点名）；
  长趋势日均热量＝记了吃多少的天（副文案早写对、数值改对）、数据天数＝记了吃多少的天（值 9＋副文案同口径）；
  多指标日均热量／运动（本就点名，不动）、达标比例＝有记录的天（值＋副文案＋注释同步）。
