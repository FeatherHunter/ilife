## 三、三条过程纪律（本轮踩出来的，照办）

1. **给子席的清单必须是生成物，不许手打。**
   实测：派单书里手打文件名 → 盘上不存在 → 乖的席标「不确定」、不乖的席去翻目录把上下文烧光。**改成「给生成好的清单文件路径」之后，一席读完 11 个文件、零越界。**

2. **改动尽快按 pathspec 提交自己的路径。**
   仓里多席并发，有一条护栏提交会 `checkpoint(<票号>-seatN)` **把工作树里所有改动一次扫走进库**（#496 席的源码面就这么被卷走的，事后要靠一条补交把漏下的新增件追回来，否则干净检出编译不过）。**别把改动长时间留在工作树里。**

3. **改超线件必须同步告警线台账。**
   `node packages/skill-calorie/scripts/check-warning-line.mjs`；红了跑 `--sync`（先 `--dry` 演练）。**`--sync` 是全表口径**（把「当场实测」列刷成当刻实况），保持原样，别改成只刷自己两行。这是设计行为，不是误报。
   本波会碰到的超线件（当场实测）：`src/render/trendMiscPortDocs.ts` 676、`src/diet/nutritionPortDocs.ts` 492、`src/render/trendDocs.ts` 1019、`src/render/html.ts` 648。

## 四、判据模板（每票照这个形状交）

1. **本类页面逐条真跑**：贴命令、`exit` 码、产物绝对路径、字节数；空库 `exit 4` ＋ `ERR 4: 取数失败（缺失阻断）` 是**设计行为**，不算失败。
2. **十一条裁定逐条**：每条给「对上了／没对上＋读数」。**没对上的不许写成对上**；写清为什么、归哪张票。
3. **不新增红**：跑本包测试；若有红，**必须做归因自证**——把本票改动退回旧写法再跑同一批，红的条数与名字逐条对得上，证明与你无关（照 #509／#511 的做法，两席都留了 `ATTRIBUTION PASS` 式的读数）。
4. **变异自证**：至少一处改坏必红，证明断言真在守。
5. **告警线台账**：同步后贴 `RESULT: n/n PASS`。

## 六、环境事实（本轮实测，直接采信）

- **唯一出口**：`packages/skill-calorie/dist/cli/cmd_read.js`（读与写都走它）。改完先 `npx tsc -b packages/skill-calorie` 再跑，否则测的是旧编译产物。
- 产物落 `<SKILLS_DB_PATH>/calorie_html/<中文名>_<YYYYMMDD_HHMMSS>.html`，**stdout 只给回执**。
- **场景 02 有 15 条写词会改库**：一条条跑会互相破坏数据。**每条跑前把库还原成同一份播种快照**——现成脚本已入库：`docs/skills/skill-calorie/t155-证据/复算-全量真跑.mjs`（播种按**真实当天**算、逐条还原、83 条真跑）。复用它，别重写。
- **抽可见文本**与**逐页残留探针**同目录：`复算-抽可见文本.mjs`、`复算-逐页残留探针v3.mjs`（87 条全量判定 ＋ 五类盲区夹具）。
- 并发席共享闸门锁：`node tooling/run-locked.mjs --ticket <你的票号> --max-wait-ms 900000 -- <命令>`。**等到超时 `exit 1` 不是失败**，加大重来。
- **Windows mtime 陷阱**：`copyFileSync` 还原会把旧 mtime 带回来 → `tsc -b` 跳过重编译 → 假红／假绿。还原后要 `utimesSync(now)`。
