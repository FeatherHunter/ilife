## 三、方法论

老模板是「数据注入型静态页」：HTML 骨架 ＋ `payload` JSON ＋ 页面内 JS 填充，所以「有哪些位置可以填」＝ 骨架里的 id 与载荷字段名（本文第一节已逐张列出）。老脚本的参数面（第二节）是当年每条唤醒词真正走的路径，出参即模板的载荷。
