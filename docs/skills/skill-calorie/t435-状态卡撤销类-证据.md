## 二、第 1 条 · 「状态」卡副行随命令键派生（真实缺陷）

**缺陷**：`calorie.workout.plan-delete` 回执页同一页对同一动作一边说「已写入训练计划」（状态卡副行，恒定兜底），
一边说「已撤销训练计划「…」／已删除（硬，不可恢复）」（副标题与改动对照结果列）。

**修法**（`src/workout/receipt.ts`）：兜底文案按命令键派生，具名键表只放撤销类一条，其余 9 条走原兜底常量。

```ts
const WRITTEN_DETAIL_FALLBACK = '已写入训练计划';
const WRITTEN_DETAIL_BY_KEY: ReadonlyMap<string, string> = new Map([
  ['calorie.workout.plan-delete', '已删除训练计划'],
]);
function writtenDetailOf(key: string): string {
  return WRITTEN_DETAIL_BY_KEY.get(key) ?? WRITTEN_DETAIL_FALLBACK;
}
// 调用点：statusCard(receipt, '已写入训练计划')  →  statusCard(receipt, writtenDetailOf(key))
```
