## 1. 判据与读数形状

| 项 | 内容 |
| --- | --- |
| 窗口 | 取窗口前 `src` 逐件 sha256 → 直调编译 → 窗口后重算 `src` 与 `dist` 逐件 sha256 |
| 红 | 窗口内 `src` 有漂移 ⇒ `RESULT: FAIL 窗口内 src 变动 <相对路径>(改字节\|新增\|删除)`，exit 1 |
| 绿 | 无漂移 ＋ 编译 exit 0 ＋ 产物非空 ⇒ `RESULT: src-n=… dist-n=… src-sha=… dist-sha=… 一致（dist 与 src 指纹一致）`，exit 0 |
| 其余红 | 编译未过（`tsc-exit≠0`）／产物为空（`dist-n=0`）／探针件还原不一致 ⇒ 一律 exit 1 |
| 组合指纹 | 逐件 `路径\0sha256` 行拼接后再取 sha256；**路径含作用域前缀** ⇒ 不同作用域写法／不同脚本版本的读数**不可直接比** |
| 对账钩子 | 末行 `GATE-RUN runId=<外层锁窗口运行标识> cmd=<本脚本命令>`；标识抄自 `<lock-dir>/owner.json`，与 `gate-runs.log` 的 `RUN` 行同标识 |

## 6. 安静窗口：谁在什么时候跑这类读数

**适用对象**：一切**以 `dist` 为前提**的读数 —— 编译门、变异电池的两态、真出口跑 CLI 的产物字节。

1. **谁**：该票**执行席自己**在**自证**时跑（不是审查席代跑）；审查席若要独立复跑，同样按本节。
2. **什么时候**：**合并点安静态**。具体＝该票的改动**已经落进版本库**、且当刻**没有别的席位在改本包的 `src`** 时开窗。开窗前先看两处：`git status --short -- packages/<包>/src` 是否只剩自己的件；`.scratch/locks/owner.json` 的属主是不是自己。
3. **怎么跑**：`node tooling/run-locked.mjs --ticket <票号> -- node docs/agents/t540-指纹绑定.mjs --scope packages/<包>`。包装器给锁与留痕，脚本在窗内直调编译并按 §1 出两行读数。
4. **红了怎么办**：`RESULT: FAIL 窗口内 src 变动 …` ⇒ **不要**重跑碰运气。按点名件的路径找到写者（`git status` ＋ 锁日志的 `RUN` 行），等它做完再开一次窗；本次读数一律作废。
5. **窗口不安静的退路**：把结论**写成有条件**的 —— 引用**同一行**读数（`src-sha` ＋ `dist-sha` ＋ 结论）作证，并写明「本读数的有效期止于 `src-sha` 改变之前」；`src-sha` 一变，之前所有以该 `dist` 为前提的读数全部作废（同 §2.3 第 2 条：没有一对一留痕的运行不计入对账）。
6. **不许**拿「多加一次 `--force` 重编」当解法：它只把窗口收窄，不解决读到混合态。
