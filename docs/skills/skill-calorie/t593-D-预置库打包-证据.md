## 二、files 改法

```diff
   "files": [
     "dist",
     "SKILL.md",
     "workflows/*.md",
-    "templates/*.html"
+    "templates/*.html",
+    "src/xunji/data/训记官方动作.json"
   ],
```

注记偏离（向总工明报）：票面要求“files 行加注释”，但 `package.json` 是严格 JSON，
加 `//` 注释会使 `JSON.parse` 直接抛错——门脚本自身（`tooling/check-publish.mjs:67/119`
用 `JSON.parse` 读各包 `package.json`）与 `npm pack` 会当场红，与验收第 3 条互斥。
故保验收：`package.json` 本体只加 files 行，注记原文
“源码态资源随包发（同 templates 机制；.npmignore 无覆盖已查——根与包下均无 .npmignore）”
改落在门脚本注释（§三）＋本证据件＋提交信息里。`package.json` 改后 `JSON.parse` 自检通过。

`.npmignore` 核查：全仓搜 `.npmignore` 只命中 `node_modules` 内第三方包自带件，
仓根与 `packages/skill-calorie/` 下均无——无覆盖，`files` 即发件清单唯一口径。
