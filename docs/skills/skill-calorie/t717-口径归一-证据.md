## 五 · 变异自证（改坏必红 → 改回必绿）

| 步 | 动作 | 读数 |
| --- | --- | --- |
| 改坏 | `src/shared/meal.ts` 的 `午餐: [10, 14]` → `[10, 15]`（＝旧诊断那一套边界） | 编译 0；本门 `tests 3 / pass 1 / fail 2`（红） |
| 改回 | 逐文件取回原内容并编译 | **首次回绿失败**：`fail 2` |
| 归因 | `tsc -b` 判「内容没变」未重出 `dist/shared/meal.js`（实测产物里仍是 `午餐: [10, 15]`），随后回绿失败是**假红** | `dist` 读数：改回编译后仍为 `午餐: [10, 15]` |
| 回绿 | `tsc -b packages/skill-calorie --force` 重编 ＋ 复跑 | 本门 `tests 3 / pass 3 / fail 0`（绿） |

**这一条要传下去**：变异／回滚的「回绿」必须在**强制重编**下取证——本包 `dist` 是共享可变产物，
`tsc -b` 的增量判定会把「内容改回原样」判成无需重出，于是回绿读的是变异版的产物。
（同源判据见 `docs/subagent-concurrency-protocol.md` §5「回滚必须连生成物与生成记录一起复位」。）
