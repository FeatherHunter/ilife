**X1【反假绿缺口·非本票引入】`Copy-Item` 保 mtime 可让 `pnpm gen:check` 在 `dist` 陈旧时报 PASS**

## 附三：本席自身的一次脚本事故（如实记账）

`mut2.ps1` 里我用自定义函数 `H` 算 sha256 —— **`H` 是 PowerShell 内置别名 `h`（`Get-History`）**，而**别名优先于函数**，于是它静默返回空：12 件文件的「SAME」全是 `$null -eq $null` 的**假绿**，且哈希列印成空。终端留痕坐实了这一点——`Get-History` 拿文件路径当自己的 `-Id` 参数去绑：
```
Get-History: 无法绑定参数 'Id'。无法将值
"D:\ilife\.scratch\t323r\mut2\packages\skill-schedule\SKILL.md" 转换为类型 "System.Int64"。
```
这是编排者当轮点名通报的同一个陷阱，我原以为 `Get-Alias -Name Section,Note,Snap` 查过就安全了——**没查单字母名**。
处理：立刻重做 `mut3.ps1`，函数改名 `Get-Sha256Of`，并在脚本开头加两条**自证**（`ALIAS-SELFCHECK h=SHADOWED-BY-Get-History`、`HASHFUNC-SELFCHECK sha_len=64`）＋每步落盘原始输出＋退出码。§一.2 第 3 条与 §一.5(c) 用的是**修正后**的 `mut3` 结果（`BEFORE-DIFF-COUNT=0`、`AFTER-DIFF-COUNT=0`、哈希非空）。事故结论：`mut2` 那批「SAME」**作废**，不得引用。
