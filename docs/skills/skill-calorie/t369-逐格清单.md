## 三、疑点（点名，不代裁）

1. **8／9 两格逐字节相同**（同 sha `ea2fd6ad07d25393…`）：`看围度` 缺省窗口＝90 天（`src/body/view.ts:41`），`看围度趋势` 显式传 `{"days":90}` ⇒ 两页一模一样。该不该合成一条词、还是给趋势那条换窗口语义，归产品侧裁。
2. **两条「看」的窗口口径不对称**：`看体脂` 缺省＝**全部历史**（`src/body/view.ts:15-23`），`看围度` 缺省＝**90 天**（同件 `:41`）。两条词面长得像，口径却不同——墙上第 6／8 格一对比就能看出来。
3. **过程型页在写之前打开时**，「最近」栏写「无记录／暂无体脂记录」——那是**写前**的当刻状态，不是缺陷。
4. **删类页**明写「软删除：行保留、已从查询与统计中排除；暂无恢复入口」——与库里 `is_deprecated=1` 一致（回读 1 行软删对得上）。
