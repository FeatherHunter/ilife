## 2. 要证伪的四条（每条都要机器读数）

### 2.1 「两处删减是无损的」
实施兵会声称：备注方括号**内**逗号**之前**那截与同行 sets 逐字一致、方括号内的 `W<n>` 恒等于该行周次。**你自己从生产库 `D:\2Study\StudyNotes\.db\calorie_data.db` 取全量复算**（编排者量过 264/264，你要独立复现这两个数），并**逐字证明**产物里丢掉的那部分确实只在 sets／周次里能还原出来。

### 2.2 「副行小字按规则拼」
- 部位细化词＝备注方括号**前**那截；类型中文化 `main→主要`、`iso→孤立`；两段用 ` · ` 连
- 无方括号的备注 → 整条作细化词；备注空或 `—` → 副行**只留**类型
- 实测：`main`／`iso` **裸词不出现在正文**（注意：`data-t` 载荷里可能仍有，**载荷不算正文**，口径要写明）

### 2.3 「节奏只在该在的地方」
- 日级会话标题尾部有 ` · 节奏 …`；**周级标题**（`第 N 周 · M 场`）**不许有**
- **休息日不许有**（它没有动作表，取不到节奏）
- 同场内节奏恒定（编排者量过 96/96）——若实施兵改成「逐行印节奏」，那是退回旧毛病，判缺陷

### 2.4 「零表判绿的后门堵上了」
上一轮审查抓到：`expectTable:'other'` 在**页内零表**时也判绿。本轮实施兵声称已堵。
**你要证伪它**：抽掉某份**应带表**的页里的整张表 → 对应判据**必须变红**；还原 → 必须变绿。两行读数。
另：`order178`（本就无表）抽表后**不该**变红（否则是把「无表」误判成「缺表」）。两面都要给。
