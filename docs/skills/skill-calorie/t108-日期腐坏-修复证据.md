**为什么三条都不是「验相对今天算窗口」**：这三件的种子是**绝对日**，且同文件里另有 20+ 条用例按**字面日期**断言，例如

是**降低/改写断言强度**（明令禁止）。它们验的是固定窗口下的页面/命令行为 ⇒ 一律走「钉时钟到种子锚点」。

**为什么钉 `Date`，不钉 #250 的 `CALORIE_TODAY`（实测否决的先手版本）**：
先按 `process.env['CALORIE_TODAY'] = '2026-09-07'` 做了一版（#250 注释即写「测试用它把窗口对到种子库的数据日」，同仓先例 `delivery-83.test.mjs:36`）。
模拟当刻 +365 天时**仍红 3 处**：`#109 链`（词 `看体脂`）、`#109 体成分`、`#109 围度`，读数 `无体成分记录（近90天）`／`无围度记录`。
根因：`todayISO()` 认 `CALORIE_TODAY`，但 **`src/fetch/body.ts:111 daysAgo()` 直接读 `new Date()`**（体成分／围度缺省 90 天走它），环境变量够不着。
⇒ 改为钉 `Date`（#326 `freeze-clock.cjs` 的同一套手法：只替换 `Date` 一个内建的无参构造与 `now()`），把进程内所有「当刻」读数一次盖住；
钉锚时刻取当日 `12:00:00Z`（UTC 日与 -12..+11 本地日同一日，避免时区把锚点挪一天）。切到 `Date` 钉法后 +365 由 33/36 复为 36/36。

**为什么不直接复用 #326 的 `freeze-clock.cjs`**：那是 `node --require` **预载**，钉的是 **spawn 出去的 CLI 子进程**；
本三件走的是**就地 `dispatch()`**，子进程预载够不着。实测（探针 `.scratch/t108fix/nowprobe.test.mjs`）：
`node --require <绝对路径> --test <件>` 时 `--require` **不进** `node --test` 派生的每个文件子进程（exit=1）；
`NODE_OPTIONS='--require <绝对路径>'` 形态才进（exit=0）。§④ 的三个「现在」即用后者。

| 步 | 动作 | 读数 | 结论 |

| 2 | 改回（删掉那行） | `ℹ tests 36`／`ℹ pass 36`／`ℹ fail 0`（`RESTORE_EXIT=0`） | 复绿 |

**sha 前后（`pin-clock.mjs`，SHA-256 前 16 位）**：变异前 `AB342E2AB9A8B79A` ⇒ 改回后 `AB342E2AB9A8B79A`（逐字还原）。
