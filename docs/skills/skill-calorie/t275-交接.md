## 二、两个具名区块函数（本票只交付、不集成）

签名与默认行为（**编排者已按这条派下一手，别改口径**）：

```ts
// 所在件：packages/skill-calorie/src/diet/nutritionPortDocs.ts（深路径 import，不经 diet/index.ts）
export function buildNutritionRatioBlock(v: NutritionRatioView): string;   // 交 #273（calorie.view.diet-review）
export function buildDietOverviewBlock(v: DietOverviewView, command?: string): string;  // 交 #271（calorie.view.diet）
```

- **调用方各自负责整页**：两块都**不夹整页壳、不夹复制区**（`<!doctype>`／`ilife-block-page-shell`／
  复制按钮都不在块里）。宿主页用 `assembleDocPage` 包，`charts` 传 `true`（两块都含图）。
- **`buildNutritionRatioBlock(v)`**：锚点 `sec-kpi`／`sec-chart`／`sec-table`（宿主页的页内导航按这三个 id 出项）。
  取数：`buildNutritionRatioView(db, start, end)`（住 `diet/nutritionPort.ts`）。
- **`buildDietOverviewBlock(v, command?)`**：锚点 `sec-week`／`sec-month`。
  取数：`buildDietOverviewView(db, date)`（住 `diet/nutritionPort.ts`；不含今日，统计到昨日）。
  **不给 `command` 则不出复制区**（不替调用方编命令原文）；给了就出一段带日志的复制区，第 4 段是它。
- 两块都自带来源脚注（普通小字行）与口径行；宿主页不必再补这两条。
