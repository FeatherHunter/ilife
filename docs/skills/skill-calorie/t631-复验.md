## 一 · 改法（呈现口径，不改数字）

落点 `nutritionPortDocs.ts:351-372`（`buildNutritionRatioBlock` 内推荐范围对比表）。

- 病因两处：① 三态判定分家——`gap` 按克数比（`m.g > maxG / m.g < minG`），`status` 按占比比
  （`m.pct` vs `range.min/max`）；克数经 `Math.round` 取整，边界上两者分家
  （如 total=100 脂肪 `g==minG==2` 但 `pct=18<20` 时旧口径印 `✓`，状态印 `↓ 偏低`）。
  ② 符号系分家——`gap` 用 `+N克/-N克/✓`，`status` 用 `↑偏高/↓偏低/✓在范围内`（D3 症状：脂肪 `44克17%`
  低于下限 `20%(52克)` 印 `-8 克`，与状态列读法不一致）。
- 新口径：三态判定一律按 `pct`（`below = pct<min`／`above = pct>max`／`inRange = !below && !above`，
  `status` 复用同一对变量，谓词逐字相同）；符号统一 `↓/✓/↑` 与状态列同系；
  差值取到侧界绝对克数（下限侧 `minG-g`／上限侧 `g-maxG`），即 `↓ 8 克 / ✓ / ↑ 25 克`。
- 数字不动：`minG/maxG/g/pct` 四处算式一字未动（`minG/maxG` 的换算、`g/pct` 取数字段均原样）；
  取数层 `nutritionPort.ts`、`review.ts` 一行未碰。
- 公共层判定：`gap` 算式住页装配本件内联（非 `base-render` 共用函数）；`renderDataTable` 只收字符串，
  本体未动——无 D1（要动本体才停手上报），本票为页级覆盖。
