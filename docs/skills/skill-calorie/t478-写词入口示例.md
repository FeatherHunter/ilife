# #478 证据：改／删两条写词的入口可执行（示例参数不再是不可达的常量 id）

> 票：[#478](https://github.com/FeatherHunter/ilife/issues/478)（地图 #156 场景 04 运动）· 2026-09-15 实施席。
> 一句话：冻结表与路由声明里「改运动记录」「删运动记录」的示例参数由不可达的常量 `"id":1`
> 换成占位符 `"<记录号>"` ＋ 写清记录号从哪来；真出口按真实记录号跑得通、按未填的占位符会阻断。

## 一、改了什么（逐件）

| 件 | 改法 |
|---|---|
| `packages/skill-calorie/src/triggers/scene-04-exercise.ts` | 两条词的 `main_prompt.cli` 与 `data_source`：`{"id":1,…}` → `{"id":"<记录号>",…}`；`fill_hints` 补一条说明（记录号取自写前先跑一次 `calorie.view.exercise-records`）。其余 37 条词一字未动。 |
| `packages/skill-calorie/src/exercise/routes.ts` | 同两条词的**路由声明** `cli` 同改（两处定义地必须逐字相同，见判据 G1）。 |
| `packages/skill-calorie/src/triggers/routes.generated.ts` | 由 `node packages/skill-calorie/scripts/gen-cli.mjs` 重生成（不手改）。 |
| `packages/skill-calorie/src/exercise/edit.ts` | 新增 `coerceId`／`readId`：`id` 收**数字或数字串**（占位符填进来的是字符串）；非数字串仍给 `id 须为正整数（可给数字或数字串）`，不拿占位符去查库。**不许用 `optNum`／`optStr` 读这一格**（两者是严格类型闸，串起来读会把数字串判成类型错）。 |
| `packages/skill-calorie/test/exercise-accept-267.test.mjs` | `fillPlaceholders(cli, recordId)` 会填 `"<记录号>"`（`round()` 先量一次种子库里真实可达的最大 id）；`runWord`／`paramsOf` 多接一个 `recordId`。 |
| `packages/skill-calorie/test/exercise-id-entry-478.test.mjs` | 本票新判据（三组，见下）。 |
