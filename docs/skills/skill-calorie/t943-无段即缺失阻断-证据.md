# #943 · 落地训练族：无段可落地即缺失阻断（不再回成功回执页）

现场来源：用户报「执行落地训练，无论什么异常都给一张虚假数据的回执 html；无计划可以落地，拿到的是演练版本」。
调查件：`docs/skills/skill-calorie/落地训练-预演回执-调查.md`。本件只记**改动与判据**。

## 一、改了什么（一句话）

「落地训练」「落地到本周末」「落地到本月底」在**该日期／该范围里一段可落的训练段都没有**时，
不再回 `ok:true` ＋ `items[0].status='成功'` ＋ 整页回执，改按技能冻结的缺失阻断口径报出：
`fail(4, '…没有可落地的训练段：<为什么 ＋ 下一步>')`，不落页、不进任何子进程。
连带：批量实跑**只跑有训练段的天**（休息日跳过），于是推送／回写天数不再把休息日数成「已落地的一天」。
