# #293 验收 · 命令自治（独立探针）

**这份是什么**：一份**独立验收探针**，不引用任何一方的自述，只从仓内可观测事实与命令输出判定五条承诺
（单一权威源／两道机器门／薄分派／parity 有主）。它**不进** `pnpm test` 的 glob——根 `package.json` 的测试
glob 只覆盖 `test/**` 与 `packages/*/test/**`，本文件住在 `docs/skills/skill-calorie/`。

## 怎么跑

```pwsh
node "docs/skills/skill-calorie/t293-验收-命令自治.mjs"          # 人读
node "docs/skills/skill-calorie/t293-验收-命令自治.mjs" --json    # 机器读（末尾一行完整 JSON）
```

- **输出怎么读**：每条先打 `P1: PASS|FAIL|PENDING`，缩进行是证据（计数／file:line／命令 exit）。
  最后一行是机读摘要：`RESULT: P1=PASS P2=PASS P3=PASS P4=PASS P5=PASS 5/5`。
- **退出码**：有 FAIL → `1`；PENDING 不算红，但摘要行会点名。
- **缺件不崩**：少文件／少生成器缺脚本 → 该条报 `PENDING` 并写明缺什么，其余条照跑。
- **不写仓内文件**：动态实验一律在**仓外临时根**（`%TEMP%\t293-accept\sandbox-<pid>-<ts>`）做，用完即清；
  删除前做路径守卫（目标必须在自己临时基底内、不在仓内、路径不含 `node_modules`／`packages`／`docs`／
  `test`／`tooling`／`.git` 任何一段）。唯一落盘：`.scratch/t293-accept/probe-report.json`（过程稿）。
