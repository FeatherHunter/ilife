### 5.4 `t516-判据-版式.mjs` 当刻跑不动（**工具缺陷，如实报**）

```
node docs/skills/skill-calorie/t516-判据-版式.mjs <两件> --json .scratch/t529/fmt-after.json
→ 每档 error: "body is not defined"；RESULT: -6/2
```

真因：该脚本的注入探针第 107 行 `out.body = rect(bodyBox);` 把 `out.body` 设成 DOMRect，

（`out.body` 之后那段把 `body` 当变量用），于是整个探针抛错、四档全空。
**只读跑、未改**（改它要走归属票）。故本票的「断点／字号／触摸区／行高」四项读数由自写探针承担（§三）；
