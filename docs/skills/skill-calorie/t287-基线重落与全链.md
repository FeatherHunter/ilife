### 2.3 漂移源定位（三步证据）

1. **文本面全同**：把写页正文按文本节点逐条落盘比对两轮，逐行零差异；`data-t` 属性值亦逐字符等长相等。
2. **属性面唯一差项**：比对两轮正文的全部属性值，唯一差异项是 `data-t`（复制日志载荷）——其值里含「日期 ＋ 时刻」。
3. **差位定位到秒**：按分段比对两轮正文，差异**只有系统时钟的秒位**，例如 `2026-09-14 23:25:18` ↔ `23:25:19`；两轮正文长度完全相同（`photo.add` 两轮均 64188 字符）。每页出现 3 处：回执行「时间」格、页内「时间戳版本」行、复制日志 `data-t` 里的 `日期`。

**时钟来源**：`receipt.meta.actionAt` ← `src/render/receipt.ts` 的 `nowStamp()`，其实现为 `new Date()` 取到秒（与库内记录无关，也与页面参数里的 `date`／`time` 无关）。该字段被饮食／运动／训练／体重各回执同样使用（`diet/receipt.ts`、`exercise/receipt.ts`、`workout/receipt.ts` 等）。基线脚本的 `normalize()` 目前只剥「临时目录路径」与「产物文件时间戳」（`\d{4}-\d{2}-\d{2}_\d{6}`），不剥「渲染当刻的系统时钟」。

**归因**：这三页漂移**不属本 MAP 的任何一处改动**（照片域 #341／#281／#282／#352／#438 的改动不改写回执时钟），**也不是别席在途改动的连带**；它是「页面参数显式传了业务日期（`date`／`time`），而写后回执另取系统时钟」这一口径落差的固有结果。

**复现口径（只读，未改脚本）**：本席另写探针 `.scratch/t287-real-probe.mjs`，按基线十页口径各跑一遍；六个读页给出的读数与基线**逐字相等**（`help.center` `fe452fad…`／`compare` `5495d89b…`／`detail` `560a9b04…`／`gif` `b303a017…`／`list` `e10e44a6…`／`gif-planner` `74358b47…`／`photo-log-wizard` `4d25708e…`），证明探针与基线同口径；而三写页两轮又是两个新读数。汇总：非写页两轮读数两两相等，写页两轮读数两两不等。
