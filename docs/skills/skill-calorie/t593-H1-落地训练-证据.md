## 三 · 票内定的口径

### 1. 宿主命令的形态（写键 `receipt` 形，`dryRun` 分流）

- `calorie.workout.land`（落地训练）：读计划（自有库，只读）→ 作息批量（`dates[]`，逐段三元组）→ 备忘逐段（`category=心愿 due`）→ `push-plan` 单日 → `backfill --days 1`；
- `dryRun: true` → 过程页（可复制实跑指令首位 ＋ 四步预告，**零子进程**，远端未调用）；
- 缺省 → 结果页（四步结局四行 ＋ 重复跑口径三行 ＋ 本地／远端区分）；
- 同步处理函数是同步的，四路外调全隔离进子进程（`spawnSync` 一次性；存在性预检＋60 秒限时＋起不来即 exit 4）。

### 2. 四步退出码表（冻结码 `cli/cmd_read.ts:5`）

| 事件 | 本面码 | 备注 |
|---|---|---|
| 用法错（`dryRun` 非布尔／合成写参数错透传） | 2 | spawn 前先验；子进程的 2 同档直传 |
| 无训练计划／缺开始日期／回执解析失败 | 4 | 取数档 |
| 本地缺 KEY（`push-plan` 退 2，或退 3 但逐段 `attempts: 0` 鉴权错） | 3 | key 档（数据分流，不只看码） |
| 作息／备忘合成写没达成（含本地成远端没成） | 4 | 取数档：外部依赖失败（页上两行分开写） |
| 远端接口错（推送 `fail_count`／回写没拉到或没写进） | 4 | 同上 |

### 3. 三旧坑逐条落实（`t350` §三）

1. **退出码恒 0 → 任一步失败即非 0＋失败不落成功页**：用法 2／无计划 4／缺 KEY 3／其余 4；`fail` 直接退，成功页只在四步全 0 时组装（`t612` ③a–③f 钉死）；
2. **外部调用无保护 → 预检＋限时＋失败进码**：两包 CLI 入口不存在先拦（exit 4）＋ `spawnSync timeout` 60 秒（exit 4）＋ 起不来即 exit 4；
3. **回执渲染器不调外部 → 调用收进同一命令**：页上读数一律来自本次四步调用的回执 data（最小形状守卫，坏即 exit 4）；本地／远端分开写（dryRun：本地已读／远端未调用；实跑：四步分写；挡板：标数据来源）。
