## 3 两条对比命令的去处

- 对比体脂：有 `source` 入口，本票已加校验（§1）。
- 对比围度：无来源入口——`body_measurements` 表无来源列，`compareMeasurements(db, date1, date2)` 与
  `viewBodyMeasureCompare` 均不收 `source`，多传 `source:nope` 原样忽略：改前改后均为 exit 0
  且产物逐字节相同（html 88773 字节，`impl-base-m-nope` vs `impl-post-m-nope` SAME）。
  故票面「两条」中需加校验的只有体脂对比一条，此处无处可加不是漏做。

## 4 `all` 口径说明与遗留

`all` 在对比路径语义＝不按来源过滤的全来源对比（与 `listCompositions`／视图页同式实现；
改前 `all` 落 exit=4 空结果，改后 exit=0 且产物与缺省逐字节相同）。
产品口径追认票待编排者当场另开（本票只对齐校验门，未定任何新口径）。
