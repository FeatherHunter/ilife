## 三、反例读数（机器原文）· 这一条不过关就说明自检永远不会红

**怎么造的**：册子正本 **83 条不动**，把**第一条真行**（`seq=15 看今日饮食`）的 `file` 字段
改成盘上不存在的文件名，其余字段逐字保留 → `.scratch/t155wall/bad-book.json`（83 条，与正本同数）。

- 改后的值：`记一餐_回执_鸡胸_20260915_122536_这份盘上没有.html`
- 该名在盘上：**不存在**（`Test-Path` → `False`，另用 node `existsSync` 复核 → `false`）
- 该行**真名**（供对照）：`今日饮食_20260915_122539.html`，在盘上 → `true`

命令：

```
node docs/skills/skill-calorie/t155-墙生成器.mjs --book .scratch/t155wall/bad-book.json
```

**stdout 原文**：

```
t155-墙-手机.html：80 格；链接 160 条；缺 1 件 -> 记一餐_回执_鸡胸_20260915_122536_这份盘上没有.html
t155-墙-桌面.html：80 格；链接 160 条；缺 1 件 -> 记一餐_回执_鸡胸_20260915_122536_这份盘上没有.html
格数 80 / 80 vs 册子条目 83（交出 81 ＋ 未交出 2）；两张墙格数一致。对账不符
SELFCHECK FAIL exit=1
```

**退出码**：`REAL-EXIT=1` —— 且**点名了那一份**（`缺 1 件 -> <文件名>`），不是只给个数字。

**为什么这条能红**：起点件 `t154-mobile-wall.mjs` 先按「盘上有没有」把清单过滤一遍、再只查页面引用
（§6.4 点名的**假绿灯**：缺件被静默剔掉、自检照样报「缺失 0」）。本生成器把 `dropped` 判据补上，
且**三套分开判**：`dropped`（册子点了名却没落盘）／`absent`（册子记着**本就没交出**）／`dead`（页面引用落不到）。
反例里 `dropped=1` ⇒ 立刻红。补了这条判据以后，**自检会红**，不是摆设。

> **注意正例与反例的差别在「对账」两字**：正例 `对账相符`，反例 `对账不符`。
> 只有 `dropped` 有值时，未交出计数那一段不会指错人（`absent` 与 `dropped` 分开数，见 §五）。

## 六、生成器侧已核的版式事实（不能替代负责人的肉眼验收）

生成器跑完，出墙页；`vision_html_screenshot` 在 **390 ／ 1280 两档视口**各渲染一次，读数：

| 核的事 | 读数 | 结论 |
|---|---|---|
| 手机墙列数 | 3 列（`repeat(3, 410px)`），1320 宽视口下 3 格并排 | ✅ 多列铺开，无横滚 |
| 桌面墙列数 | 1 列（`repeat(1, 620px)`），格内是 1280 宽整体缩到 600px | ✅ 单列排布 |
| 缩放算式（§6.3 第 3 条） | `W=390→SCALE=1.000(390px)`、`W=1280→0.469(600px)`、`W=1440→0.417(600px)` | ✅ 与正本实测值**逐位相同** |
| `loading="lazy"` | 两墙 `loading=` 命中 **0** 次 | ✅ §7 第一个坑未踩 |
| iframe 数 | 两墙各 **81** 个 `<iframe>`，与格数一致 | ✅ |
| 产物是否自足（§7「样式全丢」） | 81 份产物**非锚点引用 0 处**（无外链 CSS／跨目录图片／绝对路径） | ✅ 单文件自足，iframe 里样式不会丢 |
| 墙尾「未交出 2 条」段 | 抽出原样渲染，2 条＋各自原因都在，橙色框正常 | ✅ |

**修掉的两处自家版式缺陷（改前实测、改后复核）**：
① 桌面墙格内 `<figure>` 撑满 620px 轨道，600px 的缩放产物右边留一条白带、说明文字也不跟着对齐 ⇒
`figure{width:var(--box);justify-self:start}` 钉住；
② 长文件名／长页内 h1 的 `figcaption` 撑破格子（`fit-content` 被文字固有宽度顶到 620px）⇒
`overflow-wrap:anywhere` ＋ `min-width:0` 允许换行。

> **桌面墙的用途说明（别误判）**：1280 缩到 0.469，字面约 6.6px，**读不了字**——桌面墙是给人看
> **排布／宽度／长行有没有炸**的，不是用来读文案的。要读文案请点格内标题链接打开整页，
> 或在手机墙上读 390 原尺寸那一版。这一点写进墙页副标题了。
