**为什么铁律五的「≤5」站得住（从第一性原理，用户提问）**：对外名字＝**别人要学、作者要守的承诺**。
① 认知成本：一次能记住的面约 4–7 项，再多就得翻文档；
② 变更成本：每个外露名字都是一份兼容承诺，面越大，一次改动的溢出越多（与铁律一「能力自治」、铁律三「改动可预告」同向）；
