### 一处环境性现象（编排者要的那一行）

`tsc -b` **增量缓存陈旧**：`src/cli/keys.ts` 是生成物，它一被重写（改键或改 title），
`tsc -b` 的时间戳判据就可能判「无事可做」而跳过重编，于是 `dist/cli/keys.js` 里仍是旧的 `RouteKey` 联合类型，
下游 `src/diet/routes.ts` 直接报 **TS2820**（`'calorie.product.import' is not assignable to type 'RouteKey | undefined'`）
——而源码与生成物**当刻都是对的**（`git status` 对这两个文件都是空）。实测两笔：
`runId=16dbc561-b506-4ce8-8665-4561d2d86e83`（`pnpm build`，exit=2，TS2820 一条）与
`runId=57cd38ee-472f-48d8-9199-625ee4437b46`（`npx tsc -b --force …`，同一条已消失）。
**依据**：本仓生成物门要的是「产物 == 生成器输出」，不是时间戳（`命令登记纪律.md` §二 · 形状二），
所以环境被判旧时正解是**强制全量重编**（`--force`），不是删 `dist/`、也不是改门。
