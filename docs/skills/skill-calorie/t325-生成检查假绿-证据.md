## 3 修法（内容判据，不看时间戳）

`packages/skill-calorie/scripts/gen-cli.mjs`：

- 印记升 v2：每条声明源记 `{src, dist}` 配对（源文本 sha256 ＋ 它编译产物 `.js` 文本 sha256，缺产物记 `dist: null`）；`--stamp` 照写。
