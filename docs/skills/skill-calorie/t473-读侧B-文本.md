## 二、删掉的信息登记（不许丢）

删掉的每一句都在这儿挂号，说明它去哪了或为什么可以不留：

| 删掉的信息 | 去处 |
|---|---|
| 眉标里的命令名 `calorie.photo.detail`／`calorie.photo.compare` | 复制区 envelope 的 `key`（给 AI 的机器内容，一字未动） |
| 「身材照片域」 | 全页不再出现（域在 HELP 一级分组里还写着；页面读者不需要它） |
| 单页上限的精确写法 `1 MiB` | 退让句写成「超过 1 MB」（同一量级、读者读得懂）；精确值仍在 `PHOTO_LIST_PAGE_MAX_BYTES` 与 `#438` 的判据里 |
| 退让时的 N／M 计数（详情页恒 `0 张／1 张`） | 不构成信息（单张页只有一张）；对比页的 N／M 句保留不动 |
| 「换小图后重跑」「只看本页文字快照」两条替代操作（详情页） | 换小图的动作是 AI 的活、不是读者的；「看文件名」这条保留（写在退让句里），信息表也在页上 |
| 「文件存在」（在位时） | 照片本身就在页上显示着；缺失时仍写「文件缺失」 |
| 「硬删除／不可恢复」的术语（详情页三处） | 换成一句人话「删了就找不回来」，只留删除入口那一处；**语义没削弱**（仍是硬删除、仍不承诺可恢复） |
| 「快照明细／删前核对凭据」 | 「这是哪张照片」由大图卡与信息表承担；「删前先核对」由删除入口「先确认上面那张是不是它」承担 |
| 「按日期正序／按日期倒序」 | 日期本就印在横幅与图注里，顺序对读者无意义 |
| 对比页副标题与表注里的裸 id（`#1 vs #4`） | 两张卡各自的图注与信息表里都有 `#id` |
| 「跨标签／非同标签对比／可比性较弱」 | 换成「角度不一样……看不出真实变化」（同一意思的人话）；技术归因（标签不同）保留在 KPI 的详说里 |
| 详情页编号 KPI 卡的 `2026-09-04 08:00:00` | 与图注逐字重复；图注那一份保留（且加了相对时间） |

**一处与票面文字不符的实况**：票面第 4 条写「图注含整条路径」，实读不是——`photo.ts` 的 `toCard` 早已把
`photo_path` 取成 `basename`，页面上本来就是文件名（不是整条路径）。本次把它从纯文本改成 chip 小字块，
没有「删掉路径」这回事（路径本来就不在页上）。
