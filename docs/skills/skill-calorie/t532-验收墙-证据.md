**正例**（票面逐字的命令形态）：

```
手机墙 手机墙.html：31 格；链接 62 条；缺失 0 -> 可发          [exit 0]
```

（「链接 62 条」＝31 个 `iframe src` ＋ 31 条标题 `href`；索引的 33 条＝31 件产物 ＋ 2 张墙。链数与格数**各自对得上**，纪律件 §4「格数对得上」一栏成立。）

**反例（必跑，纪律件 §4）**——在清单 `t532-清单.json` 里故意加一行 `99-反例-盘上没有这一件.html`，再跑一次：

```
手机墙 手机墙.html：31 格；链接 62 条；缺 1 件 -> 99-反例-盘上没有这一件.html（清单第 99 行：盘上没有这个文件）
缺失 99-反例-盘上没有这一件.html（清单第 99 行：盘上没有这个文件）      [exit 1]
```

索引同样红并点名：`索引 索引.html：31 件；链接 33 条；缺 1 件 -> 99-反例-盘上没有这一件.html（…）  [exit 1]`。
还原清单后复跑，两侧都回到 `缺失 0 -> 可发 / exit 0`——**这条红是能红的，不是永远绿**。

**这一条为什么非跑不可**（纪律件 §6.4 点名的假绿灯）：起点件 `t154-mobile-wall.mjs` 先按「盘上有没有」过滤清单、再只查页面引用，缺件被静默剔掉、自检照样报「缺失 0」。本件两条判据一起判：
① `dropped`＝**清单点名的每一份**在不在盘上（顺带核字节，被换过也算缺）；② `dead`＝**墙页里引用到的每一条链接**在不在盘上。

## 3 形制与静态断证（纪律件 §6.2／§6.3／§7）

生成后另跑一遍静态断证（`.scratch/t532/_work/asserts.mjs`，只读）：

| 断证 | 手机墙 | 桌面墙 |
|---|---|---|
| `iframe` 数 | 31 | 31 |
| 带 `loading` 属性的 `iframe` | **0** | **0** |
| 全文出现惰性加载属性 | **否** | **否** |
| 格子宽／显示宽 | 390 ／ 390（不缩） | 视口 1280 ／ 显示 600（`transform:scale(0.46875)`） |
| 格高（同一张墙内唯一） | 820 | 384 |

- **禁 `loading="lazy"`**（§7 第一个坑）：生成器里没有这个属性，且有一条**标签位断言**拦它（正文里解释「不要惰性加载」那句话不算——早先版本把正文误判成属性，已改成只在标签属性位里找）。
- **清单不带签名**：`t532-清单.json` 首三字节不是 `EF BB BF`；生成器读到 BOM 会当场 `exit 2`（§7「Unexpected token」那一行）。
- **格高一致**（§6.3 第 2 条）：两张墙共用同一个源视口高常量 `CELL_H = 820`，**只有格子宽不同**；同一张墙内每格的显示高由定尺寸框钉死（390 墙＝820，桌面墙＝820 × 0.46875 ＝ 384）。
- **不藏横滚**：格子用 `flex-wrap` 换行铺开，不用 `overflow-x:auto` 藏一条看不见的横滚（§7「右边的格子看不见」）。
- **一个自己踩过的坑，已修**：初版 `figure` 用 `border:1px`，全局 `box-sizing:border-box` 下 390 宽的内容盒只剩 388 ⇒ 格子右缘 **2px 被 `overflow:hidden` 悄悄裁掉**（机器读数：`figure cw=388 sw=390`）。改成 `box-shadow:0 0 0 1px`（不占布局）后重测：**手机墙 `clip=0`**。
  （桌面墙的 `clip=62` 是**设计内**的：它的 62 个格子各有一个 `overflow:hidden` 的定尺寸框，把 1280 视口整体缩到 600 显示——纪律件 §6.3 第 3 条要的就是这个框，读数里已标范围外。）
