## 4. 方向判语缺陷：修前 / 修后（本票真缺陷）

**数据**：`#334` 锚点种子（`test/weight-compare-334.test.mjs` 同形），`today=2026-09-07`。

### 4.1 修前（已提交的 `b87b396`，实测复现）

```
wweek    window=本周 compareWindow=上周   本期 2026-09-07~09-07 vs 对比期 08-31~09-06
  均值和 69 vs 69.2（avgDiff=-0.2）  净变化 本期 0  对比期 -0.4
  页上两处判语：「体重对比」detail=下降  ＋「节奏」=较上期加速上升      ← 自相矛盾
wweekend window=工作日 compareWindow=周末 本期 08-31~09-04 vs 对比期 09-05~09-06
  均值和 69.3 vs 69.1（avgDiff=+0.3） 净变化 本期 -0.3  对比期 -0.1
  页上两处判语：「体重对比」detail=上升  ＋「节奏」=较上期减速下降      ← 自相矛盾
```

复现脚本：`.scratch/t154/probe-compare-verdict.mjs`（探针输出见 §4.3 上半）。

**病根两条**：
1. `weight/figures.ts:114` 的 `speedLabel` 用「本期净变化」符号挑词，而页上「方向」用「两段均值差」符号 —— **两个不同的量**，符号可以相反，于是同一张页并排出现「下降／加速上升」。
2. 未提交那版虽把 `speedLabel` 换成 `rhythmWord(changeDiff)`，但仍是「净变化之差」：两段不等长时（工作日 5 天 vs 周末 2 天）不是速率；本期单日时净变化恒 0，减出来的「加速」是假读数；且 `changeDiff` 没取整，页上真的印过 `差 -0.19999999999999998 kg`。

### 4.2 修法（`compare.ts` 共用口径一节，两版同调）

```ts
directionWord(n)  // 只看两段均值差的符号：下降／上升／持平
arrowOf(n)        // 同一个符号来源：↓／↑／→
rateOf(seg)       // 段日均速率＝净变化 ÷ 跨天数；单日段／只有一条记录 → null（不当 0 用）
rhythmOf(a, b)    // 幅度差：|本期日均| vs |对比期日均|，门槛 5 g/天（同 figures.ts:72）
                  //   幅度更大／幅度更小／幅度相当；任一段读不出速率 → 无从对照（如实说）
```

- 方向词与节奏词**互不带对方的词** ⇒ 不可能再出现「下降 ＋ 加速上升」这类组合。
- 单日段不再编速率；差值过 `round2`，浮点尾巴消失。

### 4.3 修后（同一份种子，节选页上文字）

```
wweek    体重对比 -0.2 kg  下降 ↓  徽章「下降」
         本期 69 kg 2026-09-07 · 1 条 徽章「单日数据」｜对比期 69.2 kg 08-31 ~ 09-06 · 7 条 徽章「共 7 条」
         节奏 无从对照  徽章「无从对照」  本期 +0 kg vs 对比期 -0.4 kg：单日段没有跨天跨度，读不出速率
         页顶：样本与口径 ⚠ 本期 1 条，低于门槛 3 条。／每段要 ≥3 条才有像样的均值差…；本期只有一天：…
wweekend 体重对比 +0.2 kg  上升 ↑  徽章「上升」
         节奏 幅度更小  本期 -0.3 kg（日均 -75 g/天） vs 对比期 -0.1 kg（日均 -100 g/天）
```

复现脚本：`.scratch/t154/probe-verdict-after.mjs`。**修前／修后是同一种子、同一条命令**。

### 4.4 视觉复核
