3. **参数与退出码未动**：缺参 exit 2／缺失阻断 exit 4 的口径原样（本件不碰 `shared/params.ts` 与取数层）。
4. 逐日达成表里「无记录」那几天写 `—`（裁定 4），不拿 0 顶——那与「记了但吃 0 卡」是两回事。
