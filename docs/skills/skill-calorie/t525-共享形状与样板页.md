## 四、照抄指引（#526～#529 看这一段）

**样板页＝`查身材照` 单张**，落 `.scratch/t525/out/查身材照-样板页.html`，生成器 `.scratch/t525/make-sample.mjs`。

### 4.1 照抄哪几段（逐段对得上）

1. **页头**：`assembleDocPage({ docTitle, title, eyebrow: '', subtitle: null, content, pageUi: true })`。
   标题写人话（`2026-06-01 的身材照`），**不带 `#编号`**。
2. **页内导航**：`renderTocBlock({ items })`，锚点 id 与区块 `id` 逐字相同；窄屏由配方转成横滑胶囊轨。
3. **结论条**：`renderConclusionBar(一句)` —— 「图放没放进本页」**全页只在这一处说**。
4. **图片／GIF 容器**：`renderMediaFigure({ id, src?, alt, ratio: '3-4', fit: 'contain', caption, placeholder? })`。
   `src` 与 `placeholder` **恰给其一**（构件会抛）；`ratio` 取闭集 `MEDIA_RATIOS`。
5. **事实条**：`renderFactStrip({ items: [{ label, value, tone? }] })` —— 原来那串 `·` 的替身；
   `tone` 只许 `ok／warn／danger`。
6. **键值行**：`renderListRows({ items: [{ left, main }] })` —— 长文本（文件名／备注）走行式。
7. **时间轴条**：`renderTimelineRows({ rows: [{ time, main, note? }] })` —— 时间序列（同期几张）。
8. **动作行**：`renderActionBar({ copyData, copyLog })`；命令原文只住 `data-t`，可见面上不出现。
9. **口径行**：`renderCaliberLine('甲 ｜ 乙')` —— 段间用全角竖线，**由版式承担分隔，字符不进文本**。
10. **复制区**：`copyArea({ data })` —— 读页面**不给 `log`**，那颗「复制日志」自动补位并**置灰禁用**。
11. **机器载荷**：`pageKit.payloadFold(标题, 命令)`，别在正文里平铺命令原文。

### 4.2 **不能照抄**的四件事

1. **不要把可复制的命令原文平铺进正文**（旧页把 `calorie-cmd-read …` 铺成 `<pre>` 占半屏）——
   用 `payloadFold` 或只住 `data-t`。
2. **不要在页面里写字号、内距、色值**：版面单源在 `base-paint`（`blocks.ts` 的 12 区 ＋ 本票两件）；
   页面件里出现一条 `font-size` 就是债。样板页里唯一的例外是数据 URI 的 `<img>`，它没有任何内联样式。
3. **不要自己再造一套页内形状与页内 CSS**：`src/photo/photoUi.ts`（中间态里那一件）是本族**临时**的
   页内件；它做的 `chipRow`／`factRows` 与本票的 `renderFactStrip` 是同一件事的两份实现，
   **#526 应当把它并掉**（并入后 `photoUi.ts` 只剩本页特有的一两条）。
4. **不要把同一件事在页头／结论条／键值行各说一遍**（样板页第一轮就犯过：结论条说「157 KB」、
   键值行又说「大小 157 KB」——已删键值行那条）。

## 五、两档 vision 分与扣分理由（**作者自测，独立复核归审查席位**）

- 出图：`vision_html_screenshot` 390×844 与 1280×900 各一张（`fullPage`），审图：`vision_describe`。
  图与该工具的「结构化预识别」通道同源，返回的是**版式描述**而非可直接取用的分数；单独问「0–100 给一个整数」
  当刻返回 **62**。
- **按五维尺自算**（尺与 `t524-改前读数.md` §6 同源、权重逐条同）：

| 维 | 满分 | 自算 | 扣分理由（逐条可核） |

| ① 结构纪律 | 15 | 13 | 1280 档内容挤在中栏、左右大片留白（页壳 `max-width:960px` 是既有口径，本票未改）；卡与主图的内距不齐 |
| ② 信息层级与版式 | 20 | 17 | 删除区一行里三种高度／字号（提示条 ＋ 两颗按钮 ＋ 脚下小字）；主图占比偏小、纵向堆叠偏长 |
| ③ 分隔符与文字纪律 | 25 | 25 | 探针**节点级 0 命中**；无内部标识符／裸代码；无英文标签 |

| **合计** | **100** | **94** | |

- **两档差**：390 档与 1280 档吃同一份 HTML、同一套可见文本，③⑤两维同分；差异在 ①②（1280 档的横向利用）。
- **诚实记账**：VLM 当刻给的绝对分 **62**，与该工具在 `t524` 对同一批页给的 70～78 同一个量纲；
  **62 低于票面的 ≥92 自测线**。作者**不自评过线**，把 VLM 逐字观察与五维自算一并交审查席位，
  由它按同一尺判「通过／退回」。VLM 逐字点名的三处（1280 留白、动作区层次碎、按钮在 390 偏紧）
  前两处已在上面扣分表里认账，第三处机器读数**否决**（三档 0 处 <44px）。

### 5.1 VLM 逐字观察里**不成立**的两条（提示器不是证据）
