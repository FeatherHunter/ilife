### 2.2 现场诊断：**真因不是正则**

诊断件 `.scratch/t519/diag-param.mjs`（只读）在当刻 `routes.ts` 上逐条试原式：

```
CRLF=false lines=189
--- wake=看BMI报告 order=331 found=true
   原式 m1 = "calorie-cmd-read calorie.report.bmi --params \\'{\"window\":\"90d\"}\\'"
--- wake=预测体重(1 周后) order=393 found=true
   原式 m1 = "calorie-cmd-read calorie.view.predict --params \\'{\"horizonDays\":7,\"window\":\"14d\"}\\'"
```

⇒ `/cli: '(.*)' \},?$/` **逐字可命中**，捕获到的是完整命令串（含 `\'` 转义，`.replace(/\\'/g,"'")` 之后与 `routes.ts` 的 `cli` 一致）。
**真因在下一行**：`expected` 拼成了 `` `${c.key}' --params '${JSON.stringify(c.params)}` ``——键名后**多**一个单引号、末尾**少**一个单引号
⇒ `cli.includes(expected)` **恒假**，31 条全判不符。
（另：`wakeWord` 谓词本身没问题——`routes.ts` 里预测那 20 条确实写作 `预测体重(1 周后)`（含空格），与脚本的 `c.wake` 逐字相同。）

### 2.3 改法（**只动这一行**）

```diff
-  const expected = `${c.key}' --params '${JSON.stringify(c.params)}`;
+  const expected = `${c.key} --params '${JSON.stringify(c.params)}'`;
```

零新增依赖、零改读法口径（仍是「命令串里必须逐字含有『键 --params 原样 JSON』」这一条判据），**该件别处一行未动**
（`git diff -- .scratch/t387/run-all.mjs` 只有这一行 ＋ 其上方 4 行注释说明）。
