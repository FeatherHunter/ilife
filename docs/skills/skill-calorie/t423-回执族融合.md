## 六、#420 审查留的 D4／D5 处置读数

- **D4（prompt 形态复制区不在打印隐藏面内）· 处置**：本族**今天不用** prompt 形态复制区——回执页的复制区只有区块形态
  `copyArea({data, log})`（打印段 `.ilife-page-printable .ilife-block-copy-block{display:none}` 命中它，实测：13 条产物里
  `ilife-block-copy-block` 落在标记上）。唯一可能用到 prompt 形态的是**撤销入口**（可复制的撤销指令块），
  而它在真出口上恒不出现（全仓 0 个 restore/undo 入口；三条写命令都不传 `undoCli`）。
  决定：**这次不补公共层规则、不开票**——理由是无消费方，补一条作用到全部页面的打印规则属空转；
  写成一条前置：**撤销入口真接线那天，必须同时决定它的打印可见性**（要么改走区块形态，要么开公共层票在
  `.ilife-page-printable` 作用域下补 `ilife-block-pre-block` 的 `display:none`，引用 #420 D4）。
- **D5（可打印开关零消费方）· 处置**：本票补上了**技能侧真出口的端到端取证**——
  真跑 13 条命令、取产物、断言 `<section class="…ilife-block-page-shell…ilife-page-printable…">`
  （类落**版面根**）、样式段含 `page: printable` 具名页绑定与 `@page printable`；13/13 命中。
  接线落点：`buildExerciseReceiptDoc` 装配后对版面根做**定点加类**（锚点须恰命中一次，否则抛错）。
  为什么不是 `renderPageShell({printable:true})` 直调：本仓整页装配只有 `src/shared/docPage.ts` 的 `assembleDocPage`
  一处（`docShell` 唯一模板，不许第二份），而该件今天**没有把 `printable` 透传下来**；#420 审查探针
  （`docs/base/base-render/t420-review-probe.mjs`）取证可打印页用的也是这条单点插入。
  遗留一手（不阻塞本票）：`src/shared/docPage.ts` 增一个 `printable?: boolean` 透传位，本处的定点加类即可删除；
  该件不在本票写集，故未动。
