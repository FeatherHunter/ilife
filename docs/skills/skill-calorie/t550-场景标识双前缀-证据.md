## 6. 转交：公共层那一对矛盾（本票**不**动，给公共层票）

根因是**两侧契约互相打架**，本票只在卡路里侧收口，矛盾本身留给公共层票：

1. `packages/base-link-core/src/envelope.ts:26` 的注释：`// registry 命名空间 key：形如 skill.combo，对不上即 fail`

   「公共层的日志场景标识再与技能名拼回整名」—— **说 key 只是场景名**；
3. `docs/base-paint-contract.md:607`：`scene` 段「由 envelope 派生……文本形如 `{skill}.{key}（{shape}）`」；
4. 公共层**自己的冻结测试** `packages/base-render/test/text.test.mjs` 把**双前缀**钉成了契约：夹具
   `skill:'skill-a'` ＋ `key:'skill-a.key'`，`:135` 的 `sceneOf` 辅助函数复刻 `'skill-a.skill-a.key（' + shape + '）'`，
