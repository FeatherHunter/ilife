## D1 专项（裁定 Y）

**结论：销账（撤回原判为伪缺陷）。**

**点不出「哪两段之间缺分隔」** —— 原因是分隔符本就不是 `｜` 字形，而是 CSS 画的 1px 竖细线，全族一致：

```css
.ilife-block-caliber:has(> span) { display: flex; flex-wrap: wrap; gap: 4px 12px; align-items: baseline; }
.ilife-block-caliber > span + span { padding-left: 8px; border-left: 1px solid rgba(210, 210, 215, .6); }
```

（源码命中：`24-看BMI报告.html` `<style>` 内 `.ilife-block-caliber` 规则；子选择器 `> span + span` 的 `border-left` 即分隔线。全族同一条规则。）

- **上轮误判成因**：我在截图里把这条 1px 灰线读成了 `｜`，由此错误推断「27／28 页有分隔、24 页没有」；实际各页机制**完全相同**。我在 27／28／29／31 页看到的「`｜`」也是这条细线。
- **现状（W5 后）**：24 页该段为 3 条 `ilife-block-caliber` 段落 —— ①`<span>BMI＝体重（kg）÷ 身高（m）的平方</span> <span>身高取档案里那一个值</span>`（两段之间有细线）②`窗口里没有称重的日子不参与均值`（独立成行）③`📊 数据来源：…`。**无任何两段之间缺分隔**。截图 `shots-r2\24-1440-fullpage.png` 页脚区（3 短行，首行可见细线）。
