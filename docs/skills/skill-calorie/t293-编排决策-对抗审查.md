## 二 · 三条特别攻击

### (a) D5 是不是"把结构性损耗推给下一张图、带着已知缺陷收口"？

**部分成立，但不构成不达标。** 本图 Destination 要求的是「汇总位＝派生件 ＋ 日常零接触」，**不含**「生成物按能力分片」；
`#293` 正文已具名裁定 `#321` 移出收口判据、`#325` 不阻塞收口，`#327` 也已带判据立票。真正被推迟的是**吞吐**（落点仍需整树 `pnpm gen` ＋ 一把全局写者锁），
这一点在 `docs/agents/编排纪律.md:42` 自己写明了"纪律文件解决不了"。**风险不在少做，而在没人保证它下次会做**：`#327`／`#321` 与 `#325` 一样处于 open 待办态，
而 `#293` 收口后新地图会照旧开工。⇒ 更优解：给 `#327` 加一条**前置关系**（"下一张 wayfinder 地图开窗前 `#327` 必须关"）并写进 `#293` 地图正文的收口段；ADR 的归属补进 `#321` 正文（当刻只有 `#327` 的边界段提到"另需一张 ADR"）。

### (b) D1 的形状守卫能被绕过吗？

**能，且我跑出了躲过守卫仍是权威写死的样例：**

- 躲过：`assert.equal(specs.length, <权威总量>, '声明条数')`
  → 实测 `bucket=undetermined`（④）、`guardPending=false` ⇒ 既不判红也不记 `PENDING`，口径与"没判"无异。
  机理：`shapeGuard` 只吃「另一侧操作数文本 ＋ 整行原文」里的**登记样名**（`REGISTRY_LIKE_CI/CS`，L429-430），`specs` 是中性名 ⇒ 不进名册。
- 被抓住的对照：`assert.equal(n, 10)`（裸标识符）⇒ `PENDING`；`assert.equal(REGISTRY_KEYS.length, 10)` 与 `assert.equal(Object.keys(index).length, 10)` ⇒ ③ `UNACCOUNTED`（P1=FAIL）。
  ⇒ 守卫**有效，但识别的是名字不是事实**：改名、换中性变量即可绕过（复核席自己写的残余风险"④ 不是判过，是没判"）。
- **更要紧的一层（D1 未涉及）**：守卫守的锚集已经陈旧。探针算「权威总量」用的是 `未搬迁清单 ＋ 体重声明`
  （`authorityTotals()`）；当刻残留清单只剩 **1** 条，于是锚＝`10/4/6/9`，而真实权威是 **101 条命令**（写 35／读 66）。
  后果两条：① ④ 的 81 行里有 50 行是 `.status` 退出码一类的**小数字噪声**（`GROUPS=退出码／差值:50 访问器调用:4 域内 metrics:5 域内量:22 裸标识符:0`），
  噪声淹没信号，正是复核席提"≥60 阈值"的来因；② 任何把**真实总量**写死的测试（如 `assert.equal(KEYS.length, 101)`）**连扫都扫不到**——扫描锚里没有 101。
  ⇒ 更优解（比 D1 更省也更强）：把 `authorityTotals()` 改成与生成器同源取权威（读全量 `src/*/commands.ts` 声明，或直接读生成物 `keys.ts`），锚变 `101/35/66/9`；
  ④ 会从 81 行塌到个位数，③ 重新有鉴别力，阈值问题自然消失；`shapeGuard` 作为便宜的追加守卫保留即可（**阈值仍然不要**，这一条 D1 判对了）。

### (c) D2 的"不放宽 85 分线"在 S1／S2 皆 0 时是不是形式主义？

**不是，而且是唯一不破契约的选项。** 三点：

1. 首轮那份报告的**分数与自己的判定不自洽**：`PASS／82` 与 §6 量刑律（均分 <85 ⇒ FAIL）冲突；真实缺陷是"证据里的数字与任何版本都不符"（`docs/agents/编排纪律.md:34` 把"数字与任何版本都不符"列为第三桶成本），属证据面缺陷，不是文风问题。
2. §6.1 只给 **S1-过程违规**开了"具名书面比例处置"的口子，**没有**任何条款允许放宽分数门槛；为 82 分放宽一次，等于把 85 线变成可议价项。
3. 实际走的路径（`5eb41be`／`b35ebfb` 定点修证据 → 原复核席 §十一 定向复评 → 95）**已经是最省的合法路径**：只重开了"证据真实可复现"一维（12→23）与"文档同步"（7→9），没有推翻首轮其他四维结论。
   ⇒ 我按同口径独立复算四个数字（`1146/745/61/34`）逐值一致，复评 95 站得住。**结论：不是形式主义，也没有拖长收口**（当刻 `#318` 已 PASS／95）。
