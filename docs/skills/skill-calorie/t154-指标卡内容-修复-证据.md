# t154 · 指标卡内容修复证据（值槽：长文本与颜色词）

口径：**KPI 卡的值槽（`value`）只放短数字或数字＋单位**（含 `±`、`%`、`kg`、`条`、`行`、`项`、`个`、`天`、`g/天`）；
句子、区间、日期、颜色词、长度超过约 8 个字符的短语一律挪进 `detail`（副说明行）或 `label`。
写集只有 `packages/skill-calorie/src/weight/` 下的文件。

用户读数三条（本次要治的）：
1. `04-看体重曲线.html` 顶部第一张卡的时间换行奇怪、四张卡不等高、内容太大
   —— 卡高与字号由公共层版式工作面去收；**本票治的是值槽里那串 23 字的日期区间**（不等高的直接成因）。
2. `05-看体重稳不稳(增强版).html` 的「阈值 黄±0.073 红±0.098 kg」奇怪，把颜色写成了文字。
3. 其他页面「或多或少都有上述问题」——六类页面（历史／对比／复盘／波动／体重盘／回执）逐卡自查。

## 二、同一处定义（不许值槽与句子各印一个精度）

`volatility.ts` 的 `deviationText()` 一处定义，值槽与红／黄／正常三句都用它——页上看到的数与复制载荷的
`最新偏离kg` 同数（§4#5）。改后读数：值槽 `±0.03` ＋ 单位槽 `kg`，`detail`＝`今天在正常范围内(±0.03kg)`。
