## 三 · 票内定的口径

### 1. 批量命令的形态（写键 `receipt` 形，`dryRun` 分流，与单日链同形）

- `calorie.workout.land-weekend`（落地到本周末）：`date`（缺省今天，相对词照 `dayField`）→ `batchDates(anchor,'weekend')` → 逐天调单日链 → 过程页（`dryRun`，**零子进程**）／结果页（实跑）；
- `calorie.workout.land-monthend`（落地到本月底）：同上，`batchDates(anchor,'monthend')`；
- 同步处理函数是同步的，逐天单日链隔离进子进程（`spawnSync` 一次性；存在性预检＋300 秒限时＋起不来即 exit 4；环境透传，单日四路挡板逐天生效）。

### 2. 天数口径（唯一定义地 `landBatch.ts#batchDates`）

- `weekend`：今天 → 本周日（含两端；周日即 1 天；可跨月，如 09-30→10-04 共 5 天）；
- `monthend`：今天 → 本月末（含两端；月底即 1 天；闰月收敛，如 2024-02-15→02-29 共 15 天）；
- 周一起算与 `planPlate.ts#weekOfDate` 同口径（周一＝1..周日＝7），不另起第二份。

### 3. 同一份天数（修老“批量只进 Step3”）

- 老实现 `--days N` 只进 Step 3、Step 4 取 `--backfill-days` 默认 1（设计件 §2.3·2）。
- 新仓构造即成立：批量＝逐天完整单日链（每天内推当天＋回写当天，同源）；成功 N 天即推送 N 天、回写 N 天（`t613` ②④d 钉死）。

### 4. 失败口径（fail-fast，与单日链／`run-sync` 一致）

| 事件 | 本面码 | 备注 |
|---|---|---|
| 用法错（`dryRun` 非布尔／坏日期） | 2 | spawn 前先验；单日子的 2 直传 |
| 无训练计划／缺开始日期 | 4 | 取数档（与单日链同词） |
| 单日子进程失败 | 2／3／4 | 原样直传（2→2、3→3、其余→4），点名 `批量<词>失败在第 N 天 DATE：原因` |
| 批量挡板指定天 | 4 | `CALORIE_LAND_BATCH_FAIL_DATE` 短路，不 spawn |

### 5. R3 双桥码表（`LandBridgeResult.code` 复用 1／2／3，`run-sync.ts` 同义）

- 计划读不出（无库／无计划／缺开始日期）→ 1（用法档，与 `run-sync` 缺省推一天同码）；
- 合成写用法错（调用码 2）→ 1；其余失败 → 3；
- 空天（多天零段）→ `{ok:true}` 无 `skipped`（真跑过零条目，与占位恒 skip 区分）。

### 6. 三旧坑逐条落实（`t350` §三，批量侧）

1. **退出码恒 0 → 首个失败天即非 0＋失败不落成功页**：用法 2／无计划 4／缺 KEY 3／其余 4；`fail` 直接退，成功页只在全部天 code 0 时组装（`t613` ③ 系列钉死）；
2. **外部调用无保护 → 预检＋限时＋失败进码**：单日链 CLI 入口不存在先拦（exit 4）＋ `spawnSync timeout` 300 秒（exit 4）＋ 起不来即 exit 4；
3. **回执渲染器不调外部 → 调用收进同一命令**：页上读数一律来自本次逐天调用的退出码与回执 message（最小形状守卫）；本地／远端分开写（dryRun：本地已读／远端未调用；实跑：逐天结局；挡板：标数据来源）。

## 八 · 有意偏离清单（与老实现／设计件不同，逐条给理由）

1. **逐天经单日链子进程（不用 in-process 复用）**：宿主处理函数同步＋`fail()` 即 `process.exit`，in-process 复用首个失败天即自杀、拿不到逐天读数；子进程边界复用整条单日链（含它的预检／限时／点名），与 `landRunner.ts` 同形（§三·1）。
2. **fail-fast（首个失败天即停，不继续跑完）**：与单日链／`run-sync` 一致；逐天读数覆盖已跑天（含失败天点名），未跑天记「未跑」。跑完再汇总会把失败天之后的写入变成 cascade junk。
3. **成功天才计推送／回写天数**：失败天没过单日链（推没全成或回写没成），不计入；页上合计与逐天行逐天对得上。
4. **批量挡板只设失败日期缝**：单日四路挡板透传已够成功分支；失败分支需逐天可控（第 3 天失败），故单加 `CALORIE_LAND_BATCH_FAIL_DATE` 一缝（生产永不设）。
5. **墙只进本周末过程＋结果两页**：月末与周末同装配（仅范围标签与行数不同，`t613` ④b④e＋真出口落盘覆盖）；票面墙预算两页，取周末（多天表最有看头）进墙。
6. **随动旧断言六处**（与本票目标直接矛盾，随动，不放宽）：`t612` ⑤（恒 skip→真实现）／`help-center-106` 冻结数（exec 432／non-exec 4／唯一 CLI 389）／根 `routing-81` 本票增量（桶／oos／exec 记录／需参数／A7／M8）／`routing.ts` M8 注记翻页／SKILL 手写计数三行（52／134）／告警线台账（`build-help.mjs` 748→752，`--sync` 回绿）。
7. **SKILL 示例走 `<日期>` 占位**：生成器把示例日期归一成占位符（同 #614 §八·4 口径）；批量两示例取 dryRun 预演形态（种子库无 KEY 无网，实跑 exit 非 0；真推进行为由缺省分支承载，见 §六真出口）。
