## 五、变异自证（本席自守）

1. **手改声明并重建 ⇒ 我的门必红**：把 `routes/scene-07.ts` 首条 `wakeWord` 改成 `设置档案MUT` → `pnpm build` **仍绿**
   （此刻没有消费者 import 声明，属**预期假绿**）→ `verify-roundtrip.mjs` **红**：`mismatched=1 bad=1`，exit 1。
2. **回滚踩到的坑（留给下一席）**：用 `Copy-Item` 复原（字节相等，sha256 与备份一致）后 `tsc -b` **未重编**——
   `Copy-Item` 保留旧 mtime，而 `tsc -b` 增量按 mtime 判定 ⇒ `dist` 仍带 `MUT`、门**继续红**。
   `touch` 源文件后重建 ⇒ `dist` 无 `MUT`、`VERIFY-PASS` 复原。**结论：回滚／恢复声明后必须 `touch` 或用 `tsc -b --force`。**
