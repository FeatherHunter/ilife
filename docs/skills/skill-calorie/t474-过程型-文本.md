**B10 的取舍（票面要求给出选择与理由）**：选**撤掉那一栏**（不是四个数字输入、也不是留个空框）。理由两条：
1. 本层表单是**零 JS 静态预览**（B-09：`renderParamForm` 只渲染预填值，输入不回填进上面那段复制文本）。
   摆出来的数字输入**不会**影响复制出去的命令，是**点了没用的死控件**——比一行看不懂的 JSON 更坏
   （审查整改 3a 就是因为先前只换了字段名、`name="crops"` 仍在盘上，仍是个带名字没人接线的空框）。

   所以这里只能**如实**用人话指路：要裁就在对话里说一句（AI 接得住），页面不再假装提供输入。
   `crops` 这个键本身仍在 `wizardPort.ts` 的白名单与 prompt 复刻里（机器面原样），只是表单不再摆它。

**B11 的取舍**：`loop／transition` 的下拉**取值的是机器真值**（`0/1/3/5`、`cut/fade/dissolve`），
