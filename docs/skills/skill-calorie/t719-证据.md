## 三 · 设计上必须记下来的两条

### ① 类名与几何值**故意不统一**

`sui-`／`wui-`／`dui-` 三套类名是既有**外部契约**——包内十余个测试件按字面断言它们
（`sui-window`／`sui-facts`／`sui-fact-k`／`wui-strip`／`wui-strip-v`／`wui-strip-note`／
`dui-window` …）。票面 §六 那句「只许类名变化」读起来像放宽，实际是十几个测试件的连锁红；
本票的红线之一是「测试只在外部行为上说话、不为绿改断言」。**故共用件收的是形状的拼装逻辑，
不是类名**：族把类名词汇（`WINDOW_VOCAB`／`FACT_VOCAB`）递给共用件。

几何值同理：三族的日期块圆角（`8px` vs `10px`）、内距（`4px 8px` vs `3px 9px`）、
条外边距（`4px 0 16px` vs `2px 0 10px`）、窄屏日期块内距（`8px 12px` vs `6px 10px`）
逐值不同，都是既有视觉裁定落下的值。故共用件里两段 CSS 按族逐值保留，
**三族外观因此在窗口条上零变化**。票面原先只预告了圆角一处，漏了胶囊内距、条外边距、窄屏内距三处。

### ② 唯一一处可见版式变更（票面已授权）

体重族事实条容器：`display:flex;flex-wrap:wrap;align-items:baseline` →
`display:grid;grid-template-columns:repeat(auto-fit,minmax(148px,1fr));gap:8px 16px`（窄屏塌单列）。
正本取运动族那套（票面 §二、§六 第 1 条，用户已在 #700 认下）。

**实测受影响页 6 页**（票面说的「体重页与目标页」是少算的）：
`weight/log`／`weight/compare`／`weight/volatilityDoc`／`weight/receipt`／`weight/logReceipt`
＋ `goal/goalWeightDoc`。

**一行未改的**：类名词汇、字号／色／字重、以及三个变体位（`wui-strip-v`／`wui-strip-gap`／
`wui-strip-note`）的原规则——纵列版式与脚注口气字照旧。
