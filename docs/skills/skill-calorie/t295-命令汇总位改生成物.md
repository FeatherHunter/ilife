## ⑦ 风险 top3

1. **未搬迁清单会退化成第二个手写汇总位**：只要各场景不按 #297 的顺序搬走自己那一段，
   `legacyCommands.ts` 就会一直是 92 行。它现在有「只许变短」的语义但**没有机器门的棘轮**（#294 的棘轮只钉分派层的 `case`）。
2. **生成器读 `dist/`**：`gen:check` 必须在 `pnpm build` 之后跑（CI 已按此排序）；若有人先跑 `gen:check`，
   会因 `dist/` 陈旧而给出与源码不一致的判定——已在生成器里对缺文件大声失败，但时钟差这种情形挡不住。
3. **`present.ts` 的连带面**：`combos.yaml` 变成我方生成物的一端之后，改声明会连带改 `present.ts`
   （base-combos 的生成关系没动）。这条链上任何一环忘了重生成，`combos-p8` 的「生成物==生成器输出」会先红，属于可发现失败。
