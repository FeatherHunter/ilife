## 一、根因与改法（一句话）

`goalProgressDocs.ts` 页名派生只看天数（`f.windowDays <= 1` 即写死「今日目标进度」），周一「本周＝周至今＝1 天」
于是周窗塌成今日页；且 `<title>` 与页头胶囊都不带窗口词。本票在装配面加一个周窗分支：
先看本次命令原文里的窗口词（`command` 字段，出口已按本次参数逐字写入，无需改出口），
命中「本周」／`week_cur` 即出「近 N 天目标进度（本周）」，页签出「卡路里 目标进度（本周）」；
其余窗口走旧口径逐字不动，取数口径一行未动。
