## 四、本票补的那一点：缺项一次报齐（不是文案好恶）

`src/body/log.ts` 的闸门块，改前三条各自 `fail`（撞到哪条报哪条），改后合成**一条**信息、缺谁报谁：

```ts

    const asks: string[] = [];
```
