### 1.1 必须具名的前置发现：判据照字面**不可满足**，修法不是放宽判据

本页的复制日志第 5 段走 `src/render/receipt.ts:155` 的 `nowStamp()` —— `new Date()` 的**直接读时钟**，没有注入口（件头自述「本仓唯一的时间戳口径」）。⇒ 同一份源码连出两遍，只要跨过 1 秒，产物 `sha256` 必不同。首次实测：

```
STABLE-A-vs-B DIFF=01(67f5b639a644->0530f260aab6),02(…),…,08(…)      ← 8/8 页全漂
（逐行 diff：唯一不同的一行是「时间戳版本 2026-09-18 21:24:29 · 版本 0.1.0」）
```

**处置**：**不动源码**，在进程外把时钟冻住 —— `.scratch/t704/freeze.mjs` 用 `node --import` 预载，把 `Date` 换成固定时刻的壳。
判据保持字面口径不放宽，冻结后：`STABLE-A-vs-B pages=8/8 DIFF=none`。
⇒ 后续任何搬迁票的重出器都要带这一步，否则「逐字节相同」这条判据会**既出假红也出假绿**。

### 3.2 变异自证两行（打的就是本窗判据本身的识别力）

把搬走后的 `src/workout/planEditorDocs.ts` 里一处**会落到页面上**的可见文案改坏（`生成的计划，照这张表落库` → `生成的计划（改坏了），照这张表落库`），重编 → 重出 → 与基线比；再**逐字节写回原文** → 重编 → 重出 → 再比。

```
MUT-RED byte-identical pages=0/8 DIFF=01(ed91d9343c8d->6d6d6e4b14ae, 274574B->274589B),02(…),03(…),04(…),05(…),06(…),07(…),08(…)
  total_before=2022256 total_after=2022376
RESTORE 相等=true sha256_12=43e1ed6c9705
GREEN   byte-identical pages=8/8 DIFF=none
```

- 8 页全红、每页 bytes 恰好多 15（＝「（改坏了）」的字节数）⇒ 判据打的是**页面产物**，不是文件名或路径。
- 变异轮与还原轮**共用一次持锁窗口**（外层 `run-locked.mjs` 持锁，窗口内 `tsc`／重出器一律直调不抢锁）。
- 还原判据＝文件字节 `sha256` 与改前逐字相同（**逐文件写回**，不是整目录还原）。

### 3.4 本窗一条必须具名的限制：**开工基线没能在动源码前存**

`tooling/baseline.mjs` 的源面是**全仓 `git ls-files`**，所以它要求开窗／收窗之间**只有本席在写**。本窗开窗当刻 `packages/skill-calorie` 正被 **#703** 的在途改动占着（31 件未提交，21:35–21:38 还在写），按「同一片地上的两次作业不叠」的硬规矩，那一刻不能动源码、也就无处存一份干净的开工基线。
⇒ 本窗 `--save` 是**收窗**存的，`--compare` 只证「**存基线之后没再动过任何东西**（差异 0 项）」，**不证**搬迁前后一致。
搬迁前后一致由上面 §3.1 的**页产物逐字节判据**承担；「本窗只碰了申报的路径」由 §五的提交对账承担。这一条与 `t518-W1-搬家-证据.md` 具名的同类限制同性质：**判据的强形式在当时那棵树上不可复算**，必须与读数同页出现。
