## 缺失口径

- 单张失败（无照片目录／文件不在／过大）一律回占位句、不抛（`embedPhoto` 契约）。
- **页面明示（本段已按 #472 的可见文本改写；老写法「缺失照片 N 张：#id 文件名（原因）」＋图注
  「文件缺失」位已下屏）**：没显示的那张在自己的位置上写一句人话——太大＝`照片太大，本页没显示`、
  找不到＝`找不到文件：<文件名>`、没配目录＝`没配照片目录，读不到文件`、读不出＝`读不出这张照片：<文件名>`。
- 张数在 KPI 那格与明细句里：`本页 / N 张已显示`＋明细 `M 张找不到文件`／`K 张太大未显示`（都齐即不出这一句）；
  下方缺失清单逐张一行 `#id · 文件名 ·` ＋状态徽标 `找不到文件`（不再有 `缺失照片 N 张` 计数句）。
- 图注＝`日期 时刻 · 标签 · 相对天数`（相对天数按当刻「今天」现算）＋文件名小字块＋`复制文件名`；
  正常张不再逐张喊「文件存在」。明细表只标异常行 `缺文件`，正常行留空（`存在` 是零信息值，已删）。
- 正常照片不受牵连（仍内嵌 `data:image/`）。
- 示例（**本行按 #472 后的用例口径重写**）：删掉 `2026-09-04_001.png` 本体后，页面该张位置写
  `找不到文件：2026-09-04_001.png`，缺失清单出 `#1 · 2026-09-04_001.png · ` ＋`找不到文件` 徽标，
  KPI 明细写 `1 张找不到文件`（用例已钉；老断言里的 `缺失照片` 计数句已由同用例反向钉死）。
