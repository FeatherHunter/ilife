# 编排者裁定：`pnpm test` 失败集 delta 的「环境抖动」分类口径（跨票统一）

> 生效：2026-09-09。适用：#63 图内所有票（#88／#97／#120／治理返修…）。
> 依据：`docs/research/t88-baseline/BASELINE.md`（冻结基线，四门 exit 0；失败集判据＝**具名测试名集合新增 0**）＋ `docs/subagent-concurrency-protocol.md` §5／§6.1。
> 触发事实：`#88` 实施 B 段 canonical `pnpm test` 5 轮中 2 轮各多 1 条新失败，签名同为 `AssertionError: exit=3221225477`（＝`0xC0000005` 访问违例，来自 `spawnSync` 起的 node CLI 子进程，`output-naming-87.test.mjs:58`／`cmd-read-t11.test.mjs:69`），而这两个文件**单独连跑各 6/6 全绿**。

## 1. 判据（不变）

`pnpm test` 的 delta 判定**仍以具名测试名集合为准**（不以 exit 码为准），基准＝`docs/research/t88-baseline/test-failset.txt`（34 条并集白名单）。**冻结白名单不得修改**（`git diff 93e27f9 -- docs/research/t88-baseline/test-failset.txt` 必须为 0 行）。

## 2. 新增项必须分类（本次补充）

对每一轮出现的「白名单外新增」，必须按**失败签名**分类，并在证据里逐条留痕：

| 类别 | 判据 | 处置 |
|---|---|---|
| **A. 内容断言不符** | `AssertionError` 携带期望/实际值差异（`expected … actual …`） | **真 delta** → 必须修；`新增≠0` 成立，本票不得关闭 |
| **B. 进程级崩溃／环境抖动** | 签名含 `exit=3221225477`／`0xC0000005`（访问违例）、`SIGSEGV`、`spawn` 子进程被信号杀死，**且**该文件**单独复跑 ≥2 次全绿**（附命令＋输出） | 如实登记（签名＋单独复跑证据＋当时并发上下文），**不计入「新增」** |
| **C. 不确定** | 签名不属于 A 也不属于 B，或单独复跑仍红 | 按**真 delta** 处理（保守优先） |

**升级规则**：同一测试名在**连续 ≥3 轮**中都出现 B 类崩溃（非偶发）→ 升级为真 delta 处理，并另开 flake 票。
**留痕要求**：证据文件必须写清「轮次／新增测试名／失败签名／单独复跑结果／当轮并发上下文」，缺任一项不得主张 B 类。

## 3. 并发上下文（本次成因）

当时同时有 **4 个 session** 在跑（#88 实施 B／治理返修／#120／#97）。全量测试经锁串行，但**锁只保证互斥、不降低残余负载**；Windows 上高负载时 `spawnSync` 子进程易出现 `0xC0000005`。

**纪律（对所有 session）**：
1. 优先跑**靶向**测试；全量 `pnpm test` 只在需要 delta 判定时跑，且经持锁包装器。
2. 全量测试**不得与其他 session 的全量测试重叠**（锁已保证），也**不得与 headless 浏览器实证同时跑**（本票 B 段已出现该组合）。
3. 报告 delta 时**必须附当轮并发上下文**（同时有几个 session 在跑、是否有浏览器实证）。

## 4. 本次裁决

- **接受 (a) 分类处置**：`#88` 轮 1／2 的两条新增按 **B 类（环境抖动）** 处理，但必须满足 §2 的留痕要求（签名＋单独复跑 ≥2 次全绿＋并发上下文）。
- **不接受**任何形式的「改白名单」或「静默忽略」。
- `#88` 收尾时须以**多轮取并集**的方式给出结论，并在证据里列出**每一轮**的新增项与分类结果。
