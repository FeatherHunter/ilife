二 · 装与更新（你第 1 条）

Q4

装与更新落在哪一半？

关键

前因：缺席的页签现在只有一行可复制的命令文本，点不动；总管宿主半是空实现、客户端没有 RPC。更新包能给出「查状态／查新版／装更新」三个电话，但它一次只管一个包，六个单品要各自接线。

➡
选 (a) 总管统管，外加 (d) 市场入口作补充。
利 (a)只改 plugin-manager 一个包，六单品零改动；且不触发已冻结的「总管不 import 单品」断言——那条正则只拦六个单品包名，dsh-plugin-update 不在集合里。
弊 (a)总管要新加一条依赖并真的装上（它现在连 dependencies 字段都没有）。
利 (d)能覆盖「别的插件」的更新，顺手给个「打开插件市场」。
弊 (d)不能跳到某个包；桌面宿主下重启指引得写死「重启 DSH Desktop」。

另两条为什么不推荐：(b) 单品自管最贴边界字面，但记账／大厨／居家／作息四家连宿主电话表都没有，要先补；(c) 混合 只提示、不提供安装能力，只满足你要求的一半，不可单独选。

利符合「总管」的身份；六张设置页不用各长一颗按钮。
弊七次网络请求（可并发）＋ 要多设计一个汇总区。

三 · 配置面（你第 2、3 条）

Q16

配置存在哪一层？

关键

前因：调查查清了：DSH 只覆写 profile 目录里它自己那几个文件，其余文件 DSH 不读不写不删；官方另有 ctx.settings（落 $DSH_HOME/settings.yaml）与 ctx.storage；但技能既被面板调、也被模型在 shell 里直接调。

➡
选 (c) $DSH_HOME/ilife/，六个技能各一个 JSON。
利唯一真相是技能自己也能读的普通文件，两条调用路都拿得到；SKILLS_DB_PATH 与训记密钥本质是机器级的东西，切 profile 不丢；与 $DSH_HOME/integrations/<插件名>/ 是同族惯例，不发明新地方。
弊要自己处理并发写与原子替换，不享受 DSH 官方检查点回滚。

为什么不选官方那两个：ctx.settings／ctx.storage 是 DSH 自己的文件，技能 CLI 自己读不了——走它们只有「面板调用」那条路拿得到配置。

Q6

配置的读取优先级？

关键

前因：已关的 #55 报的正是「终端里设了 SKILLS_DB_PATH，面板依然报缺」——终端的环境变量活在那个终端进程里，由快捷方式启动的 Desktop 进程继承不到。这就是你要的这个面板要解的根问题。

➡
选 (a) 配置文件 ＞ 进程环境变量 ＞ 报错（面板里配的说了算），但留一个例外清单：五个测试哨兵 CALORIE_FORCE_PROD／HOME_FORCE_PROD／CHEF_FORCE_PROD／BILL_FORCE_PROD／SCHEDULE_FORCE_PROD 永远环境优先，面板不许写它们。
利面板说了算，正好解掉 #55。
弊想在终端临时盖一个值做调试时，得去改文件。

哨兵为什么必须例外：那几个变量一旦被设成 1，生产库会被当测试库写——这是数据安全，不是偏好。

Q7

配置什么时候生效？

前因：面板与技能之间每次调用现 spawn，没有任何长连接，所以「重启」是白让用户等。

➡
选 (a) 保存即生效，不用重启宿主。
利改完马上能验；少一次无谓重启。
弊无——但有一条硬前提，见下。

硬前提：训记 KEY 现在写的是用户级环境，只对那一次子进程生效、对已运行的宿主无效；而且官方 scrubbedParentEnv() 会剔除名字里带 KEY／PASSWORD／SECRET／TOKEN 的变量——所以训记 KEY 必须改走 spawn 时显式并入 env，才谈得上「保存即生效」。

Q8

下面这些逐项进不进设置页？

前因：调查列出卡路里 11 项、记账 5 项「适合在设置页配」；另有一批有争议的项要逐条裁。

➡
进（11 项）：库文件名、HTML 产物目录、照片目录＋GIF 子目录、训记 KEY、训记接口地址与限频窗口、训记三份状态文件落点、外部调用限时与回写天数、记账缺省账户／账本／币种／分类树、备份目录；SKILLS_DB_PATH 见 Q9。
不进（2 类）：CALORIE_TODAY／BILL_TODAY（钉日期的测试变量，我们做基线要用）；档案／目标／预算／训练计划的具体数值（那是数据，技能功能页管）。
利一屏能配完；把「库文件名／HTML 目录／限时／回写天数」收进一条默认收起的「高级」折叠组，首页不会一屏全是输入框。
弊训记那三项会让卡路里页变长，必须分组，否则页面会显得堆。
Q9

SKILLS_DB_PATH 这种全局值放哪一层？

前因：六个技能读的是同一个环境变量；而总管那张卡现在只有一行「总开关」，正缺一块总设置区。

➡
选 (a) 在总管面板加一个「总设置区」，放一份，六个技能共用。
利配一次六家一致；正好补上总管卡缺的那块。技能页仍可只读显示它的值从哪来。
弊分开放的话你会配六遍、还可能配不一致，然后报出「memo DB 目录不存在」这种错——这就是要避免的。
