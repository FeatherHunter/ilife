## 四、判据取舍（如实记）

1. **可改 `media.dir` 用 `prefillResolved` 而不用 `prefillFrom`**：`prefillFrom` 只有 `'dataDir'` 一档
   （样板只有 1 个可改项）；备忘有 2 个可改项，附件的落点在 `resolved.mediaDir`——加一档，
   与 `resolveFrom`（只读）语义分开：`resolveFrom`＝只显示不保存，`prefillResolved`＝空串时显示、照常保存。
2. **高级组清空但导出保留**：`ADVANCED_GROUP_TITLE`／`NOTE` 与 `COMMON_ITEM_COUNT` 被 696 F 组锁住
   （源码文本断言），删导出即红——保留导出，页面有项才画分组。
3. **旧技能缺席显示空串**：`resolved`／`lark` 双可选（照样板 `resolved?` 同例）；`LarkStatus` 缺席时只显示
   一行弱提示，不画复制按钮（无 prompt 文本可复制）。
4. **`copyPrompt` 单通道**：base 渲染层的复制是双通道（clipboard＋execCommand 兜底），但 client 禁 DOM 直写
   （`document` 不可用）——通道 1 照走，通道 2 换成「全文展示＋长按手动复制」（与技能页面 `pageAssets` 的
   toast 口径同一句话）。缺席／被拒回 `false`，调用方落字，不抛。
