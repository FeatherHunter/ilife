### 2.2 验收 1 的装机前后两次读数（用卡路里走完整一圈）

```
── 卸掉卡路里（dsh plugin --profile web remove dsh-calorie）
calorie | dsh-calorie | run=null | disk=null | panelRegistered=false      ← 面板会显示「未安装 ＋ 装上」

── 装回卡路里（dsh plugin --profile web add dsh-life-pack dsh-calorie，即缺席卡「装上」走的那条口径）
calorie | dsh-calorie | run=0.2.5 | disk=0.2.5 | panelRegistered=true     ← 产物有注册代码；重启后页签应变配置页
```

配套核实（面板 `present` 账本按**注册 id** 判定，产物里的 id 必须与页签表一致）：

```
dsh-calorie     => name: "ilife.config-tab", id: "dsh-calorie",     order: 75  ✅ 与 MANAGER_TABS 的 plugin 名一致
dsh-memo-ilife  => name: "ilife.config-tab", id: "dsh-memo-ilife", order: 70  ✅
```

**收尾**：`dsh plugin add dsh-life-pack dsh-calorie` 会把声明写成 `^0.2.5`（caret），而原先是精确
`0.2.5` ⇒ 已写回精确 pin 并 `dsh plugin install` 同步（末次读数七家同 2.1 表）。这条不算缺陷，
但记下来：**走面板「装上」会把那家的声明从精确 pin 变成 caret**。
