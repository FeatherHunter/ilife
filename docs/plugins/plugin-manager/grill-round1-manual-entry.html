指导手册入口：第一轮问题

范围：在爱生活设置面板增加一个入口，打开指导手册，说明插件、技能、帮助页面的使用方法。入口与手册采用卷轴与 HELP 印章风格，排版支持单页完整显示，是否分页与翻页动效待定。本文列出 5 个待确认问题，每个给出背景、推荐答案、选项对比、对抗式审查结论、从基本目标推导的结论。

Q1 这次做到哪一步为止

问题：你希望本轮交付的是 A 可施工规格加原型（只做决定不施工），B 直接在仓库中做出可用功能，还是 C 先出规格，原型比选风格后再定是否施工？

背景

需求中入口风格未定，还需要原型比选。按常规做法，应先把决定做清楚，再施工，避免返工。

推荐答案

选 A：先定规格加原型，不直接施工。

选项对比

选项优点缺点
A 规格加原型决定做透，施工一次做对本轮看不到最终成品
B 直接做出功能最快看到成品风格未定，返工量大
C 先规格再定分步确认，风险小多一轮等待，时间长
对抗式审查：若选 B，风格争论会拖入施工，七个包重复改动的代价最大。故仍选 A。
从基本目标推导：目标是“一次做对”。决定不清时施工只会增加修改量。故选 A。

Q2 入口放在哪里

问题：入口放在 A 仅总管爱生活卡上，B 六家设置页每页各放一个，C 仅边栏功能页，还是 D 总管加边栏都要？

背景

你说的是“插件面板”，最接近的是总管爱生活卡。多处放置意味着多处维护同一份手册入口。

推荐答案

选 A：只在总管爱生活卡上放一个。

选项对比

选项优点缺点
A 仅总管位置唯一，好找，好维护在分页面时需回总管打开
B 每页各一个就近打开六处重复，样式走散
C 仅边栏使用时顺手未装边栏时没有入口
D 总管加边栏两处都方便两处状态需一致，工作量翻倍
对抗式审查：假设以后手册分家，A 只需在总管页加分组，不用改六页。故仍选 A。
从基本目标推导：手册只有一份，入口也应只有一处权威位置。故选 A。

Q3 手册讲哪些内容、多深

问题：A 七家都讲，只讲用法、细节链到各家帮助页面；B 只讲总管与打开方式，用一家做示范；C 七家全文搬进手册。

背景

各家已有帮助页面。手册若重复全文，两份内容会不一致；若太薄，则不值得单独做一卷。

推荐答案

选 A：七家都讲用法，细节用链接指向各家帮助页面。
选项优点缺点
A 讲用法加链接手册薄而全，不重复需定链接规则
B 只讲总管最快完成六家仍无指引
C 全文搬入一处看全两份重复，更新必错位
对抗式审查：C 在第二次更新帮助页面时即失效，无人能同时改两处。故排除 C，选 A。
从基本目标推导：手册的职责是带路，不是替代帮助页面。故选 A。

Q4 单页显示还是分页

问题：A 以单页完整显示为基础，翻页动效作为增强；B 必须分页，每页一屏，带舒展翻页动效；C 单页与分页各做一个原型，看后再定。

背景

你同时提到“单页完整展示”与“下一页舒展翻过去”。两者对排版与动效的要求不同，需先定基础。

推荐答案

选 C：各做一个原型，对比后再定。
选项优点缺点
A 单页为基础实现简单，阅读连贯内容长时翻页动效无处放
B 必须分页像纸质手册，有仪式感内容少时分页生硬，手机适配难
C 各做原型再定看到实物再选，不猜多花一个原型时间
对抗式审查：若现在锁死 A 或 B，手机窄屏或内容增减都会推翻决定。原型代价最小。故选 C。
从基本目标推导：排版只有看到实物才能判断阅读是否顺畅。故选 C。

Q5 风格如何定

问题：A 锁死为卷轴加 HELP 印章风格，不做其他；B 以该风格为起点，再做 2 到 3 个低保真原型比选；C 完全开放，不预设卷轴。

背景

你目前希望是卷轴与印章风格，但也愿意看其他方案。现有卷轴是点章弹出的三段式，与整本手册的体量不同。

推荐答案

选 B：以卷轴加印章为起点，再做少量原型比选。
选项优点缺点
A 锁死最快，与现有印章一致可能错过更合适的形式
B 起点加比选有比较，不走极端需评审时间
C 完全开放选择最多无起点，发散难收
对抗式审查：A 若整卷套用现有三段式外框，大内容会显得笨重；C 若无起点，评审无标准。B 保留一致又留比较。故选 B。
从基本目标推导：入口与手册应与现有印章一致，但手册体量不同，需看实物验证。故选 B。
