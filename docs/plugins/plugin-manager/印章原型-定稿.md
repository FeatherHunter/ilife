## 七、两条纪律

1. **章上极简**：章面最多一个词或一条 `产品名 HELP`。状态／人话／下一步一律进点击后弹出的卷轴，不写在章上。
2. **分级不靠放大**：三档尺寸字号完全相同，只换金属色、边线、铆钉与糙边程度。

## 八、渲染坑（踩过一次，务必记住）

**不要在整块牌面上挂 SVG 位移滤镜做纹理。** 曾用
`feTurbulence baseFrequency="0.02 0.9"` ＋ `feDisplacementMap scale=1.6` 压在整枚章上做木纹，
Chrome 把整个牌面渲染成彩色噪点／故障条纹，三档全糊，人打开即报「HTML 损坏」。

**规矩**：纹理一律用 CSS 叠层（多层 `repeating-linear-gradient` ＋ `radial-gradient` ＋ `linear-gradient`）。
糙边滤镜 `#roughA`（`baseFrequency=.9`、`scale=2.2`）经复验可安全使用，它是各向同性、幅度小，不会撕坏牌面。

### 9.1 外框一对一照抄章材质

不许把外框简化成"一圈金属色"。每档的**底色也要照抄**——技能银／金、HELP 金这几档章是**红底**，
外框就必须是红底，只把边线换成银／金。

| 章 | 外框底色 | 外框边线 |
| --- | --- | --- |
| 技能铜 | `linear-gradient(180deg,#8a4a28,#6e3418)` | `3px solid #a5652f` |
| 技能银 | `linear-gradient(180deg,#b73124,#8e1f14)` | `3px double #eef3f6` |
| 技能金 | `linear-gradient(180deg,#d34a35,#a32216)` | `3px double #f5d97a` |
| HELP 铜 | `linear-gradient(180deg,#b06a3a,#7e3f1d)` | `3px solid #a5652f` |
| HELP 银 | `linear-gradient(180deg,#8f979e,#5f666d)` | `3px double #e8eef2` |
| HELP 金 | `linear-gradient(180deg,#c63d2a,#a32216)` | `3px double #f5d97a` |
| 插件铜／银／金 | 同该档整面金属带 | 无（靠 `box-shadow` 描 1px 暗边）＋四角铆钉 |

插件三档外框加四角铆钉（11px 圆），铆钉配色与章的铆钉同源。

### 9.2 毛糙边

章与卷轴都挂糙边滤镜，但**不能共用同一条尺度**：小章上 `scale 2.2` 就够；
卷轴外框有几百像素宽，同一条会被稀释到几乎看不出。

- 章：`roughA` —— `baseFrequency .9`／`numOctaves 2`／`scale 2.2`
- 卷轴外框：`roughFrame` —— `x=-6% y=-6% width=112% height=112%`／`baseFrequency .9`／`numOctaves 2`／`scale 5`

滤镜只挂在外框那一层（`.frame`），纸不挂，否则纸的直边也会被抖。

### 9.3 结构与尺寸

- `.scroll`：`position:relative; border-radius:14px; padding:18px`
- `.frame`：`position:absolute; inset:0`，厚 18px 的材质，`z-index:1`，挂 `roughFrame`
- `.paper`：`position:relative; z-index:2; border-radius:4px`，背景 `#fdfaf2`，
  `box-shadow:0 1px 3px #3d241052, 0 0 0 1px #3d241024`（嵌进材料的凹陷感）
- 外框 18px 是下限：只给 10px 时整张卡会读成"白底加一圈边"，不像材料包着纸

### 9.4 内容与排版

三段固定顺序：**进展／状态／计划**。

- 标题居中，16px／字距 `.16em`
- 档位字：10.5px／字距 `.42em`／`text-indent` 同值（补偿字距造成的偏移）／颜色随档位
- 分隔：两侧渐隐细线夹一个 5px 菱形
- 段落标签：10.5px／字距 `.34em`／档位色
- 正文：13.5px／行高 `1.9`／字距 `.02em`
- 段间：`padding-top 15px` ＋ 1px 细线 `#ece1c9`
- 档位文字色：铜 `#9a5f2a`／银 `#6f767c`／金 `#9c7a16`

### 9.5 交互

点章弹出对应卷轴（`data-k` ＝ `角色-档位`），点遮罩或关闭按钮收起。
原型的三个区块：点章试弹／九卷轴对照／章↔卷轴外框一对一（最后一块专供材质核对）。

### 9.6 两条新踩的坑

1. **糙边滤镜的位移尺度要随元素尺寸调**。同一条 `scale 2.2`，在 120px 的小章上看得见，
   在几百像素的整框上等于没有。
2. **不要用「读取整个文件再整体回写」改长文件**。本仓读取会截断超长行：
   此前用它改 `seal-9-scrolls.html`（23862 字符），落盘只剩 9319 字符，页面下半截全空白。
   长文件一律用 `edit` 做定点替换，或直接用 `fs.copyFile` 复制；整份重出用生成器重跑。
