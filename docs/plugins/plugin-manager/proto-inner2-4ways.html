手册内页第二轮：四款版式对照（4 场景 ＋ 4 待定）

外壳与排版计划都不变（红＋金外框、页数与书签由 manual-plan.ts 算）；这一轮把旧款的零件（对话气泡／大序号／步骤链／路径签／朱红提醒／时间线圆点）搬到了新外壳上；不写「出错去哪」这类标签，提醒并进正文末尾。

A 对话式　这一页就是这一场景的对话：深蓝「你说」气泡 ＋ 米色「AI 回」气泡，文件名做成小签。手册教的就是对 AI 说话，一页一段对话。
B 卡片式　大号金色场景号 ＋ 虚线提要框 ＋ 步骤链（灰签 › 箭头）＋ 深蓝路径签，页脚一条朱红边提醒。零件最多，信息一眼扫得完。
C 时间线式　金线串朱红圆点，一步一个节点。步骤多的场景（IM 全流程）用它最顺，页脚一条细线收尾。
D 条目式　左边一枚米色方号 ＋ 标题，下面是虚线引用块与正文，页脚一行金线提醒。最安静的一款，像字典条目。
