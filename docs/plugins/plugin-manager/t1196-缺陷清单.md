**4 格全看过。**「一致」只有 D2 一格；D1／D3／M1 判「差异」，但差异全部落进 X1（字号不随纸宽派生）与**取景／外壳**两类——**没有一条**是「塌列、横向溢出、被藏起来的横滚、内部名字上屏」那类硬缺陷。

**一处容易被误报成缺陷的观感（先说明，免得后来人重开一条）**：**M1 格右侧那张原型图的下半是一片近黑**。那是**原型自带的深色舞台底色** `body{background:#15130f}`（`proto-manual-4scenes.html` 第 6／39 行），不是破图、不是渲染故障——原型在 390 宽下把整册缩到 187px 高（`window.__bookStats.fixed=187`），下面露出的就是它自己的底色；成品图底色是浅纸色，所以两张并排时显得「右图下半黑」。本轮已定向裁图确认（`t1196-证据.md` §5）。
