票 1194。你定了 4 个场景加弹窗，这稿把每节写成了可直接用的文字。依据：HELP 六主体、数据目录行（skill-bill/src/health.ts 361 行 db.dir）、IM 引用。

场景 1 基本使用：对 AI 说 xxx help

跟 AI 说一句“〈技能名〉 HELP”，比如“饼干记账 HELP”。拿到 HELP HTML 后打开，找到对得上的场景，把 prompt 复制出来发给 AI，等它执行。
去哪点：不用进设置页，直接在对话里说。
出错去哪：没收到文件，看回执里失败那一句；场景对不上，换个关键词再查一次 HELP。

场景 2 数据目录：自己备份，不加密

到配置面板找到“数据目录”，填好位置，这个技能的 db 文件就落在这里。备份自己做。我们不加密：密码一旦忘了，一手资料就永远找不回来。
出错去哪：面板告警只看 message 那一句，按它说的改目录或改权限。

场景 3 增强体验：装 IM 插件绑飞书

装上 dsh-im 和 dsh-im-companion，绑好 bot，推荐飞书机器人。配好后 HELP 和结果 HTML 直接在飞书 App 里看。
出错去哪：收不到消息，先看绑定还在不在，再看插件装没装上。

场景 4 增强流程：IM 全流程 8 步

飞书里发“xxx help”；dsh 生成 HELP HTML 并经飞书发回；打开找到场景，把 prompt 复制出来发给 AI；AI 执行完，结果 HTML 再经飞书发回来。
出错去哪：卡在哪一步，就查那一步的回执；HELP 的事回场景 1，绑定的事回场景 3。
