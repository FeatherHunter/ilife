## 场景 1 基本使用：对 AI 说 xxx help
做法：对 AI 说一句“〈技能名〉 HELP”（如“饼干记账 HELP”）→ 收到 HELP HTML 文件 → 打开找到合适场景 → 复制 prompt → 发给 AI → AI 执行任务。
去哪点：与 AI 的对话里直接说，不进设置页。出错去哪：没收到文件，看对话回执的失败一句；场景对不上，换关键词再查一次 HELP。

## 场景 2 数据目录：自己备份，不加密
做法：插件配置面板找到“数据目录”那一行 → 设到要存的位置 → 该技能的 db 文件落在这里 → 用户自己做好备份。
为什么不加密：密码一旦忘记，一手资料永远无法复原；备份在用户手里，丢了能找回。出错去哪：面板告警只看 message 一句，按它说的改目录或权限。

## 场景 3 增强体验：装 IM 插件绑飞书
做法：安装 dsh 的 IM 插件（dsh-im＋dsh-im-companion）→ 绑定 bot，推荐飞书机器人 → 配好后 HELP 与结果 HTML 在飞书 App 里打开，体验好。
出错去哪：收不到消息，先看 bot 绑定在不在，再看插件装没装上。

## 场景 4 增强流程：IM 全流程 8 步
1 飞书里发“xxx help”。2 dsh 接到指令生成 HELP HTML。3 dsh 经飞书发给用户。4 用户打开找场景。5 复制 prompt 发给 AI。6 AI 执行任务。7 结果 HTML 经 IM 发回。8 用户在飞书打开结果。
出错去哪：卡在哪一步，就查哪一步的回执；HELP 相关回场景 1，绑定相关回场景 3。
