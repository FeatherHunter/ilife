## 2 内容基数与形状

- 条目键固定 5 条、顺序固定：`contents`（目录）→ `basic`（基本使用）→ `datadir`（数据目录）→ `im`（增强体验）→ `upcoming`（待补充组）。
- 正文场景恰 3 个（`basic`／`datadir`／`im`），步骤数 **6／3／6**。
- 目录页由排版结果生成：一行一页，页码＝页序，待补充行右列写「待补充」。
- `upcoming` 是待补充组：`items` 恰 **5** 条（`待定 4`…`待定 8`），渲染成带锁 🔒 的锁页样行，行号取条目里的数字。
- 正文场景字段只有：标题、`kicker` 导语、`lead`、`steps` 步骤链、`tags`／`apps`（只作数据携带，不单独成行）、`frag` 片段、`shot`／`panelStatic`、`note` 备注、`warn`。
- **`frag` 全空**（三场景皆空）：不得为无文场景造复制按钮；有文片段才渲染复制并验成功／降级（#1242 纠偏 1）。
- **备注只有 `datadir` 有**（`note`）且渲染在正文末尾；`warn` 不渲染（不留字段名、不作出错总览）。
- 静态深色面板只出现在 `datadir`：`panelStatic: true`，面板内一处不可点。
- 步骤串里的签徽（`ctag` 路径签／`capp` 插件徽／`dbadge` 黑徽）与术语悬停（`po`）是**冻结原文的一部分**，逐字照搬。

## 3 口径（不做的事也在这里）

- **链接规则**：手册只写去向（去哪点、出错去哪），**不写 HELP 文件名与时间戳死链**；HELP 细节由 HELP 文件自己承载。内容里不出现 `href`。
- **废弃清单（6 项）**：①纸顶场景切换条；②缩略图点开大图；③HELP 死链写法；④出错总览独立场景；⑤旧版式与存档对照页；⑥其他待补充画法（旧待补充块 `.todo`）。成品里这 6 项一律不在场。
- **外壳冻结**：书签、铜扣、中缝、纸面按定稿，不在本规格内改动（外壳演进另开票）。
- **文本外置**：冻结的是中文列文案；加一门语言加词条文件、不改代码；英文列另起，不在本规格内定稿。
- **分层**：内容数据（`manual-content.ts`）与排版计算（`manual-plan.ts`）分离；界面只读排版结果，不自算页码。
