总管爱生活 · 使用手册

1 基本使用

对 AI 说一句“〈技能名〉 HELP”，比如“饼干记账 HELP”。
拿到 HELP HTML›打开找场景›复制 prompt›发给 AI 等执行

不用进设置页，直接在对话里说。没收到文件看回执里失败那一句；场景对不上换个关键词再查一次。

2 数据目录

到配置面板 › 数据目录填好位置，这个技能的 db 文件就落在这里，备份自己做。

我们不加密：密码一旦忘了，一手资料就永远找不回来。

面板告警只看 message 那一句，按它说的改目录或改权限。
