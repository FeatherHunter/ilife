## 二、改了什么

1. **取值面换家**（`nav.ts` ＋ `client.ts`）：面板拿「包名 → 本家客户端通道」不再走页签槽条目的自定义 options 格，改走总管自己那张各家表。为什么这么改，写在 `nav.ts` 的 `ManagerTab.channel` 头上：各家注册时**也**交了一份通道名，但装机槽位面不透传自定义注册选项（条目 options 只留 `{key,id,order,label,priority}`），总管读那一格恒是空串。
2. **镜子收口**（`dsh-ctx.ts`）：读侧（`SlotLedgerEntry.options`）删掉 `channel` 一格；写侧（`SlotsRegisterOptions.channel`）留着并注明原委——上游哪天开始透传自定义选项，可以一行切回账本。六家注册里那一格**没删**（同理由）。
3. **两态分开说**（`health-view.ts`）：汇总行的尾巴改成「N 家没有体检出口」；一家出口都没有时直接给红字那句「没有可体检的家：N 家都没有体检出口（通道名没登记上）」；有出口的全绿但有没出口的家时不再冒称「六家正常」，改成「有出口的都正常」。这样屏幕上不会再出现「按钮哑着、字却写『还没体检』」这种自相矛盾的态。
4. **两条判据**：`test/plugin-p10-boundaries.test.mjs` 新增跨包对齐门（真 import 六家 `dist/contract.js` 与总管 `dist/nav.js` 逐家比，另断通道名是单段路由名）；`packages/plugin-manager/test/health-706.test.mjs` 新增「两态不许同话」（含混合态把「几家没有出口」数出来）。
