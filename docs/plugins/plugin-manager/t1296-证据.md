方法：`t1296-render-entry.mjs` 从编译产物取 `manualEntryCss()` 并把 `ManualEntryButton` 元素树序列化成 HTML（不手抄 CSS/DOM），渲成 360×260 两页——浅底 `#EFF9FF`、深底 `#1e2126`（宿主深色面板观感值；规格未指定具体深色值）——用 headless Chrome 截图；`t1296-analyze-band.py` 用书封 1px 金边 `#d9ab3c` 定位书体矩形，量书体外 2–4px 三带：左 `x∈[left-4,left-2]`、右 `x∈[right+2,right+4]`（两带取 `y∈[top+8,top+24]`，避开腰封左右各外伸 4px 的轮廓与腰封自身那条保留阴影）、下 `y∈[bottom+2,bottom+4]`（`x∈[left+8,right-8]`）。
