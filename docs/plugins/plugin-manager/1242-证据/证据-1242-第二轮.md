## 9 操作留痕（本轮踩到并已修掉的两处坑，供后来者照抄）

1. **`.cmd` 必须写 CRLF**：本轮首发的 `gate5-shots.cmd` 是 LF 行尾，`cmd.exe` 读错行（把 `setlocal` 读成 `ocal`、`set EV=…` 读成 `EV=…`），导致 `%EV%` 为空、**6 张 PNG 落到盘根 `D:\`**。已把落错位的 6 张移到 `.scratch/t1242-r2/stray/` 作废并清空盘根；重写为 CRLF 后重跑，本目录内的 PNG 全部来自干净那次。教训：批处理一律 CRLF，且路径尽量写死不用变量。
2. **验收台的开关读 URL 查询串**：`manual-1195-page.js` 第 220–221 行读的是 `window.location.search`，不是注入的 `window.__Q`。不加查询串时 `go=-1`，页面走的是「跑全套断言」那条路、最后停在尾跨页——本轮首拍由此得到两张都停在尾跨页的图（与首轮 `made-1280-s2.png` 逐字节相同）。正确写法是本目录 PNG 名里那两种 URL：`stage-0.html?shot=1`（首跨页）、`stage-2.html?shot=1&go=2`（尾跨页）。
