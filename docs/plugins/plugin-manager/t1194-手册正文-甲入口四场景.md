## 本轮交付：proto-manual-4scenes.html

从用户给的技术清单里**挑**了这些进手册（不是清单，是为内容服务的）：

| 挑中的技术 | 在手册里干什么 |
| --- | --- |
| 液态 TAB | 纸顶一条场景切换条：基本使用／数据目录／增强体验／增强流程，指示条拉长再落位，点一下跳到那页 |
