## 五、过程中逮到的一件事（与本题相关，记下来免得复用踩坑）

`node:assert/strict` 子模块里，**`assert.notEqual` 绑的竟是不严格的 `notStrictEqual`**：
两个不可比的值之间（`'#0a84ff'` 对 `'var(--dsw-alias-label-secondary, #9a9a9a)'`）会退化成 NaN 比较，
`NaN != NaN` 判真 ⇒ **明明相等也不抛**。本轮变异 732-B 第一次就是因此假绿（测试报 24 绿，实际那个不变量已经不成立）。

实测（Node v24.19.0）：

```js
import assert from 'node:assert/strict';
assert.notEqual.name;                    // 'notStrictEqual'
assert.notEqual('#0a84ff', 'var(--x)');  // 不抛（!!）
assert.notEqual('#0a84ff', '#0a84ff');   // 抛 AssertionError
```

本票规避：新断言一律写 `assert.ok(a !== b, '…')`，并在断言旁留了注释说明为什么不用 `assert.notEqual`。
顺手改掉一处**假的恒真断言**：本件原先 `assert.deepEqual(Object.keys(lights[1]).sort(), [...])` 用的那种写法没问题，
但同源取色那处（本件自己抄了一份 `STATUS_COLOR`）导致「改源码里的色值」在这件里看不见——已改成从 `dist/health-view.js` 直接 import。
