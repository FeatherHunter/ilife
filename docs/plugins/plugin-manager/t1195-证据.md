## 二 · 结构设计

`src/manual-plan.ts` 对外**正好五样**（铁律五上限五）：

| 对外 | 形状 | 干什么 |
| --- | --- | --- |
| `ManualScene` | `{ key, title, state: 'written' ｜ 'pending' }` | 一个场景＝一页；`pending` 就是「待定」 |
| `ManualPage` | `{ page, key, title, side, state }` | 当前跨页的某一页 |
| `ManualSheet` | `{ sheet, front, back, facing, side, tabOffset }` | 一张纸：正反面页码 ＋ 这次露出的那一面（书签印的号）＋ 书签离中缝多远 |
| `ManualPlan` | `{ spread, spreadCount, pageCount, pages, sheets, tab }`（6 格） | 一次排版的结果 |
| `planManual(scenes, spread)` | 函数 | 唯一的干活入口 |

命名按铁律四：面板入口叫「使用手册」→ 能力名 `manual`；子功能 `plan`（排版）。本包是平铺 `<能力>-<子功能>.ts` 的写法，不新建目录层级；只碰 `manual` 一个能力。类型里的 `SceneState`／`Side` 是**不导出**的内部别名，只定义一次（铁律二）。

## 三 · 写代码

- **页**：一个场景一页 → 页数＝场景数 → 跨页＝⌈页数/2⌉（至少 1）→ 纸＝⌊页数/2⌋+1。
- **书签**：一张纸一个；正面印偶数页、反面印奇数页；翻过去时它跟着纸从右半转到左半，号码同时换成反面那一页。
- **收窄**：纸数一多，书签、字号、圆角与间距**一起等比缩**，缩小倍数取「排得下」（最外那枚不越过中缝→纸边的 49%）与「不放大」里小的那个；跌破 3% 时 `tab.overflow` 置真，界面据此可换画法。
- 常量只写一处：`TAB_WIDTH/TAB_HEIGHT/TAB_FONT/TAB_RADIUS/TAB_FIRST/TAB_PITCH` 全在 `manual-plan.ts`，界面通过读结果拿数、不再各写一份。
