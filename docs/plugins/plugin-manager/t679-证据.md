## 七、边界：本件替代不了什么

渲染台物化的是**真产物**（stub loader ＋ classic 执行，与 `test/client-bundle-48.test.mjs` 同套）、跑的是**真组件**、**真点了六个页签**；但它用一份 hooks 替身渲成静态 DOM，**不过 DSH 的槽位渲染、不跑 React 自己的调和与事件系统、不点链接**。它证明：版式（标题不被挤、折行位置、无横向溢出）与结构（卡在最底、六页签都在、悬停文案在、四行齐全）。它**不**证明：真机上点星／气泡／外链真的能打开网址——那条已由用户裁决换成对抗式审查（第四节）。
