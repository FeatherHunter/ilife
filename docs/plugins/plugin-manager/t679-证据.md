## 四、边界：本件替代不了什么

渲染台是**版式**证据，不是真机证据：

- 它物化的是真产物（stub loader ＋ classic 执行，同 `test/client-bundle-48.test.mjs` 那套），跑的是**真组件**；但用一份 hooks 替身渲成静态 HTML，**不过 DSH 的槽位渲染、不跑 React 事件系统、不点链接**。
- 因此它证明「标题在两宽下不被裁、两件折行位置正确、卡片在最底且在六页签切换下都在」，**不能**证明「真机上点星／气泡／四个外链真能打开对应网址」。后者是票面第 1 条验收，属真机（本仓先例：真机截图归维护者，见 `docs/research/t123-release-runbook.md:965`）。
- 140px 那一档只是**机制页**（证明 `flex-wrap` 真会把两件折到标题下方、且极窄也不横向溢出），远窄于任何真实设置弹窗；真机窄窗读数请以 360 档为准。
