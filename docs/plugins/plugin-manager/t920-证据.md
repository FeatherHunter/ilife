## 5 与 v3.1 的 5 处已知不同（逐条给理由）

1. **值列左对齐**（票面文字写的是「右对齐」）。v3.1 全件**零 `text-align`**，渲图里值就是左对齐、行尾才是那枚「复制」。票面同一条又说「视觉真源只有一件…逐项照搬」，故按真源取左对齐，**不自加一条真源里没有的规则**（那是「重新设计」）。—— 父席已确认这一条按我的判读走。
2. **字号一律 em（真机上比 v3.1 的 px 大 12 %）**。跨包锁 `#739` 钉死「零 `font:` 简写／零字族／字号一律相对单位」且逐项钉死 7 个值，票面又把「跨包锁的判据文字」列进不许动。故沿用锁里那两对锚点换算（**1px＝0.08em**），一个取值不丢。**真机实测宿主基准字号＝14px**（`baseFont=14px`，标题渲成 15.12px、值 12.32px），而锚点隐含的基准是 12.5px ⇒ 真机上每一档都比 v3.1 的 px 大 12 %。**这一格是「照锁」与「照 v3.1 的 px」唯一的正面冲突**，修法两条（改锁那 7 个锚点／或在共用件里钉基准字号）都会动别的票的判据，本票不动，如实记账。
3. **三样「内联样式画不出来」的**用等价形态顶上：分组箭头 `::before` → 真字符「›」；`[open]` 的 90° 旋转 → 不转；`@keyframes ic-sp` → 静态环。形状与位置同，只少了那点动。父席已同意。
4. **吸底取 `bottom:0` 而不是 `6px`**。v3.1 唯一的吸底口径是 `.ic-attnbar.is-sticky{bottom:6px}`（那是它那条琥珀告警条的），`.ic-bar` 本身不吸底；票面要的是「底栏三键贴下沿吸住」，故取 0 与下沿齐平。另有一条**真机事实**要记：真机里面板卡片只是设置窗滚动体里的**一块**（后面还有「体检」「作者其他插件」），`position:sticky` 被容器边界夹住 ⇒ 记账这一家卡片比可视区矮，底栏停在卡片下沿（`rectBottom=599`，滚动体可视下沿 900）。真要看「吸住」那一档，得卡片比可视区高（`states`／`window-bottom` 两处渲图里有：底栏钉在下沿、内容从它后面滚过去）。
5. **④那一档的字面**：v3.1 写「已保存 · 刚刚」，「刚刚」是演示里的时刻；本件取档名「已保存」。⑤那一档（值非法回落）本件**有档位、没有生产者**——它要「技能侧交出『这个值用不了』这件事实」（#915 第二步），在那之前恒不亮，与票面「遗留出口」一字不差。

## 12 #920 补 · 跟随行按 `.ic-under` 缩进（父席收活后点名的那一处形状差）

**要修的**：v3.1 的只读跟随行住在 `.ic-under` 里（相对它的可改行缩进、左边一条线），本件当时是平铺的 ⇒ 与真源差 21px 横向。

**怎么拿到的静态关系**（不改六家一个字节）：六家交的 `followKeysOf` 钩子是**纯函数**（各家只做「脏键里有没有这一格」那一下判断），把行表里的键**逐个当脏键喂进去**，返回的就是「谁跟着它」——与当刻脏不脏无关。于是：

```ts
export function followerKeysOf(items, hook) {            // packages/plugin-manager/src/config-panel.ts
  if (hook === undefined) return [];
  const out = new Set<string>();
  for (const item of items) for (const key of hook([item.key])) out.add(key);
  return [...out];
}
```

`config-panel.ts` 算出这份名单交给 `PanelBody`，`Row` 在只读那一支按它挑缩进样式。**六家的 `src/**` 一字未动**（用的是它们已经交出来的那个钩子）。

**取值照抄**：`.ic-under{margin:9px 0 0 8px;border-left:1px solid var(--ic-line-strong);padding-left:13px}` ⇒ 新样式项 `followerRow`／`followerRowLast`：`marginLeft:8` ＋ `borderLeft:1px solid --dsw-alias-border-l2` ＋ `padding:'7px 0 7px 13px'`（后半段是 `.ic-row` 自己的 `padding:7px 0`）。缩进合计 **8＋1＋13＝22px**。

**一处形态差别（如实记）**：`.ic-under` 在 v3.1 里是**一整块**——同一个可改行的一批跟随者共用一个 div、共一条左边线、块首还有 9px 上边距；本件按**行**落（钩子只回一个去重后的并集，回不出「这一行归哪一块」的分块归属）。故缩进量与左边线同值，**块首那 9px 上边距不落**（落下去会在每两行之间多出一道 9px 的缝）。
