### 1. 「纸张四周和红框之间有空隙」

结论：颜色上纸早就贴到红框了；用户看到的「空隙」是纸面里还留着的**内边距**（`.paper` padding 20px／22px、页面还有 20px 内侧留白），也就是内容能用的范围到不了红框。

处置（把所有「纸没真正铺到红框」的可能一次清干净）：

### 2. 「右侧是第 2 页、反面是第 3 页时，2 和 3 这个标签要随纸一起往左翻」
上一版是「每页一个书签」，于是 2 和 3 是两个位置不同的书签 —— 翻页时书签会跳位。这一版改成**一张纸一个书签**：
- 第 1 张纸：第 1 页（书签永远在左）；
- 第 2 张纸：正面第 2 页／反面第 3 页，书签离中缝 115px；
- 第 3 张纸：第 4 页，书签离中缝 185px。

翻页时书签写在翻转的那张纸里（正面印 2、反面印 3），于是它跟着纸从右半转到左半、号码同时从 2 变成 3。

实测：静止 = 1（左）、2 与 4（右）；翻一次 = 3 与 1（左）、4（右）。

**代价**：同一时刻顶上是 3 个书签（1、2|3、4）——第 3 页的号码印在第 2 张纸的反面，翻过去才露出来。若要「4 个书签始终并排」，书签必须固定在书壳上、不随纸走，与这一版是两种做法。

## 用户第七、八轮反馈与处置

1. **「太小了，可以随比例等比例变大变小吗」** —— 比例机制保留，基准比例整体放大一档：
   - 书签宽 4.2% → **5.9%**、高 3.7% → **4.3%**、字号 1.4% → 1.9%、圆角 0.65% → 0.9%；

   - 纸面 1080px 时书签 64×46（原来 45×40），露出书外 28px。

2. **「上一页／下一页不能换行，也可以等比例变小」** ——
   - `.brass` 加 `white-space:nowrap` 与 `flex:none`，标签永不断行；
   - 按钮与页码牌的字号、内边距、圆角、三件之间的间距，全部改成按纸面宽度算（字号 `--paper-w*.0125`、内边距 `.0065/.015`、间距 `.009`）；
   - **字号加了下限**：按钮 `max(12px, …)`、页码牌 `max(11px, …)`，内边距与间距同样有下限 —— 否则 560px 窗口下字号会掉到 6px，看不清。
