## 现象与根因

维护者 2026-09-20 点屏指出：六个技能设置页里，**第一条字段标题（如「数据目录」）离它上方那条分隔线的距离
不一致**，且正好 3 : 3。

根因（源码读数）：`rows` 容器——画那条分隔线的块——六家一致（`marginTop: 8` ＋ `borderTop` ＋ `paddingTop: 8`）；
分叉在它下面的字段行样式 `row`：

| | 备忘·卡路里·记账 | 作息·居家·大厨 |
| --- | --- | --- |
| `row` | `{ marginTop: 10 }` | `{ marginBottom: 10 }` |
| 首行标题离分隔线 | 8 ＋ 10 ＝ **18px** | 8 ＋ 0 ＝ **8px** |

行与行之间两种写法数值相同（都是 10px），所以差别**只出现在第一条字段标题上方**——正是维护者框住的那一处。

截图逐像素量（卡路里页，1px 边框占 2 图像 px ⇒ 2× 缩放）：卡片上边框 y=93.5、分隔线 y=282.5、
「数据目录」标题字上沿 y=328 ⇒ 45 图像 px ÷ 2 ＝ 22.5 CSS px ＝ `rows.paddingTop 8 ＋ row.marginTop 10 ＋ 行高半余约 4`，
与「卡路里属 18px 那一支」吻合。

血统：作息·居家·大厨三家的页出自 2026-09-17 `afe8f1ed`（三插件接页签槽）立的骨架，再由 #696「照大厨样板」铺开；
卡路里出自 #676（`6f14876b`），记账 #677 与备忘随后抄的是卡路里那一支。两支各自自洽，对拍这一环没人做。

## 改法（维护者裁定「甲案」：六家对齐到作息·居家·大厨那一支）

口径两条：**尺寸与间距**（`margin`／`padding`／`borderRadius`／`gap`／有无边框）一律取甲案；
**取值形态**（主题别名与回退值的写法）取六家 `card` 已在用的那一族（`var(--dsw-alias-*, 中性回退)`）。

| 样式项 | 目标值 | 谁改 |
| --- | --- | --- |
| `row` | `{ marginBottom: 10 }` | 备忘·卡路里·记账 |
| `hint` | 二级灰 `#9a9a9a` ＋ `marginBottom: 4` | 备忘·卡路里·记账 |
| `info` | 单行写法（`color` 在前） | 备忘·卡路里·记账（只调写法，语义不变） |
| 高级组 | `advanced: { marginTop: 12 }` ＋ `summary`（去掉上分隔线与 `paddingTop`） | 备忘·卡路里·记账 |
| `bar` | `{ display:'flex', gap:8, marginTop:12, flexWrap:'wrap' }`（去掉 `alignItems`） | 备忘·卡路里·记账 |
| `btn`／`btnPrimary` | `padding:'4px 12px'`、圆角 6 | 备忘·卡路里·记账 |
| `error`／`okText` | `marginTop: 8`；`error` 带 `whiteSpace:'pre-wrap'` | 备忘·卡路里·记账 |
| `input` | 补 `boxSizing:'border-box'`（缺它时 100% 宽＋内边距＋边框会顶出容器 18px） | 作息·居家·大厨 |
| `btnPick` | 统一一条（甲案那一支自己还分两态：居家 `var(--dsw-alias-bg-base, #fff)`／作息·大厨 `transparent`） | 作息·居家·大厨 |
| `btn`／`btnPrimary` 的 `background`／`color`／边框色 | 取别名那一族 | 作息·居家·大厨 |
| `okText` 的色标 | `var(--dsw-alias-state-success-primary, #12805c)` | 作息·居家·大厨 |
| 样式表上方注释 | 加一行「六家逐项同形，改任一条要六家一起改」＋锁的出处 | 六家 |

**`okText` 为什么不照抄甲案字面**：甲案写的是 `var(--dsw-alias-label-success, #12805c)`，而宿主
（`D:\0Tools\DSH Desktop\resources\app`）里搜不到 `--dsw-alias-label-success` 这个别名 ⇒ 会退回深绿 `#12805c`，
在深色主题下看不清。`--dsw-alias-state-success-primary` 宿主自己有（`dsh-client-ui-primitives` 在用），故取它。
同理 `error` 的 `--dsw-alias-label-error`（宿主自己的设置页就用它渲染 invalid／failed 文字）保留。
