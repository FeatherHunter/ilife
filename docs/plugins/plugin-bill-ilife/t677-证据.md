## 四、一处改造与两处读数教训

**一处改造（守边界本意，不是绕门）**：本包**原先没有定时器**；设置页要「不转圈」就得有超时，而 P10 的冻结断言规定「单品 src 里出现计时器就要有清理 ＋ 次数上限 ＋ 例外依据三件套，唯一允许的计时器是 sidebar槽注册有界重试」。设置页等的是一次 RPC 回执、不是轮询，所以改成借平台 `AbortSignal.timeout` 的 abort 事件做**一次性**超时拒绝——不自建计时器，边界的本意（无数据轮询）与「不转圈」两处都落到实处。

**教训一**：那道门是**按源码文本**匹配 `/setInterval|setTimeout/` 的，连**注释里提到**这两个词也会命中。第一版整改把「不自建 `setTimeout`」写进了注释，门因此继续红；改掉字面才回绿。

**教训二**（与 #676 同）：变异探针必须在改完源码后**重建**再跑测试——测试读的是 `dist/`，只改 `src` 量到的是假绿。
