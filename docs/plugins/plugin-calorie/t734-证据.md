## 这条链怎么解决「纯 DSH 机器上会话没有 node」

工具在**宿主进程**里执行：`run_calorie_command` → `resolveNodeBin(process.execPath)` → spawn 技能入口。宿主进程自带运行时（Electron 宿主＝该二进制加 `ELECTRON_RUN_AS_NODE=1`；出处见 `src/bridge.ts:169-178` 的 #48 真机根因注释，面板取数今天在任何机器上都这么跑）。**会话 PATH、系统 Node 都不在这条链上** —— 判据②就是它的机器读数。
