## 二、提取候选（**未做**，等收尾裁定）

1. **端口件**（`contract.ts` 的 `SavePayload`／`parseSavePayload`／`ConfigSurfaceReply`／信封三件）——四家逐字同形，是最实的候选：可提为公共层「设置面端口」一件，四家各自只留通道名与端点名。
2. **设置页行表骨架**（`ConfigItem` 类型 ＋ `readPath`／`writePath` ＋ 分级常量）——四家同形，行表内容各自留。
3. **配置页组件**（`Row` ＋ 稿换算 ＋ 报错人话 ＋ 三态框架）——版式同形、文案不同，可提为「设置页组件」一件。

## 三、为什么本票不提取

- 公共层新增面要按 `docs/agents/structure.md` 与 `docs/agents/doc-homes.md` 走一遍归属裁定（哪个包收、对外面开几个名字），属**设计动作**；票面把它明确定为「攒到本图收尾统一裁」。
