
「新进程再读」＝ `spawnSync(node, ['-e', …])` 起一个全新 node 进程再 import 同一个 bridge 读一次——宿主重启后要面对的就是这个局面：值不在内存里、只在盘上。探针跑完把改过的那一项**还原**，不留痕。（自检口径 `--self-test` 用临时 `ILIFE_CONFIG_DIR`，同样 PASS。）
