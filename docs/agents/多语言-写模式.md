# 改写器写模式（`tooling/i18n-write.mjs`）——能写什么、写不了什么

日期 2026-10-08；归属 #1233 写模式；工具版本与实现住 `tooling/i18n-codemod-write.mjs`。

## 1. 写模式的定位

它只做**机械那一半**：把扫描器（v1）认出的 `copy` 类字面量换成过渡调用 `__E('i18n-<区段>.<n>')`，
并把词条按**该文件出现顺序**落进 `packages/<包>/src/entries/i18n_<区段>.zh.ts`（值＝原字面量逐字节相同）
与 `.en.ts`（英文列本轮留空串＝待译；空串走回退链取 zh，故不启用多语言时产物不变）。

**它不做**：`__E → 条目层调用` 的接线（语言透传、渲染消费方、各技能的 `--language` 用到渲染点）。
那一步归各迁移票——写模式跑完**不等于**迁移完成。

## 2. 它能写什么（自证钉住的四条）

- 只动 `copy` 类：注释里的中文、拼接串（`'合 ' + n + ' 折'`）、命令键（`bill.record.add`）**一根头发都不碰**；
- 中文列逐字节相同：zh 表里那一行的值＝改写前源码里的字面量，逐字符相同；
- 幂等：把改写后的文本再跑一遍，已无可写（第二遍 `--write` 的 `files=0`）；
- 有备份：写前把每件原文存到 `.scratch/i18n-codemod-backup/`（首次覆盖才存）。

读数：`node tooling/i18n-write.mjs --selftest` → 四条自证 OK。

## 3. 写不了什么（隔离树实测，2026-10-08）

在 `D:\ilife-wt-writecheck`（HEAD 的隔离工作树）上跑过全量 `--write`：**959 件／13,723 条**，
随后 `tsc -b` 在**冻结面**红 —— 这是全仓铺开时必须先知道的判据，逐条记在这里：

1. **冻结的类型契约会被打断**：`packages/base-render/test-d/contract-signatures.ts` 的 `_V07`–`_V12` 逐条红
   （`ACTION_BAR_DEFAULTS`／`STATUS_DEFAULT_TEXT`／`LOG_SECTION_TITLES`／`LOG_UNKNOWN_PLACEHOLDER`／
   `TEXT_EMPTY_PLACEHOLDER` 等）。原因：契约锁的是**字面量类型**（`'复制数据'`），而 `__E('key')` 的返回值
   被推断成 `string`（过渡垫片写成 `<K extends string>(key: K) => K` 也一样）。
   ⇒ **过渡垫片救不了它**：字面量类型只对真字面量成立，对计算值必须另有机制（把类型也一并声明，或让过渡调用只**替换值位、不替换类型位**）。
2. **所以按票铺开时的第一条判据**是：先跑 `tsc -b` 与自己那片的门，**再**看产物；`--write` 之后不许直接进下一步。
3. 逐段的顺序建议：一个票一段（`--only <包>` 目前只到包粒度，票内范围靠 `tooling/i18n-scope.json` 的 files 与人工挑选）；
   每段跑完立刻 `pnpm build` ＋ `pnpm gate:i18n` ＋ 本片的中文列读数，再进下一段。

## 4. 全量读数的用途

`node tooling/i18n-write.mjs --dry` 给出「全仓会有多少件被改、共多少条」＝ **迁移票工作量的机械下界**：
959 件／13,723 条（对照 #1233 扫描器台账：copy 18,842 条、concat 12,635 条只标红不改）。
差额（18,842 − 13,723）就是「同值去重后剩不下机械可写」与「非单行／非字面量」那部分，要人工。

## 5. 跑法

```bash
node tooling/i18n-write.mjs --selftest              # 四条自证（不落盘）
node tooling/i18n-write.mjs --dry [--only <包>]     # 只报会改哪些件、各写几条
node tooling/i18n-write.mjs [--only <包>]           # 真写（先备份）
```

写完必须做的三件：`pnpm build` 绿、`pnpm gate:i18n` 绿、本片的中文列读数（`pnpm snapshot:html:check` 的 zh 列／
`node tooling/calorie-html-snapshot.mjs --check`／`node packages/base-render/scripts/i18n-pilot-1202.mjs --check`）逐件同值。

## 6. 过渡调用名的约定

`__E` 是**临时**落点：迁移票把它换成条目层调用时，顺便把 `globals.d.ts` 那样的临时声明删掉。
仓内至今**没有**任何源码用 `__E`——写模式在本轮只交付工具与判据，铺开按票走。
