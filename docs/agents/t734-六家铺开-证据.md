## 铺开时的四处偏差（统一口径，逐家一致）

1. **身份串替换不止四处**：除文件头技能名、`SKILL_TOOL_NAME`、`TOOL_DESCRIPTION`，另把参数表 `key` 的说明与「缺 key」报错里的 key 例子一起换了（例如 `calorie.*` → `bill.*`）。理由：这两处直接进模型的参数表与报错报文，留着会把别家的命令教给模型。
2. **测试的路由断言按各家 `RPC_CHANNEL` 改**（`/api/ilife-calorie` → `/api/ilife-bill-ilife`／`/api/ilife-chef`／`/api/ilife-home-ilife`／`/api/ilife-memo`／`/api/ilife-schedule-ilife`），不改必红；桩夹具仍用卡路里桩包（纯回显，不碰真技能包）。
3. **`ctx.effect?.(...)` 写成可选调用**：bill／chef／home／schedule 四家的 `SkillHostCtx.effect` 是可选面（卡路里那份是必选），照抄裸调在 strict 下编不过。
4. **镜像注释的出处写法**：chef 那席发现参照件引的「cookbook §14」在 `docs/agents/dsh-client-contract.md` 里尚不存在（现只到 §13），本包注释改为直接写出真出处（`@deepseek-ai/dsh-tools/lib/index.js` 的 `defineTool`／`ToolRuntime.register`）。**该缺章待补**（不属本票）。
