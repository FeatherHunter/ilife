## 目标

票面写死三样（并落一份口径件）：

1. **目录**：页面产物落 `<库目录>/biscuit_accountant_html/` 根，还是另起子目录（HELP 今天的落点就在同一目录，主体是 `饼干记账_HELP`）。
2. **文件名主体通式**：候选 A＝新通式「技能名_页名」，如 `饼干记账_查区间_<戳>.html`（与卡路里／作息／居家同形）；候选 B＝沿用老实物的名字，如 `查区间_<戳>.html`（用户在老技能里看惯的名字）。时间戳与同秒递补由共用件 `base-paint/save-html` 加，不自己拼。
3. **与 HELP 分家的写法**：页面与 HELP 产物互不覆盖靠什么（目录分家还是主体前缀分家），以及同参数重复调用走「同秒 `_N` 递补」还是「复用窗口」。

一并裁一句措辞：`packages/skill-bill/SKILL.md:134` 现在写着「其它 15 条命令的 `--html` 语义不变（仍写收据页）」——补上缺省支之后这句怎么改（正解应当是：`--html` 仍是显式覆盖写，只是不再是落页的唯一出口）。

## 验收命令

判据＝定稿能把实现票的路径断言填成可原样执行的命令：

```sh
node -e "const {existsSync}=require('node:fs');console.log(existsSync('<库目录>/biscuit_accountant_html/<主体>_<戳>.html'))"
```

把 `<主体>` 与目录换成定稿写死的值之后，这条现在跑**假**（盘上没有这份文件），实现票落地后跑**真**。填不出可执行路径（例如主体还要运行时才知道的字段、或落点依赖未定的配置键），视为未定稿、票不退。
