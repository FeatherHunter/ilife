## 三、与票面五条判据的对应

判据按**结果**断言（看 stdout 与盘上那份文件），不按机制（不查源码里有没有调交付件）。

| 票面判据 | 本件判在哪 | 不合时打的字样（自证逐条咬过） |
|---|---|---|
| ① stdout 顶层有 `delivery` | `judgeDelivery` 第 1 步 | `无 delivery（顶层只有 …）` |
| ② `delivery.path` 是绝对路径 | 第 2 步（缺 `path` 也归这一档） | `delivery.path 不是绝对路径`／`delivery.path 缺失（mode=…）` |
| ③ 该路径的文件存在 | 第 3 步 | `盘上没有这个文件` |
| ④ 文件字节数 ＝ `delivery.bytes` | 第 4 步 | `字节不等：盘上 <n> ≠ 回执 <m>` |
| ⑤ 内容是整页（含 `<html`） | 第 5 步 | `不是整页（正文不含 <html）` |
| （本件多加一道隔离守卫）落点须在本家隔离家目录内 | 第 6 步 | `落点越出隔离家目录：<路径>` |
| （命令本身要跑起来） | 第 0 步 | `命令未过 exit=<n>` |

「多一道隔离守卫」写进判据的理由：若某家把页落到隔离家目录之外，这一跑就可能动过真实数据目录——
那不是「交付面不合」而是「这一跑不可信」，必须当场现形（票面「不许动的东西」第 2 条）。

## 四、没被做成开关的东西

- **没有 `--only`／`--allow-red` 一类缩面开关**：本仓门禁的既定口径是「缩面＝放宽」（见 `check-warning-line.mjs`／
  `check-scene-shape.mjs` 的同一句话）。要单跑一家，直接跑那家的唯一出口即可，本件不提供「只跑几家也算过」的口子。
- **`--judge <文件>` 只给自证与变异用**：它判的是**一份落盘的 stdout**，不跑技能；真实判据一律无参运行。

另按票面要求给出该家「写出来是什么」的辅证：同一条命令加 `--html <文件>` 时**盘上确有文件、但内容是片段**——

（即票面那句「写出来是一个 `<section …>` 段、且不回 `delivery`」；原始日志 `.scratch/t904/aux.log`。）

**备忘**：该家挑不出「空库退 0 的库内命令」——库层**禁 DDL**、库文件不在即抛（`MEMO_DB_MISSING`），
实测连写命令都一样拦：`memo.search`／`memo.remind`／`memo.wish`／`memo.detail`／`memo.data.schema`／

仓里没有可用的样本库文件；在探针里手写 DDL 会把判据绑死在库结构上，结构一动探针先红——
那是假红，不是交付面缺陷。要判读键那一条，得另起一票带样本库的准备步骤，不在本件范围内。
