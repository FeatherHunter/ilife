## 4 import 与边界红线（动工前必读，每条都是机械门）

1. 单品插件**可以** import 公共层（唯一允许的跨包形态）：`plugin-chef/src/client.ts:27-29`。
2. 单品插件**禁 import 任何 `base-*` 包**（正则只认 `from 'base-…'`）：`test/plugin-p10-boundaries.test.mjs:52`
   ⇒ 新共用件放进 `base-*` 包或起名 `base-*`，这门当场红。
3. 单品插件禁 import 技能实现，只经唯一出口 `spawn`：`p10:48-56`。
4. 插件侧「装上插件＝技能装好」＋按 `bin` 解析入口＋`resolveNodeBin`，不读 PATH：`docs/agents/技能调用契约.md:27-30`。
5. 总管**禁依赖单品、禁 import 单品**（依赖面＋源码面双锁）：`p10:26-29`、`:42-47`。
6. 总管只导航，不 import 技能实现、不直调内容渲染：`p10:165-170`。
7. **设置页归属单品包，总管不许有 `src/settings.ts`**：`p10:160-164`——本次抽件的落点判据。
8. 技能包禁反向依赖插件：`p10:201-206`。
9. 插件之间没有专门门禁（p10 里 0 条）；通则：**共用位里不许出现任何一个能力的名字**（`structure.md:70`），
   共用件要「写得出哪两个能力在用、从第二个用法里长出来」（`structure.md:71`）。
10. 包门只许收窄：对外名＝`src/index.ts` 转出的名字 ＋ `package.json` 的 exports 键（`structure.md:17-19`）。
11. 若落点改成 `base-*` 包：消费方声明的下界必须逐字等于仓内版本（`tooling/check-base-floor.mjs`；`ci.yml:51-55`）。

## 6 DSH 本体对齐要点（读的是打包产物，非源码仓）

1. **控件层已有共享包**：`@deepseek-ai/dsh-client-ui-primitives`（纯 React 原子：`Button`/`Switch`/`Input`/`Menu`/
   `Pill`/`Tag`/`StateDot`/`ConnectionIndicator`/`DisclosureRow`/`Modal`/`Tooltip`/`Toast`/`JsonTree`/`MarkdownText`/
   `CodeBlock`/`TerminalBlock`/`DiffBlock`/`icons`…）。README 原话：**「插件无法 import 另一个插件的组件，
   因此本包是控件唯一可以共享的地方：合适的就复用，有意的视觉差异提升成 prop，而不是另起一份拷贝。」**
   第三方插件 `dshmarket` 真的在用（117 处 `primitives.Button`）。
2. **兄弟件共用同一个面板的既定做法**：共同依赖一个契约包 ＋ 各自 register 到同一槽位；并且**允许一个包替
   别的包渲染卡片**（`dsh-client-ui-settings-plugins` 用一个 `PluginCard` 给 bash／agent-loop／subagent／
   web-search 四个别的包托管设置卡，`lib/client.js:1785-1808`）。
3. **本体没有「技能设置页」这一槽**：`settings.*` 只有 12 个 key；六家注册的是 `settings.plugins.tab`
   （`kind: "list"`），挂在总管声明的 `children` 下。
4. **本体对插件 CSS 没有任何规矩或守卫**（`styles.insert` 只校验「是字符串」）⇒ 「不许 `font` 简写／不许字族／
   字号一律 em」这三条是**本仓自己立的锁**，去留不必迁就本体。
5. **主题扩展点** `ctx.theme.overrideTokens(source, { '--dsw-alias-…': { light, dark } })`：source 被强制成包 id，
   值必须双主题，层可叠可撤；`--dsw-static-*`（原值）与 `--dsw-alias-*`（语义）两层都定义在同一张内联
   `design-platform.css` 的 `body`／`body[data-ds-dark-theme]` 四块里。
6. **没有导航守卫这种约定**：未保存的现状是「每张卡自己脏 ＋ 表头一枚 `unsaved` 标记」
   （`settings-plugins/lib/client.js:190,242-246`），切页签直接卸载（`settings-general/lib/client.js:169-171,197`）；
   「切页签不丢状态」靠 `ctx.resources.pin`。⇒ 公共层若做草稿守卫，那是**新增约定**，不是对齐既有约定。
