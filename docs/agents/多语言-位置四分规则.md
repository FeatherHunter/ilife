# 位置四分规则（#1233 改写器 v1，tooling/i18n-codemod.mjs）

日期 2026-10-08；归属地图 #1197；工具版本 1.0.0（规则变更即 bump，台账带版本号可复现）。

## 1. 四分是四种处置，五位是五个位置

票面「版式位／标题位／数据位／载荷位／标识符位」是位置，「四分」是处置。映射：

- 标题位＋载荷位中有文案 → 整句化→词条调用（写模式，待 #1200 接口，v1 只分类不断言可写）
- 数据位 → 数据常量化（v1 只标候选，落常量需人工判归属，见 §4）
- 拼接串（前缀＋变量＋后缀）→ 只标红不改（红单 tooling/i18n-codemod.redlist.json）
- 标识符位＋版式位＋派生件＋命令关键字 → 不动

机器七类（台账 byClass）：copy 文案候选／data 数据位候选／ident 标识符不动／cmdkey 命令冻结／derived 派生件走生成器／payload 事实源整体迁移／concat 拼接串标红。

## 2. 抽取口径

- 范围 v1：packages/*/src/**/*.ts（1697 件，与 ADR-0004 的 1697 件逐件对上）。
  不含：包内 scripts、test、templates/*.html、SKILL.md、docs（后续轮次扩范围，见 §5）。
- 分词器：单遍扫描，行注释／块注释剔除（注释中文不收），单双引号串（含转义），模板字面量（跟踪大括号深度，含插值记 hasExpr）。
- 只收含 CJK（汉字＋日假名＋全角形）的字面量；纯 ASCII 不在抽取面内（命令关键字全 ASCII，天然面外——cmdkey 类保留给含中文的键，当前为 0）。

## 3. 分类顺序（先命中先得， fixtures 逐条钉死）

1. 模板插值 → concat；2. 派生文件名（generated／cli registry-keys／helpAssets／sceneData／helpShell）或头含机器生成标记 → derived；3. 头声明事实源（唯一事实源／逐字落地）→ payload；4. 命令键形／版本号／路径文件名形／已知 HELP 主体／落点目录主体行（_STEM／_DIR_／DIR_／_PATH／PATH／EXT 均要求词边界，小写 system／TEXT 常量／NEXT 不触发）→ ident 或 cmdkey；5. 加号拼接（同行／跨行上／跨行下，见 §4）→ concat；6. 纯数字带单位 → data；7. 余下 → copy。

## 4. 已知近似（召回边界，如实登记）

- 同行多语句：标题串与算术加同处一行时，要求加号必须挨着字符串占位才判红；已加反例（标题＋x+1 不红、s+=后缀红、注释加号不红）。
- 跨行链只看上下各一行；断成三段以上的需人工补。
- 纯字面量相加（两串直接相加）保守标红：机器不知切分是否有语义，人清。
- 裸单位（无数字的元／个）不断数据，留 copy 待人工；版本号／路径／STEM 精确命中才不动。
- 数据常量化不停机理：常量放哪家是归属判断（铁律二），机器只标候选，由迁移票人工落。

## 5. 台账与红单

- tooling/i18n-codemod.ledger.json：范围、类定义、工具版本、totals（files／literals／byClass）、逐件行（path／literals／byClass）。行列式：无时间戳，路径排序，跑两遍逐字节同。
- tooling/i18n-codemod.redlist.json：count＋逐条（path／line／reason／snippet≤120字），按 path:line 排序。
- 未覆盖范围（下轮）：scripts、test、templates、SKILL.md；英文列账本另起（门禁 #1199）。

## 6. 只读副本跑法（验收第一条的执行形状）

1. 跑前对 scope 内全部文件取 sha256 指纹；2. 在副本上跑 --scan（scan 只读 packages，只写 tooling 两份 JSON）；3. 跑后指纹比对相等（本轮实测指纹 4f8b2655f7717da74f61c6071c7be9d2 前后相等）；4. 台账跑两遍一致。产物逐字节不变由构造保证（无 writeFile 进 packages，grep writeFileSync 本件即验）。
- 写模式绿证程序（待激活）：副本上跑整句化写→重构建→主账本 snapshot:html:check＋calorie 基线 check 双绿；任一红即回滚。激活条件：#1200 词条接口冻结＋#1202 试点载体裁决。
