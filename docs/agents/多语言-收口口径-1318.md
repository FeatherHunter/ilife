## 2. 不迁理由更正：#1220／#1224 的 `help/manifest.ts`

- 事实：两件都是**手写常量**，不是生成件。`packages/skill-home/src/help/manifest.ts` 导出 `DEFAULT_HELP_DIR_NAME='home_manager_html'`、`HELP_FILE_STEM='居家管家_HELP'`、`LOOKUP_FILE_STEM='居家管家_速查表'`；`packages/skill-chef/src/help/manifest.ts` 导出 `HELP_FILE_STEM='私家大厨_HELP'`、`LOOKUP_FILE_STEM='私家大厨_速查表'`、`DEFAULT_HELP_DIR`。ledger 各记 `literals=2`、`byClass.ident=2`；`packages/*/scripts/*.mjs` 无生成器写它。
- 更正后的理由（替换 JSON 里现有「生成件：…」文本）：手写常量（非生成件）：HELP／速查文件名主体（ident 2 条）与落点目录默认名；文件名主体按 #1235:8 冻结不译（`docs/agents/多语言-文件名裁决.md:8`），是产物文件名不是显示文案，故不迁。
- 边界：`tooling/i18n-ticket-scope.json` 不在 #1318 写集（与 `tooling/i18n-scope.json` 同属共享清单），替换文本由 Lead 串行落地；票面评论即更正记录。
