# #1199 门禁改造：迁移票验收命令回填清单

本文件是 **#1199 门禁改造**的产物之一：给 **28 张迁移票**（地图 #1197 的子票）回填「改完这一件，该跑哪几条命令、看哪几行读数」。
口径依据：`docs/adr/0004-多语言文本外置.md` §6「门只锁结构与行为，不锁文案字面」，以及 `docs/agents/结构纪律`（`docs/agents/structure.md`）。

## 0. 一句话形状

| 层 | 唯一定义地 | 谁读它 |
|---|---|---|
| 语言闭集与缺省语言 | `packages/base-link-core/src/config/language.ts`（产品侧） | 门不 import 它，只按 `tooling/i18n-langs.mjs` 的 `LANGUAGES` 对账 |
| 语言列账本路径与排印名册 | `tooling/i18n-langs.mjs`（门侧） | 各门 `import`，不各写一套 |
| 已迁入词条层的文件清单 | `tooling/i18n-scope.json`（状态账号本） | 缺词条门 ＋ key 残留门 |

**中文列＝存量路径**（文件名不带语言段），**英文列＝`<主体>.snapshot.en.json`**。语言身份由**文件名**承载，账本正文一个字段都不加——加字段就是改字节，就是破坏「中文列逐字节不变」。

## 1. 迁移票开工前 / 收尾各跑什么（逐条命令＋看哪行）

### 1.1 未声明差异为零（每张迁移票必跑）

```
pnpm snapshot:html:check        # 中文列 194 件账本：看 COLUMN zh / RESULT / changed / added / removed 三行
pnpm snapshot:html:check --lang en   # 英文列：看 COLUMN en recorded=<n> 与 PENDING 行
node tooling/i18n-anchor.mjs         # 改造前锚（#1199 S8）：基线此刻是否仍与已提交 git 对象逐字节一致
```

- **中文列**：`changed=0 added=0 removed=0` 才算「未声明的差异为零」。任何一件变都要在票面**先申报**。
- **英文列**：`recorded=<n>` 是**已记**的偏离件数，`PENDING` 行表示「英文列还没有对照读数」——那不是绿，也不是红，是「还没有英文页」。
- **改造前锚（S8）**：`tooling/i18n-anchor.json` 逐件记 `{path, commit, blob, sha256, bytes}`。`--check` 用 git 复核三件事：① `git rev-parse <commit>:<path>`＝锚里的 blob（锚指向的历史对象真存在）；② `git cat-file blob <blob>` 的 sha256／bytes＝锚里的值（锚的摘要真来自这个对象）；③ 工作树文件的 blob sha＝锚里的 blob（这一件此刻与改造前逐字节一致）。读数形状：

```
ANCHOR tooling/skill-html.snapshot.json commit=746123ff blob=854872a30611ecf7372721c6c8c62aa18b88d45a sha256=c3477e474a7aa216… bytes=117875 worktree=clean
ANCHOR tooling/calorie-html.snapshot.json commit=b7966d40 blob=f044b24d463f12797ad7880ae163676929f2ae9d sha256=3e18b00d43761c41… bytes=915 worktree=clean
ANCHOR packages/skill-bill/test/t689-页面指纹.json commit=e5d056cb blob=3150621e5e11e7bbb193275a10bc450ae671c900 sha256=d9f3d0281b1e5dee… bytes=4170 worktree=clean
RESULT: anchors=3 verified=3 drift=0
PASS: 3 件改造前锚与已提交 git 对象逐字节一致（锚不是自录的：commit:path→blob 由 git 复核，摘要由 blob 内容复核）
```

改坏必红（实测）：工作树改一字节 → `RED [ANCHOR-WORKTREE-DRIFT] … blob=f4159692… 改造前锚=f044b24d…（差异未声明）` `RESULT: anchors=3 verified=2 drift=1` exit=1；改锚里 sha256 一位 → `RED [ANCHOR-SHA-MISMATCH]` exit=1；还原 → `verified=3 drift=0` exit=0。锚数据由 `--write` 生成（改锚是显式动作，改完在票面申报原因）。

### 1.2 calorie 列（只对卡路里线的票）

```
node tooling/calorie-html-snapshot.mjs --check          # 中文列 2 件 ＋ 英文列读数
node tooling/calorie-html-snapshot.mjs --write          # 重录中文列（显式动作；中文列数值不许动）
node tooling/calorie-html-snapshot.mjs --write-en --en-artifacts <英文列读数.json>   # 重录英文列记录
```

读数形状（#1199 实测）：

```
OK calorie/help-html c2affdec09d7303618ac28d61f75fde9/354208
OK calorie/help-meta 5b3d8322d35e2416cb78fe9cfaffdde8/137
COLUMN zh  artifacts=2 ledger=tooling/calorie-html.snapshot.json
COLUMN en  recorded=0 ledger=tooling/calorie-html.snapshot.en.json（0 件＝待录入…） 待对照=2（没有英文列对照读数）
PENDING: 英文列 0 件（骨架已立、无记录可比）：这不是「英文页通过」，是「还没有英文页」。
RESULT: calorie 基线一致（2 件；英文列 recorded=0）
```

**英文列另起** `tooling/calorie-html.snapshot.en.json`，与主账本英文列**同形**（`lang`／`basedOn`／`records`，只记**偏离中文列**的产物）：

- `records={}` 合法（0 件＝待录入）；门显式印 `PENDING` 与 `recorded=0`，不当绿也不当红；
- 记录的 `sha256` **必须 ≠ 中文列同件**（相等＝没记＝空转绿，`loadEnColumn` 直接抛）；
- 英文列**对照读数**入口：`--en-artifacts <文件>`（`{ "<id>": { "sha256": "<32hex>" } }`）。给了它，门才判「英文列漏记」；没给＝待对照。
- 正／反读数（#1199 实测）：给对照读数且 `calorie/help-html` 偏离 → `FAIL: 英文列有 1 件产物偏离中文列却没录入英文列账本（漏记＝假绿）` exit=1；`--write-en` 记进账本后 → `recorded=1 未录入=0` exit=0；还原空列 → exit=0。

> ⚠ #1199 顺手修掉一处**入口判据缺陷**：`tooling/calorie-html-snapshot.mjs` 原本用 `endsWith` 配正则归一化路径判入口，Windows 上 `process.argv[1]` 是反斜杠全路径 ⇒ 判据恒假 ⇒ 脚本静默 exit 0、**一行输出都没有**。现改成 `fileURLToPath(import.meta.url) === process.argv[1]`（与 `tooling/skill-html-snapshot.mjs` 同形）。

### 1.3 两道新门（每张迁移票收尾必跑）

```
node tooling/check-i18n-entries.mjs     # 缺词条门：看 SCOPE/TABLES/RESULT 三行（RESULT 末段 blanks= 必须 0）
node tooling/check-i18n-params.mjs      # 占位符门：看 PACKAGES/RESULT 两行（mismatch= 必须 0）
node tooling/check-i18n-keys.mjs        # key 残留门：看 SCOPE/RESULT 两行
```

- 范围为空时两道门都印 `EMPTY-SCOPE 范围 0 件：扫描面为空——缩面＝放宽，不许空转当绿` 并 exit 0；**这个读数必须贴进证据**。
- 迁移票把**本票改完的件**逐条写进 `tooling/i18n-scope.json` 的 `files`，两道门才开始真判。
- 空白词条＝缺词条：`RED 空白词条：语言 <lang> 的表 <path> 里 key <key> 的值是空串／纯空白`（#1306）。这与 `packages/base-entries/src/resolve.ts` 同口径——空白值按「未录」跳过该站，不许当「显式空白」上屏。
- 占位符门判**同一包内同一条 key 在各门语言里的 `{name}` 集合必须相等**（#1306）：少一个参＝值里留 `{name}` 原文上屏，多一个参＝`MissingParamError` 直接抛；只缺语言列不判红（覆盖缺口归缺词条门）；只有一门语言的包显式报数（没有跨语言可比的同 key，不许当成「比过没问题」）。读表口径与缺词条门共用 `tooling/i18n-tables.mjs`（同一包同一语言的多份表里 key 重复＝读不出，直接红）。
- 「有词条」按**件所属包**判（#1199 S10）：本包 `packages/<pkg>/src/entries/<lang>.ts|json` 表 ∪ 本文件**显式 import 的别包 catalog**。相对 import 落进 `…/entries/(index|<分册>).js` 时解析到那个包，并核对那个包的 `src/entries/index.ts` 真导出了这个 catalog 标识（拼错／指错包＝失明，直接红并点名标识符）。判不出归属（仓库根夹具件只 import `base-entries`）才回退跨包并集并显式说明；同一 key 跨包各自有值＝兼容（各包表里有就算有），不是重复。
- 残留（`RED 文案残留：<文件>:<行> [<语言>] ...`）不许往 `allowlist` 里塞——那是放宽。
- 范围清单的 `allowlist` 是**两道门共用**的豁免清单（#1205；#1320 改为「文件＋字面量」）：`check-i18n-keys.mjs` 拿它放过「语义上本就不该进词条」的残留；`check-i18n-entries.mjs` 拿它把**被误认成消息 key 的非文案串**（协议字段值，如复制载荷里的 `record.add`）从「该进词条」判据里剔除——抽取阶段就剔，不是判红后再放过。
- **一条豁免只放行它登记过的那件文件里的那一个字面量**：同一串（如 `日期`）在数据位登记过、在界面位再出现时照旧判红（#1320 修复的盲区；`--selftest` 有「同串两用」变异钉住）。禁止再写纯字符串清单。放行只许是「命令关键字冻结／用户可见文本不译的用户数据／派生件／唤醒词路由键」四类，且必须在 `tooling/i18n-scope.json` 里逐条登记（带 `why`）；真残留不许靠它变绿。落点也要可复核：登记的文件必须真在 `files` 清单里，否则门直接红（`tooling/i18n-allowlist.mjs`）。
- key 残留门的英文列对**内联脚本行**放行（#1205）：随页内联的 JS 片段（同时出现花括号与分号／等号，或箭头函数）不是给读者看的句子；同一行里的中文**照旧判红**（中文列不适用这条）。


- `structural=<n>/<n>`＝本工具**真判**的结构约束条数／名册里**声明**的条数。没判的三条（noWrap／touchTarget／boxModel）在行里逐条标「本工具未判」，不假装判过。
- `readings=<n>/<n>`＝文本列有读数的语言数／声明语言数；`text=<n>`＝判过的差异行总数（zh＋en）。

**版式读数基线**：既有版式夹具里已有 1 处与结构约束冲突的读数（`甲-02-待办清单.html@390` 的 `outOfBounds=1`），在 `tooling/check-typography-langs.mjs` 的 `FIXTURE_BASELINE` 里**逐条登记为存续债**。台面上新出现的读数＝红（新债不许静默进来）；基线里有而台面上没有的＝红（债还清了要显式改基线）。

**语言列文本读数（S5：英文页在排印门下不再整批红）**：门读 #1202 读数基座（`packages/base-render/scripts/i18n-pilot-1202.mjs` 的 `collectAll`——固定 now、零随机、产品自己渲染的 4 件产物 × 2 语言），**只判两列逐行差集**（语言列改写过的那几行；两列相同的行是夹具数据，判它等于判夹具），按各语言名册判 `SEP`／`HALF-PUNCT`／`BARE-LATIN`／`SCRIPT-MISMATCH`（非基准语言里出现汉字＝这几句没译）。判据实现在 `tooling/typography-text.mjs`。

- 数据位先归一（日期／时间／记录号／AI 走名册 allow，数字含千分位与小数换成占位符），否则中文页的「1,189」会被判成半角逗号（实测 9 处假红）。
- 一件产物两列逐行相同 → `TEXT SAME-TEXT`（help 壳不吃语言参数，正是如此）：显式报数，不判也不当绿。
- **反事实行** `TEXT COUNTERFACTUAL en@zh`：把英文列按中文名册再判一遍——改造前就是这个形态，所以整批红（10/10）。改造后按英文名册判只剩 3 条真债（英文页尚未把单位「卡／毫升／千克」迁进词条表）。
- **文本读数基线** `TEXT_BASELINE`：3 条真债逐条登记（`611 卡 to go`／`800 毫升 to go`／`Over by 2.4 千克`）。新债必红、基线里消失也必须红（还清要显式改基线）。

**语言无关的结构约束**（所有语言同一套，不许按语言放宽）：不溢出／不换行／最小字号下限／可点面积下限／盒模型 4px 栅格。
**语言相关的书写阀值**（每种语言一套，出处 `tooling/i18n-langs.mjs` 的 `LANG_REGISTERS`）：并列分隔符集／并列段长上限／半角标点集／允许清单／是否判裸拉丁词／字号下限。

## 2. 语言列接口契约（给迁移票与门作者）

### 2.1 账本文件

| 语言 | 主账本 | calorie 账本 |
|---|---|---|
| `zh`（缺省，基准） | `tooling/skill-html.snapshot.json`（194 件，逐字节冻结） | `tooling/calorie-html.snapshot.json`（2 件） |
| `en` | `tooling/skill-html.snapshot.en.json` | `tooling/calorie-html.snapshot.en.json` |

英文列账本形状（**记录形**，只记偏离中文列的产物，不做同哈希全量复制）：

```json
{
  "lang": "en",
  "basedOn": "tooling/skill-html.snapshot.json",
  "readonlyUntilMigrated": true,
  "artifactCount": 0,
  "records": { "<产物 id>": { "sha256": "<32hex>", "bytes": 123, "note": "为什么偏离中文列" } }
}
```

三条完整性判据（本门自己判，违反即红）：

1. 键集必须是中文列 `artifacts` 的**子集**（英文列不许凭空多产物）；
2. 记录的 `sha256` **必须 ≠ 中文列同件**（相等＝没记＝空转绿，`loadLangColumn` 直接抛）；
3. `lang` 与 `basedOn` 必须显式写对（不许沉默地指向别的账本）。

### 2.2 词条表（缺词条门的输入）

| 项 | 值 |
|---|---|
| 目录 | `packages/base-entries/src/entries/` |
| 文件名 | `<lang>.json`（`zh.json`／`en.json`；加语言＝加一条 `LANGUAGES` 名册＋加一个文件） |
| 形状 | 顶层对象，键＝词条 key（`<命名空间>.<名字>`），值＝该语言的词条 |
| 调用形态 | 源文件 `import` 词条层（模块名含 `base-entries`），按 `e('ns.id')`／`t('ns.id')`／`ent.t('ns.id')` 取词条 |

> ⚠ 词条包本体归 **#1200**（`packages/base-entries`）。本文件里的目录／调用形态是**门侧的读取契约**；#1200 冻结接口后若形状有出入，改的是 `tooling/check-i18n-*.mjs` 的读取口径与本文，**不是**把清单挪走。

### 2.3 已迁入清单（状态账号本）

`tooling/i18n-scope.json`：

```json
{
  "files": ["packages/skill-bill/src/...ts"],
  "allowlist": [
    { "files": ["packages/skill-calorie/src/weight/review.ts"], "texts": ["日期"], "why": "数据位：写进库的机器键（ADR-0004 数据不译）" }
  ]
}
```

- `files`：**已迁完**的仓库相对路径（正斜杠）。范围为空时两道门显式报「范围 0 件」并 exit 0。
- `allowlist`：逐条豁免记录 `{ files, texts, why }`（#1320 起；唯一实现是 `tooling/i18n-allowlist.mjs`）：
  - `files`：仓库内相对路径数组；精确路径（`a/b.ts`）或目录前缀（`a/b/`，只在整目录都是派生件时用，能写精确路径就不写前缀）；
  - `texts`：该文件里**逐字全等**的字面量数组；同一串在别的文件不生效；
  - `why`：为什么不迁（数据位／派生件／命令关键字冻结／唤醒词路由键…），一句话说清；
  - 校验 fail-closed：旧纯字符串数组、未知字段、空 `files`/`texts`/`why`、绝对路径、反斜杠、`..`、同一文件同一串重复登记 → exit 2；登记的文件不在 `files` 清单里 → 红。
  - 迁移器 `tooling/i18n-migrate.mjs` 按同一份记录逐件取豁免（`allowlistOf` 返回记录、`migrate()` 按件传给 `planFile`），别在别处另写一套匹配。
