# 过渡调用接线样板（#1233 写模式之后那一步）

日期 2026-10-08；归属 #1233（写模式）与 28 张迁移票共用；状态：样板（未关任何票）。
试点依据：#1202 两处硬缝（packages/base-render 的 progress-list 与状态徽章）已落地，读数 8/8、中文列逐字节不变。

## 0. 一句话

写模式只产过渡形 __E('i18n-区段.n') 与按区段落的双语词条表；迁移票把它换成 resolve(目录, 语言, key, 参数)，并把语言从命令行透传到渲染点。
写完不等于迁完，接上语言才算。

## 1. 语言从哪来（#1198 已通的链）

argv --language / --format-language → parseArgs（各技能 src/cli/args.ts，只摘不判） → resolveLanguageOrFail（各技能 src/cli/language.ts） → base-link-core resolveSkillLanguage（唯一判定地） → ResolvedLanguage { text, format }

- 配置文件 language.text／language.format（空串＝跟随调用方，最终回退 zh）；
- 未识别值 exit 1 并列出可用语言（zh、en）；
- 渲染点只吃 text（文本语言）；format 只给日期数字（formatDate/formatNumber）。

调用方偏好（宿主设置 locale.preference）本轮不传，正式接线归 #1198。样板按显式 argv 透传写，不假设 RPC 下传可用（#1230 已证不可用）。

## 2. 词条表放在哪（#1200 冻结、#1202 试点形状）

每包三件，与 base-render 同形：packages/<包>/src/entries/zh.ts（基准语言，值逐字等于改造前字面量）、en.ts（英文列，缺英文先留空串并在票面记英文待译）、index.ts（defineCatalog）。key 第一轮用派生命名，拼错编译期红。加一门语言＝加一个词条文件，不改代码。

## 3. 三种调用形态的换法

### 3.1 整句模板（含插值）——首选
改前禁止三段拼：'还差 ' + value + unit。先整句化（票面预先申报原句到模板，第二方逐处比对），再进词条。词条 zh 值为 '还差 {value}{unit}'，调用点用 sentence(language, 'progress-list.remain', { value, unit })，模板只认 {name} 具名占位；缺参抛 MissingParamError。

### 3.2 状态闭集到 key 常量表（#1202 第二处硬缝同形）
STATE_WORD_ID 逐格写死 blank/on-track/done/over 四格到 progress-list.state.*，as const satisfies Record<状态, MessageId>，拼错编译期红。取值用 resolve(目录, language, STATE_WORD_ID[state])。

### 3.3 写模式过渡形到条目层调用（本样板核心一步）
写模式产出 __E('i18n-demo.1') 与临时声明。迁移票两步：1. 删过渡声明（含 globals 那类临时声明，用完即删）；2. 换成目录调用并补语言入参：resolve(SKILL_CATALOG, language, 'demo.greeting')，language 缺省 zh（不给＝既有形状，中文列逐字节不变）。注意冻结面：若字面量同时是类型契约的字面量类型，过渡调用会拓宽成 string 而 tsc -b 在冻结面红，此时先改类型声明或直接按 3.1/3.2 整句化。判据先跑 tsc -b 再看产物。

## 4. 渲染点的语言入参（不启用多语言时逐字节不变）
按 attrs.ts / model.ts 同形：入参加可选 language?: string（BCP 47，不给＝既有形状）；常量派生视图仍从 ZH 取，保证不传语言时与改造前逐字相同；传语言时走 resolve（缺词条走回退链 请求语言 → zh → en，全缺抛 MissingMessageError）。

## 5. 迁移票的收尾四条（与票面验收命令同序）
1. 登记范围：改完的件逐件进 tooling/i18n-scope.json 的 files（咨询清单 tooling/i18n-ticket-scope.json 先行，挂号才受判）；2. 两道门先红后绿：check-i18n-entries（missing=0）与 check-i18n-keys（residue=0）；3. 中文列逐字节不变：pnpm snapshot:html:check 中文列 changed=0 added=0 removed=0，页面范围另跑 pilot --check 8/8；4. 英文列另起账本：文件名按文件名裁决，偏离项只记 snapshot.en.json（同哈希不许记）。

## 6. 本样板不做什么
不改命令关键字（冻结）、用户数据（不译）、文件名主体（冻结）；不做 747 全覆盖唤醒词（首轮 30 条，路由按语言只加载一套）；不碰宿主 Node 侧翻译接口（#1230 已证无此面）；拼接串只标红不改（红单 concat 12,635 条），整句化逐处人工加第二方比对。
