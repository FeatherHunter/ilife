# 文件名与语言裁决（#1235）

- 日期：2026-10-08；归属：地图 #1197；本票只裁决不改代码（既有产物落点目录与测试断言一行不动）。
- 现状（逐字）：HELP 文件名主体全是代码常量中文主体——`饼干记账_HELP`（bill `helpFile.ts:27`）、`卡路里_HELP`（calorie `photo/helpFile.ts:31`，另有 `卡路里_照片HELP` `output.ts:43`）、`私家大厨_HELP`、`居家管家_HELP`（home `manifest.ts:34`）、`备忘录_HELP`、`作息管家_HELP`（schedule `helpFile.ts:32`）。配置项已退休（bill `html.helpStem` #762、schedule `files.help` #764），调用方不接受传入。落盘通式 ` <主体>_<YYYYMMDD_HHMMSS>[_N].html`（bill `cmd_read.ts:65`、calorie `output.ts`）。业务页主体按中文 command（calorie `chineseCommandFor` 取 `CALORIE_COMBOS[key].title`，sanitize 后 32 字）。

## 裁决

1. **HELP 文件名主体冻结，不随语言变**：六个中文主体是落点标识符（同命令关键字冻结），不译。语言只进文件内容与 `<html lang>`。
2. **英文产物以 `_en` 后缀区分，中文缺省无后缀（存量逐字节不变）**：新通式 ` <主体>[_en]_<TS>[_N].html`；业务页 ` <中文command>[_en]_<TS>.html`（command 部分仍用中文注册表 title，不译，只加 `_en`）。中文无后缀即“未声明的差异为零”；英文加后缀即“声明过的差异”。
3. **逐字断言按语言参数化，不共用同一 equal**：现有断言全部锁定中文列（无后缀）；英文列另起账本。中文基线数值（194 件快照、bill 44 张指纹、calorie 基线 #1234）一个字节不动。

## 被否方案

- A 主体随语言翻译（如 `饼干记账_HELP → Biscuit_HELP`）：否。翻译无权威源；外部引用（fixtures/help-instances 要求文件名逐字一致、复用窗口 `HELP_REUSE_STEMS`、delivery 回执路径）全断；中英账本无法对齐存量。
- B 中英分目录：否。落点目录（`html.dir`）是库结构，改目录等于改库结构；同目录＋后缀更小，且清理/去重仍按主体聚类。
- C 英文也无后缀（靠内容区分）：否。同一目录中英并存时用户与程序都无法一眼区分，复用窗口会把中文 HELP 顶掉英文 HELP。

## 切到英文后同一目录看到什么（回答票面问题）

- 以饼干记账 `biscuit_accountant_html/` 为例：存量中文文件不动（N 个 `饼干记账_HELP_<TS>.html`）；新增英文文件 M 个 `饼干记账_HELP_en_<TS>.html`。业务页同理（`<中文command>_en_<TS>.html`）。用户按 `_en` 一眼区分；程序按后缀＋内容 `<html lang>` 双判。
- HELP 与速查表分名不变（速查主体另行冻结，同样加 `_en` 区分）；`卡路里_照片HELP` 同样冻结，加后缀形状为 `卡路里_照片HELP_en_<TS>.html`。

## 受影响的门与断言改造点（实现由对应迁移票承接，本票只列清单）

- 落盘命名：各技能 `help/helpPaths.ts`、`help/output.ts`、`help/manifest.ts`（`helpFileStem()`＋`deliverHtml`）——加语言后缀参数，缺省中文无后缀。
- 复用窗口：calorie `output.ts:200 HELP_REUSE_STEMS`、`helpReuseWindowOf`（base-paint/save-html）——按语言分窗口（中文复用不顶英文）。
