## 5 算式改动

改前：

```ts
return fieldText(envelope.skill) + '.' + fieldText(envelope.key) + '（' + shape + '）';
```

改后：

```ts
const skill = fieldText(envelope.skill);
const key = fieldText(envelope.key);
const head = skill !== '' && key.indexOf(skill + '.') === 0 ? key : skill + '.' + key;
return head + '（' + shape + '）';
```

要点：`skill` 为空不判前缀；前缀比对只认同一 `skill`（`skill-b` 配 `skill-a.key` 仍拼为 `skill-b.skill-a.key`，见新断言第三段）。

## 6 负向断言（新增 1 条）

位置：`test/text.test.mjs` `scene 段恒由 envelope 派生` 之后。

内容三段：

1. 已带前缀：`skill-a` ＋ `skill-a.key` → `skill-a.key（receipt）`，且不得出现 `skill-a.skill-a.`。
2. 不带前缀：`skill-a` ＋ `key` → `skill-a.key（receipt）`（仍补足）。
3. 前缀须同源：`skill-b` ＋ `skill-a.key` → `skill-b.skill-a.key（receipt）`（不误剥）。
