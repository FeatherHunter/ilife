票面：[#693](https://github.com/FeatherHunter/ilife/issues/693)（`bug` ＋ `ready-for-agent`，Agent Brief 在同票评论里）。
一句话结论：**修好了**——改动面是共享 HELP 模板里的一行（运行时给提示栈补上定位样式所用的类名），
加上重跑的生成物与一条新回归用例；六条新判据全绿，变异自证红／绿两态分明，六家消费面 40 例全绿。

## 一、现象与复现

用户报告：HELP 页面点复制按钮，底部不出提示，只能隐约看到一点黑边。

复现件用**真实渲染出口** `base-paint/help-shell` 出页，再在页尾追加一段触发脚本（load 时点一次页面自带的
复制按钮 `.copy-btn[data-c]`，走的是页内全局委派 → `doCopy` → `showToast` 这条真路径；之后每 3.5s 再点一次，
好让截图时提示仍在屏上）。生成器 `t693-repro.mjs` 随本件入仓，可复跑。

| 态 | 短页（24 场景） | 长页（96 场景，滚到底） |
| --- | --- | --- |
| 修前 | 视口内**看不到任何提示**：`t693-复现-短页-修前.png` | 提示卡落在文档流末尾，被固定底栏盖住，**只露一点黑边**：`t693-复现-长页-修前.png` |
| 修后 | 悬浮在视口底部、居中、完整可见：`t693-复现-短页-修后.png` | 同样悬浮，压过固定底栏、不被遮挡：`t693-复现-长页-修后.png` |

截图口径：headless Chrome，视口 1280×800。

## 二、根因

提示栈的定位样式按**类名** `.hm-toast-stack` 下发：

```
.hm-toast-stack{position:fixed;left:50%;bottom:calc(24px + env(safe-area-inset-bottom,0));
                transform:translateX(-50%);z-index:9999;…}
```

而运行时创建栈元素时只写了 `id`：

```
stack = document.createElement('div');
stack.id = 'hm-toast-stack';          ← 修前：只有 id，选择器对不上
stack.className = 'hm-toast-stack';   ← 修后：补上定位样式所用的类名（id 保留做兼容）
```

两者对不上 ⇒ 那条 `position:fixed` 从未生效 ⇒ 栈按普通块级元素排在文档末尾：短页在首屏之外，
长页滚到底被固定底栏（`.tab-bar`，`z-index:600`）压住，只剩深色卡上沿一条黑边。这与用户描述逐条对上。

同源的副产物（一并被这一行修好）：`@media (prefers-reduced-motion: reduce)` 里那条
`.hm-toast-stack .hm-toast{transition:none}` 也一直没命中过（祖先类不存在），修后按设计生效——
减动效档下提示不再跑入场过渡，但**仍然即时可见**（可见性由 `.show` 类切换，不靠过渡）。

## 四、判据

### 4.1 新回归用例（`node --test packages/base-render/test/help-toast-stack-693.test.mjs`，6/6 绿）

用例读的是**产出物本身**（`HELP_SHELL_SUFFIX`，即各技能 HELP 落盘文件里那段运行时），不是复制品；用最小 DOM 桩
把它跑起来，再拿它自带的 CSS 串去比对：

1. 栈元素必须匹配定位选择器——CSS 按类名下发，运行时就得给同一个类名（反向自证：只带 id 的同种元素必须不匹配；并锁 id 仍在）；
2. 定位规则本体仍锁在视口底部（`position:fixed`／底部锚点 `calc(24px + env(safe-area-inset-bottom,0))`／居中变换／`z-index > 600` 压得过固定底栏）；
3. 提示卡挂在栈下：多条提示共用一个栈，不许各挂 body；
4. 栈契约不变：桌面容量 5、窄视口（≤820px）3、单条寿命 4500ms；
5. 类名只有一条真相：注入样式那条规则的类名与运行时给栈元素的类名必须同源；
6. 警告态（「请先填写…」那条）与成功态落在同一个悬浮栈。

跑法：`node tooling/run-locked.mjs --ticket 693 -- node docs/base/base-render/t693-mut.mjs`（窗口内直调，不嵌套抢锁）。

```
MUTATION red: test exit=1 fail=3 失败用例行=7
RESTORE  green: test exit=0 pass=6 fail=0 模板逐字还原=true
RESULT: PASS mutate(gen=0,tsc=0,tallTop=0,tallBottom=0) restore(gen=0,tsc=0)
```
