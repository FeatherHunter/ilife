# base-render 公共组件契约（皮肤层 · 件形状 · 判据）

> 本文是**组件层的地基契约**：一件事只在这里写一遍。件怎么用住各自目录的 `README.md`；目录组织的规矩住 `src/components/README.md` 与 `src/components/index.ts` 的件头。
> 出处＝2026-09 的 60 件原型墙裁定（issue #950）：60 件 × 166 形态 × 3 皮肤 ＝ 498 格逐格打分，皮肤 paper 3.83／broadsheet 3.74／neutral 3.64。

## 一、四条不可破的地基

1. **颜色不许住在组件里。** 组件样式**只读皮肤 token 名，永不读值**。60 件 × 3 皮肤若各自写值，颜色迟早走散（铁律二）。
2. **宽度不许用视口判。** 窄宽两档一律**容器驱动**（`@container` ＋ 内在尺寸 ＋ `flex-wrap`）。媒体查询**只判设备能力**（`hover`／`pointer`／`prefers-reduced-motion`），不判宽度——这些页面会被嵌进侧栏、面板、卡片，视口宽 ≠ 组件宽。
3. **形态是骨架，不是地址。** 一件落地只带裁定的那**一个**形态；该形态要能被入参完整表达；形态闭集写在 `attrs.ts`。
4. **交互件必须有真运行时。** 走「冻结常量 ＋ `data-*` 标记 ＋ 事件委派产出 JS 文本」；DOM 只允许出现在产出的文本里。

## 二、皮肤层（`src/components/skin/`）

**皮肤 = 一份平的 CSS 自定义属性取值表**，仅此而已。凡是要改布局才成立的差异，**不算皮肤，属于形态**。

- 命名空间 `--ilife-*`；**名单住 `src/components/skin/contract.ts`（唯一事实）**，改名单要同步改所有皮肤取值表（判据会把两边对账）。
- 组件**只经 `skinVar(name)` 读**：它产出带兜底链的 `var()` 串（兜底到那 11 个冻结 token 或字面值）。**不许在组件里手写 `var(--ilife-…)`**——兜底链只许有一个出处。
- 皮肤以**类**挂载：`.<prefix>skin-paper`／`-broadsheet`／`-neutral`／`-ink`，由页面按需挂（**加法式**：不挂＝零命中、逐字节不变）。不写 `:root`、不写 `!important`、不新增冻结 token 名、不碰那 11 个旧 token。
- **四套**皮肤：`paper`（小票纸，**缺省**，暖白纸＋纸边＋方角＋零阴影＋等宽数字）／`broadsheet`（大字报刊，直角、零阴影、衬线读数、**墨黑强调**）／`neutral`（中性，**已重调**：弱文字压到对比地板、软底去蓝、线更像线）／`ink`（水墨·宣纸，宣纸米白底、暖灰墨字、发丝线、零投影、衬线数字、朱砂强调）。
  > 2026-09-24 另有两套（`terminal` 终端暗色／`blueprint` 蓝图工程）被用户整体否掉、**已删**；口径与理由见 `docs/base/base-render/选中态与皮肤语言.md`。

### 对比地板（判据会算，不靠眼看）

`ink`／`ink-2`／`ink-3`／`accent-text` 对 `ground` 与 `surface` 的 WCAG 对比度 **≥ 4.5:1**（大字 3:1）。`accent` 是**非文本**强调（条、边、底）与大字用；要当普通文字使，用 `accent-text`。

## 三、件的形状（一件一目录，目录内自足）

```
src/components/<件名>/
  index.ts      唯一出口（本件对外的名字面）
  attrs.ts      标记契约：类名／data-*／事件名／枚举闭集／入参类型（渲染与运行时共用这一份事实）
  model.ts      入参归一化与校验（把 any 与说不出的 unknown 挡在门外，产出内部类型）
  render.ts     渲染（纯函数产 HTML，按形态分派）
  style.ts      样式（本件唯一样式来源；只经 skinVar 读皮肤）
  runtime.ts    运行时段（只有交互件才有；产出 JS 文本，DOM 只出现在文本里）
  README.md     说明书（何时用／入参表／契约／不变量／常见错法）
```

四条结构标准：

- **件平铺，不按族套目录**：目录层级复现「谁和谁会一起改」。件与件互不相干 ⇒ 平铺；纸面与排版栈是整族一起改 ⇒ 进族汇总入口与 `shared/`。
- **族汇总入口**（形如「挂一族样式」的 `xxCss()`）立在族里**最先成立的那件**里，不另立族目录。
- **件与件只经对方 `index.ts` 互相引用**；`shared/` 只放跨族小件（转义／校验／排版栈），不放组件。
- **新增一件只在层出口加一行**（只加行、不重排），供并行席位各改各的目录。

## 四、件清单（机器派生，不靠记忆）

**每一件**的 id／中文名／族／入参面／形态闭集／皮肤覆盖／依赖，由包内脚本派生并带 `--check` 守（与仓里「共用位由派生器出、`gen:check` 守」同一条口径）。**人找件读它，不靠目录层级。**
（件数**不在本文里写死**：它随每一批落地变化——当前读数看 `packages/base-render/src/components/清单.ts` 的行数或包级 README 的「N 件路由」标题；写死过的数字一定会过期。）

## 五、判据（四类 ＋ 一条新缝）

每件必备四类断言：① 渲染契约（含转义与**全部**非法入参分支）；② 样式与零 DOM 纪律（样式段非空、scope 在 `.<prefix>page-ui` 之下、零 `:root`／`!important`、模块代码剥字面量后零 `document.`／`window.`／`navigator.`）；③ 加法式（不挂这件时同页产物逐字节不变）；④ 真机两档（390／1280 几何不变量与交互，headless Chrome ＋ CDP）。

**唯一新增的缝：皮肤矩阵判据**——吃机器派生的件清单，对每件跑「三套皮肤 × 390／1280」的渲染与溢出读数，并断言**同一个件在三套皮肤下的标记逐字节相同**（只许样式不同）。一条缝跑完全部件，不散成 N 个测试文件。

## 六、与冻结面的关系（红线）

- 组件层**不进**冻结签名面、**不从根出口**出；消费方走 `base-paint/blocks`。
- **不碰** `src/spec/**`、根出口、`package.json` 的 `exports`、那 11 个冻结 token 名。
- 六个技能包**零改动**；老页面逐字节不变。
