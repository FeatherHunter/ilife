## 六、收窗结论与遗留

**七件 ＋ C2 全部落地**（A1–A5／B1–B4／C1／C2），每件齐五样：入参类型、状态矩阵、a11y 语义
（`role=list`／`aria-current`／`aria-label`／图标 `aria-hidden`／`focus-visible`／44px 命中区）、
样式随公共层落盘、spec 闭集与签名表登记、单测覆盖。

**两处遗留（不是缺陷，是登记在册的下一手）**
1. **「还差 N」徽章底色偏淡**：`block-kpi-card-gap` 现在用 `var(--soft)`（浅蓝白），在纯白卡上观感接近纯文本
   （§八 实拍可见）。要更醒目得换 `warn` 档底色——那会与「状态徽章」的语义撞车，**留待视觉复评定夺**。
2. **两处未采用的墙稿细节**：A 组草案里的 `unit` 位（值位只吃成串，单位归调用方）与 B1 的
   「分段进度（stack）」（由 A4 等式条承担）——两处都在 §一 记了理由。

**两条他席在途红**（§五）与本批无关，但会让整包测试保持 `exit=1`；建议收口时按席位对齐一次。

## 八、真组件渲染总验收（不再手写标记）

跑法：`node packages/skill-calorie/.scratch/t950-kit-check.mjs`——该脚本**只调公共层产出器**
（`renderChipRow`／`renderSegmentedNav`／`renderDayStrip`／`renderEquationBar`／`renderStateBanner`／
`renderKpiCard`／`renderConclusionBar`／`renderFactStrip`／`charts.line` ＋ 三段样式），把产物拼成一页，
落 `packages/skill-calorie/.scratch/t950-kit-check.html`（81,363 字节）并截图（1200／390 两档）。

**实拍确认到的四件事**
1. 九件在两档下都渲染成设计的样子：胶囊行（含语气色）／分段导航（图标 ＋ 选中实底 ＋ 计数）／
   时间格带（缺数 `—`、今天高亮）／等式条（两段轨道 ＋ 端点读数 ＋ 合计）／态声明条（徽标 ＋ 动作位）／
   读数卡四态（**判定卡无值位**、`pending` 值位 `—` ＋ 条归零 ＋ 「未记录」）／结论条对象形态／
   事实条（单位 ＋ 缺数）。
2. **图表点数闸**：1 点 ＋ `minPoints: 2` ⇒ 出空态块（「本窗只有 1 天有记录，画不出趋势」＋带数字小字）；
   2 点 ⇒ 照画折线（含周均 markline）。**同一份调用里两态并存**，闸是逐调用的。
3. `pageUiCss()` 的三列网格与 880 列在这张真页面上按预期生效（正文收窄、读数卡排满）。
4. **实拍抓到并当场修掉一个真缺陷**：390 档下格带最后一格的「09-23 今天」被格带的 `overflow: hidden`
   （圆角需要它）**裁掉半截**——组件这一层原先没有窄档折行规则（墙稿里是用 CSS 隐去「今天」二字，
   而真组件的日期串由调用方给，隐不掉）。修法＝窄档给 `-date` 放开折行（`white-space: normal` ＋
   `text-align: center` ＋ `line-height: 1.25`），标签在自身格内换行、格子仍等宽等高；修后实拍复验通过
   （`pageBarsCss` 216→226 LF，判据 91/91 仍绿，kit-check 81,435 字节）。

**判据同源**：截图用的 HTML 与 §二 第 1–5 行的单测走**同一批产出器**（单测断字符串，实拍断观感），
两边的结论没有分歧。
