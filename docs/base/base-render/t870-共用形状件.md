## §1 件是什么

`renderCopyBlock({ hint })` —— 复制区那一排按钮**各自复制什么、拿去做什么**的那一行说明。

| 位 | 值 |
|---|---|
| 产出器 | `packages/base-render/src/blocks.ts` 的 `renderCopyBlock`（B-11 区块，既有件**加一个可选字段**） |
| 入口字段 | `CopyBlockInput.hint?: string` |
| 类名 | `ilife-block-copy-block-hint`（经 `blockPart('copyBlock', 'hint')`，与同区的 `-title` 同命名空间） |
| 落位 | 标题（`<h2>`，若有）之后、动作排（`<div class="ilife-action-bar">`）之前，**恰一行 `<p>`** |
| 样式落点 | `blocksCss()` 的 `pageShell` 区（与 `block-toc`／`block-caliber`／`block-conclusion`／`block-prose`／`block-op-head` 同一区） |
| 闭集 | `BLOCK_STYLE_SECTIONS` 仍 **12 项**（`copyBlock` 是既有第 11 项，本条只往它里面加子件规则，不新增区） |
| 控制样式区 | `CONTROL_STYLE_SECTIONS` 仍 **8 个**，一条不动 |
| token／色值 | **不新增**：只取冻结 `--fg2` |

### 排印取值（逐条给出处，不新造）

| 项 | 值 | 出处 |
|---|---|---|
| 字号 | `12px` | 同文件 `renderCaliberLine`（口径行）那一档；同时落在 `PAGE_LIMITS.textMinPx` ＝ 12（正文类下限）这条硬线上 |
| 色 | `var(--fg2)` | 口径行同一条（12px 小字压白底要过 AA；`--fg3` 只有 3.62:1） |
| 行高 | `1.5` | 口径行逐值同 |
| 下距 | `8px` | 与紧随其后的按钮排拉开一档 8px（4 的倍数，区块层既有节奏） |
| 折行 | `overflow-wrap: anywhere` | 事实条值／媒体注同一条兜底 |

**为什么不取 13px**：`block-chip`／`block-kpi-card-detail` 那条 13px 是**状态字**档（`pageUiCss` ⑨ 明写「状态类文字抬到 13px」）；本行是**旁注**，与口径行同族，取 12px。

### 三态（可选字段取「验值」这一种）

| 给什么 | 出什么 |
|---|---|
| 不给 | 一行不出（**缺省，既有调用方产物逐字节不变**） |
| 非空字符串 | 一行 `<p class="ilife-block-copy-block-hint">`（值经冻结五字符表 `esc`） |
| 空串／非字符串 | `bad-input`，消息点名 `input.hint`（**不做空串静默吞**） |

其余按 `actionId`／`data-t` 的既有口径：本条不碰激活通道（`bindCopyAction`／`buildSharedHelpersJs()` 一行未改）。

## §2 为什么要它（起因）

同一句说明行在**多个域**里各写一遍（备忘录七份模板里写成 `<dl class="hint" style="line-height:1.8">` 的两条 `dt`／`dd`，是**页内补丁**：色值 `var(--fg3)` 只有 3.62:1、字号与行高写死在行内 `style`）。

[#869](https://github.com/FeatherHunter/ilife/issues/869) 的六列机审现场把这笔债认了出来并在读数里单列：**⑤ 分隔符懒政的命中全是这一族**（同页 6 处，`<hint>` 版式位上的 `·`），且逐处标成「共用件债·复制区说明行（归 #870）」。

> 机审读数原文：`⑤ 6 处**全是「复制区说明行」共用件债**（已认出来并判到版式位那一格，归 #870）`。

搬到公共层之后：页面侧只传文本，排印只有一处定义、只有一处会改。

## §3 复用范围

**今天在用**：`packages/skill-memo-ilife` 的七份模板里那六份带复制区的（`change_category`／`wish_plan`／`wish_complete`／`memo_query`／`init_report`／`sync_report`／`receipt`），经 `src/render/memoPageAssets.ts` 接的公共层资产。

**还不用的（本票不动，另开票按同一件收）**：其余技能包里同形的复制区说明行（票面遗留出口已登记）。本件是**公共层件**，它们接过去即用——类名与样式都不必再定义一次。

**不接的理由不许是「先包内收一份更快」**：那是同一件事的第二处定义（违概念唯一），`t849-视觉基准.md` §7 的对抗审查表已把这条裁定为「不成立」。

## §4 真假例读数（公共层侧）

件级真假例在 `packages/base-render/test/blocks.test.mjs` 的 `#870` 一节（6 项，既有断言一条未改）：

| 例 | 断言 |
|---|---|
| 闭集 | `BLOCK_STYLE_SECTIONS.length === 12`，且 `copyBlockHint`／`copy-block-hint`／`copyHint` 都不在闭集里 |
| 不给 `hint` | 与给 `undefined` 同产物；产物里**不含** `ilife-block-copy-block-hint` |
| 给 `hint` | `<h2>` 之后、`<div class="ilife-action-bar">` 之前**恰一行** `<p class="ilife-block-copy-block-hint">`；`&<>"'` 按冻结表转义 |
| 空串／`null`／数字／对象 | 抛 `BlocksError`（`code='bad-input'`）且消息含 `input.hint` |
| 样式落点 | `blocksCss()` 含 `.ilife-block-copy-block-hint {`，规则体内 `font-size: 12px`／`line-height: 1.5`／`color: var(--fg2)`／无 `#` 字面量；用到的 `var(--*)` 逐个在 `CSS_VAR_TOKENS` 里 |

跑法：

```powershell

node tooling/run-locked.mjs --ticket 870 -- node --test packages/base-render/test/blocks.test.mjs
# → tests 70 / pass 70 / fail 0
```

## §5 同票另一件公共层改动：`pageUiCss()` ⑫（toast 关闭键的命中区）

**它是本票发现的，不是本票的目标**——但票面的行为腿（复制按钮真点一次 → 出 toast）一跑就把它照了出来：

| 项 | 改前 | 改后 |
|---|---|---|
| `.ilife-toast-close` 命中区 | `62×26`（**26px 高，压 `t849` §2 的 44px 硬线**） | 本体盒不变，`::after` 覆盖层 `44×44` |
| 做法 | — | 照本仓 `#642` 先例（HELP 外壳三个小关闭键）：绝对定位覆盖层撑命中区，**视觉尺寸一字不动** |
| 适用条件 | — | 规则挂 `.ilife-page-ui` 之下；helpers 注入的 toast 栈挂在 `document.body`（不在版面根之内）⇒ 启用 pageUi 的整页装配要**在 `document.body` 带上那一颗标记**（本配方本来就是 opt-in 开关） |

备忘录侧由 `memoRuntimeJs()` 读「版面根带不带那一颗类」，带了才把标记补到 `body` 上——**两处判据独立、各管一层**：根类管页内，标记管 helpers 注入的那些。
