## 5 教训（Lead 裁决点名记入）

**新增公共件的第一条判据是「既有调用方零回归」，不是「新形状照判地」。** 本件第一版把 `ticket-section.tag` 写成必填非空，而既有 13＋3 页传的正是 `tag: ''` ⇒ 全窗渲染中断（`ERR 4: 未知失败：ticket-section.tag 必须是非空字符串`），全量测试从 456 绿掉到 265 绿。
修法：`tag`／`title`／`content` 三格收 `''`／`undefined` ⇒ 空串照渲染（空 tag 照旧出空的 `.no` 槽，字节与落地前逐字相同）；`sheet-head` 的 `brand`／`titleHtml`／`sub` 同类放宽。**新件落地前先跑既有承接页的真跑读数**，再谈新形状。
