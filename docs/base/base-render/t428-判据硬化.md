## 3. 同值读数（sha256）与变异方法

- 原字节：`sha256(packages/base-render/src/blocks.ts) = sha256(.scratch/t428/mirror-live/base.ts)
  = dba73fb9fd75c11e3f9dea571e994a08631ceb6f61047323eb596779a48f1fb1`（变异前，64 位十六进）。
- 七条读数每条收尾都是 `RESTORE … 源件同值=true 产物同值=true`，镜像产物摘要回到
  `e7a463441364fe97…`（＝变异前同值）；收尾 `WINDOW-CLOSE 共享源码未动=true dist未动=true 镜像已复原=true`。
- 方法（为什么不直接改共享源码）：`packages/base-render/src/blocks.ts` 当刻有别席在途改动
  （#431 等），改它再写回有覆盖别人写入的风险，故变异做在**字节同源副本**上——
  `.scratch/t428/mirror-live/base.ts`（与共享源码逐字节同值）＋ 剥类型、相对导入改指当刻 `dist/`
  得到的可执行镜像 `blocks.mjs`；判据件只改两处导入（改指镜像产物、源码自读勾子改指跑副本自身），
  断言正文逐字不动。**还原一律写回窗口开始时另存的原字节**，未用 `git checkout --`／未从任何提交取回。
- 副本不是抄本：窗口内按当刻源码重编本包作用域后 `ARTIFACT-PARITY 真产物同值 css_equal=true
  shell_equal=true`（镜像的 `blocksCss()`／`renderPageShell()` 与真产物 `packages/base-render/dist/blocks.js`
  逐字同值，`dist` 摘要 `be8f18068ebd821d…` 窗口前后同值）⇒ 副本上的注入＝真源码上的注入。
