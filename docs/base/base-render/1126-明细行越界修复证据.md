# #1126 查询域明细行文本超出容器右侧 · 修复证据

**票**：#1126（task-37）　**执行**：wall-query　**判地**：`docs/skills/skill-bill/proto/query/w03-查某天-v2.1.html`（同位置不裁）

## 一、根因（读数在票面，本席复现一致）

`390×844` 无头 Chrome 探针（`.scratch/lead-verify/overflow-probe.mjs`）对改前产物 `w03-真跑.html`：
`ol.ilife-ticket-entries` **sw=371／cw=298（超 73px）**，`li` 同值，`div.ilife-ticket-card` 384/324（超 60），`section.ilife-ticket-sec` 385/326（超 59）；页级 `docSW==docCW==390` ⇒ **不是页面横向滚动，是容器内文本被右缘裁掉**。
越界文本逐字：`备注 · 五月水电居家/水电 · 招行卡 · 2026-05-15 11:00:`。

**根因**：`.ilife-ticket-entries > li` 是 flex 容器，文本子项 `flex: 1 1 auto` 但**缺 `min-width: 0`** ⇒ flex 子项退回 `min-width:auto`（内容最小宽度）⇒ 长文本不收缩，把 `li`／`ol`／卡片一路撑出容器右缘。

## 二、改法（**照判地同位置**，未自创）

判地同位置那份写法（`proto/query/w03-查某天-v2.1.html` 内联 CSS，逐字）：

```css
.entry-text{flex:1 1 auto;min-width:0;overflow-wrap:anywhere}
.entry-rows .entry-text{min-width:0;flex:1 1 auto}
```

产物的 `.ilife-ticket-entry-text` 只差 **`min-width: 0`** 这一条。改动一处（`packages/base-render/src/components/style/ticket-family.ts:97`）：

```diff
- .ilife-ticket-entry-text { flex: 1 1 auto; overflow-wrap: anywhere; word-break: break-all; }
+ .ilife-ticket-entry-text { flex: 1 1 auto; min-width: 0; overflow-wrap: anywhere; word-break: break-all; }
```
