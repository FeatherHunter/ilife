## 二、机器判据（口径与 `.scratch/sep-audit/probe.mjs:8-32` 同源，逐字搬）

可见文本＝源文件里剥掉 ① `<style>…</style>`、`<script>…</script>` 整段 ② `<!-- … -->` 注释 ③ 全部 `<…>` 标签（属性因此天然不进可见文本；必须全串级剥，因为产物里有跨行属性值）④ 解 HTML 实体。去除一律用字符替换为等长哨兵、换行原样保留，故行号与读工具一致（1 起）。

三级读数：行级（源文件一行的全部可见文本拼起来判；产物被压行时会低估）／节点级（单个文本节点判，附归属元素 `class`，可直接对到区块件上；门禁以节点级为准）／段落级（节点级按分隔符切成并列段后判，只用来量并列了几段）。

命中规则（三条互相独立，同一处可同时命中）：R1 含 `·`（U+00B7）／R2 含 `；`（U+FF1B）／R3 ≥3 段并列（以同一个并列分隔符切开后，连续 ≥3 个非空片段、且每段 ≤40 字）。并列分隔符集＝`· ； ; ｜ | ／ / 、 ＋`；`，。：~ → ＝` 不算并列分隔符（免得把散文误判）。探针口径不放宽：要动口径先请用户裁定。
