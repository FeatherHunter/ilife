## 1 形状口径

新增页面级件 `renderProseBlock(input)`，与 `renderTocBlock`／`renderCaliberLine`／`renderConclusionBar` 同族：类名 `ilife-block-prose`（`pageLevelBlock('prose')`），样式随 `pageShell` 区落盘，**不进** `BLOCK_STYLE_SECTIONS`（12 项闭集，`test/blocks.test.mjs` 钉死，一项不动），**不新增** token／色值／字号。

入参 `ProseBlockInput`：`{ text }` 纯文本（五字符转义与区块层同源 `esc`）与受信位 `{ html }`（调用方已自行转义，与 `renderDisclosure.contentHtml` 同口径）**两位互斥**，同给即 `bad-input`。`html` 须是短语内容（行内标记如加粗／链接；多段调多次），不得含块级标记。

空值与错值口径（与区块层其余件同）：`{ text: '' }`／`{ html: '' }` 返回空串（没内容不留空块）；缺参／`null`／非字符串／两位同给／两位全缺 → 抛 `BlocksError`（`code: 'bad-input'`，消息点名 `input.text`／`input.html`）。

产出：`text` 版为 `<p class="ilife-block-prose">转义后文本</p>`；`html` 版为 `<div class="ilife-block-prose">原文透传</div>`（同一条类选择器，两版同一样式；`html` 版用 `div` 是为块级误入时不碎嵌套）。

## 2 排印取值出处（逐条）

| 声明 | 取值 | 出处 |
|---|---|---|
| `font-size: 15px` | 与正文同档 | `t768` 原型 `.v768-prose`（`docs/skills/skill-chef/t768-原型.mjs:250`），也是页面正文字号 |
| `line-height: 1.7` | 与正文同档 | 同上（原型 `:250`） |
| `color: var(--fg)` | 只取冻结 token | 同上（原型 `:250`）；`CSS_VAR_TOKENS` 11 个冻结名之一，无字面量 |
| `margin: 8px 0 0` | 区块层既有节奏 | 原型 `:250` 原值；8px 档与口径行下距／段标题下距同值，不新造 |
| `overflow-wrap: anywhere` | 既有换行兜底 | 事实条值／媒体注同口径，防长串溢出；纯文本不受影响 |

## 3 真例读数（dist 实跑）

- `renderProseBlock({ text: '先把辣椒切丝 <b>&' })` → `<p class="ilife-block-prose">先把辣椒切丝 &lt;b&gt;&amp;</p>`
- `renderProseBlock({ html: 'Roux <strong>roux</strong>' })` → `<div class="ilife-block-prose">Roux <strong>roux</strong></div>`
- `renderProseBlock({ text: '' })` → `""`（空串，不抛）
- CSS（`blocksCss()` 内）：`.ilife-block-prose { margin: 8px 0 0; color: var(--fg); font-size: 15px; line-height: 1.7; overflow-wrap: anywhere; }`

## 4 假例读数（必跑两条）

- 把本条规则改成字面量（`color: #333`／`font-size: 14px`）→ 新增用例三处变红并点名：`字号须 15px`、`色值只许冻结 token --fg`、`色值字面量（如 #333）不得进本条规则`（实测 `MUT-RED: true`）。
- `{ text: '' }` 出空串且不抛；`null`／数字／两位同给／两位全缺 → 抛 `bad-input` 且消息含 `input.text`／`input.html`（逐条见 `test/blocks.test.mjs` `#860` 一节）。
