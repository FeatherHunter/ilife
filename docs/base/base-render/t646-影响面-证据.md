## 一、结论先行

- 根因在公共层：`packages/base-render/src/blocks.ts:1524-1538`，分布行首栏 `minmax(0, 6em)`（`font-size:13px` 下＝78px）＋ `overflow:hidden` ＋ `white-space:nowrap` ＋ `text-overflow:ellipsis`。
- 实测：78px 槽装 131px 文本「蛋白（推荐 10–20%）」，390/512/820/1440 四档全中，每页 3 处（`docs/skills/skill-calorie/t605-证据.md:65`，`t605-视觉复评.md:21` D1 表）。
- 元素级读数：83 产物页四档合计 `clippedCount` 108 格落在 `ilife-block-dist-row-name`（`t619-复验.md:52,54`），`t630-证据.md:28` 确认 `clip=3` 均为本件。
- 调用面：源码层只有 `skill-calorie` 在用 `renderDistributionRows`（`packages/` 全仓 grep，其余技能 `src` 零命中）。`skill-bill` 等产物 HTML 里出现的 `.ilife-block-dist-row-name` 只是共享样式段 bundle，无实际 `<div class="ilife-block-dist-row">` 调用。
- 已有先例：运动族页级覆盖 `9.5em` ＋ `overflow:visible` ＋ `white-space:normal` ＋ `overflow-wrap:anywhere`（`packages/skill-calorie/src/exercise/sportUi.ts:101-102`），窄屏再塌成两段式（`:149-152`）。该覆盖只盖住运动族，营养族 10 页仍走基线 6em，故 D1 只爆在营养族。
