## 1 实现（默认档零回归 ＋ 折叠档照判地）

| 落点 | 改什么 |
|---|---|
| `lookup-index/render.ts` | **追加**形态闭集 `LOOKUP_INDEX_FORMS = ['flat','fold']`；入参加可选 `form`（缺省 `flat`，闭集外报 `BlocksError`）；槽位闭集**追加** `count`／`rows` 两格（既有八格与顺序一字不动）；`fold` 分支产 `<details class="…-group is-fold" id=… data-lookup-group=…><summary class="…-head">组名<span class="…-count">N 行</span></summary><ul class="…-rows">…</ul></details>`，根上挂 `is-fold` |
| `lookup-index/style.ts` | **追加**折叠档那一组规则（判地逐条，见 §0）；颜色／圆角能读皮肤号的一律 `skinVar()`，判地字面（`#fbf7ec`／`#fff`／`#eee6d2`／`#f0d7c2`）逐处带「判地字面 · 授权照抄」 |
| `lookup-index/runtime.ts` | 锚点点击时补一句 `if (hit.tagName === "DETAILS") hit.open = true;`（判地同句）；常显档没有 DETAILS ⇒ 零命中 |
| `help/lookupPage.ts` | `renderLookupIndex({ ...index, form: 'fold' })`；段内容前置一行 `fold-note`（条数由组数派生）；样式标签里**显式拼** `lookupIndexCss()`（该件样式段不在 `blocksCss()` 区块汇总里，与 entry-card 同一条口径） |

**三处踩出来才对的细节**（都写在源码注释里）：
1. 折叠档根要 `display:block`：常显档根是 `display:grid; gap:12px`，而判地是普通块流（组间只靠 `margin-top:14px`）——不改成块流，7 个组间缝各多 12px（实测页高多 96px）。
2. 组头与计数胶囊要 `line-height:normal`：本件根上写着 `line-height:1.7`，判地那两格吃的是页面 normal ⇒ 不钉组头高 49.5（判地 48）、胶囊把组头顶高 4.4px。
3. `lookupIndexCss()` 必须由页面显式拼：`blocksCss()` 不含它（只含 12 个区块汇总），不拼则折叠档只有标记没有形状（实测页高 1358、差异比 0.3134）。

## 4 折叠后仍非 0 的差额（逐块解释）

1. **自律条（3707 px，带内 11.9%）**：判地 `.check-mini` 是「绿点 ＋ 12.8px 字 ＋ `#f4fbf6` 底／`#cfe6d6` 边／`#3e5a4a` 字」，产品的 `-note` 槽由本页 H02_CSS 摆成「无绿点 ＋ 12px ＋ `ok-soft` 底」（差 −2.56px 高、整块字面与那颗点）。**页面侧形状，不是折叠件的事**；本票只报不改。
2. **按钮区（19006 px，带内 26.3%）**：票据家具（复制区两钮 ＋ 菜单 ＋ 裁切线），比判地高 **+12.59px**；#1114 已把次按钮与菜单形对齐到判地（45→46.3），余量是**字面（判地 `.btn` 落 UA 默认 Arial）＋ 复制区摆法**——不在本票写集。
3. **八组本体只剩 0.0146**：计数胶囊与箭头的 AA ＋ 胶囊字面；判地那颗 `.cnt` 用 `--ink2`、箭头用 `--accent`，产品读的是同两号皮肤 token ⇒ 差异是亚像素级。
4. **页高 1268 vs 1258**：由上面第 1／2 条两处相加，无第三处（见 §2 的逐角色账）。
