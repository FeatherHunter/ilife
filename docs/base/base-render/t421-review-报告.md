## 三、缺陷清单

1. **本票范围·S2｜判据字面读法不可满足**：票面同写「色值皆可」与「产物不出现任何色值字面量」。P1.c／P1.d 实测：给 `#ff0000`／`rgb(1,2,3)` 时四件产物里各出 2 条字面量（迷你条与分布条行各 1）；实施席只取缺省样例，断言名「四件产物零色值字面量」易读成普适成立。转票：判据改为「产物里的色值只可能来自入参（缺省调用零字面量）」，并补「入参色值逐字透传」一条。
2. **本票引入·S2｜视觉层有兜底色**：不给 `color` 时填充由样式段 `background: var(--blue)` 决定（P1.f），「颜色只从入参来」在视觉层不成立；票面判据的机器口径未被违反（`var()` 非字面量），证据件 §1.2 已如实披露。转票：判据改写为「区块自身不写死色值字面量，缺省色走冻结 token」，或去掉兜底色。
3. **本票范围·S2｜样式判据无鉴别力**：对 `blocksCss` 的唯一断言是选择器包含（1 条谓词），变异 ③ 与 P2.3 合成退化都全绿 ⇒ 宽高／栏宽／缺省色／对比度取值无一被锚住。转票：每类补「规则体至少 N 条声明＋关键属性快照」。
4. **本票范围·S3｜a11y 无判据**：变异 ④ 删 `role="img"`／`aria-label` 仍 22/22。
5. **本票范围·S3｜空态口径未写死**：`undefined` 走 `bad-input`（P2.2），证据件只声明 `[]`。转票：注明「空＝`[]`」。
6. **本票引入·S3｜色值透传无格式约束**：`optColor` 收任意非空串并逐字进内联 `background`（`;` 可穿进声明列表；`&<>"'` 已转义，属性无法逃逸）。转票：色值允许清单，或契约写明「调用方保证色值合法」。
7. **范围外发现·S3**：`blocksCss()` 全表另有 7 处色值字面量命中（`rgba(`×4、`#b25000`、`#c0392b`；`#104` 是注释里的票号误命中），**均可追到 #104 起的既有规则，本票 7=7 未新增**。转票：若要立「样式资产零色值字面量」全表判据，另开票处理既有 `DEV_BG`／`DEV_FG` 与 `rgba()` 派生线色。
