## 四、与规格纸样的两处偏差（已按判据裁，可一句话反转）

规格 §一 的入参纸样是「4 字段（`docTitle`／`bodyHtml`／`extraCss`／`charts?`）、零可选开关」。把两侧骨架**逐字节摊开**后（探针：两侧 `dist` 骨架件逐个入参打印文档头），有两处骨架**必须**知道、纸样装不下：

1. **`pageUi`**（卡路里 11 字段之一）：它改 `viewport` 串与版面根类，两处都在骨架里；票面明写「卡路里**保留全部 11 个字段**」，40+ 个调用点在传 `pageUi: true` ⇒ 骨架件不吃这一位就没法「保留全部字段」。**这一位是票面自己推出来的**。
2. **`doctypeCase`**（`'lower'` 缺省／`'upper'`）：两侧现状写法逐字不同（一侧 `<!doctype html>`、一侧 `<!DOCTYPE html>`），而两侧都被自家断言钉死（卡路里 ~40 条「第 0 字节」硬断言；账单 3 条），两侧也都真跑在真出口上。

**本票的裁法（按判据本身）**：判据 1 是「两侧产物 sha256 不变」，判据 3 要求骨架件持有 doctype，铁律二要求常量的定义地唯一 —— 三条同时成立只有一种解法：**两种写法都住骨架件（一张 `DOCTYPE_HTML5` 表），调用方只给名字、不给字面量**。于是两侧字节全不变、判据 1 全绿，而「统一写法」这件事**没被顺手做掉**（它要动产物，是另一件事；真要做，就是一句 `doctypeCase` 的反转 ＋ 账单 32 张页的指纹账重录 ＋ 3 条账单断言改成大小写不敏感）。**反转成本＝一次 `--write --declare-layout-change` ＋ 3 行断言**。
