## 四、与规格纸样的偏差（要维护者裁）

规格 §一 的入参纸样是「4 字段（`docTitle`／`bodyHtml`／`extraCss`／`charts?`）、零可选开关」。实测把两侧骨架**逐字节摊开**后，还有一处是骨架**必须**知道的（探针：`.scratch/t725/probe-shell.mjs`，直读两侧 `dist` 骨架件打印文档头）：

- **`pageUi`**：卡路里 11 字段之一，它改的两处在骨架里 —— `viewport` 串多 `,viewport-fit=cover`、版面根多 `ilife-page-ui`。票面明写「卡路里**保留全部 11 个字段**」，40+ 个调用点在传 `pageUi: true` ⇒ 骨架件不吃这一位就落不了「保留全部字段」。故本票给骨架件加了一位 `pageUi?: boolean`（取值只认真真值）。
- **doctype 大小写**：卡路里 `<!doctype html>`（小写）／账单 `<!DOCTYPE html>`（大写），两侧各自被断言钉死（卡路里 ~40 条「第 0 字节」硬断言；账单 3 条）。这一处**待裁**：给骨架件加一个写法名位（两侧字节全不变），或统一成小写（账单 32 张页各变 9 个字符大小写 ＋ 指纹账重录 ＋ 3 条断言改）。**账单侧未动，正是等这一句。**
