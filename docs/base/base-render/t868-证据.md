## 3 反例四条（逐条必跑）

### 反例① 权重改一位（d3 25→24）

把引擎源码抄成变异件（`replace('d3: 25', 'd3: 24')`，只改脚本腿的权重表，字面腿不动），
临时放同目录（相对导入仍指 `dist/pageUi.js`），跑完即删：

```
exit=1
RECONCILE 逐页逐维（含硬扣分与总分）最大绝对差 = 1 ⇒ **不一致**（比对 21 项；最坏 d3@甲-01-记录一览 脚本 24 ／ 字面 25）
页分 每维≥80%：甲-01-记录一览=99 ／ 甲-02-待办清单=36（有维不达线） ／ 甲-03-月度小结=89；过线页（≥90 且每维≥80%）= 1/3
stderr=（空）

```

一致性自证红、`exit 1`，并点名最坏那一处（`d3@甲-01-记录一览`，脚本 24 ／ 字面 25）。
同一件事在 `自检.mjs` 里是自动跑的一条（见 §6）。

### 反例② 配置里写一个数字（必红并点名「配置只许路径与名单」）

```
顶层一处：exit=1
  判分中止（退出码 1）：配置只许路径与名单：…\反例2-顶层一处.json 出现多给的字段 d3（只许 packagePath／readingsDir／instances）
名单里一处：exit=1
  判分中止（退出码 1）：配置只许路径与名单：反例2-名单里一处.json.instances[0].file 给了数字 123 —— 数字进配置就是第二处定义
```

两种写法都红：第四个字段（顶层 `d3: 25`）走字段校验，数字值（`{"file": 123}`）走递归数字扫描。
数字一旦进配置，同一读数目录就有了第二处定义 —— 这正是「两域分差 0」要挡住的东西。

### 反例③ 实例名单指错（点名一件不存在的产物）

名单写 `["甲-01-记录一览.html", "不存在-99.html"]`：

```

```

报缺件并点名那件产物，`exit 1`；没有静默取 0 分（引擎对缺页一律报红，不照满权算）。

### 反例④ facts.json 挪走（报缺件点名，不许崩栈）

把夹具抄一份到 `.scratch/t868/反例4-缺事实列/` 并删掉 `facts.json`（现场目录只剩 `fmt.json,resp.json,sep.json`）：
