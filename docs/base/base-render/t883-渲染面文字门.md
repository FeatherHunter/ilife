## §一 一句话

同一套 ⑤⑥ 规则跑两个面：静态面（与 t869 同语义）与渲染面（真浏览器跑完页内脚本后的 DOM＋伪元素 content），逐页差表，差项逐条点名，0／1／2。只对差项判红（静态既有债归原门）。

## §二 口径（与静态面逐字对齐，只补面不扩语义）

- ⑤ 分隔符懒政：`[·|｜]` 落版式位／正文位即红；标题写法位照打；数据位／载荷位豁免。出处 t869 SEP_CHARS 与位置四分。
- ⑥ 英文裸词与半角标点：ALLOW 四条（日期／时间／`#N`／AI）＋ASCII＋HALF 半角集（含小数豁免）。出处 t869。
- 位置名册初值取 t869（备忘录域重写）；渲染面新增装饰位 `status-icon`（放过但照打，理由在位上）。出处 #878 评论＋Q2 裁定。
- 渲染取串：隐藏子树剪除（`display:none`／`visibility`／`hidden`，单遍可见性表）、伪元素 `::before`／`::after` 的 content（`attr()` 就地解析、`\B7 ` 形转义解码、无类名宿主向上找 6 步）。
- 静态取串：样式脚本 → `data-t` 载荷 → 注释剥离后分段，归属＝包住该偏移的最内带 class 元素（标签栈纪律； naive"最近开标签"会在已闭合元素上串位，已修，见 §五）。
- CDP 驱动与 `check-two-col-align.mjs` 同形（第二处用法；第三处出现即抽 `scripts/cdp-page.mjs`）。
