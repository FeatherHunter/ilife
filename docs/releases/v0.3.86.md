# v0.3.86

七个插件整体换版到 **0.3.86**：页头操作组换成 base 0.1.5 的「快捷操作」簇，联系入口收敛为页头三个彩色图标。

## 这一版改了什么

- **页头三个彩色图标按钮**（内嵌 base 0.1.5 的 ActionCluster）：无托盘、间距 4，三个按钮各自独立（不是一枚胶囊切三段）。
  - 联系我们：蓝→紫渐变对话气泡（两个白点对话）
  - Star 这个项目：金色渐变五角星 + 内层高光 + 四颗小星光
  - 提交 Issue：珊瑚粉渐变反馈气泡 + 白色感叹号
- **悬浮交互**：共用 HoverTip 显示原三句文案（160ms 延迟、同屏一枚）；悬浮时按钮出彩色柔光 + 轻动效（对话气泡轻浮、Star 星光闪、Issue 轻晃），尊重 `prefers-reduced-motion`。
- **五态完整**：默认／悬浮／按下（无灰底，改为缩小 + 柔光）／键盘焦点环／禁用（去饱和 + 降低不透明度）。
- **作者的其他插件**：每行鼠标悬浮显示该插件的完整介绍词（描述行被省略号截断时也能读全）。
- **联系弹窗**：二维码水平居中（修 box-sizing 引起的右侧溢出）；有效期最后一天不再显示「0 天内」，改「今天（M 月 D 日前）有效」；微信二维码改为随包内置，断网也有码。
- **内嵌更新包**：`dsh-plugin-update` 升到 `^0.18.39`（#1282 下限门：latest tag 下旧版会被锁冻住），内联产物同步重建。
- **入口收敛**：面板底部原来的整行联系入口已移除，只保留页头三个图标（按维护者 2026-11-01 拍板）。
