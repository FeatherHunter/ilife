#993 · 改记录复制 prompt 出去

点改记录 = 复制一段 prompt，你只说改动项

流程三步：点 → 粘给 AI → 说“账户改成支付宝”，剩下的 AI 填。

为什么这样最快

  • prompt 里自带 编号 + 现状快照，AI 不用再查一遍详情，省一轮。
  • 你只说差量（改哪一项改成什么），不动的不用说，命令里只传改动项。
  • 命令模板直接可跑，AI 补上你的差量就执行，回来一张新回执。

7222 的 prompt 长这样

改记录（7222：餐饮／咖啡奶茶 -40.80 元）
当前：账户建设银行储蓄卡(0709)，账本生活，时间 2026-10-01 15:30:00
你要改：（只说改动项，如“账户改成支付宝”）
bill-cmd-read bill.record.update --params '{"id":7222,"account":"支付宝"}'
口径：只传改动项，不动的不传；金额符号即方向
通用模板：把 7222 和现状五项换成当条记录即可，字段名固定 category / amount / account / ledger / time / note。
